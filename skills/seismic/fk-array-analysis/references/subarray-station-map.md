# 子阵台站信息 + 分布图（新增子阵 / 新事件的第一步）

适用：在已建好的台阵案里**加一个新子阵**（如 Zhou2021 的 G1 southern → G2 northern），或给新事件起头。
产物与既有子阵同款目录：

```
<子阵>/01_data/01_station_info/
├── <G>_stations.csv             台站表（经纬度、平面偏移、震中距、真实大圆 BAZ、式(1) 到时、SNR）
├── <G>_summary.txt              几何摘要（质心 / d_min / d_max / 无混叠常数 / 逐台到时）
├── fig_<G>_station_map.png      ★ 分布图正式版（双面板 PyGMT）
├── step1_<G>_map_and_table.py   台账脚本（不画图）
└── plot_<G>_station_map.py      分布图脚本（参数全在顶部 ★参数区）
```

## 步骤

1. **先找"上一版是怎么做的"，不要凭印象重画。**
   `grep -rl "station_map\|fk_schematic" --include="*.py" <case根>` 找生成脚本。
   ⚠️ 已定稿图的脚本**可能已被移进 `_superseded/<日期>_精简/`，而该子阵 README 里仍写着原路径**。
   以 README 里「保留文件表」（图 ↔ 脚本对照表）为准；脚本本体在 `_superseded/` 里也能直接抄来改。
2. 两个脚本复制到新子阵目录，只改顶部 ★参数区：
   - `step1_*.py`：`STAS`、`SUBNET` 文案。读 `stations.csv` 一律 `csv.DictReader` 按列名（禁固定索引）。
   - `plot_*.py`：台站名单、`OUT_NAME`、右图 `REG_R`、左图文字框 `TXT2`、`ARR_STOP_STATION="auto"`。
3. 全案共用同一份 `stations.csv`（本 case 在 `process_flow/1_station_distribution/`，15 列）。
4. 跑法：`/home/sy/miniforge3/envs/obspy/bin/python <脚本>`；**出图后核对 mtime 与大小**（/mnt/e 被 Windows 占用会静默失败）。

## 右图放大框 REG_R 怎么定

- 取子阵 lon/lat 极值，四边各留 1.3–1.6°。`M9.4c` 下 6.2°×5.0° → 图高约 8.4 cm，与左图
  （`M9.8c` + `[12,50,-46,-15]` → 高约 9.3 cm，两图底边对齐）拼在一起，**整张画布尺寸应与既有子阵那张完全相同**
  （同一 case 实测 5123×2382 px @600 dpi = 8.54×3.97 in）。画布尺寸相同 = "与模板同款"的最省事核对，不必看图。
- 左图 region 保持与既有子阵同幅，两子阵才能并排对照；不要为了图高好看去动它。

## 两个几何口径必须都报（最容易对不上的地方）

- ① 相对质心的等距圆柱平面偏移 `x=(lon−lon0)·111.195·cos(lat0)` → 台账摘要用它；
- ② 大圆真值（geographiclib `Inverse`）→ 子阵调查日志与 F-K 参数表用它。
  同一子阵两者差约 1 km（G2：平面 94.61 km vs 大圆 95.59 km）。**摘要里并列写两个值并注明口径**，
  否则与 `log_subarray_plan_survey.txt` 的 d_min/d_max 对不上，用户会当场质疑。
- 无混叠常数 `111.195/(2·d_min)` 用**大圆口径** d_min（与 F-K 日志一致）。
- BAZ 一律 `gps2dist_azimuth(sta, ev)[1]`（台站端真值）；`stations.csv` 的 `baz` 列应与之一致（不一致＝重复了历史 bug）。
- **交叉核对 `.m` 里写死的参考值 `BAZREF`**：应为逐台真实 BAZ 均值取整。G1 的 137.3 ≈ 均值 137.26（对）；
  另一个子阵出现 143.0 vs 均值 144.21（差 1.2°，会让导出的 |ΔBAZ| 列整体偏移）。
  每次新子阵都拿台账均值核一遍，**发现不符先报给用户、不要自行改**。

## 内容边界（别多画）

- 左图：灰白大陆 + 全台网灰三角（背景）+ 子阵红三角 + GCMT 沙滩球 + 震中→子阵质心**真实大圆**虚线
  + −1000 m 等深线 + 左下文字框（事件 + "<G> (N stations, red)  background: XX array"）。
- 右图：子阵放大 + 台站名（三角正下方，`STA_LABEL_DLAT=-0.155°`）+ 同一条大圆靠近质心的一段虚线。
  末尾箭头已按要求删除，不恢复。
- **不带任何实测波形/包络/到时标注**：这张图只表达"台阵几何 + 震源机制 + 传播方向"；要标到时是另一张图的事。
- `pygmt.meca` 的 `spec` 必须是 `numpy` 数组，传 `list` 会**静默不画**。

## 出图自检：把"看图"换成"算数"（写进脚本末尾打印）

用户不接受自我视觉检查 → 用数字判断替代：

1. **等深线**：`load_earth_relief` 后数跨 −1000 m 的网格边数；子阵放大框全在陆上时为 0
   → 打印"画不出线 ✗"是**正常**（G1/G2 都如此），不是 bug。
2. **右图虚线可见性**：沿大圆采样，数落在 `REG_R` 内的点数（太少 = 参数要调）。
3. **标签越界 + 两两重叠**：标签框按字号换算成面板 cm（`em = pt×0.03528`；M 投影 `cm/km = 9.4/(Δlon_deg·111.195·cos(lat_mid))`），
   做全部两两矩形相交检查并报最近一对的中心距。这一步能在不看图的前提下确认台站名无重叠。
4. **产物 mtime/大小**核对（共享盘写盘陷阱）。

## 来向虚线停点：自动选台

右图那段虚线终点 = 「离大圆垂距最小的台」沿大圆回退 80 km。写成 `ARR_STOP_STATION="auto"`，
不要写死台名（子阵一换台名就错）。打印各台垂距排序即可说明选择（实测两站可能几乎并列，画面差 <1°，任选皆可）。
