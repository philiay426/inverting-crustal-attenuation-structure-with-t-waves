# 波束的方向性：±u 到底对不对称 —— 由**估计量定义**决定，不是普适定理

流行说法「F-K 功率谱对 ±u 镜像对称、方位不可读」**只对某一类估计量成立**，套到别的估计量上会得出
错误结论（本项目踩过：据它把图上对面那团解释成「镜像孪生」，被用户当场追问「孪生？哪来的理论？」，
验算后发现不成立）。报数前先看清这张表。

⚠️ **「孪生 / mirror twin」这个词本身没有文献出处，是本项目早期自加的说法（2026-09-23 用户再次追问后确认）**：
文献里能查到的方位模糊是另一件事 —— ① **线性台阵关于台阵线的镜像**（Rost & Thomas 2002：
“linear arrays … the slowness resolution is very good, but the back azimuth resolution will be restricted”）；
② NMSOP-2 Ch.9 §9.7 的 array transfer function（孔径定分辨率、台间距定旁瓣与最大可解波数、几何定方位依赖；
`Schweitzer et al. 2012, doi:10.2312/GFZ.NMSOP-2_ch9`）。**不存在“单分量/任意台阵必然 ±180° 孪生”的普适定理**。
表述一律改成“与其**镜像点**（同 |u|、方位 +180°）的电平差”，并同时报 |u|、方位差、电平差三个数。

## 0. 一条代数式定生死

记台对互谱 `C_ij = X_i·conj(X_j)`、转向因子 `w_ij(u) = exp(+i2πf·u·Δr_ij)`（`Δr_ij = r_i − r_j`）。

```
只用互谱**实部**（协谱 co-spectrum）      ⇒ B(u) = B(−u)  严格成立（180° 模糊的来源）
保留互谱**虚部**（正交谱 quadrature，即台间时延方向） ⇒ B(u) ≠ B(−u)，方向唯一
差项 ∝ Im(C_ij)·Im(w_ij) ∝ sin(2πf·u·Δr) ⇒ 随 f·|u|·Δr 增大而破缺
```

⇒ **对称 / 不对称是估计量的性质**：谁把时延符号丢掉，谁就对称。判一个引擎属于哪类，看它的源码怎么处理 `C_ij`。

## 1. 本引擎（Seizmo fkvolume）属于"有方向"那一类

`seizmo/fk/fkvolume.m` 第 377–417 行（逐行）：

```matlab
cs = data(fidx,:).';  cs = cs./abs(cs);                  % 白化（每道谱按幅度归一）
case 'coarray':  cs = cs(row,:).*conj(cs(col,:));        % 唯一台对 i<j（triu(nrecs,1)）
case 'full'   :  cs = cs(row,:).*conj(cs(col,:));        % 全部有序台对
beam(:,:,b) = reshape(exp(f(fidx(b))*p)*cs(:,b), spts, bazpts);   % Σ_pairs C_ij·exp(i·2πf·p_ij(u))
case {'full','coarray'}: beam = 10*log10(abs(real(beam)));        % ★ 求和**之后**才取实部
                          %   源码注释：using full and real here gives the exact plots of
                          %   Koper, Seats, and Benz 2010, BSSA
其他方法(center / [lat lon]) : beam = 10*log10(abs(beam).^2);
```

取实部发生在**求和之后** ⇒ 虚部信息留在求和里 ⇒ 方向可判。这正是本项目实测「镜像方向比全图峰低
2.6–5.2 dB」的来源，也是**方位可以信、但只认带符号滞后拟合**的原因。

## 2. 合成注入实测（可复算，脚本 `scripts/check_estimator_symmetry.py`）

真值注入 `|u| = 30.0 s/° @ BAZ 137.3°`，G1 真实坐标、窗 120–270 s（陆地计时）、0.0078 Hz、网格 ±42.2/243：

| 估计量 | 峰 | 镜像点电平 | 全图 B(u)/B(−u) 差（中位 / 最大） |
|---|---|---|---|
| **coarray + real（= 本引擎）** | 29.87@137.37° | **−10.68 dB** | 6.10 / 55.77 dB |
| coarray + 模平方 | 29.87@137.37° | −13.43 dB | 11.66 / 45.31 dB |

⇒ 四种真估计量**没有一个**给出等高孪生；只有对照组严格对称。判断"某引擎有没有 180° 模糊"时就照这张表做，
别背结论。

## 3. 真实数据：对称性随 |u| 破缺（G1，coarray）

各局部极大与**其镜像点**（同 |u|、方位 +180°）的电平差：

| 图 | 极大 | 镜像点 |
|---|---|---|
| `ts120_270` T（双频点 0.005–0.013） | **28.4 s/°@132.0°（源向）** | **−6.25 dB**（不成对） |
| 同上 | 10.7 s/°@136.3° | −0.32 dB（成对） |
| 同上 | 8.2 s/°@316.7° | +0.12 dB（成对） |
| `s30` T（3 频点） | 28.0 s/°@130.9°（源向） | −4.31 dB（不成对） |
| 同上 | 5.8 s/°@295.0° / 7.0 s/°@135.0° | −0.76 / +0.59 dB（成对） |
| `bin78g` T（单频点 0.0078） | 33.6 s/°@131.6°（源向） | −12.06 dB（强不对称） |

规律：**近零慢度那一族几乎成对（±0.3–0.6 dB），源向真峰（30 s/° 量级）明显不成对**（−4…−12 dB）
——与第 0 节的 `sin(2πf·u·Δr)` 一致。所以用户看到的"另一半"多半是**近零慢度那一族自己的镜像对**，
不是源向真峰的孪生。

## 4. 报数规则（照此办）

1. **不许把对面那团叫"孪生 / 镜像"，除非 |u| 相等**（真孪生必须同 |u|、方位 +180°）。`10.7` 与 `8.2 s/°`
   差 30% ⇒ 它们是各自与自己的镜像点成对，互相之间没关系。
2. **方位只认带符号台对互相关滞后拟合**（`xcorr_direction_check.py` 一族，判据 rms < 15 s），
   F-K argmax 只作参考；两者不一致时以拟合为准并在回复里点名。
3. **"怎么消除另一半"**分两层答：
   - 呈现层：`MASK=back`（以理论 BAZ+180 为中心 ±60° 楔形，半径取自动主瓣半宽 `0.64/(f_hi·D_deg)`）、
     `MASK=origin` 遮近原点区 —— 只动图面、不动波束文件，回复里要写明是遮罩。
   - 物理层：换频点 / 换窗把无关能量排除。本项目单频点 0.0078 Hz 档的图上**只剩一个局部极大**、
     近零慢度那族整个消失 ⇒ 这是最省事也最站得住的做法（口径改动见 `fk-parameter-selection.md` §8b）。
4. **不要用"对称相消"当理由去挖掉对面** —— 没有这个定理支撑（第 0–3 节）。

## 5. 做合成注入验证时的两个坑

- ⚠️ **注入子波必须整个落在各台窗的交集里**：第 k 台窗 = `[T1−dly_k, T2−dly_k]`，交集 = `[T1−max(dly), T2−min(dly)]`
  （G1 时延范围 −32.6…+27.7 s、窗 120–270 s ⇒ 交集只有 152.6–242.3 s）。子波超出交集 ⇒ 各台窗里装的不是
  同一段波形 ⇒ 时延律 `X_k = S·e^{−i2πf·dly_k}` 不成立。实测：25 s 高斯包（中心 195 s）残差 **3.1 rad**，
  收到 **12 s** 包后残差 **0.0000 rad**。
- ⚠️ **自检式的符号**：`C_ij ∝ exp(−i2πf·dly_ij)` ⇒ 判据写 `angle(C_ij) + 2πf·(u0·Δr_ij) ≈ 0`；
  写成相减会得到一个恒为"大残差"的假失败（`4πf·dly` 项）。同时**必带"只留互谱实部"对照组**，
  它给出 0.00 dB / 0.00 dB 才算验证成立（否则先怀疑注入或相位符号）。

## 6. 术语（中英对照）

互谱 cross-spectrum ｜ 协谱 co-spectrum（实部）｜ 正交谱 quadrature spectrum（虚部）｜
镜像孪生 mirror twin ｜ **复制峰 grating lobe**（另一种东西，别混：它是阵列响应 `B(s)=ARF(s−s_true)` 的平移不变复制，
间距 `111.195/(f·d_min)`，判据见 `fk-parameter-selection.md` §4）｜ 带符号滞后拟合 signed cross-correlation lag fit。
