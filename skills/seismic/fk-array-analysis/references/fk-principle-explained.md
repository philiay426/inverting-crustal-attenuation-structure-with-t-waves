# F-K 分析原理详解：频域 Bartlett 波束形成

**用途**：当用户问"F-K 分析的原理是什么"、"详细讲讲最后一步"、"为什么这样做"时，快速提供完整的数学推导和物理直觉。

---

## 物理模型：平面波假设

**假设**：远场地震波到达台阵时，波前近似为平面，所有台站接收到的是**同一信号的延迟版本**。

**慢度向量** s = (sx, sy)：
- **物理意义**：波传播单位距离需要的时间（速度的倒数）
- **单位**：s/km 或 s/deg
- **方向**：**本文件里的 s 一律指"扫描得到的峰值矢量"，它指向震源**（= BAZ 方向）；
  `−s` 才是波的传播方向 ⇒ 报方位时 `BAZ = atan2(sx, sy)`，**不要再 +180**。
  定标依据（本项目实测，一次定音）：注入 BAZ=127° 的平面波 → fk4d 峰 `atan2d(s4d.x,s4d.y)` = 127°。
- **幅值**：|s| = 1/v（v 为视速度）

**时间延迟公式**（两种等价写法，合成/拟合时务必分清用哪个）：
```
τᵢ = −s · rᵢ      # s 指向震源 ⇒ 震源侧台站更早到（τ<0），τ 即物理到时差
τᵢ = +u · rᵢ      # u = −s = 传播方向 ⇒ 顺波向的台站更晚到（τ>0）
```
其中 rᵢ = (xᵢ, yᵢ) 是台站 i 相对子阵中心的位置向量。
本项目合成生成器的约定是 `τᵢ = (u·rᵢ)/v, u = −(sin BAZ, cos BAZ)`（u 指向传播方向）；
写错符号会让合成验证"方向看似对、整体反 180°"。

**例子**：
- 波从东边来（震源在东）⇒ s 指向东（sx > 0），东边的台站**先**接收 ⇒ 其 τ = −s·rᵢ < 0
- 波速越慢，慢度越大，台站间延迟越明显

## 频域 Bartlett 波束形成：6 个步骤

### **Step 1: 提取时间窗口**

对每个台站截取同一时间段（如 T-P 理论到时 ± 60s）：
```python
windowed_data[sta] = waveform[sta][mask]  # mask: time ∈ [win_start, win_end]
```

### **Step 2: FFT 获取复数频谱**

对每个台站的时间窗做傅里叶变换：
```python
Fᵢ(f) = FFT(windowed_data[i])  # 复数：Fᵢ(f) = |Fᵢ|·e^(iφᵢ)
```

**关键**：
- 必须是**复数频谱**（包含振幅和相位）
- 不能用 Welch PSD（实数，无相位）
- 不能对 STFT 做时间平均（会抹掉延迟信息）

**相位的物理意义**：
- 相位 φᵢ(f) 编码了信号在台站 i 的到达时间
- 台站间相位差 Δφ = φⱼ - φᵢ = 2πf·(τⱼ - τᵢ) 直接对应时间延迟差

### **Step 3: 相位白化（可选但推荐）**

归一化振幅，只保留相位信息：
```python
Fᵢ_norm(f) = Fᵢ(f) / |Fᵢ(f)|  # 单位复数：|Fᵢ_norm| = 1, 相位不变
```

**作用**：
- 抑制强振幅频率的主导作用
- 增强弱信号频率的贡献
- 对噪声和场地效应更鲁棒

**不影响 F-K 结果**：
- F-K 波束形成只依赖**相位**（台站间时间延迟）
- 振幅差异（场地放大、震源辐射花样）被白化抹平
- 相位白化后，所有频率"等权重"参与方向估计

### **Step 4: 扫描慢度网格**

对于每个试探慢度 (sx, sy)，计算该慢度对应的**理论延迟模式**：

```python
τᵢ_theory = sx·xᵢ + sy·yᵢ  # 每个台站的理论延迟
```

**构造 Steering Vector**（导向矢量）：
```python
steering(f, sx, sy) = [e^(i·2πf·τ₁), e^(i·2πf·τ₂), ..., e^(i·2πf·τₙ)]
```

**物理直觉**：
- Steering vector 是一个**理论相位模板**
- 如果真实慢度 = (sx, sy)，真实数据的相位模式会与 steering vector 匹配
- `e^(i·2πf·τ)` 表示频率 f 下延迟 τ 对应的相位旋转

### **Step 5: 波束输出（相位对齐）**

将数据频谱与 steering vector 的**共轭**相乘，然后求和：

```python
beam(f, sx, sy) = Σᵢ Fᵢ(f) · conj(steering_i(f, sx, sy))
                = Σᵢ Fᵢ(f) · e^(-i·2πf·τᵢ)
```

**为什么取共轭？**
- Steering vector 是 `e^(+i·2πf·τ)` = **引入延迟**
- 共轭是 `e^(-i·2πf·τ)` = **补偿延迟**
- 数据 × 共轭 steering = **相位对齐**

**相干叠加原理**：
- 若真实慢度 = (sx, sy)，各台站相位被正确补偿后**同相**
- 同相信号相加：|Σ Aᵢ·e^(iφᵢ)| 最大（建设性干涉）
- 若慢度错误，相位补偿不对，相位随机→相消干涉

**Bartlett 功率**：
```python
P(f, sx, sy) = |beam(f, sx, sy)|²
```

### **Step 6: 频率积分 + 找峰值**

对感兴趣的频段（如 2-8 Hz）累加功率：
```python
P_total(sx, sy) = Σ_{f ∈ [2,8]} P(f, sx, sy)
```

慢度网格上功率最大的点就是估计的慢度向量：
```python
(sx_peak, sy_peak) = argmax(P_total)
```

**转换为地球物理参数**：
```python
BAZ = np.degrees(np.arctan2(sx_peak, sy_peak)) % 360   # 指向震源 = BAZ（勿 +180）
v_apparent = 111.32 / np.sqrt(sx_peak**2 + sy_peak**2)  # 视速度 (km/s)，|s| 用 s/deg
# ⚠️ 别照搬别处记的 atan2+180 —— 那是把"传播方位"当 BAZ 的口径（本项目早期确有脚本这么打印，
#    被误读成"引擎约定反了、图全错"）。怀疑差 180° 时的核查顺序：① 读那一行打印/转换的**原样
#    表达式** → ② 读注入生成器的 τᵢ 约定 → ③ 才判对错；两边一致 ⇒ 只是标签口径问题，别改代码。
```

## 为什么这样做有效？

### **数学证明（简化版）**

假设真实慢度为 s₀ = (sx₀, sy₀)，台站 i 的数据频谱为：
```
Fᵢ(f) = S(f) · e^(i·2πf·s₀·rᵢ)
```
其中 S(f) 是源谱（所有台站共享）。

当我们用正确的慢度 (sx₀, sy₀) 做 steering 时：
```
beam(f, sx₀, sy₀) = Σᵢ S(f)·e^(i·2πf·s₀·rᵢ) · e^(-i·2πf·sx₀·rᵢ)
                  = Σᵢ S(f)  （e 的指数部分抵消）
                  = N·S(f)   （N 为台站数）
```

功率最大：
```
P(f, sx₀, sy₀) = |N·S(f)|² = N²·|S(f)|²
```

当用错误的慢度 (sx, sy) ≠ (sx₀, sy₀) 时，相位不匹配，求和部分相消，功率小于 N²·|S(f)|²。

### **物理直觉**

把 F-K 分析想象成"转动一个过滤器"：
1. **过滤器方向** = 试探慢度 (sx, sy)
2. **过滤器的作用** = 补偿该方向对应的时间延迟
3. **输出强度** = 如果真实波的慢度与过滤器一致，补偿后所有台站同相 → 输出最大
4. **扫描所有方向** = 输出最大的方向就是真实波的来向

## 关键细节与陷阱

### **单位一致性**

延迟公式 τ = s · r 要求单位匹配：
- 若 r 单位是 **km**，s 必须是 **s/km**
- 若 r 单位是 **deg**，s 必须是 **s/deg**

**转换公式**：
```python
# 台站坐标 km，慢度网格 s/deg
sx_km = sx_deg / 111.32  # 因为 1 deg ≈ 111.32 km
sy_km = sy_deg / 111.32
```

### **相位符号**

Steering vector 必须是：
```python
steering = exp(+i·2πf·τ)  # 正号 = 引入延迟
beam = Σ Fᵢ · conj(steering)  # 共轭 = 补偿延迟
```

若写成 `exp(-i·2πf·τ)`，峰值会在 **-s_true** 的位置（方向反了 180°）。

### **慢度网格范围**

网格必须覆盖目标波型的理论慢度：
- **地壳 P 波**（6 km/s）→ 慢度 18.5 s/deg
- **地壳 S 波**（3.6 km/s）→ 慢度 30.9 s/deg
- **SOFAR 声道 T 波**（1.48 km/s）→ 慢度 75 s/deg

**推荐默认设置**：
```python
SMAX = 40.0  # s/deg（覆盖地壳波）
DS = 0.5     # s/deg（161×161 网格）
```

若 SMAX 太小，真峰在网格外，算法只能找到旁瓣假峰。

### **FFT vs Welch vs STFT**

| 方法 | 返回 | 时间分辨率 | F-K 适用性 |
|------|------|------------|-----------|
| FFT | 复数频谱 | 无（整窗） | ✅ 最佳 |
| Welch PSD | 实数功率谱 | 无 | ❌ 无相位 |
| STFT | 复数时频谱 | 高 | ⚠️ 不能时间平均 |

**正确用法**：
```python
# 整窗 FFT（推荐）
fft_result = np.fft.rfft(windowed_data)
freqs = np.fft.rfftfreq(len(windowed_data), d=delta)
```

**错误用法**：
```python
# ❌ Welch PSD（丢失相位）
f, psd = welch(windowed_data, ...)  # psd 是实数

# ❌ STFT + 时间平均（抹掉延迟）
f, t, Zxx = stft(windowed_data, ...)
spectrum = Zxx.mean(axis=1)  # 时间平均 → 相位延迟被抹掉
```

## Seizmo `fk4d`/`fkvolume` 逐行对应 + 四项硬约束

讲原始工具箱源码 / 写"公式推导"文档时按这个骨架（用户会要求"源码讲一下 + 公式推导"）：

| 代码行（`fkvolume.m`） | 公式 | 说明 |
|---|---|---|
| `fft(data,npts,2)` | `X_i(f)` | **整窗 FFT**（复数带相位；Welch/STFT 时间平均都不行） |
| `cs = data./abs(cs)` | `X̂_i = X_i/\|X_i\|` | 相位白化：每频点、每台都抬成单位振幅 |
| `cs = cs.*conj(cs_shift)` | `C_ij = X̂_i·X̂_j*` | 台对互谱，**相位 = 台对到时差** `−2πf·s·Δr` |
| `p = 2πi·s·r`（`r = r_j − r_i`） | 导向因子 | 对试探慢度 s′ 的补偿 |
| `beam = reshape(exp(f*p)*cs, …)` | `B(s′) = Σ w_ij C_ij e^{+i2πf s′·Δr}` | 求和；峰值条件 `s′ = −u/v`（u = 传播方向） |
| `beam = beam − max(beam)` | 0 dB = 峰值 | 所以"峰 − 背景中值"才是有意义的显著度 |

**四项硬约束（都从公式直接读出，不是经验之谈）**：

1. **白化 ⇒ 频带必须落在相干带内**：噪声频点与信号频点**同权** ⇒ `FRNG` 上界越过相干带
   （包络常止于 ~0.02 Hz）图必然趋平；此时别去改 SMAX/SPTS/窗长（错误调参维度）。
2. **Δf ≈ 1/T ⇒ 可无歧义分辨的台间延迟 |τ| ≲ T/2**（超了按 T 折叠）⇒ 定窗长先算
   `2 × 子阵内最大理论到时差`。
3. **空间混叠**：台间距 d ⇒ 频带上限 `f < v_app/(2d)`（d≈107 km 时 v=3.6→0.017 Hz、
   6.0→0.028 Hz）；频带越高只会越糊涂，不会"越清楚"。
4. **谱波束要求亚周期相位对齐**：台间到时残差须 ≪ 1/f —— 1-3 Hz 的远震 P 波残差 5-8 s
   已错开十几个周期 ⇒ 必然平图（这与"到时级相干"是两件事）。

⚠️ **dB 口径不可跨方法比较**：`center` 用 `|Σ|²`，`coarray`/`full` 用 `real(...)`（Koper 2010）
⇒ prominence 数值只能同方法内比。细节见 `envelope-fk-band-coherence.md`、
`sliding-window-aliasing-limit.md`。

## 方法简介（可直接引用的段落）与概念清单

写摘要/图注/汇报页需要"一两句话讲清 F-K 方法"时用下面两段（已按用户口径核过措辞），不要现场编。

**中文（约 110 字）**：
> 频率-波数（F-K）分析把台阵记录变换到频率-波数（慢度）域：将各台站波形切同一时间窗、做整窗 FFT，
> 相位白化后按试探慢度矢量补偿台间到时差、相干叠加，扫描慢度即可由能量峰的**方向**给出反方位角（BAZ）、
> **幅值**给出视速度（|s| = 1/v）。峰的锐度受阵列孔径与频带限制，分辨率约 Δs ≈ 1/(L·B)
> （L = 孔径、B = 带宽）。

**English**：
> Frequency–wavenumber (F-K) analysis maps array records into the slowness domain: after windowing and
> phase-whitening, the traces are coherently summed with time shifts predicted for each trial slowness
> vector. The energy peak gives the back-azimuth (from its direction) and the apparent slowness
> (|s| = 1/v, from its modulus). The resolution is limited by aperture L and bandwidth B, Δs ≈ 1/(L·B).

⚠️ **措辞铁律**：iasp91/TauP 算出的一律写"**理论走时**"（一维参考模型＋射线理论），写"真实走时"会被用户纠正；
图上用的到时口径（恒速 Eq.1 / 投影走时）必须在正文写明是哪套。

**概念清单（被问"慢度怎么解释、还有别的概念"时按此顺序讲）**：

| 概念 | 一句话 | 单位/关系 |
|---|---|---|
| 慢度 s | 波传播单位距离所需时间 = 速度的倒数；台阵里是**矢量** | s/° 或 s/km；\|s\| = 1/v |
| 方向约定 | 扫描峰矢量**指向震源**（= BAZ）；`−s` 才是传播方向 | BAZ = atan2(sx, sy)，勿 +180 |
| 射线参数 p | 慢度的水平分量 = sin i / v（i = 入射角） | 与 s 同量纲；常写作"时间/距离" |
| 时差 τ | τᵢ = −s·rᵢ（rᵢ = 台站相对子阵中心的位置） | s；这就是 F-K 要测的量 |
| 视速度 v_app | 波前沿阵面扫过的速度，1/\|s\| | km/s；台阵测的永远是视速度 |
| 波数 k | 空间频率，k = ω s | 1/km；F-K 的"K"就是它 |
| 频率-波数谱 | 各频率上按 k 扫描的相干能量 | 本项目实现 = 每频点算 P(s) 再对频带合成 |
| 分辨率 | 主瓣宽度下限 Δs ≈ 1/(L·B)（孔径 × 带宽） | 稀疏台阵实测可宽到 ~20 s/° |
| 混叠 | 空间：f < v/(2d)（d = 台间距）；时间：\|τ\| < T/2（T = 窗长） | 越界就出栅瓣/折叠假象 |
| 相位白化 | 抬平各台各频点振幅，只留相位 | 抗场地/震源振幅差异，但噪声频点同权 ⇒ 频带必须落在相干带内 |

**方法流程（汇报页/方法节步骤框的写法）**：① 选子阵与全台共用绝对时间窗 → ② 现有环境预处理出包络（2-8 Hz → 包络 → 低通）→
③ Seizmo `fk4d`/`fkvolume`，method 默认 `coarray` → ④ 扫慢度（±35 s/°、步长 0.35 s/° 级别）→
⑤ 输出 dB 慢度图（0 dB = 峰值）→ ⑥ 判峰：局部极大 + 峰−扇区中值显著性 + 物理约束（BAZ 一致、\|s\| ↔ 1.43–8.1 km/s）。

## 实例：马达加斯加 Mw6.2

**子阵**：BKTA/CPSM/AMPY（边长 101-160 km）  
**时间窗**：T-P 窗 120s  
**频段**：2-8 Hz  
**慢度网格**：-40 到 +40 s/deg，步长 0.5  

**理论值**：
- BAZ = 151.6°
- 慢度 = 18.5 s/deg（地壳 P 波 6 km/s）

**调试历程**：
1. 用 Welch PSD → 慢度 0.00 s/deg（相位丢失）
2. 用 STFT + 时间平均 → 慢度 0.43 s/deg（延迟被抹掉）
3. 用整窗 FFT → 慢度接近 18.5 s/deg ✅

详见 `references/fft-vs-welch-stft-pitfall.md`
