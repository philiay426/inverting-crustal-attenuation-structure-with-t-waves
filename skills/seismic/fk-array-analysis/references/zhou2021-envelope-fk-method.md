# Zhou et al. (2021) GRL — F-K on Envelope Method

## 核心发现

Zhou 2021 在 ~100 km 台间距的 XA 台阵上成功做 F-K，关键不是方法选择，而是**信号对象不同**：

| | 传统 F-K（我们失败的） | Zhou 2021 F-K |
|:---|:---|:---|
| 输入 | 2-8 Hz 原始波形 | **2-8 Hz 滤波后的包络** |
| 预处理 | 无 | **低通 <0.25 Hz** |
| 频率范围 | 2-8 Hz | <0.25 Hz |
| 空间 Nyquist | 需要 <375 m 间距 | 需要更大间距 |
| ~100 km 间距 | ❌ 混叠 | ✅ 可用（82站统计堆叠） |

## 具体做法（Section 3.2）

```
1. 三分量 2-8 Hz 带通滤波
2. 取包络 (Hilbert envelope)
3. 包络低通滤波 <0.25 Hz
4. 传统 F-K (SEIZMO)
5. 子阵孔径 <400 km, 平均间距 ~107 km
```

## 为什么可行

T 波包络是慢变信号（~0.05-0.25 Hz），不是 2-8 Hz 的载波。包络的空间"波长"取决于包络的频率和台阵上的视速度：

- T-P 包络视速度 ≈ 8-11 km/s（Zhou 实测）
- f < 0.25 Hz → λ > 32-44 km
- **但** 100 km 间距仍然理论上 < λ/2

实际可行原因（可能）：包络平滑 + 子阵堆叠 + 已知理论值约束，即使理论 Nyquist 不满足，统计上仍可提取信号。

## 实测结果（Zhou 2021, Figure 4）

- T-P: slowness ~10.0 s/° (11.1 km/s)，反方位角与理论海岸方向一致
- T-S: slowness ~24.7 s/° (4.5 km/s)
- 南北子阵结果一致（偏差 ~10°）

## 对非洲南部现代台网的实测结论 (2026-08-02)

**33 站实测 — 包络法也失败：**

1. 严格按 Zhou 2021 方法：2-8 Hz BP → Hilbert 包络 → LP 0.25 Hz → PMCC
2. 测试了 dmax ≤ 110/200/300 km 所有三站组（共 ~350 组）
3. **0 组有效** — 全部返回 -12345 m/s

**失败原因：**

- XA 有 82 站，可分成多个密集子阵（每子阵十几站）做统计堆叠
- 现代南非台网仅 33 站，真正 <100 km 的只有 5-6 站，最多凑 3 站一组
- PMCC 需三站间互洽延迟，90 km 间距包络互相关全为 dt=0.000s
- **结论：33 站不足以做包络 F-K**，不是方法问题，是台站数太少

## 对非洲南部最终结论

| 验证方法 | 可行性 | 理由 |
|:---|:---|:---|
| 偏振 R-T 平面 | ✅ 唯一可靠 | 单台即可，不需要台阵 |
| 包络 F-K (Zhou 2021) | ❌ 台站不够 | 33 vs 82，无法统计堆叠 |
| 三站延迟拟合 | ❌ | 包络 dt 全为 0 |
| 传统 F-K (2-8 Hz) | ❌ | 空间混叠 |
