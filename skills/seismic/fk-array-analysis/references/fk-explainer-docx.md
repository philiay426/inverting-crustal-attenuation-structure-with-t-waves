## docx 生成要点（python-docx，环境 miniforge3/envs/obspy）

- **排版规范（用户 2026-08-31 明确指定，非默认）**：US Letter 8.5"×11"；边距左右上0.85"/下0.75"；
  中文微软雅黑、英文数字 Segoe UI；正文 12pt、行距 1.3x、首行缩进 24pt、两端对齐；
  标题 20pt Bold 居中；Heading 1 = 15pt Bold（段前16pt/段后8pt）；Heading 2 = 13pt Bold
  （段前12pt/段后4pt）；标题颜色黑色（不用彩色/深蓝）；页眉留空；页脚"— 页号 —"灰色9pt
  居中（用 `w:fldChar PAGE` 域插入真实页码，不能写死数字）。
- **⚠️ 不用圆点/项目符号/彩色符号**（用户明确要求"不要用圆点和那些彩色符号"）：列表项改成
  普通段落（无 `List Bullet` 样式），✓/✗ 等符号改成文字描述。写文档前默认就应遵循此偏好，
  不要等用户挑出来才改。
- 公式：居中段落 + Cambria Math 字体文本（python-docx 不支持 OMML，用 Unicode 文本公式），
  公式下方灰色斜体小字标"出处：..."。
- 代码块：每行一段、等宽 Consolas 9.5pt、`OxmlElement('w:shd')` 浅灰底纹 `F2F2F2`。
- 参考文献：悬挂缩进 10pt、字号 10。
- 验证：`pandoc -t markdown out.docx` 检查结构完整（soffice 转 PDF 在本 WSL 环境
  对含中文路径/简单 docx 均失败，勿依赖；文件本身用 python-docx 回读 + `unzip -t` 校验）。
- **写完必须逐条验算数字/公式方向**：`pandoc -t plain out.docx` 导出全文后，对每个
  比较句（"A比B快/大/慢/小"）和每个除法/倒数关系都单独用 Python 算一遍再核对措辞方向，
  不能凭直觉过。本文档 2026-08-31 曾出现方向性错误（见下）+ 一次口头解释也搞反过方向，
  说明"看着像对的"公式描述最容易在改稿时不知不觉说反。

## 代码块 vs 数学符号的取舍原则（2026-09-01 用户要求"代码可不可以用数学符号标识"）

- **判断标准**：codeblock() 里的内容若本质是数学/算法步骤（向量运算、矩阵乘法、求和、
  相位指数、坐标旋转），改写成 formula()（居中 Cambria Math），用 Σ/Φ/上下标/· 等规范
  符号表达，不留 Python 语法；若本质是工程 I/O（读文件、csv 解析、路径处理），保留
  codeblock() 或改文字描述，不用强行数学化。
- **核心公式段落（如 4.4 fk_bartlett）**：数学符号做主要表达，可在其后附一段"极简伪代码
  对照"（仍用 codeblock()），让读者能对照脚本变量名，但不能让代码语法成为主要呈现方式。
- 已按此原则改过的小节：3.6/4.3（慢度网格集合 s_x,s_y∈[−S_max,S_max]）、4.4（G_ij=s_i·r_j，
  Φ(f)=e^{+i2πfG}，beam(f)=Φ(f)·X(f)，P=(1/N_f)Σ_f|beam(f)|²）、4.5（az_θ/az_s/Δaz 掩膜）、
  4.2（坐标投影 x=(lon−lon0)·111.32·cosLat0）、6.2（R/T 旋转，与第9节公式汇总保持一致）。

## Windows 文件被占用无法覆盖：PowerShell 优雅关闭

- 复制 docx 到 Windows 桌面覆盖旧版时，若旧文件正被 Word（含"阅读模式"）打开，会报
  `PermissionError: [Errno 13] Permission denied`。**不要**直接 taskkill 强杀 WINWORD
  （可能丢用户未保存的其他文档改动）。正确做法：先用 PowerShell 查找该进程
  （`Get-Process WINWORD` 或按窗口标题匹配），调用 `.CloseMainWindow()` 触发正常关闭
  （相当于用户点了关闭按钮，若文档有未保存修改会弹提示，不会强制杀进程丢数据），
  等待退出后再重试复制。
