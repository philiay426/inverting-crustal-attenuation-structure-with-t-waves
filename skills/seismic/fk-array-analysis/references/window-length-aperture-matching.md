# F-K 分析窗长与台阵孔径匹配

2026-09-02 马达加斯加 Mw6.2 BKTA/CPSM/AMPY 子阵实测

## 问题场景

用户询问失败案例（80s 窗）的参数，并要求用 120s 窗重新测试同一子阵。

## 台站几何

**BKTA/CPSM/AMPY 三角形子阵**：
- BKTA - CPSM: 159.5 km
- BKTA - AMPY: 110.5 km
- CPSM - AMPY: 101.2 km
- 最长边：159.5 km

**最近邻距离统计**（25 个岛内台站）：
- 最小：35.7 km（ABPO/TANS 对）
- 最大：230.0 km（MMBE 孤立）
- 中位数：102.4 km
- 平均：111.1 km

⚠️ **最近邻距离 ≠ 子阵孔径**：
- 最近邻距离表征台阵密度（台站分布疏密）
- 子阵孔径（最长边）决定波前穿越时间，进而决定窗长需求

## 窗长计算

### 80s 窗（失败）

最长边 159.5 km ÷ 1.5 km/s 声速 ≈ **106s 延迟**

窗长 80s < 106s → 波包在窗内不能完整覆盖所有台站 → 相干叠加失败

### 120s 窗（成功）

窗长 120s > 106s 延迟 → 余量 14s（13%）

即使最短边 101.2 km 的延迟（~67s）也只占窗长的 56%，留有充足的波包宽度余量。

## 经验准则

**窗长 ≥ 1.5 × (最长台站间距 / 视速度)**

- 系数 1.5 包含：波包本身时长（~30-40s）、波前畸变（各台转换点不同）、相位白化对时窗边界的敏感性
- 视速度保守估计：T-P 用 1.5 km/s（声道声速）、T-S 用 3-3.6 km/s（陆地 S 波）
- 安全余量：窗长应超出理论延迟 10-20%

## 公式窗可能比孔径要求的还短（必核）

照抄目标口径生成的窗 `[min(tt_tp) − 30, max(tt_ts) + 50]`（+ synchronize 系偏移）**不保证**满足
上面那条 `T ≥ 1.5·D/v`：台阵越紧凑、各台到时越挤，公式窗越短。

实测（马达加斯加 Mw6.2，5 台 MAHA/AMPY/FOMA/CPSM/BKTA，d_min 100.9 / D 367.4 km）：

- 5 台 `tt_ts` 856.0–954.5 s，展布仅 98.5 s → 公式窗 **T = 184.5 s**
- 而 `1.5·D/v_app = 1.5×367/2.47 = 223 s` → 公式窗偏短
- 后果（20 sps）：`nsp = 2^⌈log₂(T/dt)⌉ = 4096`、`Δf = 0.004883 Hz`，照抄频带 [1/1000, 1/25]
  内只剩 **8 个频点**；同窗的 geo 口径（f2 收到 `C/smax = 0.0085`）只剩 **1 个**
- 换 1000 s 窗：`nsp 32768`、`Δf 6.10e-4` → copy 64 点 / geo 12 点

⇒ **算完窗立刻核两件事**：① `T ≥ 1.5·D/v_app`（`v_app = 111.195/|u_pred|`）；
② 该 T 下带内频点数 ≥10。任一不满足就换更长的窗（同起点的 1000 s 档最省事），
**不要为了“照抄公式”硬用小窗**。

⚠️ **窗长同时决定频点集合**：`nsp = 2^⌈log₂(T/dt)⌉`、`Δf = 1/(nsp·dt)`。同一频带，1000 s 窗
给 64 点（0.001221–0.039673 Hz），553–728 s 窗只给 32 点。要“与某张图/某篇论文同一组频率”
必须用同一窗长；报参数必须把窗长与 Δf 一起写。

## 子阵可行性体检（加新子阵的第一步）

先跑 `scripts/check_array_geometry.py <sta1,sta2,…>`（逐项 PASS/FAIL），再画台站图 / 跑 F-K。
它一次给出：两两距离矩阵、d_min/D/中位、孔径比、PCA 长短轴比（二维性）、真实大圆 BAZ 范围、
走时场 `u_pred/BAZ_pred` + 拟合残差、分辨率表 `Δu(f) = 0.61·111.195/(f·D)`、
几何地板 `1.28·d_min/D`、coarray 对数 `N(N−1)/2`、各窗档的带内频点数与建议窗长。

判据（`≥3` / `≥10` / `≥2` 这些阈值是**本项目经验值，不是文献定理**；对外报时标明出处）：

- coarray 对数 ≥10 —— 5 台刚好 10 对，再少就不稳
- 孔径比 `D/d_min` ≥2 —— 低于此几何地板太差
- PCA 长短轴比 ≥3 才算二维覆盖良好；<3 = 台阵单向伸长，只约束一个方向

⚠️ 走时场平面拟合得到的 `BAZ_pred` 在**大孔径**（>1000 km）上可以离真实大圆 BAZ **60–90°**：
`tt = ocean_km/v_ocean + land_km/v_land`，而 `ocean_km` 由每条大圆的**上岸点**决定，
∇t 被海岸线几何主导（全 25 台拟合残差 37.9 s vs 5 台小孔径 13.8 s）。
⇒ **判 F-K 峰一律拿真实大圆 BAZ（`gps2dist_azimuth(sta, ev)[1]`）当基准**；`|∇t|` 只用来定
“网格要装多大”。报 `BAZ_pred` 必须同时给拟合残差。

## 相关公式

- **波前穿越时间**：τ = D / v（D = 孔径，v = 视速度）
- **慢度延迟**：Δt_ij = s · (r_i - r_j)（s = 慢度矢量，r = 台站位置）
- **窗长约束**：T_win ≥ max(Δt_ij) + T_packet（T_packet = 波包时长 ~30-50s）
