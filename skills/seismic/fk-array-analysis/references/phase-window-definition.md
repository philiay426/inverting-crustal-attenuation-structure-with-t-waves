# 相位窗的定义与选择（F-K 输入窗）

F-K 的输入窗决定一切下游结论（慢度、方位、分量优劣）。本文件给出口径、跨震相重叠的处理定则、
以及"把窗选择画出来"的构图配方。包络 F-K 与波形 F-K 通用。

## 1. 口径：全台共用的绝对时间窗（不是逐台独立开窗）

- 边界由**逐台理论到时**算出：`t_lo = min(理论到时 over 子阵) − 30 s`、`t_hi = max(理论到时) + 50 s`
  （理论到时用 Eq.1 / 走时表；min/max 取遍该子阵所有台）。算完即作为**同一个绝对区间**施加到每条记录。
- 施加方式：Python `t = (tr.stats.starttime − ORIGIN) + tr.stats.sac.b + np.arange(npts)/sr`，
  掩膜 `(t>=t_lo)&(t<=t_hi)` 对所有台相同；Octave `cut(data, o+win(1), o+win(2))` 等价——
  前提是 F-K 输入的 SAC 已统一**公共起点**（各台起点差几十 ms 会让 fk4d 插不到值 → NaN →
  `No windows contained 2 or more records!`）。
- **为什么不能逐台开窗**：F-K 测的就是台间到时差。同一绝对窗内各台波包本来就落在不同位置
  （XA G1 T-S 窗 [1243,1386]：SA18 在窗内第 29.5 s、SA25 38.7、SA17 44.1、SA23 62.0、SA16 68.0、
  SA22 88.9、SA29 93.0，摊开 63.4 s）；若每台以自己理论到时为中心开窗（各切 60 s），
  各台都落在窗内**同一位置**、台间散布归零 ⇒ F-K 只能给 0 慢度。这正是**对齐残差 F-K** 的语义
  （36 站对齐后峰≈原点、显著性 3.6/3.0：验证到时模型自洽，不能测绝对慢度）。
- 前 −30 s / 后 +50 s 不对称的理由：窗头只需一段噪声基线；窗尾必须装下长拖尾的 T 波尾波。
- 实测窗位核对脚本（对照 Eq.1 逐窗验证）：`fk_python/check_windows_eq1.py`。

## 1c. 窗长下限：τ 展布 ÷ 窗长 < 0.7（边距扫描实证）

（陆地计时输入的生成、链路标定与读数口径见 `land-time-fk.md`。）

陆地计时（转换点）模型下 τ_i = L_i/v 全为正、只差一个共同偏移（台对互谱里抵消），因此开窗写成
`lo = min(τ) − M`、`hi = max(τ) + M`（M = 边距，定稿 **±40 s**）。τ 随台组固定，能调的就是 M
⇒ 窗长 = (τ_max − τ_min) + 2M。G1 七台扫描（正演注入 + 真实数据同窗对照）：

| M (s) | 窗长 6.0 / 3.6 km/s (s) | τ 展布/窗长 | 回收 6.0 km/s | 回收 3.6 km/s | 判定 |
|---|---|---|---|---|---|
| 10 | 57.6 / 82.6 | 0.653 / 0.758 | 0.70 s/° @270° | 1.74 s/° @0° | ✗ 波束塌到零慢度 |
| 20 | 77.6 / 102.6 | 0.484 / 0.610 | 18.82 @133.5° | 31.37 @131.8° | ✓ |
| 30 | 97.6 / 122.6 | 0.385 / 0.511 | 19.06 @134.3° | 31.33 @134.5° | ✓ |
| 40 | 117.6 / 142.6 | 0.319 / 0.439 | 19.06 @134.3° | 31.08 @135.0° | ✓ |

真值 18.53 s/°/134.8°（6.0 km/s）、30.89 s/°/134.8°（3.6 km/s）。

- **判据用「τ 展布 ÷ 窗长」**（`(τ_max−τ_min)/窗长`），不是 `max|τ|/窗长`——后者在陆地计时模型下
  给 1.2 / 1.65 的**假 FAIL**；实现上等价于"窗长 ≥ 约 1.6 × τ 展布"。
- ⚠️ **超限的失败模式是"峰掉到零慢度"而不是"图变糊"**，且**真实数据与正演是同一种失败**
  ⇒ 见到 0–2 s/° 的极低慢度 + 极锐峰时，先核 ① τ 展布/窗长 ② 是否公共包络假峰，别先怀疑数据或引擎；
  反之，过了判据的窗仍给不出峰才是真的数据问题（转 `envelope-fk-band-coherence.md` 的相干性诊断）。

## 2. 跨震相重叠 → 取两相空隙的中点分界（用户定则，2026-09-11）

先算后一震相的最早理论到时；若有重叠，把两个**内边界各让一半**、在**两相理论到时空隙的中点**断开，
外侧 −30/+50 不变，两窗间留 1 s：

| 子阵 | T-P 理论 (s) | T-S 理论 (s) | 空隙 | 分界 | 新 T-P 窗 | 新 T-S 窗 |
|---|---|---|---|---|---|---|
| G1 | 1203.0–1241.8 | 1272.5–1336.0 | 30.7 s | 1257.2 s | [1173,1257]（内 +15.2 s） | [1258,1386]（内 −14.5 s） |
| G2 | 1224.4–1268.0 | 1293.4–1355.2 | 25.5 s | 1280.7 s | [1194,1280]（内 +12.0 s） | [1281,1405]（内 −12.4 s） |

- 旧标准窗 `[min−30, max+50]` 的重叠：G1 49 s（T-P 窗含 3/7 台的 T-S 到时）、G2 57 s。
- **判定污染的方法：同一数据跑含/不含泄漏两个窗**。XA G1 T-P 旧窗 Z/R 给 0.8 s/°@63°、0.3 s/°@180°
  （看似有方向），切到 T-S-free 后三分量全落 0.0 s/°@0°（零慢度针尖）⇒ 原来的"方向"完全来自
  泄漏的 T-S 能量。（同时满足 ①prominence 5-7 dB 极锐 ②慢度≈0 ③偏离理论方位>50° 即公共包络假峰。）
- **切窗会改变分量间的一致性**：G1 T-S 旧窗 12.0/26.6/35.5 s/°（散）→ 新窗 33.7/35.2/35.5 s/°（收敛，
  v≈3.1–3.3 km/s）；Z 12.0→35.2、T 26.6→33.7、R 35.5 不变。报"哪个分量好、慢度多少"之前先切干净。
- 反向污染（T-S 窗头段含 T-P 尾波，XA 占 21%）不含 T-P 到时本身，但**不等于可忽略**：陆地计时下把 T-S 窗左界 143.6 → 173.6 s 平移（等长 141.7 s），Z 峰由 2.69@113° 变 1.46@166°、T 峰由 2.06@121° 变 2.91@166°，prom 降 0.3–1.15 dB ⇒ 方位可动 >45°。报告时两边重叠量都要写。
- ⚠️ **对照实验必须"定长平移"，不要靠缩短窗**：缩短窗会同时改掉 `nspts`/`Δf`/带内频点数（freq bin），读不出到底是窗内容还是频率栅格在变（本次先做缩短版，T-S 带只剩 1 个频点，结论作废；改等长平移才干净）。
- ⚠️ **频带不同不能免除窗内污染**（用户会直接问"频带不同也会被污染？"）：包络不是严格带限（0.25 Hz 低通后 0.03–0.1 Hz 仍有残余），另一相的**上升沿短 ⇒ 带宽宽**，在离散频点上幅度不是零；窗内容一变，每道 FFT 的幅度/相位估计就跟着变。实测（等长平移、参与频点完全相同）：

  | 带（陆地计时） | 含相邻相 | 平移开（不含） | Δprom |
  |---|---|---|---|
  | T-P 带 0.020–0.0552（R） | [74.2,191.2]，含 T-S 起点前 17.6 s，**10.74 dB** | [43.6,160.6]，9.24 dB | −1.5 dB |
  | T-S 带 0.008–0.0224（Z） | [143.6,285.3]，8.11 dB，2.69@113° | [173.6,315.3]，7.84 dB，1.46@166° | −0.3 dB |

  ⇒ 1.5 dB 在 prom 只有 8–11 dB 的尺度上足以改变"取哪个局部极大"。
- **陆地计时窗（G1，V = 6.0/3.6）**：T-P 104.17–141.17 s ⇒ `[74.2, 191.2]`（117 s，**上界压进 T-S 起点 17.6 s**）；T-S 173.61–235.28 s ⇒ `[143.6, 285.3]`（141.7 s，下界离 T-P 终点只 2.4 s）。
  切干净（T-P 上界收到 173.6 s ⇒ 99.4 s 窗）**不损失频点数**：两档 `nspts` 都是 256、`Δf` 都是 0.0078 ⇒ T-P 合法带仍是 5 个频点。⇒ 切干净几乎零代价，没理由留着泄漏。

### 2b. 一条长窗同时罩住两相 = 慢相被拉塌（用户会要求「直接从 A 秒到 B 秒做」）

用户按「单窗覆盖全部」下参数时（如「扩充一下频带，直接从 60 s 到 260 s 做，频带下限下调到最近的频点」），
**先按合法性/装得下算一遍，再跑并同时交对照**，别只交一张塌掉的图：

| 窗（陆地计时） | 罩住的相 | 带 / 网格 | 峰（coarray ｜ center=full） | 判定 |
|---|---|---|---|---|
| 120–270 s（150 s） | 只 T-S | 0.0078 单频点，SMAX 52.5/301 | **33.48@131°（三 method 逐位相同）** | ✓ 可用 |
| 60–260 s（200 s） | T-P + T-S | 0.0078–0.013，SMAX 42.2/243 | 1.78@79° ｜ 1.44@76°（prom 6.5–7.8） | ✗ 塌 |
| 60–260 s（200 s） | T-P + T-S | 0.0078–0.0195，SMAX 28/161（上限 35.21） | 2.47@82° ｜ 2.21@72° | ✗ 塌 且装不下 |

- 机制：包络不是严格带限，`≲0.013 Hz` 的低频带里**前相（T-P）包络的能量与后相同级**；窗一罩住两相，
  波束就被前相拉走 ⇒ 与 §2 的反向污染同源，但量级不是 prom 掉 0.3–1.5 dB，而是**峰位直接失效**。
- 与「装不下」叠加：G1 实测 T-S 慢度 ~35 s/° ⇒ `f ≤ 0.3225/u = 0.0092 Hz`、`SMAX ≥ 1.706u ≈ 60`；
  带顶抬到 0.013 / 0.0195 后抗混叠上限只剩 46.95 / 35.21 ⇒ 抬到 0.0156 以上连「装得下」也不成立。
  ⇒ 结论句式：「本数据的 T-S 只支持 0.0078 单频点；扩带必然塌或装不下」。
- 交付口径：用户拍板的窗/带**照跑**（他是甲方），但同时给 ① 单频点、只罩该相的对照读数
  ② 一句「哪一版能引用」；两版图都留着，别用对照版替换掉他要的那版。

### 2c. 名义带边要落到本窗的栅格频点上

`Δf = 1/(nsp·dt)`（`nsp = 2^⌈log₂(T/dt)⌉`）、合法频点 `f ≥ 1/T`；`FRNG` 两端直接写**频点的精确值**
（`[0.01953125 0.032]`、`[0.0078125 0.013]`），脚本里再按 ceil/floor 落栅格，日志与波束表头才不至于
「名义带 ≠ 实际带」。dt = 0.5 s 的阶梯：

| 窗长 | nsp | Δf | 1/T | 典型带的合法频点 |
|---|---|---|---|---|
| 100 s | 256 | 0.0078125 | 0.0100 | 带 [0.005,0.013] 里唯一栅格 0.0078 < 1/T ⇒ **一个合法频点都没有** |
| 110 s | 256 | 0.0078125 | 0.0091 | 带 [0.0195,0.032] ⇒ 0.0195 / 0.0234 / 0.0273 / 0.03125（4 点） |
| 150 s | 512 | 0.00390625 | 0.0067 | 带 [0.0078,0.013] ⇒ 0.0078 / 0.0117（2 点） |
| 200 s | 512 | 0.00390625 | 0.0050 | 带 [0.0078,0.032] ⇒ 0.0078 / 0.0117 / 0.0156 / 0.0195 / 0.0234 / 0.0273 / 0.03125（7 点） |

- 「下限下调到最近的频点」时注意方向：**低于 `1/T` 的那一档不能算**（200 s 窗里 0.0039 不可用）
  ⇒ 0.005 这种名义下限只能落到 **0.0078**（该窗的最低合法频点）。
- 脚本自检打印：带内实际频点、`f_hi`、`SMAX ≤ 0.550231/f_hi`、本跑 SMAX/SPTS 与 Δs
  （`04_landtime_fk/export_landtime_new4.m` 的写法），别只在回复里说。

## 1b. 零时刻（t=0 = 发震）与 SAC `o` 字段的两种相反用法（用户会追问）

- 全项目的相对时间都以**发震时刻**为零：`t = starttime_abs − ORIGIN_abs`。
- 判定一份输入的零时刻**必须算 `starttime + o`**，不能只看 `b` 或起点文件名：
  - 全时段输入（发震在数据起点之后）：`b=0, o=+600` ⇒ 数据从发震前 600 s 开始；
  - **切窗后的 F-K 输入（窗起点已在发震之后）：`b=0, o=−win_lo`**（如 o=−1163.25 ⇒ 窗起点 = 发震后
    1163.25 s）⇒ 光看 `b=0` 会误以为波形从发震开始。写切窗脚本时就按 `o = −win_lo` 写，回溯才能自洽。
- 正演/合成要与真实链路对齐时，对齐的是**绝对时间轴三件套**（starttime、o、npts），不是文件内容：
  如 2 Hz / 8399 点 / starttime=11:57:38.049 / o=599.951 ⇒ 发震 12:07:38.000，与真实包络文件逐项相同。
- 快速自查（任一份输入）：`from obspy import read; tr=read(p)[0]; print(tr.stats.starttime + tr.stats.sac.o)`
  ⇒ 所有台应给出同一发震时刻。
- ⚠️ 同一事件里 **20 Hz 原始数据与 2 Hz 包络产品的 starttime/o 相隔几十 ms**（如 38.035/o=600.0 vs
  38.049/o=599.951），两者算出的发震时刻才对齐；跨产品算窗/SNR 时不要混用基准（统一用包络产品的
  `time(b−o)`，或先对齐到同一基准再算）。

### 5d "窗 vs 波形"诊断图的配方与四个坑

### 5e 同一张图的**绝对计时版**（用户会追加"补一个绝对计时的窗口版本"）

陆地计时版交了以后用户**必然再要一版绝对计时横轴**（他要拿它论证"陆地计时窗 = 逐台错开 `ocean/1.48` 的绝对窗"）。
两版**同一套窗数字**，只换横轴与色带形状，别当成两张不同实验：

- 横轴换 `t − o`（相对发震），显示范围要含 `窗 + ocean/1.48`：G1 两窗落进 **1100–1450 s**（`xticks` 每 50 s）。
- 数据换绝对计时输入 `envelope_0.25LPF/envelope_lp_all_28{,_R,_T}/*.sac`，时间轴
  `t = (tr.stats.starttime − ORIGIN) + k·dt`（`ORIGIN = UTCDateTime(1997,4,28,12,7,38)`）。
- 窗**逐台**换算 `绝对 = 陆地计时 + ocean_km/1.48`（G1 = 1098.65–1108.78 s、跨 10.1 s）
  ⇒ 陆地计时下的竖直矩形在这里变成**斜带**：`ax.fill_between([w1+t_oc, w2+t_oc], j−0.42, j+0.42, alpha=0.13)`。
- 另加**均值平移参考竖线**（`+ t̄ = 1102.41 s`，细点线）⇒ 两版能逐窗对读（G1 T-P 1162.4–1272.4、T-S 1222.4–1372.4 s）。
- 式(1) 理论到时用绝对口径：`ocean/1.48 + land/6.0`（T-P 蓝）、`+ land/3.6`（T-S 紫）。
- **自检**：打印逐台窗的并集与理论到时范围，确认理论点全部落在并集内 —— G1 T-P 理论 1203.0–1241.8 ⊂ [1158.6, 1278.8]、
  T-S 1272.5–1336.0 ⊂ [1218.6, 1378.8]。
- 面板小标题写清"哪个分量对应哪套窗/带/SMAX"（本例 Z、R 面板 = T-P 窗 0.020–0.032 Hz SMAX 17/99，
  T 面板 = T-S 窗 0.005–0.013 Hz SMAX 45/257），否则波形图与结果图对不上号。
