# T-S 带宽与网格的互斥、逐频点扫描、±u 镜像的消除（XA G1/G2 陆地计时）

被问"频带最宽能设多少 / 各频点偏向 / 图上另一半怎么消除"时照本文件答，并给数字，不要只说"受混叠限制"。

## 1. 带宽与网格是同一个旋钮的两端

判据 `SMAX ≤ C/f_hi`，`C = 111.195/(2·d_min)`：**G1 = 0.550231**（d_min 101.04 km）、**G2 = 0.581599**（95.60 km）。
带内合法频点还须 ≥ `1/T` 且落在 `Δf = 1/(2^⌈log2(T/dt)⌉·dt)` 栅格上。

G1/G2 窗 120–270 s（Δf 0.00390625、1/T 0.00667）实测四档：

| 带 (Hz) | 频点数 | f_hi | SMAX 上限 G1 / G2 |
|---|---|---|---|
| 0.005–0.0095 | 1 | 0.0078125 | 70.4 / 74.4 |
| 0.005–0.013 | 2 | 0.01171875 | 47.0 / 49.6 |
| 0.005–0.0176 | 3 | 0.015625 | 35.2 / 37.2 |
| 0.005–0.0215 | 4 | 0.01953125 | 28.2 / 29.8 |

用户 2026-09-22 口径：**SMAX 直接定 30**（显示半宽画到 ±30）⇒ 该网格下最宽带 = 3 频点 0.005–0.0176 Hz。
⚠️ **3 频点（要求 SMAX ≤ 35.2）与"装下 R 在 0.0078 档的 39.2 s/° 峰（要求 SMAX ≥ 40）不可能兼得** ——
只能按用途二选一，别答"都行"。
加长窗是唯一能真加**独立**频点的手段，但按 2 的幂阶梯跳：150/200/250 s → 3 档，300–512 s → 7 档，600 s → 13 档。

## 2. 网格是方形，判读只认内切圆

±SMAX 是**每轴**半宽，角点可达 √2·SMAX。峰落在内切圆外、或成为贴边的"非内部极大"⇒ 按边界/折叠像处理，不写进结论。
实测（0.0078 档，窗 120–270 s）：R 的峰 39.2 s/° 在 ±30 网格里 x 正好贴边（30.00，内部极大=False），
读数被截成 35.73 s/°（差 3.5 s/°）；T/Z 离边 4.9/1.8 s/° 是内部极大，与 ±42.2 网格差 ≤0.16 s/°。
⇒ **换网格先做"同频点双网格对照"再报数**，别直接拿新网格的 argmax。

## 3. 逐频点扫描：能量只集中在最低合法频点

G1、窗 120–270 s、SMAX 30、coarray、argmax：

| 频点 (Hz) | T | R | Z |
|---|---|---|---|
| **0.0078** | **33.50@131.6°**（prom 10.1） | **35.73@122.9°**（贴边，取大网格 39.24@120.4°） | **36.16@128.7°**（10.3） |
| 0.0117 | 2.23@288.4° | 10.16@200.3° | 5.05@282.1° |
| 0.0156 | 3.35@251.6° | 2.85@352.9° | 3.16@333.4° |

"震源向 ±15°、慢度 20–45 s/°"锥内最强值相对全图峰：0.0078 档 = **0.00 dB**（本身即全图峰）；
0.0117 档 −2.6…−7.6 dB；0.0156 档 −6.0…−7.8 dB。
⇒ 只有最低合法频点指向震源，上两档以近零公共模式/噪声为主；**3 频点平均会把近原点那族提上来**
（s30 三格 argmax = 5.6–7.3 s/°），所以宽带档的 argmax 不能当慢度读数。
出结论页：**主图用单频点档（0.0078 Hz）、宽带档作对照**。

## 4. ±u 镜像：成因与三种消除

`B(u) = |Σᵢ aᵢ·exp(−i2πf·u·rᵢ)|²` ⇒ `B(−u) = B(u)`，**对任意台阵几何严格成立** ⇒ 每团能量在过原点的对面有等高孪生，
是估计量固有的 180° 模糊，不是噪声也不是 bug。实测镜像电平（同 |u|、方位 +180）：
两频点档 T −6.9 / Z −8.6 / R −4.1 dB；单频点档 T −12.9 / Z −16.1 dB（白化/有限窗/噪声让它不严格对称）。

（示例：ts120_270 的 T 图上有三个同高局部极大——源向真峰 28.4@132.0°、近零族 10.7@136.3°(−0.09 dB)、
其镜像 8.2@316.7°(−0.33 dB)。用户说的"另一半"就是这一对镜像孪生。）

消除手段（按"改图 → 改读数 → 改估计量"排序回答）：

1. **图面遮罩（现成）**：`MASK=back` —— 以理论 BAZ+180 为中心 ±60° 楔形、半径 = `0.64/(f_hi·D_deg)` 的自动主瓣半宽，
   只动图面不动波束文件；出图名自动加 `_back`。近原点那族另可用 `MASK=origin`。
2. **读数（现成，推荐）**：方向只认带符号台对互相关滞后拟合（`xcorr_direction_check.py`），镜像不参与。
3. **估计量层面（真正消除，待实现）**：sign-selective / causal coarray —— 只保留使 `τᵢⱼ` 与候选 `u·Δr` **同号**的台对贡献，
   镜像的时延符号相反会被压掉。可先在 Python 侧做验证版（7 台 × 单频点，秒级）再决定是否进 Octave 引擎。

最省事的"消除"：换单频点 0.0078 Hz 档后近零那族整体消失（`bin78g` 的 T 只剩一个局部极大），镜像掉到 −12.9 dB。
