## 1. 论文慢度图（Fig4b/d）与普通"功率云图"的本质区别

- 论文图背景**纯白**，只有 T-P/T-S 两团像"靶心"的彩色晕圈 → 对 beam 做了**阈值遮罩**，
  只保留高于阈值的像素，其余全不画。普通 `pcolormesh(beam_db)` 铺满整网格是错的。
```python
beam_db = 10*np.log10(beam/beam.max()+1e-30)
masked = np.ma.masked_where(beam_db < vmin_db, beam_db)   # vmin_db=-0.6（论文窄动态范围）
pcm = ax.pcolormesh(SX, SY, masked, cmap="turbo", vmin=vmin_db, vmax=0, shading="auto")
```
- 色标范围窄（0 ~ -0.6 dB，不是 -6~0）。
  **现行硬性口径（交付主图 / 三方法对比图）：范围 0 … −0.7 dB，刻度标 `0 / −0.2 / −0.4 / −0.6`**：
  ```python
  D = b - b.max()                      # 以**峰值为 0 dB**（不是背景中值）
  pcm = ax.pcolormesh(x, y, D, cmap=CMAP, vmin=-0.7, vmax=0, shading="auto")
  cb = fig.colorbar(pcm, ax=ax, fraction=0.046, ticks=[0.0, -0.2, -0.4, -0.6])
  cb.ax.set_yticklabels(["0", "-0.2", "-0.4", "-0.6"]); cb.set_label("dB rel. peak")
  ```
  下限 **−0.7 只作为色标底端、不写字**（用户先要"只标 0 与 −0.7"，随即改成上面这四个刻度；
  拿不准时刻度已列全就要一次给对，别只留两端）。⚠️ **两套色标口径并存、别混用**：
  **遮罩版（复刻论文原图）**用 `vmin = 遮罩阈值` + 整数刻度（§1f）；**全盘连续填色版（我们的交付图）**用本条硬范围。
  实测保留比例（峰值色像素占全图）≈0.13%，与参考图"白底小彩团"的量级一致
  （6 dB 动态范围时峰值色像素 ~5–6 万，改后 ~1.5 万）；自查 = 数峰值色像素，量级差一个数量级就是范围设错了。
- ⚠️ **旧产物（`fkmap` / bfa 的 beam 网格）必须显式设这个固定范围，别让色标自适应**：
  SEIZMO `fkmap` 的 dB 网格跨度可达 **50–70 dB**（本项目 300×300 网格 −69.98…0 dB），自动色标下整图均匀、
  什么都看不出来；改成 0 … −0.7 后只有 3.5%（set1，300×300）/ 5.9%（set2，200×200）的格点着色，峰才显形。
  但 **bfa 网格是按自身峰值归一后再转 dB，跨度只有 3–5 dB**（本项目 runA −3.18…0、runB −4.89…0）⇒
  对它用 0 … −0.7 等于只留 1–10 个格点（runB 恰好 1 个）。**bfa 类图单独给范围**（0 … −3 / 0 … −5），
  并在图注写明范围——"同批图同一色标"的原则不能跨引擎硬套。
- 自查（脚本层，免视觉）：数 `≥ 下限` 的格点占比 **并列出该窗口下仍可见的局部极大**（本项目 4 张图实测：
  fkmap set1 3.48% / 5 个可见峰、set2 5.94% / 2 个、bfa runA 0.02% / 1 个针尖、runB 0.00% / 1 个点）。
  只有占比而没有"还剩哪几个峰"，用户问"那这条色标下能看到什么"时还是答不上来。
- ⚠️ **遮罩阈值决定观感，且必须按数据定，不能照抄一个数**：把阈值放宽到峰以下 3 dB 时，宽峰
  数据上留下的"彩色斑点"其实是峰自己的旁瓣/混叠像（都还在 3 dB 内）⇒ 图依然花。自查 = 数
  **遮罩后保留的网格占比**：>10% 就是阈值太松。本项目同批两例实测：−3 dB 保留 62% / 23%（仍花）、

### 1b. 复现自己的结果时：不要遮罩，用全盘连续填色 + "背景=0 dB" 色标

- 遮罩是**论文自己那张图**的样式；当我们的复现结果弥散、没有单一能量团时，遮罩会把整张图变成
  "大片空白 + 一点杂色"（用户："即使是假象也不至于这样啊"；背景纯白也被否："不强制纯白背景"）。
- 复现图定稿做法：`pcolormesh` **全盘连续填色**（不 mask），动态范围取 `VHI=sig`、
  `VLO=max(DB.min(), VHI-6.0)`；背景用浅灰/连续色（不要纯白）。
- **色标基准语义要分清**（用户会追问"峰值不是说 2.85 吗"）：慢度图常规写法是"相对峰值 0 dB"，
  而标题里的显著性数值是"峰 − 背景中值"。要显示真实 dB 就把 beam 整体平移到 `DB = DB_rel + sig`，
  色标 `VLO, VHI = sig-0.6, sig`，即**以背景中值 0 dB 为基准、范围 = 【峰 ↔ 下限】**。
- ⚠️ **BAZ 必须标在图上，不能只写进子图标题**（用户直接问过"为什么没有实际 BAZ 和理论 BAZ 标注"）：
  - 理论 BAZ：黑色**半线**（只从原点画到该方位，**不要**画过圆心的整条直径——用户 2026-09-17 指出"画过圆心没意义"）
    + 文字 `theory BAZ xxx°`（放在该线 72% 半径处）；
  - 实测 BAZ：从原点到**实测峰**画箭头 + 文字 `obs BAZ xxx°`（别只留一个白×不写数值）；
  - 两者角度差（理论 vs 实测）是核心判读量，标出来才能在图上直接看出方向是否对。
- 网格是**极坐标风格**（同心圆 + 放射线），不是 `ax.grid()` 方网格：手画
```python
from matplotlib.patches import Circle
for r in np.arange(10, rmax+1e-6, 10):
    ax.add_patch(Circle((0,0), r, fill=False, color="0.72", lw=0.6, ls="--"))
for ang in np.linspace(0, 360, 12, endpoint=False):
    a = np.radians(ang)
    ax.plot([0, rmax*np.sin(a)], [0, rmax*np.cos(a)], color="0.85", lw=0.5)
```
- **理论慢度十字（绿 +）位置必须按 BAZ 算，不能写死 `(0, -slow)`**（曾写死导致理论点落在
  无关位置、用户指出）。坐标要与黑色 BAZ 方向线用**同一个角度**：
```python
def baz_to_xy(baz_deg, slow_sdeg):
    a = np.radians(baz_deg)
    return slow_sdeg*np.sin(a), slow_sdeg*np.cos(a)
tx, ty = baz_to_xy(baz_ref, slow_theory)   # baz_ref = 子阵中心→震中 BAZ
ax.plot([0, smax*np.sin(np.radians(baz_ref))], [0, smax*np.cos(np.radians(baz_ref))], color="black")
ax.plot(tx, ty, "+", color="lime", ms=8, mew=1.5, zorder=5)   # marker 精巧，勿 ms=14 占 1/8 图
```
- 一张图若同时标 T-P/T-S 两点并连线：两点同 BAZ 方向、半径=各自 slow，拉线即论文效果。
- BAZ 情况要确认：单相位图每张一个理论点、与黑线共用子阵 baz_ref；若每点有独立 BAZ 才分开算，
  不要假设。
- ⚠️ **同一交付物里所有图必须用同一方位约定，且约定要靠合成定标确认**：曾出现 `slowmap_*.png`
  的理论十字用 BAZ 正向、而对比图 `fk_method_compare_*.png` 的绿十字写成 `BAZ+180` → 两张图的
  理论点方向相反，用户一眼判定"差 180 肯定是有什么东西设置错了"。定标法（一次定音）：注入已知
  来波 BAZ 的平面波（物理延迟 τ=−(r·û_source)/v）用**同一引擎**跑、读回峰角 —— 本项目实测
  atan2(sx,sy) ≈ 来波 BAZ（注入 127° → 143°，慢度 24.5 vs 24.7），所以理论十字/黑线/实测峰
  一律 BAZ 正向，别照搬别处记的 "BAZ=az+180"。
- 图注写明每个标记的含义（"绿十字 = 理论慢度（沿 BAZ 方向、半径 = 理论慢度值）"、"白×=波束扫描峰"），
  否则审核者会问"绿十字是理论还是扫描"。顺带口径：**慢度图原点 = 零慢度（视速度无穷），不是台阵
  中心的位置**；台阵中心只是算 r_i 时的参考点（各台减子阵平均经纬度），不出现在图上。

### 1c. 标注口径按图型分——图例必须写明"哪条线是实测/理论"

同一类慢度图用户给过**两套**标注口径，别把一套默默套到另一种图上（用户会逐图核对）：

| 图型 | 实测 BAZ | 理论 BAZ | 能量峰 |
|---|---|---|---|
| 复刻论文 Fig4（定稿单图） | 原点→实测峰**箭头** + `obs BAZ xxx°` | 黑色**直线**（过圆心直径）+ `theory BAZ xxx°` | 白 × 标出（另有绿十字=理论慢度） |
| **方法对比图**（多方法上下对比） | **黑色实线半线**（原点向外） | **黑色虚线半线**（原点向外，**不过圆心**） | **不标**（去掉 × 与数值） |
| **结果主图 / 标定图（左地图 + 右慢度图，只画默认方法）** | **细黑实线半线**（圆心→径向） | **浅灰细虚线半线**（圆心→径向） | **不标**；只画**灰虚圈 = 理论峰值点**（白虚圈/淡红圈已废，见 §1f） |

- 不管哪套，**图例都要写清哪条线是实测、哪条是理论**：线型含义随图型变，靠记忆复用必错。
  ⚠️ **本表第一行是被取代的早期版**（白×/绿十字/过圆心直径）：最后定稿以 **§1f / §1h** 为准（减法版：
  细半线 + 灰虚圈 + 窄窗口遮罩），别再照第一行实现。
- 方法对比图其余口径：各面板**独立色标**（背景中值=0 dB、跨度 6 dB）⇒ **不要用颜色深浅跨面板
  比显著度**，把 prominence 数值（如 3.86/2.31/5.95/2.85 dB）报出来代替；理论 BAZ 用大圆方位
  （= stations.csv 的 baz 均值，与论文图一致），若改用理论慢度梯度方向的 BAZ 要在标题/图注声明
  （两者可差 ~10°）。

### 1d. fk4d beam 数组的索引方向（转置即镜像）

- `fkvolume.m`：`.x` = E-W 慢度轴（随**列**索引递增）、`.y` = N-S 轴且 `y=fliplr(sx)'`
  （随**行**索引递减）⇒ `beam(iy, ix)` 行=N-S、列=E-W，**正好是 `pcolormesh(X, Y, C)` 的约定**：
  reshape 成 `[ny, nx]` 后**直接传 C=b，不要 `.T`**（转置会把 E-W/N-S 互换、整图沿对角线镜像，
  峰与方位线一起错位，而看单张图根本发现不了）；也**不要再 `flipud`**（行序已与 `.y` 递减一致）。
- 自查：出图前先打印 `unravel_index(argmax(b))` 反算 (x,y)，与已知峰位核对一次。
- ⚠️ **换一种重建写法会踩同一个镜像坑**：用 `np.unique(d[:,1])`（升序）重建 y 轴 = 又把行序翻过来，
  方位变成 `180°−az`（**慢度模不变**⇒ 数值看着都对，只有方位错）。要重建必须
  `y = np.unique(d[:,1])[::-1]`；最稳的是按文件原始顺序 reshape（推荐）。

### 1e. 多图集（震相 × 分量 × method）的产出与命名

用户会连续追加"再做一版 X 的"（X = 另一个分量 / 另一个 method / 另一个震相），按图集一次做全：

- **一个导出脚本循环 phase × component × method，一个绘图脚本带参数**，不要每次复制粘贴脚本：
  `python plot_Tcomp_TS.py {TS|TP} {center|coarray}`；文件名把三要素都写进去
  （`fk_Tcomp_{PH}_G1[_coarray].png`；beam 存盘名带 method 后缀，**不带后缀 = center**）。
- **行/列各代表什么必须在图里说清**：多窗版的行标题写完整窗号并标出来源（A = 标准窗
  `[min−30, max+50]` / B = 稳健性扫描挑出的窗），suptitle 明写"两行都是同一震相"——
  否则用户会问"怎么有两个窗口？""这是 T-S 的？"。
- **稳健性扫描是判断"好结果=真信号还是选样运气"的唯一手段**：报结论先给"几个窗里几个窗成立"
  （如 T-S 的 T+center 4/4 窗成立、R+center 只有 1 窗），不要只报最好的那一窗。
- 增量交付用**新文件名**，不要覆盖已有图（旧图的 beam 数据源要留着对照）。
- **参数迭代（换频带 / 窗长 / 慢度网格）只改 ★参数区，不新增脚本和目录**：一个 `export_*.m` 顶部放配置表
  `C(1..N)`（tag / 相位 / 分量 / FRNG / win / SMAX / SPTS）+ `RUN_TAGS={'tag1','tag2'}` 过滤器，一个 plotter 用
  `WSET / ERANGE / NPEAK / PEAK_DBAZ / THEO` 环境变量选图；**同一个 `beams/`、同一份 `log_*.txt`、同一份 summary**。
  用户会直接问"换频带直接改参数不就好了，为什么会有这么多代码" ⇒ 每迭代一次就另存 `new2/new3` 脚本 +
  另一个 plotter + 另一个产物目录是明确被否的做法（新配置追加在配置表尾部，旧 tag 保留可复跑）。

### 1f. 「地图 + 慢度图」双面板结果主图（**减法版定稿**）

结果主图口径（用户原话："左边为台站分布…右边为慢度图"）。**这一版取代早期的"绿十字 + 淡红圈 +
viridis + 整条直径 BAZ"写法**——用户对这类图的原则是**做减法**：每轮只提"删掉什么 / 改细什么 /
简化什么"，最终留下的就是"白底 + 一团彩色 + 两条细线 + 一个灰虚圈"。主动"加一个更清楚的标记"
会被否（绿十字、淡红圈都是加了又被删的）。

- **只画默认方法**（现为 `coarray`）：主图里不放多方法对照，**标题里也不标方法名**；多方法差异
  另出一张诊断图。
- **左图 = 台站分布（地图），不上色**（没有色标）：黑三角 + 台名（白描边）；台阵群必须居中——
  范围以子阵中心为中心对称留白（±6° lon / ±5° lat），❌ 不要 ±1.5° 紧裁；
  `ax.set_aspect(1/cos(lat))` 等比；从中心沿真值 BAZ 画虚线指向震中并标 `true BAZ xxx°`。
- **右图 = 慢度图（减法版四条）**：
  1. **低于阈值整片不画**：`np.ma.masked_where(db < MASK_DB, db)`，阈值按上面的"保留占比 <10%"选；
     色板 = Zhou 参考图系（色序见上文"配色按图型分两套"那条：白→黄→红→紫→蓝→黑，黑 = 峰）。
  2. **BAZ 只画"半线"**（圆心 → 径向外侧各一条，**不贯通 0 点**）：理论 = **浅灰细虚线**
     （`0.62`, lw 0.9）、反演 = **细黑实线**（lw 1.0）。两条都别加粗（"细一些"是用户原话）。
  3. **理论峰值点用灰色虚线圈标**（`peak_dashed_circle`，默认色 `0.45`、`ls=(0,(5,4))`；`slowness_panel` 同理）。
     ❌ **白虚圈已废**（2026-09-15 用户改定：白圈在白/浅底图上根本看不见）——改灰圈后**不再需要
     “落在空白处就降级”的分支**，一条口径画到底；❌ 绿十字在**本类主图**里已删、❌ 淡红圈已删、
     ❌ 实测判定点不标（"实际的判定点无需标注，我可以看得出来"）。
  4. **慢度圈必须可见**：0–360° 同心圆（每 10 s/°）+ 12 条放射线，**画在 pcolormesh 之上**
     （`zorder` 高于色图）。画在下面会被色块完全盖住 —— 用户原话"现在看不见慢度圈"就是这个原因，
     别去调颜色或线宽。
- **表头 = 纯词两行，不带任何符号、不标方法**：第一行真值（`injected 24.7 s/deg, BAZ 126.4 deg`）、
  第二行误差（`slow error +0.72 s/deg   BAZ error +1.9 deg`）。❌ 不用 `Δ`/`°`/`@` 等符号（用户：
  "表头不要有特殊符号，简化"），❌ 不写 `(fk4d coarray)`、❌ 不写 `|`。
- **色标：整数刻度**（−3/−2/−1/0 这种），vmin = 遮罩阈值 ⇒ 下限就是阈值，不必再 ceil(min)。
- 交付前自查（脚本层，不靠视觉模型）：① 遮罩保留占比 <10%；② 理论圈心 =
  `baz_to_xy(baz_true, slow_true)`；③ 实线角度 = 结果 csv 的 `baz_inv`；④ 慢度圈 zorder > 色图；
  ⑤ 表头两行无符号、不重叠、不出框；⑥ 图例里不再残留已删标记（绿十字/淡红圈）的条目 —— 图例是面板代码**之外**的独立 `fig.legend()` 块，只改面板会留下旧条目（曾残留"绿十字 + inverted peak"两项）；改完 grep 旧标记色（`#4daf4a` / `marker="+"`、`#e06666`）确认清干净。
- **实现收在一个公共样式模块里**（本项目 `synth_forward/_pubstyle.py`）：`apply_pub_style()`、
  `save_pub()`、`panel_label(ax,"a")`、`zhou_cmap()`、`polar_grid_360()`、`baz_half_line()`、
  `peak_dashed_circle()`、`slowness_panel(...)`（把上面四条一次画全，各图只传数据/真值/阈值）。
  用户会连续要求微调 ⇒ **阈值/后缀走参数或环境变量**，改样式只改这一个模块、不逐图改脚本。

### 1g. 「台阵分布 + F-K 方法示意」图（用户连续三轮定稿）

双面板示意图（左 = 地图/台阵与震源，右 = 选中台站清单），用户逐条否掉的写法与最终口径：

- 地图：**只画灰白大陆轮廓、不要地形**（`land="gray92", water="white"`）；区域范围按用户指定给足
  （曾用 `[12°E–50°E, 46°S–15°S]`），**震源必须落在范围内**——画大圆路径要 `InverseLine`（❌ `Line`），
  GMT 不认 `crimson` 之类的颜色名，用 RGB 数值。
- 台站画**三角形**（`style='t'`），**不标台站名字**；**色标尺不能压住经度标注**、标签不带 `$` 符号；
  地震信息（事件/时刻/坐标）放**左下角**。
- 平面波传播方向：箭头从台阵外侧起画，**长度别太长、严禁盖住台站**；文字只写
  `theoretical BAZ = xxx°`，**不写公式、不写推导**（用户："右图表信息太复杂，不用标注各种公式"）。
- 右面板 = 选中子阵的台站清单（站名 + 理论到时），**保持简短**，别堆公式/参数说明。
- 交付前自查（脚本层，不靠视觉模型）：震源与标题不出框、箭头与色标不压台站和经纬标注、右表不超面板高度。
- **要加深浅线（如 −1000 m 等深线）**：`fig.grdcontour(grid=..., levels=[-1000], pen="0.7p,black,--")`，
  画在海岸填色之上、台站符号之下；**只有真的有水才画得出来**——全陆地的面板里这条线不存在。
  所以脚本必须**打印每格的地形极值与该等深线的穿越数**（实测左格 5910 次穿越 = 有线、右格 0 次 = 全陆），
  否则就是“静默什么都没画”，用户会以为你漏了。
- ⚠️ **pygmt 里“面板专属的 text/legend”必须在 `fig.shift_origin()` 之前发出**（或写在该面板自己的段落里）：
  挪到 shift 之后，坐标会按**下一个面板的框**解释 ⇒ 标签画进另一张图（实测：左图的 BAZ 标注跑到右图）。
- 方位角标注有三种口径，必须挑明：`centroid`（子阵→震源 = 阵列 BAZ）、`mean`（逐台 BAZ 取平均）、
  `local`（射线中点处的位置角）。实测 **137.24° / 137.26° / 132.56°**（差 4.7°）⇒ 报数要说明用哪种；
  用户说“在方位角中央标注”一般指射线中点，但图注里要写清是阵列 BAZ 还是局部角。
- ⚠️ **面板比图例窄时，任何角落都挡 —— 先量再决定，不要猜着放**：取渲染后图例框的 `get_window_extent`
  （实测 3 项 @14 pt = **3.57 in 宽**）与该面板宽度（**3.235 in**）比，再看波形顶到面板上边还剩多少
  （实测只剩 0.13 step ≈ 0.05 in）⇒ 结论只能是**删图例**、说明移到底部文字行。
  别把时间花在“换个角落试试”上（这是被实测否掉的路）。

### 1h. 观感 ≠ 分辨率：显示窗口与显示平滑（用户问"论文是不是平滑了"时按这两层答）

- **彩色面积几乎完全由遮罩窗口宽度决定，不是分辨率**：同一波束只换阈值就能从"一整片花"变成"白底一团"
  （数值见上面那条）。参考图色标只跨 0 ~ −0.65 dB = 只画峰顶；用 −3 dB（跨 3 dB）在宽峰数据上等于没遮。
- **论文那种"圆润小彩团"用未平滑波束画不出来 ⇒ 论文（或其绘图链）做了显示层平滑/插值**：同一个
  −0.65 dB 窗口下，未平滑只剩 0.14% 网格（1-2 个格点的针尖）；加高斯平滑 σ=1 格点（0.35 s/°）→ 0.56%、
  σ=2 格点（0.7 s/°）→ **6.97%**（真实 G1 T-S）——量级才与论文的团相当。
- **显示平滑 ≠ 分辨率提升**：真实分辨率由孔径×带宽定，`Δs ≈ 1/(L·B)`（G1 孔径 180 km、相干带
  0.03 → 0.08 Hz ⇒ ~20 → 9 s/°）；论文 G1/G2 与我们同量级 ⇒ **不能据"论文图上团小"断言他们分辨率高**。
  被问到时先把两层分开（显示窗口/平滑 vs 孔径带宽）再给量化对比，别把观感差异说成分辨率差异。
- **照论文观感出图（窄窗口 + 轻平滑）要在图注/方法里写明"显示平滑 + 色标范围"**，否则审稿人会问
  为什么只画 0.65 dB；**汇报/论文主图推荐 −2 dB 无平滑**（不引入人为处理、又干净），复刻参考图观感
  才用 −0.65 dB + 轻平滑。
- 实现：`slowness_panel(..., vmin_db=…, smooth_sigma=…)`（平滑在遮罩**之前**做）；出图脚本读环境变量
  `MASK_DB` / `SMOOTH_SIGMA` / `OUT_SUFFIX`，一次出多版（`_thr2` = −2 dB 无平滑、`_paper` = −0.65 dB + σ=1）
  给用户挑；**变体一律新文件名，绝不覆盖主版**。
- ⚠️ **统计"保留占比"注意符号**：判据是 `v >= mx + thr`（thr 为负）——写成 `v >= mx - thr` 会得到
  "所有阈值都 0%"的假结果，看着像"遮罩生效了"。任何阈值统计先做一次单调性 sanity check：阈值放宽
  ⇒ 占比必须变大。
- ⚠️ **同类慢度图一次改全**：结果主图、正演标定图（含转换点图）、分频带图都走同一个 `slowness_panel`
  ⇒ 改样式时一起重出（用户只会说"我是说正演的那张"，其余同类图同样要跟上），否则同批图风格不一致。

### 1i. 「陆地计时正演」图组：用户会点着拆图（2026-09-15）

### 1j. 慢度图的**显示范围**由论文图定：固定 ±30 s/°（用户会拿论文图当硬约束）

用户会直接说"论文的慢度图上限是 ±30，你也改一下" ⇒ **显示半径固定 30**，不随各相位各自的 `SMAX` 变：

```python
gx = float(np.max(np.abs(x)))   # 网格半径 = 该配置自己的 SMAX（T-P 17.1 / T-S 42.2 …）
lx = 30.0                       # ★ 显示半径：固定 ±30 s/deg，与论文 Fig4 同框
grid(ax, lx)                    # 同心圆每 10 s/° 一个、到 30 为止；刻度 [-30, 0, 30]
ax.set_xlim(-lx, lx); ax.set_ylim(-lx, lx)
inside = int(sl <= gx)          # ⚠️ "峰是否在搜索网格内"的判据仍用 gx，绝不能用显示半径
```

- ⚠️ **判据与显示半径是两个量，别合成一个 `lx`**：合成后 `inside` 会放宽（T-P 的 SMAX 只有 17.1，
  拿 30 去判会把网格角点的截断伪影算成"内部峰"）。
- ⚠️ **改显示范围要一次改全同类图**：结果主图 / 方法对比 / 分频带 / 陆地计时 每个脚本各自算一次 `lx`,
  漏一个就同批图风格不一致（本项目一次改了 6 个脚本、13 张图）。
- ⚠️ **±30 会切掉我们的 T-S 峰**：我们测到 **35.3（G1）/ 36.2（G2）s/°**，落在 ±30 之外，
  而论文的 13.7 / 24.7 都在内 ⇒ ±30 画幅里 T-S 只剩探进框内的"肩膀"
  （沿 BAZ 方向 ±30 处仅比峰低 −0.18 / −0.56 dB）。**改之前先把这个副作用讲出来**，并给三个选项：
  全图 ±30（与论文可比、峰切边）／T-S 单用 ±45／全用 ±45（一行切换 `lx = 45 if phase == "TS" else 30`）。

### 1k. 单格慢度图（一个配置一张、不做论文对照）：显示半径 = 本格 SMAX、色标在画布内、刻度每 10

与 §1j 的固定 ±30 是**两套口径**，按图型选：单格诊断图的显示半宽取该配置自己的 `SMAX`，
这样"峰贴不贴网格边界"一眼可判（判据量仍是 SMAX，见 §1j 那条）。

- **色标必须落在画布内**：先 `fig.subplots_adjust(left=0.135, right=0.84, ...)` 收窄主 axes，再
  `fig.colorbar(pcm, ax=ax, fraction=0.05, pad=0.035)`（`pad` 是**轴宽比例**，给大值必越界）。
  先加色标再 `tight_layout` 最容易把它甩出画布（用户会说"色标不在图内了，整体向左移动一些"）。
- **慢度刻度每 10 s/° 一个**、到显示半径为止；别自动抽稀刻度，也别把 0 之外的刻度省掉。
- **布局自检（脚本层，不靠视觉模型）**：打印各 axes 与 colorbar 的 `get_position()`，断言
  `x0 ≥ 0 且 x1 ≤ 1`，并打印 `在画布内=True/False` —— 比看图快，且能进日志留档。
- 同类图（T-P R/Z、T-S T）一次全改，别只改当前那一张。

### 1l. 并排/多格图的版面硬坑 + 出图前的规范自查（每次出图都过）

- **并排图 = 把已有单图搬进一格，不是重做参数**：各格保留各自的窗长 / 频带 / 网格范围
  （原本 T-P `[60,170]`、T-S `[120,270]` 就原样搬入），**别顺手统一成同一个窗** —— 统一窗 / 统一带是
  独立决定，用户没点名就别做（做了会被要求"窗长也恢复原先的对应窗长"）。各格范围不同 ⇒ 每格画自己的刻度与显示半径。
- **绿十字的存废按图型分**：本类"地图 + 慢度"减法主图不画理论十字（上面 §1f），但**陆地计时单格 / 并排
  慢度图**上理论慢度点要画**淡绿十字 + 50% 透明度**（口径与裁剪/翻转写法见
  `peak-reading-and-method-comparison.md` §6）—— 两类图别互相套用。
- **每格慢度范围不同时禁用 `sharey=True`**：sharey 让后设的 `set_ylim` 覆盖先前的，各格 y 范围被锁成同一个，
  而 x 范围仍各是各的 ⇒ 数据纵横比不同、**窄范围格被压扁成一竖条**（实测 ±17 的格只剩 1.4 in 宽，±42.2 的格 3.47 in），
  y 刻度还统一错标成最大那格。三格并排（T-P R/Z + T-S T）必须 `sharey=False`。
- **先 `subplots_adjust` 再挂 `fig.colorbar`**（反了会把色标甩出画布，同 §1k）。
- **面板文字要塞进"方形 axes 的宽度"，不是面板槽宽度**：`set_aspect("equal")` 后方形图只占槽宽的一部分，

## 2. matplotlib 频谱展示坑：小幅度包络信号 PSD 会被 ymin 压出画面 → 误判"没能量"

- 场景：展示预处理链频谱对比（original / bandpass / envelope / envelope lowpass）。
  env/env_lp 幅度 ~1e-8 m/s，Welch PSD 峰只有 **~1.5e-17**；若 y 轴下限设 1e-14（以为"很小"），
  整条曲线掉到画面外 → 用户看到"第四张图根本没有能量"。
- 修法：**各曲线自归一化（P/P.max()）+ loglog 频率轴（0.01-10 Hz）**，比较"能量集中在哪个
  频段"的形状，不比较绝对量级。加 0.25Hz 虚线、2-8Hz 阴影做参照。
- 数值验证能量归属：env_lp（0.25Hz 低通后）Welch PSD 峰在 ~0.02Hz，<0.25Hz 占其总功率约 53%；
  bandpass 峰在 2-8Hz。展示时才不会被质疑。

## 3. envelope 链物理澄清（用户会问："2-8Hz 带通后再低通怎么会有能量？"）

- 链：`2-8Hz bandpass → |Hilbert envelope| → 0.25Hz lowpass → (2Hz 降采样) → F-K`。
- 不矛盾：2-8Hz 带通输出的是 2-8Hz **振荡（载波）**；Hilbert 包络是**幅度解调**，把"能量
  随时间变化"提取成低频、非负的包络（类比 AM 收音机：高频载波卸掉、留低频调制信号）；
  0.25Hz 低通平滑包络、只留几十秒尺度的"能量包"。**送进 F-K 的本来就是这个低频包络**，
  测的是 T 波能量包在台阵间的到达时差（慢度）。
- 喂给 Seizmo fk4d 的文件必须已是包络低通产物（2Hz、能量 <0.3Hz≈100%、非负平滑），
  可直接读文件统计验证，别口头声称。
- 论文口径：Fig2c=2-8Hz filtered，Fig2d=对 (c) 取包络 → F-K 输入 = 2-8Hz 带通后的包络再
  0.25Hz 低通（马达加斯加沿用 2-8Hz 一致；1-5Hz 试过结果几乎不变，2-8 为准）。

## 4. matplotlib 混排布局坑：x 轴范围不同的面板不能 sharex

- 时间轴面板 + 频谱面板（x=Hz）混排、只想部分共享 x 时，❌ 传
  `sharex=[False,True,True,False]` 这类列表**不生效**（曾致 savefig/tight 后整图宽爆到
  ~218k px、PDF 巨大）。每个 add_subplot 显式指定 `sharex` 目标轴，或频谱面板单独创建
  不共享；出图前核对 `fig.get_size_inches()` 与输出像素宽度（~几千 px 正常，几十万 px
  就是 sharex/bbox 爆炸）。

## 5. 「时窗画在波形上」图（窗选择的可视化交付物）

用途：证明送检 F-K 的窗罩住了目标波包、没跨相。固定版式 = 1×N 面板（各分量），纵轴按陆地距离递增，
站名写在面板内左缘（不用 y 轴刻度标签）。

- **数据就用 F-K 输入本身**（`envelope_0.25LPF/envelope_lp_all_28{,_R,_T}`），别另算一套包络；
  每道画细波形 + **红色包络线**，振幅按**全局 P98** 归一（保证台间相对振幅可比、不互相压扁）。
- **理论到时画逐台短竖虚线**（T-P 蓝 / T-S 紫），**不要圆点、不要贯穿全图的长竖线**。
- **窗的画法由横轴决定**（窗定义在哪个基准就用哪个基准画）：
  · **陆地计时横轴**（0 = 理论上岸）：窗是**全高竖直色带**，各台同一位置；
  · **绝对计时横轴**：同一批窗按**逐台 `+ocean/1.48`** 平移 ⇒ 画成**逐台斜带**（按道 `fill_between`），
    另加细点竖线标"按阵列均值平移后的窗"作参照（G1 均值 ≈ 1102.4 s）。
- **一个脚本两种横轴**：参数区 `TIMEBASE = "land" | "abs"`，窗列表也在参数区；不为横轴差异另写脚本。
- 自检（脚本层）：打印各理论到时区间与所属色带区间，断言"理论到时 ⊂ 色带"且"两相色带不重叠"——
  例：T-P 104.2–141.2 ⊂ [60,170]、T-S 173.6–235.3 ⊂ [120,270]，且 170 < 173.6。
