## 复用的口径（与周2021 逐字相同，只换数据/子阵/窗位/分量）

2–8 Hz 带通 → `synchronize` → `interpolate(…,20,'spline',win)` → `normalize → envelope →
getspline(0.1) → removemean → taper` → `fkmap(smax, spts, [1/1000, C/smax])`，method coarray。
两套计时口径：`abs` = 共用绝对时间轴 cut、逐台不平移（论文口径）；`land` = 逐台按上岸时刻平移。

## 可复用教训（换事件/换子阵都适用）

1. **段指纹两套口径都要做**（旧版只对陆地做）：取源记录里「该窗应覆盖的样本段」的 mean|dep|，
   与切出段比，相对差 <1e-3 即 PASS。⚠ **源段必须先降到与切窗同采样率再比**
   （绝对计时输入是 40 sps、切出 20 sps，直接比会假报 CHECK；`stride = 0.05/dtraw`）。
   实测相对差 1e-7…5e-4 全 PASS，这一条把「切窗偏移语义搞错」这类事故变成可自动发现的。
2. **Seizmo `interpolate` 的点数 = `floor(T/dt) + 1`**（不是 round+1）：200.00 s → 4001、
   126.278 s → 2526、500.00 s → 10001。参数表里的带内频点数必须按这个 npts 推 nsp/Δf，
   否则频点数对不上（本次第一版按 round+1 算，126.28 s 窗多算 1 点）。
3. **去响应 SAC 的三分量头不严格一致 → obspy `Stream.rotate` 直接报
   `All components need to have the same time span`**。实测本数据集：3/5 台的 BHZ 或 BHN 比
   其余分量差 **1e-6 s**，FOMA 的 BHE 还多 1 个采样点（84001 vs 84000）。
   ⇒ 旋转前先「统一到最早 starttime + 最短 npts」（1 µs 相对 0.025 s 采样间隔可忽略），
   并把对齐动作打进日志。
4. **旧脚本的回读自检公式 `starttime + b == REF` 恒 FAIL（假警报）**：obspy 写 SAC 保留源头的
   参考时刻 `nz*`、算出的 `b = 0.0195 ≠ 0` ⇒ 判据应写 `starttime == REF`，b 单独打印。
   遇到一路 FAIL 的自检先核公式，别去改数据。
5. **三分量 R/T 用统一 `baz_ref`（子阵中心理论 BAZ）旋转**，不逐台用各自 BAZ（本子阵各台
   142.4–155.7°，跨 13°，逐台旋转会把方向差混进 R/T）。obspy `NE->RT` 约定：R 指向震源。
   自检用 `|R|²+|T|² == |N|²+|E|²`（正交，逐点残差应 0）。
6. **绝对计时口径在短窗下会只剩 1 个合法频点**：要装下绝对走时场 T-S 46.4 s/deg 就得
   `f2 ≤ C/SMAX = 0.0085 Hz`，而 200 s 窗（Δf 0.004883）的第一个 bin 已是 0.004883 Hz。
   ⇒ 短窗的绝对口径读数只作**单频点对照**；频点充足的绝对结论看 500 s 长窗（6 点）。
   报参数必须带窗长与 Δf（skill 主文件里那条的老问题）。
7. **注入期望回收值 = |∇τ|（平面拟合梯度），不是 `111.195/V`**：τ_i = land_km_i/V 不是沿程线性的
   （FOMA 与 MAHA 的 land_km 都 54 却相距 212 km）⇒ V=3.6 → 25.17（不是 30.89）、
   V=6.0 → 15.10（不是 18.53）。实测回收 −2.2% / +2.4%、dBAZ ≤ 0.3° = PASS。
8. **注入必须用解析子波**（高斯包络调制带内载波，包络峰精确落在 τ_i）；拿实测波形整体平移会把
   波包送出窗外（实测峰退化成近反源向）。
9. **两套计时口径不许并列成同一个量**：本子阵海段跨度 99.3 s ⇒ 逐台按上岸时刻平移等价于扣掉
   一个 **32.84 s/°** 的慢度场（与 T-S 信号同量级，`scripts/check_static_shift_slowness_bias.py` 复算）。
   图上/表里分别标 `abs (common axis)` / `land (per-station)`。
10. **判读基准按口径切换**：`abs` → 真实大圆 BAZ 均值；`land` → 陆段走时场梯度方位
    （本案例 124.7°，与大圆差 23°）。图上同样两条线：黑实线 = 本口径基准、灰虚 = 另一口径。
11. **beam txt 的 y 是降序**（+smax → −smax），reader 按文件出现顺序取；用 `np.unique` 升序会把
    方位镜像成 `180−az`（实测 40.98@160.2° 会被读成 @19.8°）。
12. **重建后必须与旧版重叠配置逐位对表**：本次 `M5_land_Z_main` = 旧 `S5_land_leg`
    (28.050@126.67)、`M5_abs_Z_main` = 旧 `S5_abs_rt65` (40.984@160.22)、
    `M5_abs_Z_long` = 旧 `S5_abs_rt65_500` (39.763@163.54)、`M5_land_Z_long` = 旧
    `S5_land_leg500` (25.732@122.30) —— 逐位一致才算「只改了结构没改数值」。

## 子阵扫描（用户要求“扫描测量符合台间距的子阵，再做一些”时的做法）

脚本：`00_params/scan_subarrays.py`。20 台可用集里枚举 k=4..8 的全部 **262599** 个组合，全向量化算指标。

**判据分层是关键**（本次头一版把分辨率地板/PCA 当硬门槛，结果把参照子阵 MAHA5 自己刷掉了）：

| 当**硬门槛** | 当**诊断量**（只报告、不筛选） |
|---|---|
| 带内频点 ≥3（不足则退到 500 s 长窗再算） | 分辨率地板 `k/(1-k)`，`k=1.28·d_min/D` |
| 孔径 `D ≤ 400 km`（平面波假设） | PCA 长短轴比（“≥3 才算二维”是经验值） |
| 台数 ≥5（coarray ≥10） | 各相位的 `\|∇t\|`（进 SMAX） |

事实依据：MAHA5 自身地板 **54%**、PCA **2.19**，但它测得 25.77 vs 理论 25.17（差 2.4%）⇒
地板是**几何最坏界**不是实际误差；拿它当门槛会得出“本事件没有可用子阵”的错结论。

**必须配一张逐判据审计表**（每个 k 下通过各判据的组合数）——本次它直接给出了结论：
决定性的约束是**孔径**（k=5 的 15504 个组合里只有 61 个 `D ≤ 400 km`；k=8 为 0），
因为岛内 20 台横向跨 1427 km，随机取 5-6 台几乎一定超平面波假设上限。
同时必须跑一条“参照子阵基线”行（把 MAHA5 自己当候选跑一遍），它是判据口径是否合理的唯一自检。

### 多子阵化暴露的 4 个新坑

17. **整台三分量“根本没同步”**：GE 网 `VOI` 的 Z/N/E starttime 相差 **8.65 s**、`SBV` 相差 **18 s**——
    拿它们做 NE→RT 旋转是错的。正确做法：取三分量**公共区间**（**最晚** starttime 起、最短 npts 止；
    旧代码用“最早 starttime”，对真同步差的台会错位），并对跨度 >0.1 s 的台**只出 Z**，
    下游对缺失分量跳过并记日志。
18. **通道码要归一**：II 网 `ABPO` 的 SAC 文件名是 `BHN/BHE`，但**头里的通道码是 `BH1/BH2`**
    ⇒ obspy `rotate('NE->RT')` 不认（旋转后仍是 BH1/BH2，断言失败）。旋转前把末位改成 N/E。
19. **注入标定脚本必须按该波束实际用的台站筛台**：台站台账变成全台站后，拿全表做 `\|∇τ\|`
    平面拟合会给出完全不同的期望值（实测把 PASS 变 du −40%）。台站名单从 beam 文件头解析。
20. **段指纹的容差与判据**：Seizmo `interpolate(...,'spline')` **本身**会把 mean\|dep\| 平滑掉
    0.5–2%（20 sps 输入也一样，不只是降采样才有）⇒ 固定 1e-3 容差会假报 CHECK。
    改用两个条件：幅度相对差 <5% **且** \|dep\| 互相关的**最佳对齐滞后 ≤1 样本**
    —— 滞后判据才真正抓“切窗错位”（真错位是几十~上百样本）。
