# F-K 台阵分析（Python 实现）

> **本流程定版模板（`templates/`）**：`fk_geometry.py`（**先跑**：由 `FK_VT` 现算 `u_pred`/`smax`/`spts`/`C`/分辨率地板/理论 BAZ）、
> `step3_fk_driver.m`（Octave + SEIZMO 引擎）、`step3_fk_demo.py`（慢度图 + 峰表）、`step3_fk_subarray_map.py`（子阵分布图）。
> 铁律：`smax = 1.4·u_pred`、`u_pred = 111.195/V_T`、`f_hi = min(F_MAX, C/smax)`，换地区只改 `FK_VT` 与 `FK_TWIN`。

区域台阵（T 波台网、地震台阵）F-K 波束形成分析全流程。基于 Seizmo `fk4d` /
Zhou et al. (2021) 思路的 Python 实现，2026-08 马达加斯加 Mw6.2 事件实战验证。

> **要复现旧盘上当年那批 f-k 图 / 判"这份老产物是哪次运行"**：读数与口径见
> `references/legacy-bfa-beamforming-artifacts.md` §7–§9——§7 窗口反解（零样本法 + 文件名扫描表 + 逐组合复跑对表）、
> §8 上新数据判读纪律、**§9 是已验证的精确复现口径**（2–8 Hz → `envelope`+`getspline(0.1)` → `frng=[1/1000 1/25]`，
> 缺包络、或把上界写成 1/33.3，峰就离开源向；**对照图的色标与配色也必须从原 `.fig` 抠**（`CLim` + colormap，别自己挑 jet），§9 末给了具体值与脚本）。从 `.fig`/`.png` 里挖当年的结果网格、窗、频带与子阵名单的通用方法见
> `seismic-paper-reproduction/references/legacy-artifact-excavation.md`——**反查参数前先读它，别拿脚本注释猜**。
> **新增子阵第一步**（台站信息表 + 双面板分布图，含几何口径与出图自检）：见 `references/subarray-station-map.md`。
> **报/画跨频带慢度图之前**先读 `references/octave-seizmo-fk4d.md` 的「频带合并方式决定哪个峰当第一」：
> `fkmap`（频点复数相干叠加）与 `mean(fk4d 体积,3)`（dB 平均）**不是同一种合并** —— 实测同一数据下前者给
> T-S 25.1 s/°@133°、后者给 T-P 11.5 s/°@144°；判相靠方位（T-P 方位 > T-S 方位），不靠慢度；
> 一张图要同时扫到两相则用相干/功率合并、`SMAX >= 35`。
> **fk4d 图"糊成一大片"时**（而不是去怀疑数据）按同文件「非相干合并为什么出一大片糊图」那节的顺序归因：
> 先算台阵平面波 PSF 排除几何 → 比两种合并下的 prom 与 −3 dB 面积 → 逐台 SNR → 包络各子带功率占比
> （最低子带常占 90%+ 功率，而它主瓣比图幅还宽）→ 无混叠频点票数（小慢度相位票更多，会翻峰位）；
> 另报"南北子阵"前先比对台号，老盘切片可能共用台站。
> 加新子阵/新事件时先读它，别重画：已定稿图的脚本可能已被移进该子阵的 `_superseded/`，以 README 的「图 ↔ 脚本」保留表为准。
> **把慢度结果往地图上放之前**先读 `references/fk-parameter-selection.md` §15：慢度峰只给方向与视速度、**不给距离**，
> 不能当成一个"点"（转换点）；两个子阵方位线交会的可用条件（基线/射程比 ≳0.3）也在那节。
> **报任何慢度峰读数之前过三关**：① 峰是否钉在网格边界 —— 判据看 `|x_peak|`/`|y_peak|` 是否顶到 SMAX
> （方格角点可达 `√2·SMAX`，所以"`|u| ≤ SMAX`"不够用；被截的峰换大网格会跳好几 s/°，`references/fk-parameter-selection.md` §4b-1/§9 判读第 1 条）；
> ② 图上那条理论方向线用的是**哪套到时场的梯度** —— 陆地计时图上不能画大圆 BAZ（实测可差 8°，同一子阵绝对/陆地两口径也可差 23°，`references/land-time-fk.md` §8.1/§9）；
> ③ 固定色标 `−0.7…0 dB` 下，比近零共模峰低 3–5 dB 的源向特征在图上**看不见** —— 先算落在色标范围内的网格占比
> （`references/fk-parameter-selection.md` §13d）。用户说"窗口选择这个你对比一下、选最好的一个出图"时，照 §13d 的判据表做，并把两处溢出报给用户。
> **报任何慢度峰之前先跑扇区读数**：`scripts/sector_peak_check.py <beam.txt> <理论BAZ> [扇区±°] [|u|下限] [理论慢度表]`
> —— 全图 argmax 常是非源向伪影，要把「理论 BAZ ±20° 扇区内最强局部极大」与全图峰、中位一起报；
> 慢度数值接近论文读数但 BAZ 差 90° 只算伪影（口径与实例见 `references/peak-reading-and-method-comparison.md` §5）。
> **报「这是/不是 X」这类判断时必须标出处**：① 有理论式子（给出可自己验算的公式链）；② 只是源码注释/代码行为（给 `文件:行`）；
> ③ 文献（给可查出处，如 Rost & Thomas 2002 式(30)/§[47]–[52]、NMSOP-2 Ch.9 §9.7、VanDecar & Crosson 1990、Cansi 1995）；
> ④ 以上都不是 = **本项目自己的做法/判断**，必须写明。用户会直接追问"有理论支持吗？还是源码注释过？你可不要自己判断"——
> 查不到就直说查不到，别把工程判断说成定理（例："孪生/mirror twin"曾被当成定理用，实为自造、已废，见 `references/estimator-direction-and-ambiguity.md`）。
> 方位/慢度估计器的口径与出处（滞后拟合的文献链、主瓣半宽系数 C 的三种定义、"滞后拟合不进判据"的裁定）见 `references/xcorr-lagfit-and-mainlobe-citations.md`。
> ⚠️ **"振幅沿距离衰减单调"不等于 "这簇台能做 F-K / 平面波拟合"**：前者是**径向**性质（各站从各自上岸点起算 τ_i = land_i/v），后者要求**同一个波前**。判法 = 把实测两两包络时差**同时**对各模型做残差 rms 对照：
> 径向 `(land_i−land_j)/v_S` vs 平面波 `u·Δr`（u 取 `111.195/v` 与实测滞后拟合值各一遍），残差小的那个模型才说明这组台的时差由什么决定。
> 实测（马达加斯加 Mw6.2）：`BAND BATG KIRI MAHA VOI`（land 54–616 km，跨度 562 km）径向 23.1 s、平面波 24.7 s/°@大圆 BAZ 39.2 s / @径向场向 36.5 s ⇒ **没有任何平面波模型能进 10 s**；
> 对照组 S5（land 54–199 km）：径向 7.8 s、平面波 24.7 s/°@124.7° **8.7 s**。同走廊去掉 BATG 的 `BAND KIRI MAHA VOI`（4 台，land 跨度仍 562 km）：D 465–469 km 仍超 400、coarray 仅 6 对 <10、线状 PCA 8.9 ⇒ 拟合 **|u|=78–79 s/° @ &nbsp;75.6°、du 37.8、dbaz 38.1**（横向零杠杆，数值不可用），而径向/平面波残差 18.6 / 29.0 s —— 去掉一台只少了一对最差的，没解决前提。该组另 D=502.7 km > 400 km 硬门槛、**未进 `coherence_rank_in_scanPASS.csv`**、逐对中位 cc 0.57（S5 0.80）。
> 结论：**陆段跨度大 ⇒ 同时否掉 F-K 与滞后拟合**（每台从自己的上岸点起算，时差由陆段长度差决定，拟合出的 |u|、BAZ 是计时场梯度而非入射方向 —— 别当物理量报）。点名组合的逐对明细样板脚本：`_superseded/2026-10-14_振幅距离与平面波拟合_废弃分支/from_3fk_2station_groups/lagfit_groups_check.py`（2026-10-14 用户指示归档，脚本内已改绝对路径、仍可复跑；import `screen_coherence` 复用同一口径，只把整池枚举换成指定组）。
> **镜像兄弟子阵的图件脚本时**：只改台站名单 / `OUT_NAME` / 窗与文案，**版位与配色一字不动**；交付前比一下两子阵同款图的
> PNG 像素尺寸是否相等 —— 相等即版位一致，不必看图（换数据源前先核时间基准：npz `time[0]`、SAC `b/o` 是否同口径）。
> **改版位或改图下说明块的文本后，凭脚本自查而不是看图验收**：出图脚本会打印 `未出框` / `与主图不重叠` /
> `色标在画布内`，三个都要 True（说明块行数 +1 就要跟着放宽 `subplots_adjust` 的上下界，否则块底掉出画布）；
> 像素级核对图上的标记时，掩膜要用**不透明**的那个元素（50% 透明的标记压在不同底色上颜色会变，同一张图上有的检出、有的漏）。

  ③ 里的波束数据一律放 `3_fk_results/beams/` 子文件夹（`beam_*.txt` 波束网格 + `fkinput_*.txt` 送检波形）
  —— 图就是它们的函数，不跟图放一处则图不可复现。
  ⚠ **适用范围：只管 F-K 目录内部**（用户 2026-09-29 明确）——上游 `raw/`、`0_data_processing/`、
  `1_station_distribution/`、`2_single_station_analysis/` **不在范围内**，只作数据来源被只读引用，不要顺手整理。
  重排路径时：每个脚本顶部统一写 `FKDIR = dirname(HERE)` + `DATA/GROUPS/RES` 三常量；
  `run_fk.py` 里的步骤路径必须用 `FKDIR` 拼（用 `HERE` 会指到 `3_fk_results/` 下面）；

  6 张表逐位一致、唯一差异是 `summary_fkmap.txt` 的 `elapsed_s`）。
- **换窗 / 换频带 / 换网格只改原脚本顶部「★ 参数区」，不许另存新脚本**：一个类任务只留
  ① 一个入口 `.m`（配置写成 `C(1)…C(n)` 列表 + `RUN_TAGS` 过滤变量只跑子集）

  （"换频带直接改参数不就好了，为啥会有这么多"）。新参数先想"加一行 C(n)"而不是"新脚本"。
- ⚠️ **入口脚本用 `'w'` 写 `summary_*.txt` 时，`RUN_TAGS` 只跑子集会把整份汇总覆盖成子集**（这份文件本来
  就是设计成只跑一两个 tag 用的）：跑前把旧汇总备份到 `/tmp`，跑后按 `(tag, comp, method)` 键把新行合并回旧表；
  新写的入口脚本，汇总一律用 `'a'` 追加、并给每行带 tag 列。
- **产物各留一份**：波束 `beams/`、日志 `log_<入口脚本>.txt`、汇总 `summary_*.txt`。迭代期产物归并回入口
  脚本后，旧脚本与旧产物移 `_superseded/<主题>/` 并写 `README_去向.md`（含"旧图 → 新图"对照表），
  不删除、也不并行留两套目录。
- 🔧 **报任何单频点/单网格的慢度读数之前，先跑 `scripts/beam_peak_check.py <beams 文件或目录> --baz <子阵理论 BAZ>`**：
  逐文件报到 峰位 / prom / **是否内部极大** / 离 x,y 边距离 / 源向锥内最强与相对 dB / 判定。
  `|u| ≤ SMAX` 只是必要条件：贴边（`|x|` 或 `|y|` 顶到 SMAX）或落在角点区都不可用；
  定/改 SMAX 前拿同一频点在两个网格下各跑一份对比（细则见 `references/fk-parameter-selection.md` §4b-1）。
- 🔴 **报"镜像 / 另一半 / 孪生"之前必须先判对称性**：本引擎（`fkvolume.m`）的 `abs(real(Σ_pairs C_ij w_ij))`
  在**求和之后**才取实部 ⇒ 保留台间时延方向 ⇒ `B(u) ≠ B(−u)`，对面那团**不是**必然的孪生；
  只有"只留互谱实部"的估计量才严格 `B(u)=B(−u)`。真孪生必须**同 |u|、方位 +180°**；实测近零慢度族常成对
  （±0.3–0.6 dB）而源向 30 s/° 量级的峰不成对（−4…−12 dB）。方位一律只认带符号滞后拟合。
  判定用 `scripts/check_estimator_symmetry.py`；证据链、五种估计量的注入对照、以及"怎么消除另一半"
  （`MASK=back/origin` 是呈现层，换频点/换窗才是物理层）见 `references/estimator-direction-and-ambiguity.md`。
- ⚠️ **波束文件名：无后缀 = center，`_coarray` / `_full` 才是对应方法**（与 `plot_landtime_fk.py` 一致）。
  出图/map 脚本默认要读 `{tag}_{comp}_coarray.txt`（项目默认方法）；读成无后缀等于把 center 的读数
  当默认报出去，与入口脚本打印的 coarray 读数对不上。翻转后缀约定会连带毁掉既有对比图的读法，别翻。
- ⚠️ **`RUN_TAGS` 只跑子集时，入口 `.m` 会以 `'w'` 整文件重写 `summary_*.txt`**（原有行被洗掉）
  ⇒ 先 `cp -p` 备份到 `/tmp`，跑完按 **(tag, comp, method)** 合并回写并核对行数。合并键必须正则解析
  （`\b([RZT])\s+\d` 取分量、`\b(coarray|center|full)\b` 取 method）：phase 列含空格、method 前一个 token 是 SPTS，
  按空格切 token 会把 SPTS 当分量，去重后每个 method 只剩最后一行。
- ⚠️ **同一 plotter 两种布局共用一份 `summary_*_maps.txt`（都以 `'w'` 写）**：单格集通常是并排集的超集，
  ⇒ `LAYOUT=single` 放最后跑，汇总才完整。
- 把某分量的口径复制到其他分量（同 tag 换 comp）、复算与合并脚本、方向锥读数与滞后拟合 rms 判据、
  换窗换带的合法频点自检：见 `references/landtime-fk-rerun-and-reading.md`。

## 出图与脚本纪律（每次都适用）

> ⚠️ 出图分两级：**过程检查图**（默认）只要 文字不重叠/不出框 + 轴带单位 + 字号可读 + 不覆盖原图；
> **期刊交付图**（尺寸/DPI/矢量/文字极简/降饱和配色）**只在用户点名“按期刊要求检查/修改图”时才做**。
> 完整定义见 `plotting-standards` skill 的「〇、出图规范分两级」。

- **迭代只改 ★参数区**：换频带 / 窗长 / 慢度网格 = 改同一个 `export_*.m` 顶部的配置表 `C(1..N)` 与
  `RUN_TAGS`，同一个 plotter 用 `WSET / ERANGE / NPEAK / PEAK_DBAZ / THEO` 环境变量选图；
  **同一个 `beams/`、一份 log、一份 summary**。被替换的脚本与产物移入 `_superseded/<日期>_<原因>/`
  并写 `README_去向.md`（旧图→新图、旧脚本→新入口逐条对照，不删）。每迭代一次就另存 `new2/new3` 脚本
  + 另一个 plotter + 另一个产物目录会被直接否掉（判据：用户会问"换频带直接改参数不就好了，为什么会有这么多代码"）。
- **不自造术语**：报数、图注、summary 一律用脚本里既有的标签；**不要给已有量另起名字**
  （把 `prom` 解释成"峰背比 / prominence"会被否）。图上不出现代码参数名（SMAX / SPTS / NPEAK），
  写 `grid ±17 s/°, step 0.35 s/°`，精确值留给图注。
- **出图后必须过规范自查（脚本层，不靠目视）**：`scripts/check_fig_text_overlap.py <出图脚本>`
  与 `scripts/fig_ink_margins.py <fig.png>`，迭代到「相交 0 / 出框 0 / 四边不贴边」；并排图
  **禁用 `sharey`**（各格范围不同会被压扁 + 刻度错标）、**先 `subplots_adjust` 再 `fig.colorbar`**、
  写 `/mnt/e` 的图**先写 /tmp 再 `shutil.move`**（drvfs 偶发 `OSError 22/12`）。
  细则见 `references/slowness-figure-paper-style.md` §1k / §1l；多峰读数与"一窗一带两能团"见
  `references/peak-reading-and-method-comparison.md` §2 / §6。

- ⚠️ **旧盘或别人留下的 F-K 产物不能直接当"论文结果"**：引用前先核四件 —— 时间戳、引擎、
  输入口径（原始带通 vs 论文的 **0.25 Hz 低通包络**）、台站子集 + 慢度单位；四项任一不同就只能写成
  "某次测试"，**不能写成"论文期参数"**（用户会当场纠正）。论文自己发布的数据包也可能只有波形、
  没有 F-K 产物与脚本 ⇒ 论文值只能从 PDF 图读或按口径重算。
- ⚠️ 第三方 bfa/Beamforming.pl 的 `fk_signal.out`：**表头报的峰来自引擎内部搜索，与网格 argmax 不是同一点**
  （实测差 0.6 个网格步长 / 7°），且**单位可能实际是 s/km 而表头自称 s/deg（差 111.19 倍）**；
  写入网格按其自身峰值归一（max 恒 = 1.000000）。解析格式、引擎默认参数（grid/slowness_max/theta）
  与"四项核对"表见 `references/legacy-bfa-beamforming-artifacts.md`。
- ⚠️ **可以把老引擎拉到本机跑，但必须先让它"逐位复现自己那份产物"**：用旧产物自带的输入
  （`fk_signal.dat`）+ 从产物表头反解的参数（频带 / `slowness range` / `grid_pts` / `unit_in_deg`）喂同一个
  可执行文件，表头与网格逐位一致才算引擎/参数/单位全部定死（本项目 13 行表头全同）；
  缺老运行时库时**先从旧盘自己的 root 卷取**（`<旧盘 root>/usr/lib64/libgfortran.so.3.0.0` → `libgfortran.so.3`
  + `LD_LIBRARY_PATH`），不要用新版库硬顶。沙盒、两个引擎的 stdin 接口（bfa 是**固定字段**格式，
  宽度写错会静默读成 0.000028 且网格全 0）、成本与并行方式见同参考文件 §6。
- ⚠️ **旧脚本的窗位先问"`-T begin/duration` 相对谁"**：`Beamforming.pl` 的 `begin` 相对 **SAC b**（文件起点），
  作者却常按 **o（发震时刻）** 的意图给值 ⇒ 两者差一个 `o`（本项目 325 s，窗整段落进发震前的噪声，读数退化成
  `quality 4` 的弱针尖）。反解办法 = 逐条数产物输入里的**开头零样本数** + 读切片头段 `b/o`（同参考文件 §7）；
  要跑"论文当年的意图窗"就按 `begin = o + 意图偏移` 传参，并在交付里标明这是修正口径版。
- ⚠️ **判"这个峰方向反了 / 不是震源方向"之前，先给该引擎做一次平面波注入检验**：老产物/切片头段里的方位
  可能是**另一端口径**（本项目 XA 台站真实 BAZ ≈ 137°，旧产物表头却写 313.4°），拿它当基准会把指向震源的峰
  误判成反向。注入已知 BAZ 与慢度的平面波、看引擎报什么（本项目注入 315°/10 s/° → 报 318°/10.6 s/°）
  ⇒ 约定确认后再判读；`|u| ≈ 0` 的针尖其方位本身无意义，不能拿它代表那次运行的方位。

0. **先拿到记录剖面图**（用户 2026-09-28 要求）：把步1 出的
   `process_flow/1_station_distribution/record_section_abs_land_3x2.png`
   （绝对计时 + 陆地计时 3×2，窗口默认 0–1800 / -1000…+500）copy 一份到**本步骤目录**，
   作为**圈定 F-K 分析时窗 / 选子阵**的参照图。出图脚本 `plot_record_sections_abs_land.py` 已自动 copy（缺图时手动 `cp`）。
   🔴 **目录名（2026-09-28 定）**：新事件 F-K 目录 = `process_flow/3_fk_analysis/`；既有事件仍是 `4_fk_analysis/`（本 skill 的 references 里出现的 `4_fk_analysis/...` 都是这些历史事件的实际路径，不要当成新规范）。
1. **选台阵/子阵几何**：Delaunay 三角剖分筛优质三角形（边长 60-400 km、面积>2000 km²、
   最小角>20°、质量=面积/周长²、SNR 均值排序）；大台阵先画台站分布图给用户确认
   - ⚠️ **筛选时必须同时按 SNR 硬阈值（本项目 8 dB）剔除台站，不能只看几何**（见下方
     "假象诊断三层排查"）；若某台站三分量 SNR 全部不达标，直接从候选站列表移除后重新跑
     Delaunay，而不是让它继续参与三角剖分再事后补救
2. **合成验证引擎**（改引擎后必做）：真实台站几何 + 宽带带通白噪声 + 已知 BAZ/v 平面波延迟，
   确认能精确恢复。❌ 单频正弦不行（白化后噪声频点主导）
   - ⚠️ **合成信号必须共享同一个源信号**（一个带通白噪声），各站只加不同延迟 τ=s·r（频域乘
     e^{-i2πfτ}），不是每站独立白噪声——每站独立噪声时各站相位不相关、补偿后无法相长干涉，
     合成验证会"假失败"（max/mean≈1.1 也恢复不出方向，容易误判为引擎有 bug）。共享源信号时
     注入 153°/3.6 km/s 可恢复 153.4°/3.99（方向准），但 max/mean 仍偏低（~1.4，理想平面波
     的峰本就不如真实数据尖锐），这正常，别据此怀疑引擎。
   - ⚠️ **共享源的"谱"必须 = 真实 F-K 输入的谱**（否则正演结果与"参数已定"不符、图也不像论文，
     用户会直接问"按理说你的正演应该和论文一样有那种明显的峰值团"）：真实输入（2-8 Hz → 包络 →
     0.25 Hz 低通）天生 DC 占优（**96-98% 功率 <0.03 Hz、σ_eff 0.019-0.029 Hz**），自造 σ=8 s 高斯
     包络只有 σ_eff ≈0.011 Hz ⇒ 峰-中值仅 2.8-3.4 dB（−3 dB 掩膜留半张图、看着"发花"），
     容易误判成"正演数据质量差"。做法：**直接拿真实包络波形当共享源**
     （`envelope_0.25LPF/envelope_lp_all_28/{STA}_env_lp.sac`，全长 8399 点、同时间基准），逐台频域小数延迟平移
     （`irfft(rfft(padded)*exp(-2j·pi·f·τ))`，线性平移不循环），其余参数一律不动（单自变量对照）——
     实测峰-中值 6.9-8.2 dB、主瓣 −3 dB 半径 ≈1 s/°、\|Δslow\| ≤0.23 s/°、\|ΔBAZ\| ≤0.3°。
   - ⚠️ **定正演参数前先读论文原文**：`pdftotext -layout <paper>.pdf` 查 Methods 的处理配方/频带
     （Zhou2021 正文写明"envelope 后 0.25 Hz 低通"、无子带；论文自述防混叠上限 0.25 Hz 反推
     v=53.5 km/s，与 T 波 4.5-8 km/s 自相矛盾 ⇒ 别照抄它的混叠论断）。论文图上的量值用
     `pdftoppm` 渲染 + 色度掩膜像素测量，不靠目测；参数一律分「论文给的 / 我们自选的」两栏交付。
     全部对照表与判读规矩见 `references/forward-modelling-calibration.md` §5。
   - **完整标定（9 组 case 矩阵 + 双引擎对照）见
     `references/forward-modelling-calibration.md`**：真实台站坐标 + 共享高斯包络 + `τ_i=−(s·r_i)`，
     慢度扫描 10→75 s/° × 方位扫描 0/90/180/270°，Python 与 fk4d 共用同一切窗输入（`03_fk_input/`）；
     实测 |Δslow| ≤ 2.68 s/°、|ΔBAZ| ≤ 10.1° 且三引擎 bias ≤ 0.52 s/°/1.64° ⇒ 这是"真实数据测不出峰
     不是代码 bug"的定量凭证。该文含：**每步都落可核对产物**的编号阶段目录组织（用户硬要求）、
     **跨引擎方位约定差 180°**（Python `atan2+180` / fk4d 不加）、**fk4d `s4d.beam` 已是 dB**、
     输入准备路径会动 fk4d 峰位、注入延迟要用互相关+抛物线内插校验。
3. **物理可行性检查**：最大台站延迟（孔径/v）必须 < 窗长，否则 FFT 循环移位时间混叠
   - **定量判据**：最大延迟 ÷ 窗长 < 0.5-0.7（留安全边际），比值接近 1 时相干能力急剧下降
   - ⚠️ **陆地计时（转换点）模型下判据换成「τ 展布 ÷ 窗长」**：τ_i = L_i/v 全为正、带一个共同偏移
     （偏移在台对互谱里抵消，不影响 F-K），用 max|τ|/窗长 会得到 1.2 / 1.65 的**假 FAIL**；
     判据 = (τ_max − τ_min)/窗长 < 0.7（实测 0.319 / 0.439 PASS）。报窗长与判据时写明用的是哪一个。
   - ⚠️ **延迟计算用陆地段地壳速度**（T-P: 6.0 km/s P波，T-S: 3.6 km/s S/Love波），不是
     水声速度 1.5 km/s——陆地转换后是体波传播。用错速度会高估延迟 3-4 倍。
     - **快速估算两步**：
       1. 算**最近邻间距统计**（每台站到最近邻的距离）：haversine 公式计算所有台站对球面距，
          每台站取 min(到其他站距离)，统计全体最近邻距离的中位数/均值反映典型间距密度。
          ⚠️ 不是"所有台站对的两两距离统计"（那是 n(n-1)/2 对，混淆了孔径尺度与局部密度）——
          用户说"台站间距"通常指**最近邻距离**，体现台站布设的空间密度。
       2. 对于三角形子阵，三条边中的**最长边** ÷ 对应波速（T-P: 6.0 km/s，T-S: 3.6 km/s）
          = 该窗的最大延迟；该延迟必须小于窗长（留 ≥30% 余量更稳）
     - **实测案例**（马达加斯加 Mw6.2，25 站岛内台阵）：
       - 全台阵最近邻间距：最小 35.7 km、最大 230.0 km、中位数 102.4 km、平均 111.1 km
       - BKTA/CPSM/AMPY 子阵边长：101.2 km（最短）、159.5 km（最长）、110.5 km（中间）
       - **T-P 窗延迟**（地壳 P 波 6.0 km/s）：最长边 159.5 km → 26.6s
         - 原 80s 窗：比值 26.6/80 = 0.33 → 物理可行（但实测仍失败，见 Welch/STFT bug）
         - 调整至 120s 窗：比值 26.6/120 = 0.22 → 留有充足余量
       - **T-S 窗延迟**（地壳 S/Love 波 3.6 km/s）：最长边 159.5 km → 44.3s
         - 原 80s 窗：比值 44.3/80 = 0.55 → 勉强可行
         - 调整至 120s 窗：比值 44.3/120 = 0.37 → 足够
       - **结论**：80s 窗对 T-P 延迟余量足够（0.33 < 0.5），但实测返回 0.00 s/deg 慢度假象
         是因为 **Welch PSD 丢失相位**，不是窗长问题。修复为 STFT 后应能正常工作。
   - 全阵列孔径大 → 用**对齐残差 F-K**（每站窗对齐到理论 T-P/T-S 到时，模型自洽→峰≈原点）
   - 或**子阵直接 F-K**（窗长 ≥ 2×最大延迟，6 站+120s 窗为马达加斯加甜点）
   - 扩大窗口只改善这一层（孔径/窗长比），对下面的 SNR 污染完全无效，别在错误维度调参数

## 假象诊断：三层排查顺序（孔径/几何合格 ≠ 结果真实，SNR 常是真正病灶）

子阵结果看起来像假象（弥散、栅瓣、峰不稳定/跨频段跳动）时，按顺序查，**不要止步于前两层**：

1. **孔径/窗长比**：最大站间延迟(孔径/v) ÷ 窗长 <1（留安全边际更稳）。只排除时间混叠一类假象。
2. **三角几何质量**：边长/面积/最小角/quality 达标。同样只是必要条件，不是充分条件。
3. **⚠️ 参与子阵的每站、每个所用分量的 SNR（最容易被忽略、但常是真正病灶）**：前两层全合格，
   仍可能整组假象——相位白化对每站"等权重"叠加，一个低 SNR 台站贡献的是噪声相位，会直接
   污染整组波束图，跟孔径/几何无关。诊断：把子阵里每站在用分量（Z/R/T）的 SNR 单独对照阈值
   （本项目 8 dB），任一站不达标，这组结果不可信，不管几何多完美。
   - 台站**只是用错分量**（Z 低但 R/T 高，见下方"Z/T 分量互补"）→ 换分量重跑即可救回。
   - ⚠️ **换分量要重建候选池、重新跑 Delaunay，不是给已选三角形套换分量**：Z 分量候选池
     排除的台站，到 R/T 分量分析时应该重新纳入候选站列表、按 snr_r/snr_t 阈值重新筛、
     重新做一遍三角剖分——不能拿 Z 分量选出的三角形直接照搬到 R/T 分析（会漏掉本该纳入
     R/T 候选池的 Z-弱-R/T-强台站，人为缩小候选池）。实测：马达加斯加 Z 候选池 20 站选出
     12 组，R 分量候选池扩到 21 站（放回 SBV/ZOBE/MMBE）后多选出含新台站的组（如
     BERG-ZAKA-ZOBE、BAND-KIRI-MMBE）。
   - 台站**三分量全低于阈值**（真噪声台站，如马达加斯加 BITY/BARY/MMBE 等）→ 换分量没用，
     必须从候选站列表剔除、重新做 Delaunay 选三角，可能要接受"该区域测不出可靠结果"，
     不要勉强凑数（2026-08-31/09-01 马达加斯加实测：只精确剔除确认为真噪声的 4 站
     BITY/MMBE/BAEL/BARY 后，Delaunay 重新选出 12 组几何+SNR 都合格的三角，比原来 6 组里
     含 4 组污染明显改善；⚠️ 剔除名单要让用户逐台确认，别自己扩大范围——曾一次性建议剔除 9
     站，用户纠正只要剔除其中 4 个，其余台站的判断留待单独核实）。
   - **可疑台站（SNR 很低甚至为负）先诊断"真弱"还是"到时/窗口错位"，别想当然归因**：
     2-8Hz 带通 + Hilbert 包络，在理论 T-P/T-S 窗内外都扫一遍，比较窗内峰值/噪声基线比
     （真弱信号该比值明显低于同批台站，如 MAJA 理论窗内峰仅噪声基线 2.8 倍，同批 BERG
     5.3、ZAKA 20），同时扫理论窗外有没有更强能量脉冲及其相对理论到时的偏移量。偏移几十秒
     量级可能是到时模型小误差；偏移几百秒量级的强脉冲大概率不是目标震相。两种可能都要
     经人工看波形图确认，不能只凭数值扫描结果下结论（该台站是否可用，等看图后再定）。
4. **⚠️ 三层全过≠结果可信：批量跑多个三角后必做"组内圆形一致性"检验**（2026-09-01 马达
   加斯加实测新增第四层）：孔径/几何/SNR 三层都合格的 12 组三角，批量出结果后仍有近半数
   单条偏理论>30°——3 站小三角本身角分辨力粗糙，不能只看"单个三角偏理论多少"判断真假，
   要按 (region, win, comp) 分组，用**圆形统计标准差**（角度周期性，不能用普通 std）衡量
   同一区域内多个三角形反演 BAZ 彼此是否印证：标准差 <15° 才算"组内一致"（哪怕整体偏理论，
   系统性偏差本身也是有意义信号，可能指向该区段转换点模型误差，不是测量假象）；
   30-40° 量级是常态型"勉强"，不代表流程错，只说明这组三角統計量太小、不该单独下结论；
   批量脚本建议输出结构：按 region 分文件夹 → 每个三角一个子文件夹 → Z/R/T×tp/ts 共6张图 +
   一张跨三角/跨分量/跨窗汇总 csv（含理论BAZ、反演BAZ、有符号偏差、v），再单独算圆形标准差，
   不要只看散点罗列的偏差表就下结论。
5. **⚠️ 第五层、且应最先算：batch 出图前先查"峰值显著性"（P.max/P.mean），不要只信
   peak_in_sector 返回的坐标**（2026-09-01 马达加斯加实测）——三层几何/SNR 都合格的 12 组
   三角，逐组算 `P.max()/P.mean()` 后发现**全部**落在 1.07-1.16（对照：真实尖峰该远超此
   量级），换算成 dB 后 100% 网格点落在峰值-3dB 以内，说明整张慢度图是一片平的"高原"，
   没有任何候选慢度明显更优——这解释了为什么第4层的组内标准差普遍在30-40°：不是统计量
   小的正常波动，是这批 3 站直接 F-K 在真实数据（非合成信号）上系统性测不出相干峰，
   `peak_in_sector` 依然会在扇区里挑出一个数值上略高的格点当"峰"，但那只是噪声地板上的
   随机极值，报出的 BAZ/v 数字没有物理意义。**诊断脚本**：见
   `scripts/check_peak_significance.py`，对每组三角算 P.max/P.mean 和"接近峰值(-3dB内)
   占比"，建议阈值：ratio<1.5 或 占比>10% 时标记"疑似假象/弥散"，不要出图前先过一遍这个
   检查，比事后看图省时间。
   - **⚠️ "合成验证通过"只验证了引擎在理想 SNR 下的数学正确性，不能反过来断言"这个台站数/
     几何在真实数据上必然测得出峰"**——本项目早期用 6 站+120s 窗合成信号（真实几何+人工
     注入已知方向的宽带信号）验证引擎成功，这只证明公式/代码没写错；后续换算真实数据时，
     若拿同样"6 站"配置去测，还要重新核验孔径/窗长约束（如换了台站组合、孔径变成 930km

### 判读与显著性（报数前的关）

- ⚠️ **包络 F-K 先测频带相干性**（2026-09-11）：包络主能帯只到 ~0.02 Hz，0.08-0.25 Hz 多为各台不相干噪声
  （相位残差 101-103° vs 相干帯 46-55°，合成对照 0.0°）；把噪声带算进 `FRNG` 会把图稀释成弥散

### 脚本（几何 / 参数复算 / 判读 / 出图自查，共 15 个）

- `scripts/check_array_geometry.py` — **单子阵几何体检**（命令行传台站名）：逐项判无混叠 `f <= C/SMAX`、分辨率 `Du = 0.61*111.195/(f*D)`、方位误差、几何地板、带内频点数、窗长 `T >= 1.5*D/v_app`、二维性 PCA、coarray 对数，给 PASS/FAIL；阈值是本项目经验值，对外报要标出处。
- `scripts/check_estimator_symmetry.py` — **报"镜像 / 孪生"之前的对称性判定**：判 `B(u)` 与 `B(−u)` 是否必然对称（本引擎保留台间时延方向 ⇒ 不对称），并给出真孪生的判据（同 |u|、方位 +180°）。
- `scripts/check_timing_convention_params.py` — **换计时口径（绝对/陆地）时 F-K 参数要不要改的复算工具**
  （只用标准库）：现算 `nsp/Δf/带内频点/f_hi/合法 SMAX`、陆地窗 `[min(L_land/v)−30, max+50]`、
  两口径 τ 判据，并判"两版是否同档 ⇒ 参数能不能沿用"。被问"都改用陆地计时是不是所有参数都要更新"
  或要并列两版参数数值时先跑它，别手算（参数地图见 `references/land-time-fk.md` §8）。
- `scripts/check_grid_radius_choice.py` — **慢度网格半径三档口径的复算**（只用标准库）：给窗长 / 采样率 / 频带 / `d_min`（或直接给抗混叠常数），打印 `Δf`、带内合法频点、`f_hi`、抗混叠上限、**"就近取整"与"向右取整"两个网格半径**（含各自 `SPTS`、`Δs`）、复制峰间距 `111.195/(f·d_min)` 与"是否落在显示半径外"、以及目标慢度装不装得下。用户说"不做慢度上限 / 就近向右取整"、或要报"网格取多少、为什么"时先跑它。
- `scripts/check_static_shift_slowness_bias.py` — **逐台时间平移的"等效慢度偏置"复算**（只用标准库，
  自带球面几何 + 平面拟合自检）：对 `ocean/v`、`land/v`、`dist/v` 各模式做最小二乘平面拟合，
  打印 `|u|`、方位、沿传播向 / 横向分量与拟合残差 rms，并给出"读数会被改掉多少"的解读。
  回答"陆地计时对齐 vs 震中距对齐""这个平移等效多少 s/°"时先跑它，别手算
  （数值与三种做法的性质差异见 `references/land-time-fk.md` §9）。
- `scripts/beam_peak_check.py` — **单个 / 整目录波束文件的峰体检**：逐文件报 峰位 / prom / **是否内部极大** / 离 x、y 边的距离 / 源向锥内最强与相对 dB / 判定（`|u| <= SMAX` 只是必要条件，贴边或落在角点区不可用）。
- `scripts/sector_peak_check.py` — **源向扇区读数**（用法 `<beam.txt> <理论BAZ> [扇区±°] [|u|下限] [理论慢度表]`）：全图 argmax 常是非源向伪影 ⇒ 要同时报「理论 BAZ ±20° 扇区内最强局部极大」与全图峰、中位。
- `scripts/peaks_table.py` — **波束多峰读数表**：列前 N 个局部极大（不只看 argmax）+ 与理论 BAZ 的差，贴边的峰标 OUT。

- `scripts/check_peak_significance.py` — 峰值显著性诊断（P.max/P.mean 比值 + 接近峰值占比），
  批量出图/反演前先跑一遍，别等看完慢度图才发现整组是弥散假象（见工作流第5层）
- `scripts/check_power_map_symmetry.py` — **功率图"有没有 ±u 镜像"的复核**（只用标准库）：对 beam txt 报
  全局峰/反极点 dB 落差与全网格 `max|B(s)−B(−s)|`。被问"那个反方向的峰是不是镜像"时先跑它

  窗位早 `|b|` 秒"（陆地计时 100 s 的坑）。怀疑某族读数整体塌到近零慢度/方位反向时先跑它。

  像素，报顶部/底部留白与**内部空白带**占图高百分比（标题↔内容应 ≤2%）。用户反复提"表头/
  空白太大"，方形面板（`set_aspect("equal")`）落在偏高的子图槽里居中时最易中招；改
  `figsize` / `ax.set_anchor("N")` / `subplots_adjust(top=…)` 后复测一次。
  另有**矢量级 bbox 自查**（改版式后立刻跑，比像素快且能定位到元素）：`fig.canvas.draw()` 后取
  `fig._suptitle.get_window_extent(renderer)`、**各 `ax.title`（面板标题，与 suptitle 比对最易出问题）**、
  `fig.axes[0].get_legend().get_window_extent(renderer)`、

  并核对 `fig.canvas.get_width_height()` 的宽高比（1:1 方图应 ≈1.000）与 `ax.get_xlim()`。
  视觉模型被关掉时，标题/图例越界只能靠这个 + 回头核坐标逻辑兜底。
