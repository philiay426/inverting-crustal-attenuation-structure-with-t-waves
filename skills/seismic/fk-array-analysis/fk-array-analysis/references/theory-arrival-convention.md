# T-P/T-S 理论到时的算法口径（复现论文时必须先对齐）

适用：任何要在剖面/包络图上画 T-P、T-S 到时线，或据其开偏振窗、F-K 相窗的事件。
一句话规则：**论文式 (1) 的陆地段是恒速近似，我们的 `tt_t()` 陆地段走 TauP ⇒ 同一台站系统性偏早 20-25 s。**

## 两套口径的定义

| | 海水段 | 陆地段 |
|---|---|---|
| 论文式 (1)（Zhou 2021 Eq.1） | `L_ocean/1.48` | **恒速** `L_land/6.0`(P) 或 `L_land/3.6`(S) |
| 我们的 `t_phase_analysis.tt_t()` | 同（`ocean_deg→km /1.48`） | **TauP(iasp91) 走时**，仅 NaN 时回退到 6.0/3.6 |

- 代码位置 `t_phase_analysis/traveltime_profile.py`（`_get_first_taup_arrival_time(..., phase='S')`；
  `if np.isnan(...): segment_time_s_s = segment_distance_km / vel_s`）。
- ⚠️ **`vel`/`vel_s` 参数只在 TauP 回退时生效** ⇒ 想强制恒速必须改代码或在上层覆盖，光传参没用。

## 量化（SA18，land 626 km ≈ 5.63°，ocean 1626 km）

| 项 | 论文恒速 | 我们 TauP | 差 |
|---|---|---|---|
| 海水段 | 1626/1.48 = 1098.6 s | 同 | 0 |
| 陆地段 P | 104.3 s（6.00 km/s） | 83.7 s（等效 7.48 km/s） | −20.6 s |
| 陆地段 S | 173.9 s（3.60 km/s） | 149.5 s（等效 4.19 km/s） | −24.4 s |
| **T-P 总** | **1203.0 s** | **1182.4 s** | −20.6 s |
| **T-S 总** | **1272.5 s** | **1248.2 s** | −24.3 s |

机制：626 km 是**水平**距离，TauP 走的是折射/上地幔快层（Pn/Sn 型），平均速度自然高于 6.0/3.6。
差异**只来自上岸以后的陆地段**，与距离划分无关（两套都用同一 track 的 land/ocean 距离）。

## 校准标尺：用 T-S 包络峰判口径，别用 T-P

SA18（2-8 Hz 带通 → |Hilbert| → 6 s 滑动平均包络，实测）：

- **T-S 是宽包**，内峰 1261 / **1278（最高）** / 1298 / 1313 s：论文式 1272.5 s 落在最高峰（**93% 峰高**），
  TauP 式 1248.2 s 只在上升沿（**63%**）⇒ 论文口径更贴观测。
- **T-P 邻域有两个小峰** 1182.7 s（36%）与 1207.6 s（48%）：TauP 式落在前一个、论文式落在后一个
  ⇒ **T-P 上"线落不落在峰"区分不了口径对错**；且 T-P 段能量本就弱（论文亦称 T-P 只明显见于 Z/R），
  不要拿它当校准标尺。
- ⇒ 排到时时序/开窗前，先按上面的表说明两套口径差多少秒，再决定用哪套。

## 平滑窗长的量化（判"线是否落在峰上"前先固定平滑）

- 0.25 Hz 四阶零相位低通 ≈ **3.1 s** 等效平滑尺度（ENBW 折算；单向因果实现上升时间 1.55 s）。
- 6 s 矩形滑动平均 ≈ 6.9 s 等效尺度；粗峰度指标（相邻点差分 RMS ÷ 峰值）6 s 平滑 vs 裸包络差 ×14.9。
- ⚠️ **平滑窗长直接改变上面的落点判据**：同一 SA18，6 s 平滑 → 论文式 T-S 落在 93% 峰高；
  **3 s 平滑 → 峰变尖变高（1278.0→1279.6 s），线只到 73% 峰高**。切平滑窗长后必须重报这一项，
  别沿用上一版"压在峰顶"的说法。

## 口径命名（按用户的说法，别自己换词）

- 我们的这套 = **"投影走时"**：代码里的"投影"指 `traveltime_profile.py` 用 `pygmt.project` 沿
  震中→台站大圆路径**投影取点**生成地形剖面，再切海洋段/陆地段分段累加（海洋段 1.48 / 陆地段 TauP）。
  用户会纠正"论文不是用的恒速，我们用的投影走时"——因此答话时用这个词，不要把我们的口径只称作 "TauP"；
  说"论文用恒速"时也要限定为"**陆地段**恒速"（海水段两套完全相同）。
- 论文的这套 = **恒速式**（陆地段 `L_land/6.0` 或 `3.6`）。

## 切换方式（试验变体不得污染数据文件）

- 作图级：`process_image.py --tt-paper` —— 用 `ocean_km/1.48 + land_km/6.0(或 3.6)` 覆盖
  `arrivals['T-P']/['T-S']` 后重画，**不动 stations.csv / npz**（配 `--out-suffix` 出新文件名）。
- 作图级（两套画在同一张图）：`process_image.py --tt-both` —— 以**射线理论（stations.csv）为虚线**、
  **论文恒速式为点线**（同色系：红 T-P / 蓝 T-S），图内右上用**英文**注记两套时刻值（图内不放中文，
  避免字体缺字）；两套线的间距可直接读图（SA18：T-P 差 20.6 s、T-S 差 24.3 s）。
- 数据级：给 `tt_t` 加"陆地段用恒速"的开关后重跑 `step1_compute_arrivals.py`，并**重跑全部下游**
  （剖面到时线、偏振窗 ±25 s、F-K 相窗）——相窗会整体后移 20-25 s，旧窗的结论不能照搬。
- 报口径按「论文给的」/「我们自选的」两栏写：论文给了恒速 1.48/6.0/3.6，TauP 是自选。
