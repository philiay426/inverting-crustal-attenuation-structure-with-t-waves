# F-K 峰显著性判据直接出图（fk8 约定，2026-09-02 马达加斯加实测）

## 背景：真实数据直接 F-K 系统性测不出相干峰

用相位白化 Bartlett 引擎（direct_fk：每站每窗 FFT → X/|X| → 频域波束 P(s)=Σ_f|Σ_i e^{+i2πf s·r_i}·X_i(f)|²）对马达加斯加 2013-08-17 Mw6.2 真实记录批量反演，无论台站数量/区域/分量/窗口，全部得不到显著峰：

| 批次 | 子阵 | sig_db（峰高-扇区中值） |
|---|---|---|
| 12triads 6 组 | 3 站三角（含 BKTA-CPSM-FOMA 等） | 0.3–0.8 dB |
| multista 3 组 | 5–6 站长窗（South/Central/North） | 0.2–0.7 dB |
| 中部 5 站（新增） | ABPO-BAND-BATG-KIRI-VOI | 0.4–0.5 dB |

谱面全平面动态范围仅 ~1.8 dB、>−6 dB 像素占 100%、−6 dB 内局部极大 ~700 个——
即整张慢度图是平的"高原"。合成验证（强相干宽带平面波）能出峰（max/mean>3），
证明引擎没写错：**是真实记录窗内没有跨台相干平面波**（陆地散射/多径 Love 波列 +
2-8 Hz 横向相干尺度远小于站间距）。直接 F-K 绝对 BAZ 对这套数据不可用。

## 判据（写进结果图，不做事后再看）

扇区 = 理论 BAZ±45° 且 v<11 km/s（mask 排除慢度原点奇点）内：

    sig_db = 10·log10(P.max() / median(P_sector))   # 峰高相对扇区中值

- sig_db ≥ 3 dB → 显著峰：画红星、summary 填 baz_peak/baz_dev/v_kms
- sig_db < 3 dB → **不画红星**、baz_peak/baz_dev/v 置空、图上标 "no significant peak"

⚠️ 教训：summary 里 baz_dev 小的行（如 BKTA-CPSM-FOMA Z/tp dev=-8.1°、v=3.84 km/s
看似合理）是平坦扇区内 argmax 噪声点的**巧合**——`peak_in_sector` 总会在扇区返回
某个数值最大格点，没有显著性门槛时会把噪声地板当检测结果。任何"BAZ 贴理论线但图上
没有亮点"的慢度图都按此处理：假象，不可信。

## 判峰前置检查：三类假峰优先排除（2026-09-14 分频带实测）

在宽网格（如 SMAX=78 s/°）上直接取 argmax，先撞上的往往是**假峰**。G1 三段带扫
（[0.005 0.03]/[0.03 0.08]/[0.08 0.25] Hz，coarray，win [1173 1386] s）实测：

| 带 | f̄ | 混叠周期 Δs = 111.19/(f̄·d_near) | argmax | = n·Δs | 0 慢度处 | 理论点 24.7@126.4° |
|---|---|---|---|---|---|---|
| b1 | 17.6 mHz | 62.6 s/° | 64.5 @22° | 1.03× | −2.79 dB | −4.25 dB |
| b2 | 54.7 mHz | 20.1 s/° | 65.4 @294° | 3.25× | −3.37 dB | −2.31 dB |
| b3 | 166 mHz | 6.6 s/° | 78.1 @58° | 11.8×（网格边缘） | −3.38 dB | −1.80 dB |

⇒ **0 慢度（各台近似同时到达的公共模式）始终是谱里的最强特征，它的周期性混叠像在宽网格上会超过真实峰**。
规则：读图前先排除 ① 0 s/°；② 半径 Δs = 111.19/(f·d_near) 整数倍的混叠像；③ 网格边缘（|s| 近 SMAX）。
剩下的才是真候选。另外：**不要把“慢波在高频折叠到小慢度”当成必然**——本例 b2 的 4.57 s/°（−3.12 dB）
与 b3 的 −1.83 s/°（−2.92 dB）都不是峰；全带下那个 4.1 s/° 更像针尖+高原的混合产物。
参考：`4_fk_analysis/fk_code_octave/run_fk4d_bandscan_G1.m`、`plot_bandscan_G1.py`。

## 多峰时怎么定峰（2026-09-13 多峰正演实测，fk4d coarray）

背景：程序里一律 `argmax`（全局最大）——多峰时它只挑最高的那个，既不告知有几个峰也不判真伪。
用正演把多峰情形做出来（两相位不同 BAZ / 同 BAZ 不同慢度 / 等幅与不等幅 / 单波前多驼峰）后得到：

| 情形 | 结果 |
|---|---|
| 单脉冲基线（同一判据） | argmax 命中真值，但 `sig_sector` 仅 **2.71 dB** |
| 单波前 + 3 个驼峰源信号 | argmax 命中，`sig_sector` **4.18 dB**（最高），4 个显著候选簇在真值附近 |
| 双相位等幅、BAZ 不同 | argmax 只高 0.55 dB 就落在其中一个上（**噪声决定**）；另一个相位虽在候选表里但不会被报出 |
| 双相位 2:1 / 4:1 | argmax 稳定落在强相位 |
| **同 BAZ、不同慢度** | 两相位在同一条射线上干涉，慢度图退化成高原（前 8 候选只差 0.36 dB），argmax 落到**射线外且象限相反**（34.1 s/° @318.3°，真值 18.5/30.9@126.4°）|

规则：
1. **阈值必须同口径标定**：上面 3 dB 阈值是拿真实数据“平坦谱 0.2–0.8 dB”定的；合成口径下单相位基线就只有 2.71 dB。
   先跑一个**已知真值的单相位基线**，取「基线 sig × 1.2–1.5」作阈值，不要直接搬 3 dB。
2. **不要只取 argmax**：`maximum_filter` 取全部局部极大（设最小间隔），逐个算 sig_sector/sig_ring 后全部列出。
3. **同 BAZ 多峰 = 多路径/频散信号**：用**子窗/子频带**把相位分开（两脉冲相隔 100 s 时，各 100 s 子窗
   分别 F-K 即可各得一峰），不要在同一窗里硬找。
4. **物理约束**：BAZ 与理论/直达方向一致；`|s|` 换算视速度在 1.43–8.1 km/s（13.9–77.8 s/°）。
5. **波形多峰 ≠ 慢度图多峰**：只要属于同一波前（同 BAZ/同慢度），多驼峰波形仍给出单一干净峰。
参考实现：`4_fk_analysis/synth_forward/06_multipeak/`（`gen_multipeak.py` + `run_multipeak.py` + `peaks_multipeak.csv`）。

## 对用户的表述建议

- 直接 F-K 对该事件岛内记录不可作绝对 BAZ 证据；能写的 F-K 结论 = 合成验证（引擎正确）
  + 对齐残差 F-K（T-S 对齐残差≈0 → 走时/转换点模型自洽验证）
- 若救绝对 BAZ：120s 长窗 + 6 站密集子阵 + 窄带 2-4 Hz + 先做跨台互相关诊断
  确认存在可用相干波前再上 F-K
