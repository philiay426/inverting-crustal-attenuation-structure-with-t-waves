# 包络 F-K 的频带相干性（先测相干性，再决定频带）

适用：对**包络**（2-8 Hz 带通 → Hilbert → 0.25 Hz 低通）做 F-K/波束形成时。
教训来源：Zhou et al. (2021) 南非 XA 复现（2026-09-11）—— F-K 图一直"平"，最后发现是频带上限把噪声带算进去了。

## 0. 先确定"是哪个包络"：三条链路的身份卡（+ 反查方法）

项目里「包络」不是单一产物，被问"这个包络是怎么计算的"时先对号入座——三者的滤波/平滑/采样率/时间基准都不同：

| 用途 | 产物 | 链路 | 采样率 | 时间基准 |
|---|---|---|---|---|
| **F-K 输入** | `envelope_0.25LPF/envelope_lp_all_28{,_R,_T}/{STA}_env_lp.sac` | 去响应速度 → obspy `bandpass(2-8 Hz, corners=4, zerophase=True)` → `obspy.signal.filter.envelope`（≡\|Hilbert\|）→ `butter(4, 0.25 Hz)+filtfilt` → 每 10 点抽 1 | 2 Hz | `b=0`、`o = ORIGIN − common_start`（**全台共用同一 starttime** = 最晚者） |
| **剖面/偏振** | `sacprocess/envelope/{STA}_envelope_2-8Hz.npz` | `butter(4,[2,8])+filtfilt` → `\|hilbert\|` → **6 s 滑动平均**（矩形核） | 20 Hz（不抽取） | npz 自带 `time` 数组（`t_off`） |
| **正演标定** | `synth_forward/*/{STA}_env_lp.sac` | 解析高斯驼峰按 BAZ/慢度注入 τ 后相加 + 噪声（**非 Hilbert 包络**） | 2 Hz（与 F-K 输入同格式） | 同上 |

- 🔴 **三条不可互换**：F-K 输入是"0.25 Hz 低通后的解调量"，**不能拿去算 SNR/频谱**（得到的是与 2-8 Hz 波形无关的低频分布）；npz 是 6 s 平滑、通带到 ~0.17 Hz、20 Hz 采样，**直接喂 `fk4d` 就是采样率+频带两重口径错**。要 SNR/频谱一律回到**去响应未带通 SAC**。
- **反查"这个包络是怎么算的" = 从源头 SAC 按候选链路重算，与存盘逐点比对**（与"这张图用哪个 method"同法）：只有 `max|diff|` 落在浮点量级的那条才是数据源。实测：F-K 输入链重算 vs 存盘 `max|Δ| = 8e-16`（相对峰值 4.6e-8）；npz 链 ~1e-12（相对 ~1e-4，来自 SAC 以 float32 落盘）。⚠️ **别凭脚本名、docstring 或 mtime 断言**——脚本常在导出之后被改过。
- 🔴 **更省的闭环自证：文件里存了上游数组时，用"它的上游重算它的下游"，不必回原始 SAC 重跑整条链**：
  `sacprocess/envelope/*.npz` 同时存了 `waveform_{z,r,t}`（带通后）与 `envelope_{z,r,t}`，直接验
  `np.abs(hilbert(npz['waveform_z'])) == npz['envelope_z']` —— 实测 **`max|Δ| = 0`（逐点完全相同）**；
  平滑版同理 = `np.convolve(无平滑包络, np.ones(120)/120, mode='same')`，也是 `max|Δ| = 0`。
  ⇒ 这比"从源头 SAC 重算"更快、且不含 SAC float32 落盘的 1e-4 级残差，是回答"这个包络怎么算的/是不是 Hilbert 包络"的首选证据。
- **`scipy.signal.hilbert` ≡ Seizmo `envelope.m`（同一构造，可自证）**：按 `1+sgn(ω)` 手写乘子后
  `abs(ifft(fft(x)*h))`，与 `np.abs(hilbert(x))` 差 **~1e-23（浮点级）** ⇒ 我们 npz 链的包络定义与论文点名的
  工具箱完全同源，唯一差别就是后面那一步平滑。被问"是不是希尔伯特变换的包络"时给这个数字，比口头断言硬。
- ⚠️ **FFT 实现的 Hilbert 隐含"首尾相接"周期性假设**：`scipy.signal.hilbert`（以及 Seizmo 那份）在记录**两端**
  有边缘伪影。6 s 平滑把它压掉，无平滑版（`--env-smooth 0`）会露出来 ⇒ 用无平滑包络做时间轴首尾附近的
  统计/判读前先知道这一点，别把它当成信号或数据缺陷。
- ⚠️ **存盘包络可能含极小负值**（`filtfilt` 数值噪声，实测 `min = −3.7e-12` = 峰值的 2e-4）：别用 `(data>=0).all()` 当合法性判据，会莫名判失败；看相对量级。
- ⚠️ npz 链的 6 s 滑动平均用 `np.convolve(..., mode='same')`：**两端零填充**，首尾各 ~3 s 的包络被系统性压低（不是无偏滑动平均）。中段无影响；一旦某张图/某个统计量用到时间轴首尾（t_off 起的 −600 s 附近或数据末端），先想到这个偏差。
- 频带旁证（F-K 输入包络，去 DC 后能量）：0.001-0.05 Hz **89%**、0.05-0.08 **2.5%**、0.08-0.25 **8.2%**、>0.25 **0.3%** ⇒ 与第 1 节铁律一致：真正相干的是 <0.08 Hz 那一段，0.08-0.25 Hz 的 8% 能量是各台不相干噪声。

- **被问"这三个包络文件夹是过了 0.25 Hz 滤波的吗"给两个证据，不必重跑整条链**：
  ① 读生成脚本参数区（`ENV_LP_HZ = 0.25` / `LP = 0.25` 配 `butter(4, LP/(0.5·sr), 'low')` + `filtfilt`，
  文件名 `*_env_lp.sac` 的 lp 就是 lowpass）；② 量**谱的滚降**（Welch，以 0.005–0.05 Hz 均值为 0 dB）：
  0.05–0.15 Hz −10~−12 dB、**0.25–0.35 Hz −24 dB**、0.5–0.7 Hz −68 dB、0.8–1.0 Hz −101 dB
  ⇒ 拐点以上 ≈ **−48 dB/oct**，正是 4 阶 Butterworth 再 `filtfilt`（双向 = 等效 8 阶）的签名。
  结论模板："是 0.25 Hz 低通后的解调量，F-K 可利用的频率上限就是 0.25 Hz"（与论文口径一致）。

## 1. 铁律：别把"不相干频带"算进波束

包络的**主能帯**只到 ~0.02 Hz（波包宽 60-90 s ⇒ 1/60 s）。高于该频段的部分（0.08-0.25 Hz）对多数台站
是噪声与仪器尾流的叠加，**各台相位互不相干**；把它们计入 `FRNG` 会把相干信号稀释掉，图就变成弥散。

实测（G1 七台，T-S 窗，逐台对互谱相位 vs 平面波预测 `-2πf·s·Δr` 的残差 RMS）：

| 频带 | 实测相位残差 | 合成对照（注入真平面波） |
|---|---|---|
| 0.005-0.08 Hz | **46-55°**（部分相干） | 0.0° |
| 0.08-0.25 Hz | **101-103°**（等同随机） | 0.0° |

改 `FRNG=[0.005 0.08]` 后，同一数据的显著度从 ~2.9 dB 跳到 **4.6-7.3 dB**（圆亮尖峰），
20-35 s/° 环带内出现与论文读数一致的峰（24.5 s/° vs 论文 24.7）。

**机制（为什么频带上限越界 = 稀释，不是"数据没信号"）**：`fkvolume.m` 的频率循环里先做
`cs = data./abs(cs)` —— **相位白化**，把每个频点、每台都抬成单位振幅，再互谱并相长叠加。
于是混进来的**纯噪声频点与真实相干频点权重完全相同**，只是相位随机会被稀释 ⇒ `FRNG` 上界一旦
越过相干带，图必然趋平。**别在这时候去改 SMAX / SPTS / 窗长**（那是错误的调参维度），先量相干带。
同一白化还决定了两件事：`beam` 存盘前被 `beam - max(beam)` 归一 ⇒ **0 dB = 峰值**，所以
"峰 − 背景中值"才是有意义的显著度判据（在 dB 归一化数组上算 max/mean 会 <1，两种判据不可比）。

## 2. 诊断配方（`diag_phase_coherence.py` 型）

对每个台对 (a,b)、每个频点 f，算 `C=X_a·conj(X_b)`，与平面波预测相位
`φ_pred = -2πf·(s·Δr)`（s 指向震源、模 1/v；生成器约定 `τ_i=(u·r_i)/v, u=-(sinB,cosB)`）比较；
功率加权后拆两个统计量：相位残差 RMS（应 <40° 才叫相干）与圆集中度残差
`acos(|Σ w·e^{iΔφ}|)`。**必须用已知平面波的合成做对照，残差应≈ 0°**：否则诊断本身有符/向错
（本次就是一个符号错让合成对照也报 104°）。

## 3. 不要把"平图"当成"数据没信号"

平 F-K 图的可能原因（按检验顺序）：
1. **频带选错**（本节）；2. 窗长/分辨率不足（见 `sliding-window-aliasing-limit.md`）；
3. 真的不相干；4. 代码 bug。

必须用**独立方法**交叉验证数据里到底有没有信号：
- ⚠️ **不要用"逐台以理论到时为中心开窗"的质心/峰**做平面波拟合——质心会被窗中心"吸"过去，
  人为造出 R²≈0.99、慢度≈理论值的假相关。**必须全台用同一个绝对窗**。
- 可用的无偏统计量（三套互相独立，一起给）：同时窗下的①包络峰时间、②能量质心、③台对互相关时差。
  Zhou2021 实例：三套分别给 30.7/18.5/20.3 s/°（G1）与 30.8/17.7/30.2（G2），R² 0.60-0.97，
  与理论 30-31 s/° 同量级、方位与理论 BAZ 一致 ⇒ 信号确实存在。
- ⚠️ 长窗上的互相关容易被"共同包络形状"（长尾、尾波）主导而给出 ≈0 的时差——
  早期因此错误得出"各台几乎同时到达、无平面波"，后续修正。交叉验证时务必看**跨度**是否接近理论跨度。

## 4. 论文口径核对（Zhou2021 可验证的硬指标）

- **论文的"预测慢度" = Δ(Eq.1 走时) / 子阵最大基线**（不是 |∇t|）：G1 T-P 算得 13.8 s/°
  vs 论文 13.7；G2 13.4 vs 13.7 ⇒ 子阵与几何对得上。Eq.1 梯度 |∇t| 更大（17.7 / 30.2 s/°，
  G1），两者差在"基线方向与梯度方向的夹角"。
- 论文 Fig 4b/4d 是**一张图两个团**（T-P_local + T-S_local 同现）⇒ F-K 窗必须是**两相并集窗**，
  不是分开的两个单相窗。
- 论文用 −1000 m 等深线做 T 波参考时刻、垂直分量包络、低通 0.25 Hz；窗长/smax/spts/method 未公开。

### 4a. "论文有没有说几秒平滑 / 包络怎么算" —— 答案：都没有（先查原文再答）

被问"论文里提到了什么参数吗"时**不要凭印象答**：把 PDF 文本提出来 grep 关键词，**命中与零命中都摆给用户**。
提文本用绘图环境里的 pymupdf（`import pymupdf`，`page.get_text()` 拼全文；`fitz` 别名已废弃），
正文与附件（SI）分别提；关键词清单 `envelop / smooth / moving average / second / Hilbert / analytic /
decimate / downsampl / band-pass / low-pass`，逐条 `grep -n -i`。

Zhou et al. (2021) 正文（11 页）+ SI（8 页）实测结果：

- `smooth`、`moving average`、`second`、`Hilbert`、`analytic`、`decimate`、`resample` —— **全部零命中**。
- `envelop*` 仅 4 处，**全是结果描述、无一句方法**：图 2 图注 "(d) enveloped waveform data"；
  §3.1 "The envelope for the filtered seismograms is shown in Figure 2d"；§3.2 "three-component
  enveloped seismograms"；§3.2 "applied a low-pass filter of 0.25 Hz to the enveloped vertical
  component seismograms"。
- ⇒ 论文给出的包络相关参数**只有两个：滤波带 2–8 Hz、包络后低通 0.25 Hz**；滤波器类型/阶数/因果性、
  包络定义（Hilbert 还是绝对值）、**平滑窗长一个都没写**。图 2c→2d 就是 2–8 Hz 波形 → 包络。
- ⚠️ 别把论文里的 **25 s** 当平滑窗：那是偏振分析窗（理论到时前后各 25 s）；SI Text S2 里的窗口是衰减 coda 窗。

**出处链只有一级，且止于"envelope"这个词**：论文 §3.2 把 F-K 预处理明确归给
Matsumoto et al. (2016) 的 *three-step preprocessing technique*。该文
（GRL, doi:10.1002/2016GL071425）是 **closed access**（Semantic Scholar `openAccessPdf.status=CLOSED`、
Unpaywall 无 oa_location；Wiley 页面被 Cloudflare 拦）。但**同作者组的公开会议摘要写明了三步**：

> (1) high-pass filtering above 1 Hz to retrieve the T-phase → (2) extraction of the envelope →
> (3) low-pass filtering below 0.4 Hz（Tohoku 版用 0.375 Hz）

（来源：EGU2016-11837、AGU 2016 `2016AGUFM.S34A..04M`、CTBTO S&T 2017 poster）。
⇒ 即使在这一级来源，"取包络"仍只是个词，**同样没有包络算法和平滑秒数**。
**更硬的落点：论文自己点名的工具源码**。Data Availability 写着"The code **SEIZMO** … is used for data
preprocessing and F-K analysis. MATLAB … GMT … were used to generate figures." ⇒ 包络算法不必靠猜，读 Seizmo 源码即可定案（本地那份与论文同源）：

- `solo/envelope.m`：包络 = **频域解析信号取模** —— 构造乘子 `h`（奇数长 `h(1)=1, h(2:(n+1)/2)=2`；偶数长 `h([1 n/2+1])=1, h(2:n/2)=2`，即 `1+sgn(ω)`），`dep = abs(ifft(fft(dep).*h))`，数学上等价于 `|Hilbert|`；
  **函数签名 `envelope(data)` 里没有窗口/平滑参数，代码里也没有任何平滑步骤**（Feb 2012 起无零填充）；文档还提醒 "Make sure to remove the trend/mean beforehand!"，正对应论文那句 "After removal of the trend and mean value"。
- `fk/` 全部 60 个文件（`fk4d.m`/`fkvolume.m`/`fkmap.m`…）grep **零命中** `smooth`/`envelope`/`lowpass`/`iirfilter` ⇒ **F-K 引擎内部不做任何预处理**，输入完全由使用者准备（所以"预处理链"只能从论文正文/我们自己的脚本来定）。
- Seizmo 确实自带平滑工具（`solo/slidingmean.m`、`slidingabsmean.m`、`slidingrms.m`、`slidingfun.m`），但**窗宽 `n` 是必填参数、没有默认值**，而论文从未提及用过它们。
- ⇒ 论文口径下"预处理阶段的包络" = **2–8 Hz 波形的 |解析信号|，零平滑**；唯一的平滑就是那一步 0.25 Hz 低通（只作用于 Z 分量包络、只为 F-K）。

**通用做法（拼出来的出处链顺序）**：论文只给一个方法词（"envelope" / "whitening" / "beamforming"）而没给算法时 →
① 先读它 **Data Availability 里点名的工具箱源码**（最硬，本文即靠此法定案）；② 出版页被反爬 / 正文 closed 时，
去找**同一作者组同方法**的会议摘要（EGU/AGU/CTBTO Indico），方法参数常在这类摘要里说全；
③ 开放状态先用 Semantic Scholar / Unpaywall 两个 API 查（`openAccessPdf.status` / `oa_locations`），别硬撞 paywall。

**由此确定的复现口径（论文给的 vs 我们自选，报数时必须分开写）**：

| 项 | 来源 |
|---|---|
| 频带 2–8 Hz、包络后低通 0.25 Hz | **论文给的**（0.25 Hz 与论文自述的"站间距 ~107 km ⇒ f<0.25 Hz 防空间混叠"一致；Matsumoto 原文用 0.4 Hz） |

⚠️ **别把 0.25 Hz 低通和 6 s 滑动平均当成同一件事**（被问"几秒平滑"时最容易糊）：
实测等效时间尺度（ENBW 4σ 折算）—— 0.25 Hz 四阶零相位低通 ≈ **3.1 s**（单向因果实现 10-90% 上升时间 1.55 s），
而 6 s 滑动平均 ≈ **6.9 s**，比论文口径宽一倍。⇒ 论文没有独立的时域平滑环节，它的"平滑"就是那个低通。

## 5. 到时级相干 ≠ 波形级相干（为什么 SNR 40 dB 的 P 波 F-K 也是平的）

频谱域波束形成（含 fk4d）能在 s 处聚焦的前提是**各台互谱相位与 2πf·s·Δr 对齐**，
即相对到时误差必须**远小于一个周期**（亚周期对齐）。只有"到时/包络峰对齐"是不够的。

实测（Zhou2021 XA 的 G1，远震 P/S，1-3 Hz 带通波形，Δ≈20°）：

| 量 | P | S |
|---|---|---|
| 到时处 SNR（1-3 Hz，Z） | 37-45 dB | 5-13 dB |
| 包络峰拾取平面波拟合 | 10.1 s/° BAZ131 R²=0.65 | 21.4 s/° BAZ143 R²=0.38 |
| 台对互相关拟合 | 8.9 s/° BAZ140 R²=0.75 | 18.0 s/° BAZ161 R²=0.54 |
| 理论（TauP 射线参数 p） | 10.87 s/° @126° | 19.98 s/° @126° |
| fk4d 1-3 Hz 波束图 | 峰-中值 1.67 dB、−6~0.65 dB 全图起伏 ⇒ **平** | 1.51 dB ⇒ 平 |

关键：到时残差有 5-8 s，而 1-3 Hz 一个周期只有 0.3-1 s ⇒ 相位已错开十多个周期，必相消。
同一个 5-8 s 残差在包络的 0.02 Hz（周期 50 s）只占 0.1-0.16 周期 ⇒ 相位仍相干。

推论：
- 分析频带越高（宽带体波波形、2-8 Hz），对台间时间对齐的要求越苛刻；用大孔径、~100 km 间距的
  台阵做体波 F-K 很难聚焦，不是代码错。
- 不要用"强信号却平图"去否定代码：先用**同时窗**的到时/互相关拟合确认到时级相干，
  再判断是"亚周期相位不足"还是真不相干（相位残差诊断，见第 2 节）。
- 极性（初动符号）也会破坏相长叠加：XA 的 G1 中 P 有 2/7 台、S 有 2/7 台初动反号
  （`check_ps_polarity_beam.py` 翻回后仍平 ⇒ 本例不是极性问题），检查顺序上可与相位残差并列。

## 6. 用已知震相验证 F-K 方法（推荐固定流程）

怀疑"是不是方法/代码错了"时，不要靠争论，挑一个**到时与射线参数已知**的震相（远震 P/S）跑三件事：

1. **合成注入（最关键）**：取真实记录，按理论平面波 `τ_i = -(s_true·r_i)`（s 指向震源、模 1/v，v 由 TauP p 反算）
   频域移位，走**同一代码路径**跑 F-K。能精确复原 |s| 与 BAZ ⇒ 引擎/坐标映射/`atan2(x,y)=BAZ`/s-per-deg
   单位全部正确。XA 实例：注入 10.87 s/°@126° → 恢复 10.7@126；注入 19.98@126 → 20.0@126。
2. **到时法（同时绝对窗）**：拾取/互相关平面波拟合应与 TauP 射线参数与 BAZ 一致（XA：P 10.1@131 R²0.65、
   互相关 8.9@140 R²0.75；偏 8-18% 属可接受）。
3. **谱波束**：若 1、2 通过而它仍平，就是第 5 节的相位相干性不足，**不是代码错**。

**相关波束（时域）作为备选估计器**：`beam(sx,sy) = mean_{pairs} cc_ij(ℓ_ij)`，其中 ℓ_ij = -s·(r_j-r_i)、
cc 为归一化互相关。只要求"到时级相干"，对波形差异鲁棒，适合短波包/低 SNR。
实现要点：±MAXLAG 内取 cc（MAXLAG 要大于最大台间延迟，否则按台对掩膜并除以**有效台对数**）；
window 长度 ≥ MAXLAG + 波包长度。XA 实例：P 给 5.9 s/°@135°（方位对、幅度偏小）、S 因 Z 分量 SNR 仅
5-13 dB 不可靠。

## 7. 包络后处理的四口径取舍（平滑 vs 保峰）——"为什么包络没跟着波包走"

用户会指着图问"为什么这个包络不是按照波包来的 / 包络线怎么钻到波形里面了"。**这不是画错、也不是数据问题**，
是包络后处理（第 3 步）在压峰。机制：2–8 Hz 带通波形的振荡周期只有 **0.125–0.5 s**（5 Hz ≈ 0.2 s），
而平滑窗 3–8 s 比它大 20–60 倍 ⇒ 对**非负的裸包络**再做一次长窗平均 = 二次平滑，波包内那些 0.2 s 尺度的
起伏被抹平，峰值必然矮掉；`filtfilt` 零相位低通（论文那条 0.25 Hz）同理，只是轻一点。

实测（SA18 BHZ，2–8 Hz 带通后；判据 = 包络低于 \|波形\| 的时间占比 / 最强段"包络峰÷波形峰"）：

| 包络后处理 | 包络 < \|波形\| 时间占比 | 峰值保持 | 备注 |
|---|---|---|---|
| 裸 \|Hilbert\|（不平滑） | **0.0%** | 1.00（严格包住） | `--env-smooth 0`；两端有 FFT-Hilbert 边缘伪影、逐点毛 |
| 3 s 矩形平均 | 20.7% | 0.61 | 峰位 1279.6 s |
| 6 s 矩形平均（npz 默认） | 20.8% | 0.52 | 峰位 1278.0 s |
| 8 s 矩形平均 | 20.7% | 0.51 | 峰位 1268.5 s |
| **0.25 Hz 零相位低通**（论文 F-K 口径） | 20.6% | **0.60** | 峰位 1280.0 s；T-P 处只剩 17% 峰高（被抹平） |
| 8 s **滑动最大值** | **0.0%** | **1.05**（严格包住） | `--env-mode max`；峰保持时间被拉长、上升沿偏方 |

实用结论：
- **"平滑"与"包住波形"不可兼得**，除非用滑动最大值（代价是台阶感/峰被拉宽）；要"又包住又平滑"的标准做法是
  **先 peak-hold 再 1–2 s 短平均**（本项目尚未实现，需要时再加一个 mode）。
- 所有"理论线是否落在峰上"的判断都随后处理口径变（6 s → 93%、3 s → 73%、8 s → 89%），**换平滑窗必须重报**。
- 论文图 2d 的包络 = Seizmo `envelope.m` 的**裸解析信号模、零平滑**（见 §4a）⇒ 想贴论文图 2d 的观感就用
  `--env-smooth 0`；想让线条好看就接受压峰。**别默认加平滑再声称是论文口径。**
- 0.25 Hz 低通包络会带极小负值（实测 `min = −1.5e-14`，峰值 8.4e-7 的相对量级）——低通振铃，图上不可见，
  但用它做 `>=0` 类判据前要知道。

对应开关（`process_image.py`，都在 `plot_packet`/包络分支里，默认行为不变）：`--env-mode mean|max|lp`、
`--env-smooth <秒>`（`0` = 不平滑）、`--env-lp-hz <Hz>`（默认 0.25）。产物一律走 `--out-suffix`，
别覆盖 `sacprocess/envelope/*.npz`（下游硬依赖）。

## 8. 波前存在性判据：白化波束 B(s) + 零假设标定（2026-09-15，XA G1 定案）

**用途**：当"F-K 出不来结果"要被归因时，别靠争论；用一个**不依赖 F-K 网格**、且**可与零假设比较**的
标量判据，把"数据里有没有指向震源的平面波前"量化。实现（XA 案例）：
`4_fk_analysis/diag_rootcause/01_wavefront/step1_wavefront_test.py`。

```
B(s) = 带内平均 |Σ_i X_i(f)·e^{−i2πf·s·r_i}| / N          X_i = 逐频点白化的谱（与 fk4d 同口径）
  完美平面波 → 1.000 ；完全不相干 → 1/√N（N=7 时 0.378）
```

- ⚠️ **符号**：数据由 `τ_i = −(s·r_i)` 注入时其相位 = `e^{+i2πf s·r}` ⇒ 对齐乘 `e^{−i2πf s·r}`。
  写反的后果不是"结果差一点"，而是**峰值整条跑到镜像方位**（本案例第一版就栽在这，自检①立刻 FAIL）。
- ⚠️ **单个 B 值不能判真假**（N=7 时同一 s 上的零假设分布本身很宽，σ≈0.1）⇒ 必须配**经验零假设**：
  同窗长/同带/同白化、逐台独立高斯噪声 200 次，给出 `z=(B−μ)/σ`（单点）与
  `p=P(零假设网格最大值≥观测值)`（网格极值统计量）。
- ⚠️ **理想上限 1.000 在真实情况下不可达**：波前曲率残差 + 矩形窗泄漏下，**已知真值的合成**在本窗长+本频带
  也只到 ~0.81 ⇒ 真实数据要与**同窗同带的合成参考**折算，别直接对着 1.000 判"没信号"。
- ⚠️ **必须分频带**：同一组数据在 0.005–0.03 Hz 有 z=4.2 的成分，在 0.005–0.08 / 0.02–0.25 Hz 就掉到 z<2
  ——高频 bin 相位已缠绕（τ 残差 4 s × 0.25 Hz ≫ 1 周期），把相干成分稀释掉。
- ❌ **别用"互谱矩阵秩-1 占比"度量相干**：单个频点的互谱外积**天然秩-1**（每频点只有一个快照向量），
  秩-1 占比恒为 1（连独立噪声也是 1）；整带求和又会毁掉秩-1 结构。相干只能靠"跨频带的相位一致性"来量
  （即波束 B 本身）或非白化的带间相干 γ。
- 🔴 **先标定再相信**：脚本第一次跑完、必看三组地面真值自检全 PASS 才允许引用任何数字
  （① 自造平面波（单频、`τ=−s·r`）B 必须 = 1.0000；② 同窗同带的**已知真值合成**应显著高于零假设；
  ③ 独立噪声落在零假设内）。诊断代码的符号/形状 bug 会产出**看起来合理**的整张表
  （实测：转向向量符号反 ⇒ 峰整条跑镜像方位；把 list 当数组传给用 `[:,None]` 的函数 ⇒ 全表数值错、
  程序不报错）——表越"像样"越要警惕。
- ⚠️ **绝对时间轴口径 `t_abs = (b − o) + i/sr`**（真实包络 `o=+599.951` ⇒ 从发震前 600 s 起；
  合成切窗 `o=−win_lo` ⇒ 从 `win_lo` 起）。写成 `o + b + i/sr` 会把整窗挪到发震附近：
  症状 = 目标窗内**无数据**（`numpy.fft.rfft` 收到 n=0 直接抛 `Invalid number of FFT data points (0)`）
  或分析到完全错误的时段。**窗内点数 <8 的配置要跳过并记 NaN**（合成"切窗文件"只覆盖自己的窗，
  拿它去取"到达前噪声窗"必然为空），并且**只对同窗同带的数据集做对照**——配对用错窗会得出
  "已知真值的合成也测不出"这种假结论。

**XA G1（1997-04-28 Mw6.6）实测**（T-S 窗 1232.5–1376.0 s，`b_lo` 0.005–0.03 Hz）：

| 数据集 | B(0) | B(TS 真 30.89@134.8) | z | 网格峰 | p |
|---|---|---|---|---|---|
| 真实 Z | 0.432 | 0.544 | 2.5 | 14 s/°@95° | 0.32 |
| 真实 T | 0.479 | **0.683** | **4.2** | **33 s/°@135°** | **0.025** |
| 合成参考 land3p6 | 0.330 | 0.790 | 4.9 | 29 s/°@135° | 0.000 |
| 到达前空窗（真实 T）| 0.658 | 0.400 | 0.7 | 0@0° | 0.05 |

T-P 窗结论：`B(0)` = 0.885(Z)/0.961(T) 是 `B(TP)` 的 2.3–2.5 倍、网格峰在 0–2 s/°（p=0.000）
⇒ F-K 里那个"极锐零慢度针尖"是**各台同相的公共模式**，统计显著但不是平面波。
**最终归因**：不是引擎/窗/预处理（同窗同带合成可复原真值），而是本数据在论文口径宽频带里只有
"T 分量 + 0.005–0.03 Hz"这一窄带内有 ~86% 参考幅度的弱平面波，Z 分量在**整带平均**下几乎测不到
（逐频点扫描的 0.007 Hz 单 bin 上 Z 也测到相干波前，见 §9）。

## 9. 逐频点无混叠扫描：整带判据会把"单 bin 的相干"平均掉

整带 B(s)（§8）里混进不相干频点就被稀释，可能得出"该分量没有波前"这种**被平均掉**的结论。补一步**逐频点扫描**：
每个频率 bin 用**它自己的**无混叠上限 `SMAX(f) = 111.195/(2·f·d_min)` 建网格（bin 越低格越宽），
逐 bin 报 B(真值)、**B(0)**、z、网格峰与 p（零假设与该 bin 同窗同带同白化）。

读法同 §8，加一条硬判据：**必须同时报 B(0)** —— `B(0) ≪ B(真)` 才是平面波；如果 `B(0)` 与 `B` 同量级或更大，
说明这一点只是零慢度公共模式（各台同相），不是平面波前。

实测（XA G1，T-S 窗 143.5 s；d_min = 101 km；带内 4 个 bin）：

| f (Hz) | 无混叠 SMAX | 真实 Z：B(真) / B(0) / z（网格峰） | 真实 T：B(真) / B(0) / z（网格峰） | 同窗合成 B(真) |
|---|---|---|---|---|
| 0.0070 | ≈ ±79 | 0.978 / 0.631 / 3.9（26.5 s/°@131°） | 0.988 / 0.643 / 3.7（26.7 s/°@133°） | 0.992 |
| 0.0139 / 0.0209 / 0.0279 | ≤ ±40 | 无峰（z < 2.4） | 无峰（z < 2.4） | — |

- ⇒ 相干内容**集中在最低那个 bin**：同一份数据整带（0.005–0.03 Hz）平均后 Z 只剩 B = 0.544 / z = 2.5，
  逐 bin 却给 Z **B = 0.978 / z = 3.9、p = 0.000** ⇒ 归因必须落到"哪个频段"上，不能用整带结论否定某个分量；
  报数时同时给 SMAX(f)（因为每个 bin 的搜索范围不同，峰位才可比）。
- ⚠️ 零假设批量的谱阵布局必须是 **[nf, N]**（每行一个频点，白化后逐行算波束）；写成 `[N, nf]` 会让
  `np.std` 跨频点取标准差、σ → 0、z 冲到 1e15 —— 数值"显著得像结论"，先看自检再相信。
- 窗长限死了能扫几个 bin（143 s 窗、Δf ≈ 0.007 Hz → 4 个）：这是窗长给的物理限制；加长窗只能下移频率下限，
  **不改混叠上限**（`fk-parameter-selection.md` §2b）。

## 10. 包络已过 0.25 Hz 低通，还能再拆成窄带吗？——能，但四道约束（2026-09-16 定）

用户会问"我现在的包络已经 0.25 Hz 滤波了，后面想拆成几个窄频带分析有影响吗"。答案 = **能拆**，条件是把下面四条一次讲清（别只答"可以"）：

1. **上限 = 0.25 Hz**：`>0.25 Hz` 只剩滤波器阻带残留（实测占信号带 0.005–0.25 Hz 能量的 **0.8%**）⇒ 窄带必须整体落在 ≤0.25 Hz 内；越过 0.25 Hz 的带（含论文原带 0.02–0.25 的高频段）在频率高端平均的是阻带噪声，不是信号。
2. **幅值校准看带宽上边缘**：同一套 `butter(4, fc=0.25 Hz)` + `filtfilt`（双向 = 等效 8 阶）实测响应 —— 0.10 Hz −0.00 dB、0.15 −0.11、0.20 −1.16、**0.25 −6.0**、0.30 −15.9 dB ⇒ 上边缘 ≤0.2 Hz **不必校正**；要含 0.2–0.25 Hz 就用 `freqz(butter(4, fc/(0.5*sr)))` 现算 `|H(f)|²` 做逆校正（否则那段被人为压低 6 dB）。
3. **必须先去掉趋势（最容易漏的一条）**：包络恒非负，`<0.005 Hz` 的"均值+趋势"占包络总能量 **75–77%**。**这不是预处理漏做** —— `process_image.py` 的 `detrend('demean')+'linear'` 作用在**去响应前的波形**上，包络链（带通→`|Hilbert|`→低通）里没有任何去均值步骤，也不该有（那是波包自身的形状）。但**跨频带比较能量/占比前必须先减均值或去线性趋势**，否则最低那个带把趋势全吃进去、"哪一带强"不成立。去趋势后信号带内部仍是 `0.005–0.02 Hz` 占 ~60–67%，与 §9"相干集中在最低 bin"一致。
4. **每个窄带各自的无混叠上限**：`SMAX(f_hi) ≤ 0.5502/f_hi`（d_min 101 km）⇒ 0.02 Hz 带 ≤27.5、0.05 ≤11.0、0.10 ≤5.5、0.20 ≤2.8 s/°。带越高能扫的范围越小，"高频窄带 + 大搜索范围"必然混叠。

两条省心的结论（被问"有影响吗"时先给这两条）：**`filtfilt` 零相位 ⇒ 拆带不移到时**（可直接用于到时/τ 分析，不必重新对齐）；**0.25 Hz 低通本身就是抗混叠滤波**（2 Hz 采样、Nyquist 1 Hz）⇒ 拆带不引入混叠。代价只是频点数：213 s 窗 Δf=0.0039 Hz ⇒ `0.005–0.02 / 0.02–0.05 / 0.05–0.10 / 0.10–0.20 Hz` 四带分别只有 **3 / 7 / 12 / 25** 个频点，最低带统计最弱，报数时标注。

**交付形态**（用户会说"这个信息用图表示"）：三联图 = ① 实测幅值响应（dB，标 0.15/0.2/0.25/0.3 Hz 与"免校正 / 需校正 / 阻带"三分区）② 七台**中位** PSD（去趋势；涂四条候选带 + 标各自占比，另标 DC/趋势与 >0.25 Hz 残留）③ `SMAX ≤ 0.5502/f_hi` 曲线 + 各带上限横杠。案例实现：`4_fk_analysis/G1/01_data/04_processed_waveforms/waveform_compare/step2_lpf_response_and_bands.py`（PSD 用七台中位而不是单台，避免挑台）。

## 11. 选带三问：扩带前逐条算（XA G1 实测）

**① 扩带会不会把目标慢度推出网格？** 联立两条既有约束：抗混叠 `SMAX ≤ 0.5502/f_hi`（§10.4）与
"装得下目标慢度" `SMAX ≥ 1.70·u` ⇒ **能扩到多高由目标 u 决定**，不是带宽越宽越好：
`f_hi ≤ 0.5502/(1.70·u)`。实测 `u ≈ 35.7 s/°` ⇒ `f_hi ≤ 0.009 Hz` ⇒ 只能取最低那一个 bin；
把带扩到 `[0.0078, 0.0195]`（f_hi 0.0195 ⇒ 上限 35.2）时峰被压到网格边缘，读数 2.47 s/°（假的边界针尖）。
**被要求"扩充频带"时先把这两个数算出来摆给对方**，再决定扩到哪。

**② 多 bin 平均之前，先看三个 method 一不一致**——最便宜的相干性检验（比 §9 的 B(s)/零假设轻，不必另跑脚本）：
同一窗、同一带，coarray / center / full 的读数（含方位）一致才可信；**任一方法差 ≥2×** 即说明带内偏高的
那个 bin 没有在载相干波前，平均进来只是稀释。实测（XA G1，同一 T-S 窗）：单 bin 0.0078 Hz =
33.5 / 35.7 / 35.8 s/° @131–141°（三方法一致）；双 bin `[0.0078, 0.013]` = 28.4 / 9.7（差 3 倍）
⇒ 0.0117 Hz 那一档不成相干，该相只能用最低 bin。**报读数时必须说明是几 bin 平均**。

**③ 窗里有没有前一个震相的包？** 低频档（≤0.02 Hz）对包络能量最敏感：一段长窗同时罩住 T-P 包
（104–141 s）与 T-S 包时，先到的高能包络会把低频档的波束拉走。实测 T-S 带 0.0078–0.013 Hz、窗 60–260 s
⇒ 1.78 s/°@79°（方位同样错到 59° 之外）；把窗尾挪开前一包（120–270 / 150–280 s）⇒ 8.2–35.8 s/°。
**单 bin 抗污染强得多**（同长窗含前一包仍给 21.2@124°，双 bin 只剩 1.78）⇒ 要用长窗就只取最低 bin，
并把"含 / 不含前一包"两组读数一起报。⚠️ 这与 §4 记的"论文 Fig4 是一图两团、窗必须是两相并集窗"**不冲突
但要声明口径**：并集窗成立与否取决于频带（论文未公开），本项目在 ≤0.013 Hz 档实测并集窗会塌。

**窗长决定可用频点与带内点数**（选带前先算）：`Δf = 1/(nsp·dt)`、可用频点须 `f ≥ 1/T`、
`nsp = 2^⌈log₂(T/dt)⌉` ⇒ 100 s 窗 `1/T = 0.010 Hz` 会**杀掉** 0.0078 频点；150 s 窗 `1/T = 0.0067` 保住它；
200 s 窗 `1/T = 0.005` 且给到 0.0313（7 个频点）。反过来，加长窗只下移频率下限，**不改混叠上限**（§9）。
