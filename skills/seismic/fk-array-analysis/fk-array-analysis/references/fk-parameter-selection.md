## 0. 速查：谁定谁

| 参数 | 定值依据 | 公式 |
|---|---|---|
| `WIN`（分析窗，s 相对发震） | 覆盖目标震相全部理论到时 + 两端余量 | `WIN = [min(理论) − 30, max(理论) + 50]`（两震相各一窗；并集窗用于分带扫描） |
| `WIDTH` / `OVERLAP`（窗内分帧） | 要不要时间分辨 | `nframes = fix((1 − w·o)/(w − w·o))`，`w=WIDTH/100`、`o=OVERLAP/100` |
| `SPTS`（网格点数） | 目标步长 Δs + 0 点落在格点上 | `SPTS = 2·SMAX/Δs + 1`，取奇数 |
| `SMAX`（慢度半宽） | 网格必须覆盖最慢波型 **且** 不把折叠像折进来 | `SMAX ≤ 111.195/(2·f·d_min)`（无混叠，＝与 f 的乘积锁死，见 §4b）；覆盖用 `≥ 111.195/v_min` |
| `FRNGS`（频带） | 论文口径上界 + 窗长下限 | 上界 < min(论文低通, `1/(2·dt)`)；下界 ≈ `1/T` |
| `POLAR` | 出图/解析口径 | `false` = 笛卡尔网格 `sx = −smax : 2smax/(spts−1) : smax` |
| `METHOD` | 项目默认（用户定） | `coarray`；对照另跑 `center`/`full` |

## 0b. 窗长 / 频带 / SMAX 的三条链（用户只关心这三个时，只答这三条 + 一条联立式）

```
T     ≥ 震相到时跨度 + 余量(30/50 s)      ← 由逐台理论到时定（装包络，不是装脉冲）
T     ≥ N/(f2−f1)                        ← 由"要几个独立频点 N"定
f1    = 1/T                              ← 由窗长定（低于 1/T 无分辨率）
f2−f1 = N/T
SMAX  ≥ 111.195/v_min                     ← 由必须覆盖的最慢波型定（v_min = 该相视速度）
SMAX  ≤ C/f2,   C = 111.195/(2·d_min)     ← 由最小台间距定（无混叠）
```

联立（把 `SMAX ≥ 111.195/v_min` 代进 `SMAX ≤ C/f2`，111.195 约掉）：

**`f2 ≤ v_min/(2·d_min)`**  ← 能用的最高频率 = 最慢波型视速度 ÷（2×最小台间距），即"波长 ≥ 2 倍台间距"。

⇒ 这三条**不是三个自由参数**：`d_min`（几何）、`v_min`（要覆盖的相）、`T` 才是自由量。顺序一律
**先由 u 定 `SMAX` 与 `f_hi`（§4b），再由 `f1 = 1/T` 与需要的频点数定 `T`**；反过来先挑带会得到无解组合。
⚠️ **答话范围**（用户明确说过"我只关注重要的几个，窗长、频带、SMAX 这些"）：只给这三条链 + 那条联立式，
`SPTS`/`WIDTH`/`OVERLAP`/`POLAR`/`METHOD` 等他没点名就不要铺开（问到了再照 §0 表补）。

### 0b-1. 读别人脚本里的 `fkmap(...)` / `frng`（SEIZMO `fkmap`，与本项目 fk4d 不同引擎）

- `fkmap(data,smax,spts,frng)` 的 `frng` 是**绝对频率 Hz**（源码 `fk/fkmap.m`：`[FREQLOW FREQHIGH] in Hz`；
  规范例 `fkmap(data,50,201,[1/51 1/49])` ≈ 50 s 周期）⇒ 惯用写法是**给周期的倒数圈一个窄带**，不是给带宽百分比。
- 参与平均的是 `f = k·Δf`（`Δf = 1/(nspts·delta)`、`nspts = 2^nextpow2(npts)` = **补零**）里落进 `frng` 的那些 bin，
  `fkmap` 自带检查 `frng < 1/(2·delta)`（Nyquist）；**带内 bin 数 ≠ 独立频点数**（`≈(f2−f1)·T`，见 §2d）。
- 写法惯例：`frng` 下界常直接写 `1/窗长`（= 分辨率极限 `1/T`，命中从下一个 bin 开始）。
- ⇒ **报这种带必须连窗长一起给**：同一个 `frng` 换窗长后命中的频点数就变（实例：1000 s 窗命中 64 点、
  700 s 窗只 32 点；见 `seismic-paper-reproduction` 的 `zhou-twaves-original-archive.md` F-K 节）。
- 老盘 `fk_map.m` 那两套的确切值（窗 1200–2200 s @20 sps ⇒ npts 20001、**nspts 32768**、Δf 6.1e-4 Hz）：
  `[1/1000 1/25]` 命中 k=2..65 共 **64 点 = 0.00122–0.03967 Hz**（周期 25.2–819 s；独立频点 ≈ 39）；
  bak 的 `[1/1000 1/33.3]` 48 点 = 0.00122–0.02991 Hz。注意下界 `1/1000` 比第一个非零 bin（0.00061）大 ⇒ 从 k=2 起。
- ⚠️ 拿到别人的 `frng` 必须顺手核混叠：老盘那套上界 0.04 Hz 超 `C/SMAX = 0.55/30 = 0.0183`（XA，d_min 101 km）
  ⇒ 带内 k≥31 已在混叠区，自洽写法应为 `[1/1000 1/550] Hz`（≈ 0.001–0.018 Hz）。
- 与预处理低通不冲突：`0.25 Hz` 低通是**数据内容上限**，`frng` 是**实选带**（实选带 ⊂ 低通带内）——
  用户会指出"不可能去扫 0–0.25 Hz 全带"，这一条正是答他的口径。

## 1. 分析窗 `WIN`

- 构造式（逐台理论到时取 min/max，取遍子阵所有台）：`[min(理论) − 30 s, max(理论) + 50 s]`。
  余量 30/50 s 是为了装**包络**而不是脉冲（0.25 Hz 低通后波包本身几十秒宽）。
- XA G1 实例（Eq.1 口径：陆地段恒速 6.0/3.6）：T-P 到 1203.0–1241.8 s（跨度 38.9 s）、
  T-S 到 1272.5–1336.0 s（跨度 63.4 s）⇒ T-P `[1173,1292]`、T-S `[1243,1386]`，
  **并集 `[1173,1386]`（T = 213 s）** 就是分带扫描（bandscan）用的窗。
- ⚠️ 窗用的是 **Eq.1（论文恒速）口径**，不是 `stations.csv` 的 `tt_tp/tt_ts`（后者早 25–30 s，换口径要整体平移窗）。
- 跨震相重叠时按"两相理论到时空隙的中点"断开（见 `phase-window-definition.md`），不要只压上界。
- 窗内分帧（fk4d）：`nframes = fix((1 − w·o)/(w − w·o))`（`fk4d.m` 源码），
  `WIDTH=100, OVERLAP=0 → nframes = fix(1/1) = 1` = 整窗一帧、时间维无分辨；
  子帧长 = `WIN × WIDTH`，可辨台间延迟上限 = 帧长/2（`sliding-window-aliasing-limit.md`）。

## 2. 窗长决定了什么

| 被决定的量 | 公式 | G1 实测（T = 213 s，dt = 0.5 s） |
|---|---|---|
| 频率栅格 | `nspts = 2^⌈log₂⌉(npts)`，`npts = T/dt`，`Δf = 1/(nspts·dt)` | npts 426 → nspts 512 → **Δf = 0.00391 Hz** |
| 真分辨率 | `1/T` | 0.00469 Hz（补零只加密栅格、不提高分辨率） |
| 带内频点数 | `nfreq = (f2 − f1)·nspts·dt` | b1/b2/b3 = **6 / 13 / 44**，与存盘 beam 表头 `nfreq` 逐位一致 |
| 可用的最低频率 | `f ≳ 1/T` | 0.0047 Hz ⇒ b1 下界取 0.005 Hz |
| 覆盖台间到时跨度 | 窗长 ≥ 跨度 + 余量 | T-P 跨度 38.9 s、T-S 63.4 s |

⇒ 窗长越长：频点数与低频覆盖越好，但窗内混入的不相干能量越多（波束被稀释，
`envelope-fk-band-coherence.md`）。fkvolume 里另有硬检查 `frng < 1/(2·dt)`（Nyquist）。

## 2a. 窗内的另一相会污染结果（即使两者频带不同）

判量用**定长平移对照**：把窗整体平移（**窗长与频点数逐项保持不变**），比较"含另一相"与"不含"的
峰显著性。XA G1 实测（同一批波束、只平移起点）：

| 带 | 含另一相 | 等长平移后不含 | Δprom |
|---|---|---|---|
| T-P 带（R） | 10.74 dB，0.49 s/°@135° | 9.24 dB，0.34 s/°@0° | 1.5 dB |
| T-S 带（Z） | 8.11 dB，2.69 s/°@113° | 7.84 dB，1.46 s/°@166° | 0.27 dB |
| T-S 带（T） | 7.89 dB，2.06 s/°@121° | 6.74 dB，2.91 s/°@166° | 1.15 dB |

⚠️ **频带不同 ≠ 互不干扰**（用户会直接问"频带不同也会被污染？"）：① 包络不是严格带限——0.25 Hz
低通后 0.03–0.1 Hz 仍有残余；② F-K 只看离散频点，另一相的能量落在低频格点上照样进来；
③ 改窗内容会改**每道自己的谱估计**（白化与窗内均值都变）。三者叠加 ⇒ 另一相可在 0.3–1.5 dB
尺度上改 prom 甚至改峰位，而本项目 prom 总量级只有 8–11 dB ⇒ 1.5 dB 不可忽略。

规则：**切窗以另一相的理论到达时刻为界**（T-P 窗上界切到 T-S 起点、T-S 窗下界保持在 T-S 起点之后），
代价只是丢掉 T-P 窗口的下半段；报数时说明"窗内装的是哪一相"。做对照时窗长/频点必须逐项相同，
否则分不清"污染"与"窗长效应"。

## 2b. 台间距 vs 窗长：可用频带必须非空（2026-09-15 XA G1 验算）

台间距 `d` 与窗长 `T` **不直接关联**——它们拧的是频率轴的两端：

| 约束 | 公式 | 由谁定 |
|---|---|---|
| 无混叠上限 | `f ≤ 1/(2·s·d_min)` | 台间距（d 越小越能上高频） |
| 分辨率下限（测准到 δs） | `f ≥ 0.64/(D·δs)` | 孔径 D |
| 频率下限 | `f ≥ 1/T`；且 `T ≥ s·D`（窗要装得下孔径走时差） | 窗长 |

方向性（易搞反）：**只加长窗 T 只下移下限，混叠上限与 T 完全无关**；只缩小 d 只抬高上限、不改分辨率。
联系人就是台间走时差 `Δt = s·d`：T 要装得下 `s·D`，频率要低于 `1/(s·d)`。

XA G1 实算（`d_min`=101 km、`D`=312.4 km、`T`=213 s；s = 18.5 / 30.89 s/deg）：

| 震相 | 孔径走时差 `s·D` | 无混叠上限 | 10% 精度所需下限 | 只求一个主瓣的下限 |
|---|---|---|---|---|
| T-P (18.5) | 52.0 s | ≤ 0.030 Hz | ≥ 0.123 Hz | ≥ 0.012 Hz |
| T-S (30.9) | 86.8 s | ≤ 0.018 Hz | ≥ 0.074 Hz | ≥ 0.007 Hz |

⇒ 10% 精度那一列与上限**直接矛盾**（0.123 > 0.030）：G1 这套几何在数学上就无法定量测该视慢度，
与数据质量无关。只求"看到一个主瓣"时 T-S 的可用带是 **0.007–0.018 Hz，正好落在 b1（0.005–0.03）**
——与实测"真实 T 分量只在 b1 相干（B=0.683、z=4.2、峰 33 s/°@135°）"一致；b_cb 掉到 z=1.9、b_orig 0.5
（`envelope-fk-band-coherence.md` §8）。换台阵才救得了：f=0.05 Hz + 10% 精度需 `d_min ≤ 60 km`、`D ≥ 769 km`。

## 2c. 覆盖 ≠ 可用：判据看**参与平均的最高频点**，不要看名义带宽

用户会问"只要覆盖这个频带就行吧，难道必需精确吗"。答法：**不行**——
`SMAX < 0.55/f` 里的 `f` 是**实际拿去平均的最高频点**，不是名义带宽：

- 带里只要还有一个高频点参与平均，SMAX 就被它压住。例：带 0.02–0.25 Hz 名义上"含"0.005–0.010 Hz，
  但 0.25 Hz 那个点把上限压到 `±2.2 s/°` ⇒ 低频并不会"说了算"。
- 要让低频说了算，只有两条路：① **切带**（把参与平均的范围压到 ≤ 无混叠上限对应的 f）；
  ② **逐频点**（每个 f 各算一张图，只挑低频点出图/平均 = 等价于手切带）。
- 边界不必"精确"：频带边界只决定哪些 `k·Δf` 落进来；要报清的是"**参与平均的最高频点是多少**"，
  再套 `SMAX < 0.55/f`。

⚠️ **频点太少是统计问题，不是越界问题**，别混：同一台站同一条带，频点少（如 T=213 s 时
0.005–0.010 Hz 只有 1 个频点）⇒ 图抖、不稳（统计问题）；而 `SMAX` 是否超 `0.55/f` 是物理问题（混叠）。
报结论时分开说；要更多频点只能加长窗（`Δf ≈ 1/T`）。

⚠️ **"预处理时直接把包络低通到 X Hz" 不能替代 F-K 选带**（用户会直接问"为什么不干脆在包络后做 0.05 Hz LPF"）：

1. 低通到 0.05 Hz **不够**——0.018–0.05 Hz 那段照样通过、照样参与平均；要"物理上切掉"必须截止到
   ≤ 该慢度对应的无混叠上限（本例 ≈0.018 Hz）。
2. 对参与平均的那几个低频点，"先低通再 FFT" 与 "FFT 后只取低频点" 结果**基本等价**（低通只压带外，
   白化又把幅度归一化掉）；差别在低通**不可逆** + 滤波边缘效应。
3. 唯一实质好处：截止降到 0.02 Hz ⇒ Nyquist 只需 0.02 ⇒ 采样可从 2 Hz 降到 0.05–0.1 Hz，数据量降
   ~20–40 倍；`Δf ≈ 1/T` 不受采样率影响，低频频点数与结果不变。
4. 做法：**不要改预处理链**（保留 0.25 Hz 版供分带/噪声/论文口径复用），在 F-K 脚本入口加可选
   "低通 + 降采样" 开关（`--pre-lp / --decim`），想省算力就开、想复查高频就关。

## 2d. 频点数的阶梯，与"加长窗"的真实代价（陆地计时 G1 实测）

用户会问"怎么增加频点"。先给唯一正确的公式链：

```
频点数 = #{k·Δf ∈ [f1, f2]}      Δf = 1/(nspts·dt)，nspts = 2^⌈log₂(T/dt)⌉
独立频点数 ≈ (f2 − f1)·T          ⇒ 要 N 个独立频点需 T ≥ N/(f2 − f1)
```

| 频带（宽度） | N=5 | N=10 | N=20 |
|---|---|---|---|
| T-P 合法 [0.020, 0.0552]（0.0352） | 65 s | **257 s** | 513 s |
| T-S 合法 [0.008, 0.0224]（0.0144） | 257 s | **513 s** | 1025 s |

⚠️ **频点数不是随窗长线性涨，而是跟着 `nspts` 的 2 的幂阶梯跳**：T-S 合法带在 T = 142 / 200 / 240 s
**全是 3 个频点**（Δf 都是 0.0039），到 T = 320 s（nspts 512→1024）才变 7 个；T-P 合法带在 117 → 175 s 由 5 变 9 个。

手段与代价（照此答，不要只答"加长窗"）：

| 手段 | 效果 | 代价 |
|---|---|---|
| **加长窗 T** | 唯一真增加**独立**频点 | 装进另一相/尾波；prom 单调下降（见下） |
| 放宽带宽 | 频点数 ∝ (f2 − f1) | 受 `f × SMAX ≤ 0.5502` 压住（§4b） |
| 补零（nspts×2/4/8） | 栅格变密 | **不增加信息**（独立频点仍 ≈ (f2−f1)·T），只用于画细曲线/插值峰位 |
| 改采样率 fs | 无 | `Δf ≈ 1/T`：fs 在 `fs/2^⌈log₂(T·fs)⌉` 里抵消（0.5/1/2/4/8 Hz 频点数完全相同） |
| WIDTH/OVERLAP 分帧 | 增加**时间**分辨 | 帧长变短 ⇒ Δf 变粗，频点数反而减 |

### 2e. 改采样率 / 改预处理口径：先重建并核对“逐点一致”，再谈变体

用户问“**如果用 4 Hz 呢** / 预处理改一下呢”时**必须实测回答**（他会把你的推演当结论用）。做法：从
**原始去响应数据**按同一条链子重建（`2–8 Hz 带通 → Hilbert 包络 → 0.25 Hz 低通 → 抽取`），但在跑
变体之前**先用当前口径重建一遍、与工程现用文件逐点比**：直到 `max|Δ| = 0`、`corr = 1.0000` 才准拿
这套代码去解释变体结果。

- ⚠️ **漏掉链子里的任何一步只表现为“振幅差几个量级”**（实测漏掉带通：max 3.8e-4 vs 现用 1.9e-8、
  corr 0.05），不会报错。定位法：拿**与所验假设无关的分量/步骤**当对照（本例 Z 不经旋转 ⇒ 一次就锁定
  问题在 T 那一支），不要先去解释“信号不一样了”。
- ⚠️ **两个都写成 Hz 的数必须分清**：`0.25 Hz` 是**低通截止**（信号内容上限，实测 99.7% 能量在它之下）、
  `2 Hz` 是**采样率**（`dt = 0.5 s`，来自脚本参数 `NEW_SR = 2.0`，20 Hz ÷ 10 整数抽取）。
  进 `Δf = 1/(nspts·dt)` 的是**采样间隔**；截止只决定可用频带的上限。
  **说“包络降到 2 Hz”是错的**（用户会当场纠正），正确说法是“低通到 0.25 Hz 后按 2 Hz 采样”。
- 实测（同窗、同带、同参数，只换输入采样率 2 Hz ↔ 4 Hz）：**Δf 逐位不变**（`T/dt` 翻倍时 `nspts`
  同步翻倍 ⇒ `nspts·dt` 不变），有信号的配置**峰位/方位/prom 一致**（T-S 带 11.59 vs 11.59 s/°@136°；
  单频点 34.79 vs 34.54 s/°@137°）；无信号的配置**峰位换了个地方**（T-P 带 0.35@270° → 0.49@225°）
  —— 又一次证明那是近零平台上的随机落点。
- ⇒ 结论：**采样率不是分辨率杠杆**（窗长才是），4 Hz 只把文件与 FFT 成本翻一倍；答话先给这一句，再给表。

**加长窗要拿显著性买**（同带、同 method、只改窗）：T-S 合法带 prom 于 T = 142 / 200 / 240 / 320 s 为
**11.76 / 10.38 / 7.51 / 5.22 dB**（峰始终在 1.3–3.5 s/°、方位乱）；T-P 合法带于 T = 117 / 175 / 230 s 为
**10.74 / 10.15 / 9.30 dB**。⇒ **窗长不是提高分辨率的自由杠杆**；要"频点够多 + 显著性够高"只能换几何。

### 窗长的两端硬边界与"最低可用频点"阶梯（用户会问"窗长还能再长吗 / 再小的频带还有频点吗"）

- **上界 = 数据文件长度**：陆地计时输入 `b=−100 s、npts=1001、dt=0.5` ⇒ 时间轴 −100…+400.5 s，
  最长可切 **500.5 s**（绝对计时文件虽有 4199 s，但波包之外没有信号）。物理上更紧：波包自己只占
  **T-P 104–141 s、T-S 174–235 s**（= `land_km/V`，V 取 6.0/3.6）⇒ 现用的 143.6–285.3（141.7 s）、
  74.2–191.2（117.0 s）就是"波包 + 两端余量"；再往两头拉只是装尾波或另一相。
- **下界 = `1/T`**：`Δf = 1/(nspts·dt)`、`nspts ≥ T/dt` ⇒ 阶梯步长 ≈ `1/T`，**跨不过 `1/T`**。

| 窗长 T (s) | nspts | Δf (Hz) | 1/T (Hz) | 最低可用频点（首个 ≥1/T 的 k·Δf） | 该频点主瓣半宽 |
|---|---|---|---|---|---|
| 117（T-P 窗） | 256 | 0.0078 | 0.00855 | **0.0156**（0.0078 在 1/T 之下被剔除） | 14.6 s/° |
| 143（T-S 窗） | 512 | 0.0039 | 0.00699 | **0.0078** | 29.2 s/° |
| 200 | 512 | 0.0039 | 0.00500 | 0.0078 | 29.2 s/° |
| 256 | 512 | 0.0039 | 0.00391 | **0.0039** | 58.4 s/° |
| 500（数据上限） | 1024 | 0.0020 | 0.00200 | 0.0039 | 58.4 s/° |

🔴 **表里的 `nspts` 是 `2^⌈log₂(T/dt)⌉` 的理想值；引擎吃的是切窗后的实际样点数（含两端 ⇒ `npts = T/dt + 1`）**：
256 s 的窗实测切出 **513** 点 ⇒ `nspts = 2^nextpow2(513) = 1024`、`Δf = 0.001953`（不是 512 / 0.0039）⇒ 阶梯比表里细一倍，
**0.0039 Hz 在那个窗里是 k=2**（k=1 = 0.00195，仍 `< 1/T` 被剔除），合法档变成 0.0039 / 0.0059 / 0.0078 / 0.0098 / 0.0117（5 档）。
**报数必须带窗长**：同一个频率在两窗里的 k 序号不同名（143 s 窗 k=1 = 0.0039，256 s 窗 k=2 才是 0.0039）⇒ 只写"k=2"没有意义，
一律写 `(窗, Δf, k, f)`；定 Δf 时**读导出 log 里的 `npts=`/`nspts=`**（或与存盘 beam 表头核），不要用 `T/dt` 手算——差一个采样点就整档错位。

⇒ 三点结论（照此答，不要只答“可以加长”）：① **在 143 s 窗里** 0.0039–0.0078 Hz 之间没有频点（低的那档在窗里不满一个周期；更长窗按实际 `nspts` 另算）；
② 想再往下只能把窗拉到 ≥256 s，而 0.0039 Hz 的主瓣半宽 58.4 s/° 比目标慢度 24.7 还大一倍 ⇒ **更低频不是更好**，
只是把斑变胖；③ 反向的坑更硬：117 s 窗里 T-S 合法带 `[0.006, 0.0131]` **一档频点都拿不到**
（0.0078 被 `1/T` 剔掉、0.0156 出带）⇒ **T-S 必须配 ≥143 s 的窗**，别拿 T-P 的短窗套 T-S 的带。

## 3. 慢度网格 `SPTS`

- fkvolume 内部先把 `smax` 由 **s/deg ÷ d2km(≈111.195)** 转成 s/km，再建笛卡尔网格：
  `sx = −smax : 2*smax/(spts−1) : smax`（`POLAR=false`）。
- **步长 `Δs = 2·SMAX/(SPTS−1)`**；反解 `SPTS = 2·SMAX/Δs + 1`。
- `SPTS` 取**奇数** ⇒ 0 慢度恰在格点上（分带扫描 441 点：`0.0 in ax` = True），
  零慢度针尖/公共模式诊断因此不需要插值。
- 经验步长 `Δs = 0.35 s/deg`（老口径 SMAX=35 / SPTS=201 正好给 0.35）；
  SMAX=78 → 取 SPTS=441（=21²）给 **0.3545 s/deg**，与老口径可比。
- 够不够密：`Δs ≤ ½ × 主瓣半宽(f_max)`——0.354 在 b1/b2/b3 里分别是分辨率的 1/37、1/12、1/4 ⇒ 够密，
  图面平滑不是网格限制的。
- 成本 = `SPTS² × nfreq`（441² = 194,481 值/频点/帧；导出的 beam txt 就是 194k 行）。

## 4. 主瓣与复制峰（`SMAX` 的真正依据）

记 `D` = 子阵最大基线（孔径）、`d_min` = 最小台间距。

```
主瓣半宽（B 降到 0.5 的半径）  ≈ 0.64 · 111.195 / (f · D)      [s/deg]   ← 分辨率
复制峰（grating lobe）间距      ≈      111.195 / (f · d_min)    [s/deg]   ← 折叠像从哪来
无混叠判据（搜索范围内不出现真峰的折叠像）  SMAX ≤ 111.195 / (2 · f · d_min)
```

XA G1 实测（d_min = 101.0 km，SA16–SA17；D = 312.4 km；单频平面波注入 18.5 s/deg @134.8°，ARF 扫描）：

| f (Hz) | 实测最近复制峰 Δ | 公式 `1/(f·d_min)` | 实测主瓣半宽 | 公式 `0.64/(f·D)` |
|---|---|---|---|---|
| 0.0050 | （网格外） | 220 | 45.6 | 45.6 |
| 0.0176 | 59.1 | 62.6 | 13.0 | 12.9 |
| 0.0300 | 34.6 | 36.7 | 7.6 | 7.6 |
| 0.0547 | 18.9 | 20.1 | 4.2 | 4.2 |
| 0.0800 | 12.9 | 13.8 | 3.0 | 2.9 |
| 0.1660 | 6.1 | 6.6 | 1.4 | 1.4 |
| 0.2500 | 4.2 | 4.4 | 1.2 | 1.2 |

（实测比公式小 ~5%：真复制峰来自整族基线的组合，不只是最近一对——量级与趋势完全一致。）

**独立复核（2026-09-17，波束图半幅直接数值测量）**：沿传播方向切 `B(s) = |mean_i exp(−i2π f s·r_i)|`，
在 G1 七站真实坐标下 f = 0.008 / 0.0131 / 0.02 / 0.0322 / 0.05 Hz 五个频点**全部给出 C = 0.6096**
（与 f 无关 ⇒ 系数只由几何定）；−3 dB（半功率）定义为 **0.4502**。连续矩形孔径（sinc 波束）理论值：
半幅 `f·D·u = 0.6034`、半功率 `0.4429`。⇒ **`0.64` 是半幅口径的保守值（实测 +4.8%）**，要与实测贴齐就写 **0.61**。
各向异性：同一频点每 5° 扫一遍，C ∈ [0.556, 0.775]（中位 0.619），作通用值 0.64 偏保守但可接受。

**C 到底怎么算出来的（用户会追“源码有吗”）**：`4_fk_analysis/G1/check_mainlobe_coefficient.py` 的核心就 6 行 ——
把台站位置投影到方位角 û 上 `rr_i = r_i·û`，令 `B(x) = |mean_i exp(−i2π f x rr_i)|`（x 从 0 扫到 `4/(f·D)`，单位 s/km），
内插出 `|B| = 0.5` 的横坐标 `x0`，则 `Δp = x0`、**`C = x0·f·D`**（无量纲；换 `|B| = 1/√2` 即 −3 dB 口径）。
⚠️ **论文里没有这个系数**（Zhou2021 不做分辨率分析，全文无 `resolution/mainlobe/sinc` 类说法）⇒ 报数、写稿一律标
“**本项目自检项，非论文参数**”，概念出处写 **Rost & Thomas (2002) Rev. Geophys. 的 ARF（阵列响应函数）**
（论文自己引它来限定子阵孔径 <400 km，链条是通的）。路径与日志：同目录 `+ log_check_mainlobe_coefficient.txt`。

**推论 —— 几何分辨率地板（2026-09-17，用户会问"那这套几何是不是根本没法做"）**：
把无混叠上限与半宽联立，`f` 会被消掉：

```
Δs = C·111.195/(f·D)  且  f ≤ 0.5502/SMAX
⇒ Δs ≥ (C·111.195/0.5502)·SMAX/D = (C·2·d_min/D)·SMAX      ← 与 f 无关！
```

G1（d_min 101.04、D 312.44）：`Δs/u ≥ 1.28·d_min/D = 41%`（峰心进网格时）/ `71%`（整瓣进网格时，
=k/(1−k)）⇒ **10% 分辨率与无混叠在数学上不相容，降 f 也救不了**（降 f 提分辨率的同时把 SMAX 上限压下去）。
要 10%：`D ≥ 1423 km`（d_min = 101 不变）或 `d_min ≤ 22 km`（D = 312 不变）；要 25%：647 km / 49 km。
旁证：论文自身 T-P 实测 10.0 vs 预测 13.7 差 **37%**，正压在这块地板上 ⇒ 复现目标应写成
"峰存在 + 方位 + 落在理论值 ±1 个主瓣内"，而不是"测准到 x%"。脚本：
`4_fk_analysis/G1/check_mainlobe_coefficient.py`（+`log_...txt`）。

**地板卡死时的三条出路（用户说"没招了"时给这个，别继续调参数）**：

1. **换量：逐台到时回归** —— 不测慢度，测陆地段走时差：`τ_i ≈ t0 + land_i/V` 最小二乘，斜率给 `1/V`；
   误差 ≈ `σ_t / 距离跨度`（G1 跨度 221 km：σ_t = 4 s ⇒ V 误差 ±8.6%；σ_t = 2 s ⇒ ±4.3%），
   **不依赖台间相干**（正是几何地板卡住的那个量）⇒ 比波束的 41% 好 5–10 倍。
2. **换量：偏振反推** —— 入射角 i 经 `v = sin i · 111.195/u` 给量级/上界，独立于孔径，受自由表面效应影响（见 `single-station-analysis` 的入射角参考）。
3. **换数据：几何或事件** —— 要 10% 需 `d_min/D ≤ 0.09`（如 20 km 间距 + 300 km 孔径）；现有台阵做不到，
   替代是多事件联合（不同方位把慢度矢量约束住）。

调参数（窗长/频带/SMAX/method）都在同一块地板下打转 —— 先说明这一点，再给上面三条。

**G1 的逐频安全上限** `SMAX_safe = 111.195/(2·f·d_min)`：

| f (Hz) | 0.005 | 0.0176 | 0.03 | 0.0547 | 0.08 | 0.166 | 0.25 |
|---|---|---|---|---|---|---|---|
| SMAX_safe (s/deg) | 110 | 31 | 18 | 10 | 7 | 3.3 | 2.2 |

⇒ 论文口径 `±35 s/deg` 只在 **f < 0.016 Hz** 才真正无混叠；b1 的上半段、b2、b3 都落在混叠区。
分带扫描故意取 `SMAX=78`（> 2×35）就是为了**把折叠像一起画出来**——宁可看见像，也不让真峰被折进来。

⚠️ **整带口径：SMAX 由带内最高频决定，宽频带基本没救**（用户把频带改成 0.02–0.25 Hz 后会直接问这个）：
严格无混叠上限落在 **0.25 Hz 那一档 = ±2.2 s/°**（G1，带内 59 个频点），而这个范围**根本不含**
T-P 18.5 / T-S 30.9 s/° ⇒ 想看到目标慢度就必然把折叠像画进来。三种可选做法：
① `SMAX ≤ ±2.2`（干净，但只能说“有没有接近零慢度的能量”）；
② 保持 `±35` 或更大，**并在图/结论里声明含折叠像**，同时配一份合成注入对照把真值与折叠像位置一起标出来；
③ 拆窄带分别出图（0.005–0.03 那一档可用 `±18`）。

判读坑：
- ⚠️ **峰报在网格边界（|s| ≈ SMAX）不是峰**：那是波束朝外单调上升被网格截断的假值
  （实测 b3 报 78.10 s/deg@58°）。报峰前先确认它是**内部**极大。
- ⚠️ 复制峰是**平移不变**的：`B(s) = ARF(s − s_true)`，偏移向量与真值无关 ⇒ 可先算一次偏移表，
  再按任意假定真值摆放，用来判断"观测峰是不是某个真峰的折叠像"。

  诊断脚本不要硬编码单一路径 —— 用候选路径列表，并在几何文件缺失时**从 `stations.csv` 的 lat/lon 重算偏移**
  （等距圆柱：`x=(lon−lon0)·111.195·cos(lat0)`、`y=(lat−lat0)·111.195`，再去质心；
  与旧 `stations_used.csv` 逐台偏差 <0.05 km，可直接当同一口径用）。

## 4b. 混叠预算：`f × SMAX ≤ 常数`（一个式子两种读法）+ SMAX 作为未知量怎么解

用户会连问三次（“f 是哪来的” → “f 不是反过来定上限的吗，怎么又说跟 SMAX 有关” →
“给你预测慢度 18.53，SMAX 怎么定”）。根因是**把一个式子的两种用法讲成了两个方向**。唯一的正确说法：

```
f × SMAX ≤ 111.195 / (2·d_min)        ← 唯一约束；本项目 d_min = 101 km ⇒ 常数 = 0.55 (Hz·s/deg)
  读法 A（判据）：给定 f        → 算出 SMAX 的上限    （用来检查是否越界）
  读法 B（设计）：给定想要的 SMAX → 算出频带上限       （用来定参数）
```

⇒ 不是“f 由 SMAX 决定”，而是**乘积被锁死**：面积固定，长宽不能同时大。答话先给这一句，再给数字
（f=0.03 → SMAX ≤ 18.4；f=0.25 → ≤ 2.2；想要 SMAX=24 → f ≤ 0.023）。所有关系仍应先回到
“f = 带内的 FFT 频点”（§5 第一步），不要回答成“f 跟 SMAX 有关”。

**SMAX 当未知量（已有预测慢度）的解法**：

```
SMAX = 预测慢度 + 主瓣半宽      主瓣半宽 = 0.64·111.195/(f_hi·D)，而 f_hi = 0.55/SMAX
                                ⇒ 两量互相依赖，代 3 轮即收敛
快速版：SMAX = 1.3 × 预测慢度    （够用；但峰宽会顶出网格 → argmax 贴边、慢度报小，见 §4 判读坑）
SPTS  = 2·SMAX/Δs + 1，Δs = 0.35 s/deg（习惯值），取奇数
```

代入（D = 312.4 km）——快速版（1.3×，够用但峰会顶出网格）与**严格解（含峰宽，迭代收敛）**：

| 预测慢度 | 快速版 SMAX | 严格解 SMAX | 对应 `f_hi = 0.55/SMAX` | SPTS（Δs=0.35） |
|---|---|---|---|---|
| **13.7（论文 T-P 预测，⇔ 8.12 km/s）** | 18 | **23.4** | 0.0236 Hz | 135 |
| **24.7（论文 T-S **实测**，⇔ 4.50 km/s；原文 "fits well with predictions"，**不是预测值**）** | 32 | **42.1** | 0.0131 Hz | 243 |
| 论文 T-S 预测（按论文口径 Δt/最大基线复算）G1 ≈ 22.6 / G2 ≈ 19.0 | 32 | 42.1 | 0.0131 | 243 |
| 18.53（式1 恒速梯度 T-P） | 24（峰±10 会顶出边界） | **32**（峰 5.3–31.8 装得下） | 0.017 Hz | 183 |
| 30.89（T-S） | 40 | **53**（峰宽 ±21.8） | 0.010 Hz | 303 |

**闭式解**（不必逐轮迭代）：把 `f_hi = 0.5502/SMAX` 代回 `SMAX = u + 0.64·111.195/(f_hi·D)` 得

```
SMAX ≥ u / (1 − k),      k = 0.64·111.195 / (0.5502·D)
G1（D = 312.4 km）⇒ k = 0.414  ⇒  SMAX ≥ 1.706 · u
```

（13.7 → 23.4、24.7 → 42.1、18.53 → 31.6；旧表 32 是常数取 0.55 的结果，差 <1）。
`D` 越大 ⇒ `k` 越小 ⇒ 峰越窄、SMAX 越贴近预测慢度本身。

**单式判据（用户会追到这一步：“最后的比值怎么算？就是 0.3225/u”）**：把上下限写成夹逼
`u/(1−k) ≤ SMAX ≤ A/f` ⇒ 消掉 SMAX：

```
f ≤ A(1−k)/u = 0.3225/u           A = 0.550231、1−k = 0.5861
0.3225 = 111.195/(2·d_min) − 111.195·C/D = 0.5503 − 0.2278
         ↑ 台间距给的频率余量        ↑ 容下半瓣、孔径必须让出的份额
```

两种用法（一张表答完，不要逐条展开）：

| 已知 | 求 | 公式 | G1 数值 |
|---|---|---|---|

🔴 **顺序定则：先由 u 定 `f` 上限与 `SMAX`，再挑频带；反过来先按无混叠挑带会得到无解组合。**
实例：带顶 0.022 / 0.055 Hz ⇒ 无混叠只允许 `SMAX` 25 / 10，而装下 24.7 需要 42.15 ⇒ 下限 > 上限，

⇒ 见到这种症状先按“参数不相容”处理（查 `f ≤ 0.3225/u`），不要归因成“分辨率不够”去加窗长/换分量/换 method。

⚠️ **装箱判据要用带内实际参与的最高频点，不是名义带顶**：离散化后最后一个 bin 常落在带顶之下、斑更胖，
`u + Δs` 会略超 `SMAX`（实测 u = 10 的 T-P 档：带内最高频点 0.0312 Hz ⇒ 半宽 7.29 s/°、`10 + 7.29 = 17.29`，
比 `SMAX 17.1` 大 1.1%）⇒ 只影响“整瓣进网格”这一档，报数时说一句即可；“峰心进网格”（`SMAX ≥ u`）通常很宽裕。

⚠️ **名义带顶怎么写：贴到“最后想用的那个 bin 之上一点点”即可，写宽了不赚频点、只赔稳健性**。
用户会拿自己拟的带问“这样对吗”（实例：T-P `0.02–0.035`、T-S `0.005–0.014`）⇒ 按两步答：

`u_max 10.32 ≥ 10` ✓ 可用；② 再点名两处毛病：**下界低于 `1/T` 不成立**（`0.005 < 1/T = 0.0070`，
实际最低频点仍是 0.0078，写作应写 0.006）、**名义上界超判据 7–9%**（`0.035 > 0.0323`、`0.014 > 0.0131`）
——换窗长使 `Δf` 变细就会溜进超限频点（`Δf = 0.0033` 时 0.0330 落进 `(0.0323, 0.035]` ⇒ `u_max` 掉到 9.77 < 10）。
⇒ 定稿写 `0.008–0.0322` / `0.006–0.0131`（每条带顶都刚好卡在最后一个想用的频点之上）。

### 4b-1. 用户"直接定 SMAX=某个整数"时，必须先做换网格复核（**网格收小会切峰**）

用户口径常是"我想直接定 30，正好符合那个慢度上限，上限也就可以直接画到 ±30"——**照做，但先把下面的夹逼算给他看**：

```
SMAX 的夹逼：     要看到的峰慢度 ≤ SMAX ≤ C/f_hi
  G1 要收进 0.0156 Hz 这个频点（3 档）⇒ SMAX ≤ 0.550231/0.015625 = 35.21
  而最低频点 0.0078 档的实测峰可到 39.2 s/°（G1 的 R 分量）⇒ 需 SMAX ≥ 40
  ⇒ **3 频点 与 大慢度 互斥**，只能按用途二选一；SMAX=30 满足前者、装不下后者
```

**复核做法**（6 条配置、约 1 分钟）：同一 tag、同一频点，**只换 SMAX 各跑一遍**（`s30` vs `s35`、`bin78` vs `bin78g`），比三样 ——
① 峰位差（`|Δu|`、`ΔBAZ`）；② 峰是否**内部极大**（邻域 ±1 点是否都比它低）；③ 离边距离 `SMAX − |x_peak|`、`SMAX − |y_peak|`。
🔧 这三样一次打印出来：`python scripts/beam_peak_check.py <beams 目录或文件> --baz <子阵理论 BAZ>`
（逐文件报 峰位/prom/内部极大/离边距离/源向锥内最强与相对 dB/判定；换网格复核时把两批 beam 一起喂给它比）。

## 4c. 逐频点、每个频点各自合法网格的扫描（
"这张图能当证据吗"的正确做法）

固定 `SMAX` + 宽带的慢度图必然在混叠区（§4 末），不能当"有没有波前"的证据。改成：

```
对带内每个频点 k 单独算：SMAX_k = 111.195/(2·f_k·d_min)
   → 该频点的网格一定合法；再扫一遍并把结果存表
表列：dataset, k, f_Hz, SMAX_safe, SMAX_used, B(真值), B(0), z, p_gridmax, peak_slow, peak_baz,
      peak_B, truth_inside（真值是否在合法网格内）
```

必带两项判据：
- **`z` = (B(真值) − μ_null)/σ_null**，零假设 = 同窗长/同频点/同白化的**逐台独立高斯噪声** 200 次；
  网格极值用 `p = P(零假设网格最大值 ≥ 观测网格最大)`。
- **`B(0)`（零慢度值）必须一起报**：低频点上"波包整体平滑起伏"会给出高 B，只有
  `B(真值) 明显 > B(0)` 才能排除"公共模式主导"（XA G1 T-S 窗实测 0.99 vs 0.63）。

XA G1 T-S 窗（143.5 s → 只有 4 个频点）实测形态：相干集中在**窗长允许的最低频点**
（0.007 Hz：真实 Z 0.978 / 真实 T 0.988，z≈3.7–3.9、p=0.000，峰 26.5–26.7 s/°@131–133°，
合成参考同频点 0.992/28.2@138），≥0.014 Hz 就掉到 z<2.4；0.021/0.028 Hz 的合法上限只剩 26/20 s/°
⇒ 真值已在合法网格之外（`truth_inside=False`，那一格的 B 值无意义）。
⚠️ 最低频点处于分辨率极限（周期 ≈ 窗长），只有 1 个频点支撑——报"低频相干"时要写明这一点。

⚠️ **笛卡尔网格别画在极坐标采样上**：网格点要量 `(sx, sy)` 两个独立坐标（
`prj = R_x·sx/111.195 + R_y·sy/111.195`），在 `(|s|, BAZ)` 上采样却标成 "E-W/N-S" 会让
理论圈/真值标记与色图错位；峰值提取用 `slow = hypot(sx, sy)`、`baz = atan2(sx, sy)`。

## 5. 频带 `FRNGS`

- 上界：论文给定的包络低通（Zhou2021 = 0.25 Hz），且必须低于采样 Nyquist（fkvolume 有检查）。
- 下界：≈ `1/T`（窗长的物理下限）。
- 分段：按**相位相干性**切（本项目 0.005–0.03 / 0.03–0.08 / 0.08–0.25；b1 最相干、b3 ≈ 随机），
  理由与实测相位残差见 `envelope-fk-band-coherence.md`。

⚠️ **“这个 f 是哪来的？是按那个 0.25 Hz 滤波算的吗？”——用户会连问两次，先分清两件事**：

1. **预处理（2–8 Hz 带通 → Hilbert 包络 → 0.25 Hz 低通）只决定数据里还剩哪些频率**，它给的是
   **上限**（>0.25 Hz 的成分已被滤掉，F-K 也用不到），**不是 f 本身**。
2. **`f` = 你选的频带内、对包络做 FFT 得到的那些频点**（`f = k·Δf`，`Δf = 1/(nspts·dt)`）；
   F-K 对**每个频点各算一张慢度图**，每个 f 各有一套混叠上限，**整带取最高频那个**。

例子（T = 213 s ⇒ Δf = 0.0039 Hz）：带 0.005–0.03 Hz ⇒ 6 个频点 0.0078…0.0273 Hz（这些数才是 f）；
带 0.02–0.25 Hz ⇒ 59 个频点，`f_max` = 0.25 Hz（§4 末的整带上限就是这么来的）。
⚠️ 报参数时**截止与采样率不要混**（用户会直接问“包络降到 2 Hz 什么意思，不是 0.25 Hz”）：
0.25 Hz 是低通截止、2 Hz 是采样率（`dt = 0.5 s`）；重建与核对方法、换采样率的实测结论见 §2e。

⚠️ 答话口径统一见 §4b：**只给公式链**（待求量放左边 + 逐项说明来源），本案例数字只在核对时补，
不要先铺长表格或例子。

### 6b. 视慢度 = 射线参数：`s = 111.195 · sin i / v`

⚠️ **用户 2026-10-08 纠正的三条（报数/汇报时必须带）**：

1. **"陆地计时"输入不是纯观测场**：F-K 的 land-time 数据 = 实测到时 − 每台 `ocean_km/1.48`，而
   `ocean_km`/`land_km` 的拆分取决于**假设的登陆点（−1000 m 参考）与海相声速 1.48**。
   ⇒ 模型场梯度（含 `|∇L_land|`）与观测 F-K 峰一致，**部分是"同一套几何假设进、同一套几何假设出"**
   （S5：观実 25.7~30 vs 模型 25.36）。汇报要主动声明这一点，被问才不会被动。
   量化参考：海速 1.48→1.50（+1.35%）只改台间走时差 ~1.3 s（慢度 ~0.4 s/deg）；换参考等深线
   （−1000 → −2000 m）影响更大。
2. **偏振的"独立"是有限度的**：偏振（单台振动方向）与 F-K（台间相位差）用的是**不同信息**，互检有意义；
   但两者用**同一事件的同一批波形** ⇒ 偏振给的 i **对 F-K 方法独立，对数据不独立**。
   真正完全独立的是**坡的几何**（坡角 + 海陆速度对比 → Snell）那条路。
3. **从 R–Z 偏振读 i 必须做自由表面校正**：地表质点运动方向 ≠ 入射角（自由表面改变振幅比），
   P 波要用 `V_P/V_S` 关系反推。**直接用 `atan(R/Z)` 当 i 会有系统偏差**。做法：用自由表面传递函数
   算 `R/Z(i)` 曲线再反查。
   ⚠️ 本项目现有偏振脚本（`2_single_station_analysis/<台>/pca_polarization.py`、`pca_theory_polarization.py`）
   只做 **R–T 平面**（头注释原话"仅 R–T 平面"）⇒ 只能给方位（BAZ），**给不了 i**；要 i 得新增 R–Z 分支 + 校正。
4. **论文"预测慢度"的真正算法（2026-10-08 从导师老盘 `fk_map.m` L85–105 查到，不要再反解）**：
   既不是偏振、也不是走时场梯度，而是 **TauP(iasp91) 的射线参数**：
   ```
   cont_dis = 事件→质心 大圆路径上、-1000 m 等深线交点→质心的陆段长度 (km)
   taup_time -model iasp91 -h 1 --stadepth 0 -km <cont_dis> -ph P/S -rayp  -> 取 min
   ```
   ⇒ 得到的是 **Pn/Sn 视慢度**：**13.7 / 24.7 s/deg（8.1 / 4.5 km/s）**——正是论文正文那个
   `predicted value of 13.7 s/° (8.1 km/s)`，也与他们 `back_projection.m` 里的 `vp=8.0; vs=4.5` 同源。
   对 cont_dis 在 120–900 km 内几乎不变（Pn/Sn 渐近斜率），所以各地区数值几乎相同 ⇒ 跨研究只能比这一列。
   ⚠️ **别把它读成**"用 `sin i = u·V/111.195`（V=6.0）反解出 i=47.7°"——那是误读：8.1/4.5 是 iasp91 的
   Pn/Sn，与式(1)里陆段走时用的 6.0/3.6 是两回事。

```

v_app    = 1/p = v / sin i = 111.195 / s

             ←→ 与偏振分析的入射角 i 联立即可闭环（F-K 给 p、偏振给 i），做法见 §6d
```

⚠️ **"视速度"只有一个定义**：`v_app = 111.195/s`。以下都不是视速度，别混（用户会逐个追）：
- `Δt(Eq.1 走时跨度) / d_max`：端点斜率，且分子分母常不是同一对台站；
- `陆地段距离跨度 / 总走时跨度`（曾算出 5.68 km/s）：分子只用陆地段、分母含海洋段，量纲凑出的假速度；

真正的连续场梯度 = 对逐台理论到时做平面波最小二乘 `t_i ≈ t0 + sx·E_i + sy·N_i`，`s = hypot(sx,sy)`。

### 6d. 单台偏振入射角 → F-K 峰的"可信门禁"

用户要"**用入射角检查相关数据可靠性**"时照此做。口径：**只算他点名的那一个台**
（他会明确说"就以 SA18 为例算就行，不要用别的算了"）——不要顺手铺成全阵七台表。

入射角定义：**3D PCA**（Z,R,T 协方差主轴）取 `i = arccos|v_Z|`（从垂直方向量）；同一窗再用**独立第二
估计器**（Z 与水平分量 RMS 振幅比 `atan(水平/Z)`）复核，两者差 ≤3° 才算稳。
⚠️ 项目现有的 `SA*/pca_*.py` 只做 R-T 平面 ⇒ 给的是**水平面方位角** `atan2(v_T,v_R)`，**不是入射角**；
用户之前"测得的角"就是它，拿它去谈垂直入射角会答错口径。

五项检查，缺一项结论都要打折扣：

| 检查 | 判据 |
|---|---|
| ① 窗长敏感性 | ±2/5/10/25 s 内 i 漂移量（漂 >10° ⇒ 窗内混相） |
| ② 滑动窗 | 直线度 >0.75 的**连续段**里 i 是否稳（取该段中位与 σ） |
| ③ 分频带 | 只在 SNR 足够的频带判读；高频段 i 乱跳就弃（报该带 RMS 与直线度作证） |
| ④ 两估计器 | PCA 主轴 vs 振幅比，差 ≤3° |
| ⑤ 窗内 SNR | 弱相如实报，**不要沿用拾取表里别人口径的 SNR**（两套窗不同数） |

闭环门禁（把偏振与 F-K 绑在一起的唯一硬判据）：

```
v = sin i / p      p = s_FK / 111.195
```

| F-K 峰 | p (s/km) | 反推 v | 判定 |
|---|---|---|---|
| 与偏振自洽的峰（实例 R 窗 16.41 s/°） | 0.1476 | 5.28 km/s | ✅ 与式(1) 的 6.0 差 12%，量级合理 |
| 式(1) 梯度 17.7 | 0.1592 | 4.90 km/s | ✅ 同量级 |
| 不合理的峰（实例 C 窗 demean 10.34 s/°） | 0.0930 | 8.39 km/s | ❌ 超地壳速度 ⇒ 伪峰（其方位 246° 也不对） |
| 论文实测 10.0 | 0.0899 | 8.68 km/s | ❌ 同样超限 |

⇒ 门禁规则：**凡是反推 v 落不进 ≈4.5–6.5 km/s 的 F-K 峰判为伪峰**；再叠加方位是否指源，两条证据一起定性。
⚠️ **自由表面效应**让 P 波质点运动的地表视入射角 > 真实射线入射角（偏陡）⇒ 由 i 反推的 v **偏小**，
4.5 是下界；i 与 `s_FK` 都随窗/频带变，报结论必须带上是哪个窗、哪条频带。

实例（Zhou2021 XA G1 / SA18，2–5 Hz）：T-P 入射角 **51–56°**（±2→±25 s 稳定、两估计器差 ≤3°、
1164–1196 s 滑窗直线度 >0.75 且 σ=2.8°），2–5 Hz 内频散 ±7°、≥5 Hz 直线度塌到 0.45（能量只剩 1/10）⇒ 弃；
T-S 入射角 **≈82°**（近水平，与 T-S 横向偏振自洽）。换算慢度 `s = 111.195·sin i/v`：
T-P ≈15.1–15.4 s/°（v=6.0，落在论文预测 13.7 与式(1) 梯度 17.7 之间）、
T-S ≈30.6 s/°（v=3.6，与式(1) 梯度 30.2 吻合）。

### 6e. 入射角会不会"循环验证"：三条边界与一条不变性

用户会直接问「这个 R 是根据什么旋转的？计算入射角会不会循环验证？」——答话分三层，别混：

1. **R 的旋转依据**：`R, T = rotate_ne_rt(N, E, baz)`，`baz = gps2dist_azimuth(台站, 震中)[1]`
   ——**台站端真实大圆方位角**，纯几何量（只由坐标算出），不含任何到时/偏振信息。
   ⚠️ `stations.csv` 的 `baz` 列是**震源端**方位角（`azi1+180`），偏西 ~11°，不能拿来旋转。
2. **入射角本身不是循环量**：`i = arccos|v_Z|` 只取决于"垂直 vs 水平"的能量分配，是**水平旋转的不变量**
   ——把 baz 从真值换成错值（如 137.63° → 126.8°），i 逐位不变（实测差 0.00°）。
   自检写法：同一窗用两个 baz 各算一遍 i，差 ≈0 才算证明了这一条。
3. **真正有循环风险的两处，必须主动交代**：
   - ① **窗的选取**：若用"偏振引导的拾取窗"测 i、再用 i 去验证偏振，就是循环。
     解药 = **盲检**：滑动窗全段扫描，只按直线度门（如 >0.75）筛窗口，完全不引用拾取，
     看该段 i 的中位/σ 是否与拾取窗一致（实例 T-P 段 11 窗中位 49.7°、σ4.6°，与拾取窗 56.4° 同量级）。
   - ② **闭环里的 p 依赖 baz**：F-K 输入是 R（或 T）**分量包络**，而 R 由 baz 定义 ⇒ `p_FK` 是 baz 相关的；
     `v = sin i / p` 里只有 i 与 baz 无关。要彻底去假设：对**原始 N/E 做矢量（二维）波束形成**
     （同时解慢度矢量与偏振，不预设方位），或只用 Z 做 F-K（无需旋转）。
   - （对照）**`obs_baz = 理论 baz + R-T 角` 不是循环而是自洽**：换 baz 时两项同量反向变、和不变，需单独验证这一点。

存档形态（用户会要求"公式和结果存到文件夹"）：`<台站>/incidence_angle/` 放 README（公式链+结果表+可靠性结论+循环性分析）、
一个可重跑脚本、逐窗 CSV（centre/i_pca/i_amp/rt_angle/linearity/pass_gate）、分频带 CSV、SNR 与闭环 CSV、i(t)+直线度双面板图。

### 6g. 被问"我们测的慢度怎么这么大？对应速度多少？为什么？" —— 四件套

## 7. 可复用自检片段（本文件表格就是这么算出来的）

```python
import csv, numpy as np
from scipy.ndimage import maximum_filter

# 台站表：必须按列名读（见 §4 的列错位坑）
rows = [r for r in csv.DictReader(l for l in open(CSV) if not l.startswith('#'))]
E = np.array([float(r['east_km']) for r in rows]); N = np.array([float(r['north_km']) for r in rows])
X = np.c_[E - E.mean(), N - N.mean()]
n = len(rows); D = np.hypot(X[:, None, 0] - X[None, :, 0], X[:, None, 1] - X[None, :, 1])
iu = np.triu_indices(n, 1); d_min, d_max = D[iu].min(), D[iu].max()      # 带宽/复制峰要用这两个

ax = np.linspace(-SMAX, SMAX, SPTS); SX, SY = np.meshgrid(ax / 111.195, ax / 111.195)
def beam(f, s_deg, baz):                       # 单频平面波注入的阵列响应（位置无关，平移不变）
    s0 = np.array([np.sin(np.deg2rad(baz)), np.cos(np.deg2rad(baz))]) * s_deg / 111.195
    ph = 2*np.pi*f*((SX - s0[0])[..., None]*X[:, 0] + (SY - s0[1])[..., None]*X[:, 1])
    return np.abs(np.exp(1j*ph).mean(-1))
# 复制峰：局部极大 >0.75 且距主瓣 >3 s/deg 中最近的那一个；主瓣半宽：沿真值方向射线找 B 首次 <0.5
```

核对清单（改子阵或换频带后重跑一遍）：① `SMAX_safe` 逐频是否都 ≥ 实际 `SMAX`；
② 实际 `Δs` 是否 ≤ ½ 主瓣半宽(f_max)；③ `nfreq` 与存盘表头是否一致；④ 报出的峰是否在网格内部。

🔧 多峰读数用本 skill 的 `scripts/peaks_table.py`：`python peaks_table.py <理论BAZ> <beam文件或目录> [前N名]`
—— 导出脚本里的 `[mx, idx] = max(beam(:))` 只取全局 argmax，会漏掉第二个能团
（实例：T-S 整带的 43.8 与 9.8 s/° 两个团、论文式并集窗下 "最大峰 2.51 s/°@236° ≠ 源方向峰"）。

整带平均会把高频的折叠像摊进来（§4 末），所以诊断“数据里到底有没有指向震源的平面波前”时，
应当**每个频点各用合法网格**扫一遍，而不是一条带扫一张图：

```
每个频点 f_k:  SMAX_k = 111.195 / (2·f_k·d_min)        ← 该频点自己的无混叠上限（不要统一取 ±35/±78）
判据不变:       B(s) = |Σ_i X_i(f_k)·e^(−i2π·f_k·s·r_i)| / N      （白化谱）
必报四列:       B(真值) | B(0 慢度) | z = (B−μ_null)/σ_null | 网格极值 p
还要报:         真值是否落在该频点的合法网格内（不在 ⇒ 该格无意义，不得当证据）
```

- **为什么必须报 B(0 慢度)**：低频点的相干可能只是“波包形状各台相似”（公共模式），与平面波前无关。
  真峰要同时满足三条：显著（z/p）、**明显高于 B(0)**、网格最大值落在真值附近而不是原点。
  ⚠️ **判断"理论点有没有信号"要拿它跟 B(0) 比，不能只跟峰值比**（2026-09-17 G1 的 T-P/R 实测教训）：
  主瓣半宽 `0.64·111.195/(f·D)` 随 f 变宽（G1：0.0078 Hz → **29.2°**、0.0312 Hz → 7.3°），
  低频时理论慢度（13.7 s/°）**必然落在 0 慢度主瓣内部** ⇒ "理论点只比峰低 0.8 dB"是几何必然，不是信号。
  G1 的 T-P/R 七种配置实测：`beam(0°)` 永远紧贴峰（−0.15…−0.54 dB），而理论点比 0 慢度**低 0.3–11.6 dB** ⇒ 无 T-P 信号。
- **为什么这项不比带平均“多此一举”**：每个频点单独算时 SMAX 变小（合法），峰要么真、要么无峰；
  带平均反而会把高频道上的折叠像混进低频结果里。
- **XA G1 实测（T-S 窗 143.5 s，带内只有 4 个频点）**：相干信号集中在**窗长允许的最低频点 0.0070 Hz**
  ——真实 Z 与 T 都在 26.5–26.7 s/°@131–133° 出峰（B≈0.98–0.99、z≈3.7–3.9、p=0.000），
  B(0)=0.63–0.64 明显低于峰；合成参考同频点一致（0.992／28.2@138）。**≥0.014 Hz 无显著峰**（z<2.4），
  而 0.021/0.028 Hz 的合法上限只有 26/20 s/°，连 30.89 s/° 都装不下。
- ⚠️ **最低频点 = 窗长的分辨率极限**（周期 ≈ 窗长）：该格只有 1 个 bin 撑着，要当定论必须换更长窗复核
  （而本项目又受“别装进 T-P 尾巴”限制 → 回到 §2b 的那个矛盾）。
- ⚠️ **谱布局契约**：`beam_at` 要 `[nf, N]`。`whiten(rfft(noise))` 出来是 `[N, nf]`，**必须先转置**再取频点行；
  写错不会报错，只会让零假设的 σ≈0，z 变成 1e15 量级（假的“极高显著”）。自检：真实 z 应在 O(1)–O(5)。
- 实现：`4_fk_analysis/diag_rootcause/02_bin_scan/`（`step1_bin_scan.py` + 表/日志/图 + README），
  直接 import `01_wavefront/step1_wavefront_test.py` 复用同一套 `beam_at/whiten/spec/prj_of`（勿另写一套）。

### 8b. 逐频点 × 三分量 × 两窗长的对照扫描（"每个频点如果出图，慢度会是多少"）

用户会要"**把每个频点的值、三分量、两窗长都做一个对比**"，并且"到某个上限频率为止"。固定 SMAX 扫所有档：

```
每个窗各有自己的频率阶梯（Δf 由窗长定 ⇒ 两窗的 k 序号不同名，报数必须同时写 f 与窗长）
  143 s 窗：Δf 0.0039 → k = 1…8  （0.0039 … 0.03125 Hz）
  256 s 窗：Δf 0.0020 → k = 1…17（0.0020 … 0.03320 Hz）
每格单跑：FRNG = [f−0.0005, f+0.0005]、SMAX/SPTS 固定（与既有图可比、只换频点）
逐行 append 到 TSV：win_len, comp, k, f, peak_slow, peak_BAZ, |dBAZ|, prom
另列两列合法性：① f ≥ 1/T（窗长下限） ② f ≤ 0.550231/SMAX（无混叠上限）
```

⚠️ **固定 SMAX 时，`f > 0.550231/SMAX` 的档全是混叠区**（SMAX 42.2 → f > 0.0131 Hz）：实测这些档读数在
1–60 s/° 之间乱跳、方位随机 ⇒ 表里必须标注/灰掉"不可用"，否则会被读成"高频也测到了东西"。
⇒ 这条扫描同时是"频带上限 ≤0.0131 Hz"那条判据的**实测依据**，写汇报时可直接当证据用。

**G1 实测形态**（T 分量 / coarray / SMAX 42.2 / SPTS 243，75 次单跑）——"三分量一致 + 方位指源 + 显著"只有这几档：

| 窗 | f (Hz) | Z | R | T | prom | 主瓣半宽 |
|---|---|---|---|---|---|---|
| 143 s | **0.0078** | 35.31@138° | 35.78@133° | 34.79@137° | 8.9–9.8 dB | 29.2 s/° |
| 256 s | 0.0039 | 23.23@139° | 20.77@139° | 25.67@137° | **2.7–3.1 dB** | 58.3 s/° |
| 256 s | 0.0059 | 16.54@132° | 15.78@135° | 22.71@137° | 6.4–7.8 dB | 38.9 s/° |
| 256 s | **0.0078** | 25.65@135° | 24.52@140° | 30.45@140° | 8.7–8.8 dB | 29.2 s/° |

- **0.0078 Hz 是两个窗里唯一"三分量一致 + 显著性高 + 方位对"的档**；两窗读数 34.8–35.8 与 24.5–30.5
  差 15–25% ⇒ 同一档换窗长就漂，只能报量级（§9b 同一结论的另一条证据）。
- **0.0039 Hz 必须配 ≥256 s 的窗才存在**：更短的窗里 Δf 变粗（如 114 s 窗 Δf = 0.0078），阶梯上根本没有这一点；
  即使合法，prom 也只有 2.7–3.1 dB（0.0078 档的 1/3），且主瓣半宽 58.3 s/° **大于目标慢度本身** ⇒ 只作低频侧提示。
  在不合法的短窗里它给 14–17 s/° 但 prom 仅 2.4 dB（= 平背景上的落点，不是结果）。
- **≥0.0098 Hz 方位就散**（|dBAZ| 20–170°）；**≥0.0131 Hz 进混叠区**不可用。
- 0.0117 Hz 是唯一"分量之间打架"的合法档（Z/R 给 40–42@142–143° 而 T 给 4.3@256°）⇒ 一律不报（§8 的第③条分量互检）。

**成本与运行**：单频点单跑只算 1 帧 ⇒ **75 次几分钟内跑完**（贵的是宽带多帧，不是档数）。
长扫描（>1 min）用工具的后台模式启动并落 log，不要靠 shell `&`；脚本**每算一格就 append 一行**，中断后不必重跑。

**对比图 recipe**（用户说"做一个对比"时）：两面板 = 两窗长；x = f (Hz)、y = 峰慢度 (s/°)；三色线 = Z/R/T；
**实心点 = |dBAZ| ≤5°（方位指源）、空心点 = 方位不对**；灰底 = 混叠区；一条水平虚线 = 论文值；
轴下再标该窗的 k 序号。一张图就能读出"哪档能信"。

### 8c. "把整段合法带一起平均"救不回来 —— 四组合法带实测（两相 × 两窗）

用户会顺着 §8b 说"那就把两个窗各自的合法带都做出来看看"（本次即 T-S `[0.0078,0.0117]` / `[0.0039,0.0117]`、T-P 同规则）。
**做，但先给结论**：合法只保证"不混叠"，不保证"有信号"；`带 = [1/T, A(1−k)/u]`，同 SMAX/SPTS 固定，T-S 用 T、T-P 用 Z+R，coarray：

| 相 | 窗（绝对计时） | 合法带 / 档数 | 分量 | 峰慢度 | \|dBAZ\| | prom | 判定 |
|---|---|---|---|---|---|---|---|
| T-S | 1243–1386（143 s） | 0.0078–0.0117 / 2 | T | 11.59@136° | 1° | 5.8 dB | 方位对；慢度＝两档平均劈出的次团 |
| T-S | 1243–1499（256 s） | 0.0039–0.0117 / 5 | T | **42.23@149°** | 12° | 6.6 dB | ⚠️ 峰贴网格边缘（SMAX 42.2）⇒ 边界伪影，不可用 |
| T-P | 1173–1292（119 s） | 0.0156–0.0312 / 3 | Z / R | 0.99@135° / 0.00（原点） | 2° / — | 8.9 dB | 近零针尖；R 全塌在原点 |
| T-P | 1036–1292（256 s） | 0.0039–0.0312 / 15 | Z / R | 0.78@153° / 1.10@288° | 16° / 151° | 7.1 dB | 近零 + 方位也散 |

三条规则：

- **加宽合法带 ≠ 更稳**：档数一多，各档主瓣半宽从 58 s/° 跨到 19 s/°（§4），平均后 argmax 不稳；5 档那格直接把峰推到网格
  边缘（42.23 ≈ SMAX）⇒ 报数前先过 §9 判读第 1 条（峰必须在网格**内部**）。能用的仍是**最低那一两档**（§8b 表）。
- **扩 T-P 的窗要往"早"扩**：T-P 到时 1203–1250 s 紧接 T-S 到时 1272–1344 s，往后拉 256 s 必装进 T-S
  ⇒ 一律向前扩（实例 1173–1292 → 1036–1292），并按 §2a 一句话说清"窗内装的是哪一相"。
- **T-P 在任何合法带配置下都别报慢度**：3 档 / 15 档、119 s / 256 s 全给 0.78–1.10 s/°（v_app >100 km/s），
  只有 119 s/3 档的 Z 方位勉强对上（2°）——与 §9 判读第 4 条一致：公共模式，不是平面波。

交付形态（用户会数图）：T-S 单面板 ×2、T-P **Z/R 双面板** ×2，共 4 张、**只出 PNG**；轴半宽 = 网格半径就近取整到 5 的倍数
（T-S ±40 / T-P ±15）；出图后跑 §9 的 `scripts/fig_ink_margins.py` 量四边留白。

   （Z 35.3 / T 34.8 s/° @137–138°，|dBAZ| ≤ 1°，center 与 coarray 逐位一致）；0.0117 Hz 那档**无方向性**
   （峰落在 0.3–4.2 s/° 的随机方位）。⇒ 该窗的**定性**读数 = "最低合法频点上存在指向震源的相干能量"；
   慢度数值 ≈35 s/°（⇔ v_app 3.18 km/s，比式(1) 的 3.6 还慢）**但随窗长在 7–35 s/° 间漂移，不得当测得的慢度报**
   （窗长稳定性表见 §9b）；与论文 24.7 只能写"相差 +41%、落在分辨率地板内不可分辨"。
   🔴 **两档一平均会把主瓣劈成"两个几乎等高的团"**（11 与 45 s/°）：用户盯整带图时会直接问"怎么有两个峰值"——
   答法 = 拆单频点重跑、指出两团都是平均伪影，不要当两个真实震相；判读新规则：**慢度按逐频点报数，整带图只作粗筛**。

   **平均这一步的口径出处（用户会追“源码和理论出处有平均吗”）——两部分答案不一样，别都答“有”：**
   ① **源码有**：Seizmo 官方函数 `fk/fkvol2map.m`，说明首句即 “averages the fk beam data in VOL across
   the frequency range”，实现一行 `vol(i).beam = sum(vol(i).beam(:,:,fidx),3)/sum(fidx);`
   —— 与本项目脚本的 `mean(s4d(1).beam,3)` **逐字等价**，且它的 Note 明写“在 dB 域平均”
   （我们的波束文件存的正是 dB）；`fk4d` 本身**不做**平均，返回的第 3 维就是频率。
   ② **理论没有**：Rost & Thomas (2002) 只给单频点的 ARF/PSD 定义与分辨率约束（它的 ARF 图都是单一
   频率），**全文不含“频带内如何合并”的规则** ⇒ 合并方式是软件约定，不是方法步骤；提示用户“每个
   频点各出一张图”才是理论支持的读法。
   ③ **两团高度实测**（T-S 整带平均后）：T 分量 11.59 (0 dB) vs 46.29 (−0.31 dB)、Z 44.40 (0 dB) vs
   10.26 (−0.64)、R 12.33 (0 dB) vs 31.28 (−0.35) ⇒ **两团只差 0.3–0.6 dB（噪声量级），argmax 随分量/
   method 翻**。用户看到“40 多那里还有个圈”时，正确的解释是“**它在同一张平均后的图里，只是不是最大值**”，
   不是“没参与平均”。

**🔴 三分量交叉验证（必做；用户会问"那 T-S 的 Z 分量？T 分量呢？每个分量都做一下"）**：
同一窗、同一合法频点把 **Z/R/T 三个分量各跑一遍**（版式 = 2 行相位 × 3 列分量的 2×3 网格，每个 method 一张图），

`字符数 × 0.5 × 字号/72` 英寸）；页脚 y 低于 ~0.02 会把下留白压到 1 px ⇒ 页脚 y 取 0.045/0.018、
`subplots_adjust(bottom≥0.175)`。自检**一律量四边留白**，脚本：`scripts/fig_ink_margins.py <png 或目录>`。

**要提高分辨率只能换几何**（改 f / 改窗 / 改 SMAX 都没用，见 §4 的地板）：按 `k = 1.28·d_min/D` 枚举候选子阵
（脚本 `4_fk_analysis/subarray_plan_survey.py`；台对距离用 `gps2dist_azimuth` 精确大圆，别用局部平面近似——
投影原点不同会让 d_min/D 差 0.5% 以上）：G1 southern（7 站）**41%** / 孔径 ≤400 km 内最优（9 站）27.5% /
≤800 km（21 站）11.2% / XA 全台网（37 站）5.6%。要 10%：`D ≥ 1423 km`（d_min 101 不变）或
`d_min ≤ 22 km`（D 312 不变）；要 25%：647 km / 49 km。

**给定"参与平均的最高频点 `f_max`"反推几何需求**（用户会这样问："用 ≤0.25 Hz 的数据，D 该多少"）：

```
抗混叠（定台间距）： d_min ≤ 111.195 / (2·f_max·u)
分辨率（定孔径）  ： D     ≥ C·111.195 / (f_max·δ·u)      C = 0.64（半幅），δ = 目标相对精度
f_max = 0.25 Hz、δ = 10%：u = 10.0 / 13.7 / 24.7 s/° ⇒ d_min ≤ 22.2 / 16.2 / 9.0 km，D ≥ 285 / 208 / 115 km
```

⇒ 用 0.25 Hz 时**卡的是台间距、不是孔径**（G1 的 D = 312 km 本已够，d_min = 101 km 差 5–11 倍）；
这也印证了论文那句 "f < 0.25 Hz" 与它自己 ~107 km 平均台间距不相容（见 §6c ⚠️）。

## 9b. 峰是"伪影"还是"掺相"：三条判别测试 + 单频点峰的窗长稳定性

用户会盯着数值直接问"**这个 T-S 频带怎么把符合 T-P 的结果慢度图算出来了？**"（实例：T-S 带在 T-S 窗上给
11.59 s/°@136°，而 T-P 的目标是 10.0–13.7 s/°）。先别改口径、也别顺着"掺相"答——按顺序做下面三条，一次排干净：

| 测试 | 做法 | 判据与实例 |
|---|---|---|
| ① 切另一相 | 把窗起点推到另一相**理论到时的最大值之后** | 峰不消失 ⇒ 不是它掺进来的（11.59 → 8.63 s/°@133°，仍在近零区） |
| ② 换带不换窗 | 窗**一字不动**，只把频带换成另一相的带 | 给出完全不同的东西（1.74 s/°@323°，方位近反向）⇒ 那个值不是另一相贡献的 |
| ③ 分量互检 | 同窗同带 Z/R/T 各跑一遍 | **同一窗同一带宽两个分量差 4 倍（Z 44.4 vs T 11.6 s/°）⇒ 必是伪影**；真波前三分量必须给同一慢度矢量 |

回答"为什么数值恰好接近另一相"：**近零慢度区是同一片平台**，任何伪影峰都落在 0–12 s/° 量级
（11.6 s/° ⇔ 9.6 km/s、10.0 s/° ⇔ 11.1 km/s，都远高于任何地壳视速度）⇒ 数值接近是"同处测不到慢度的区域"
的巧合，不是同一物理量；**不要写成"两个相位都测到了"**。

### 单频点峰的窗长稳定性（报"测到多少 s/°"之前必做）

同一频点、同一分量，只改窗长（保持 0.0078 Hz 这个 bin 与 T-S 窗相容），G1 实测：

| 窗（绝对计时） | 窗长 | 1/T | 峰慢度 | 峰 BAZ | prom |
|---|---|---|---|---|---|
| 1243–1386 | 143 s | 0.00699（合法） | **34.79 s/°** | 137° | 8.91 dB |
| 1258–1386 | 128 s | 0.00781（合法，最短） | **27.40 s/°** | 138° | 8.76 dB |
| 1272–1386 | 114 s | 0.00877（`0.0078 < 1/T`，不合法） | 19.29 s/° | 139° | 8.56 dB |
| 1300–1386 | 86 s | 0.01163（不合法） | 6.98 s/° | 143° | 8.34 dB |

⇒ **方位稳（137–143°）、prom 稳（8.3–8.9 dB），但慢度随窗长漂 5 倍**（34.8 → 7.0）⇒ 该频点只能声称
"窗内存在指向震源的相干能量"，**35 s/° 这个读数落在 §4 的 41% 几何分辨率地板内、换个窗长就跑到 7 s/°，
不能当测量值**。汇报句式："T-S 窗最低合法频点上出现指向震源的峰（|dBAZ| ≤1°），慢度读数 ≈35 s/° 但受
分辨率地板限制不可定量；T-P 窗各分量均为近零针尖，无可分辨平面波前。"
⚠️ 后两档窗长严格不合法（含 bin 也照跑），只作稳定性参考；做这个测试时**窗长必须写进表里**，
否则分不清"窗长效应"与"频点效应"。

### 9b-2. "把窗口后移去覆盖另一相"是死路：这是频段问题，不是窗位问题

用户会接着要求"用甲相的频带 + 把窗后移覆盖乙相的到时"（想借高分辨率带救回慢度）。**别只跑他点名的那一格**，
一次做"频带 × 窗位"两张扫描（T 分量、coarray、窗长固定 143 s ⇒ `1/T = 0.00699` 全部合法）：

| 窗（绝对计时） | T-P 带 0.020–0.035（`u_max` = 10.3） | | | T-S 带 0.005–0.014 | | |
|---|---|---|---|---|---|---|
| | 峰慢度 | BAZ | \|dBAZ\| | 峰慢度 | BAZ | \|dBAZ\| |
| 1243–1386 | 1.74 | 323° | 174° | 11.59 | 136° | 1° |
| 1256–1399 | 1.44 | 76° | 61° | 12.33 | 135° | 2° |
| 1270–1413 | 2.88 | 104° | 33° | 11.35 | 137° | 0° |
| 1284–1427 | 1.74 | 143° | 6° | 8.63 | 137° | 1° |

T-P 带单独细扫（起点每 7 s 后移一格、窗长恒 143 s）：峰 BAZ 依次 **323 / 118 / 76 / 0 / 90 / 180 / 146 / 117 / 27°**
（\|dBAZ\| 9–174°），慢度恒在 0.35–8.3 s/°。

三条结论（报数就按这个顺序）：

1. **频带抬到 0.02 Hz 以上就测不到指向震源的慢度**——与 §8 的"≥0.014 Hz 无显著峰"一致；
   换窗位救不回来，因为指向震源的相干能量只存在于**窗长允许的最低合法频点**（143 s 窗的 0.0078 Hz）。
   因此"用 T-P 带去覆盖 T-S 到时"不是窗位问题，别再去挪窗。
2. **单格"对上了"不算证据**：9 个相邻窗位里只有 2 格 \|dBAZ\| < 30°，且相邻窗位立刻跳到 61–174°
   ⇒ 近零平台上的随机落点。判据 = **相邻窗位可复现**；单窗一命中一律先按偶然处理。
3. **稳的是方位、不稳的是慢度**：T-S 带 4 个窗位全给 135–137°（\|dBAZ\| ≤ 2°，prom 随窗后移升
   5.77 → 8.88 dB），而慢度在 8.6–12.3 s/° 之间飘（同样条件下单频点单跑是 34.8）
   ⇒ 只报"存在指向震源的相干能量 + BAZ"，慢度一栏写"受分辨率地板限制不可定量"。

## 10. method 三选一的定义与对照（用户会问"还有别的方法来着？full？"）

| method | 台对 | 备注 |
|---|---|---|
| `coarray` | 上三角台对 N(N−1)/2 | 项目默认 |
| `center` | 各台对阵中心 N 对 | Zhou(2021) 用的 |
| `full` | 全部配对 N²（**含自配对 = 零延迟项**） | 用户口头问的那一个 |

2026-09-17 G1（`03_fk_paper_measured_params/` 同一批参数）三方法实测：
**`full` 与 `center` 峰位逐位相同**（多出的自配对只抬 prom：T-P Z 10.46 vs 10.49 dB、T-S Z 7.73 vs 7.70 dB，
峰不动）；`coarray` 峰位也几乎相同，但 prom 低 ~1.5 dB、−3 dB 面积约大一倍（更弥散）。
⇒ 被问"换个 method 是不是就测出来了"时，先用这张表把 method 这个变量排掉，再查频带/窗/几何
（实例：T-S 的 T 分量三方法都给 11.1–11.6 s/°@136° ⇒ 11 s/° 不是 method 造成的）。
脚本写法：`export_*.m` 里 `METHODS = {'center','coarray','full'}`，后缀 `''`(center) / `'_coarray'` / `'_full'`；
出图脚本按同一规则取文件（`SFX = "" if METH=="center" else f"_{METH}"`），别把后缀硬编码成 coarray。

⚠️ **用户问"还有别的方法来着 / full？"时：直接补跑并出那张图，不要只解释差别**（他要的是能看的对照）。
同批参数、新后缀、新文件名；补完把三方法的峰位排成一张对照表，并明说"哪个变量被排除了"
（实例：三方法都给 11.1–11.6 s/° ⇒ method 被排除，问题只能出在频带/窗/几何）。

本文件只补两条最容易搞错的口径：

- **必须在共用的绝对时间轴上 cut，再逐台平移**；先平移、后按陆地计时 cut 等于额外扣掉各台海段之差，是另一个口径。
- `getheader(data,'b')` 返回**逐道向量**（n×1），不能与单道时间轴（如 1001×1）直接相加；
  且写错字段时平移/注入**静默不生效**（不报错、照出结果）——自检：换一组参数重跑，两份结果逐位相同就是没生效。

## 13. 判"哪个峰是信号"：无信号对照窗 + 不要用 prom（2026-09-22 XA G1 实测）

用户问"这个弱峰是什么 / 是不是镜像孪生 / 直接筛掉算不算造假"时按本节答。

### 13a. ±u 对称性：只在"丢掉互谱虚部"的估计量上成立

- 波束里带方向信息的是台对互谱 `C_ij = X_i·conj(X_j)` 的**虚部（正交谱 = 台间时延方向）**。
  只保留实部（协谱）⇒ 时延符号被抹掉 ⇒ `B(u)=B(−u)` 严格成立，这才是"F-K 180° 模糊"的来源。
- **本引擎保虚部**：`seizmo/fk/fkvolume.m:378–417` 是 `cs./abs(cs)` → 唯一台对 `C_ij` →
  `Σ_pairs C_ij·exp(i·2πf·p_ij(u))` → `10*log10(abs(real(·)))`（注释：照 Koper, Seats & Benz 2010 BSSA）
  ——**求和之后才取实部** ⇒ 方向有分辨。
- 合成注入实测（真值 30 s/°@137.3°，G1 几何、窗 120–270 s、0.0078 Hz、网格 ±42.2/243）：
  镜像点电平 coarray+real（本引擎）**−10.7 dB**、coarray+abs² −13.4 dB、全有序台对+abs² −21.4 dB、
  延时叠加 −10.9 dB；只有"只留互谱实部"那一行给出 **−0.00 dB 且全图 B(u)≡B(−u)（中位/最大 0.00/0.00 dB）**。
  ⇒ 四种真估计量**都没有**孪生；不要再说"必然镜像"。
- 对称性随 `|u|` 增大而破缺：实数据里 `|u| ≲ 10 s/°` 的近零族与其镜像点差 −0.01…−0.3 dB（近似成对，
  看着像"另一半"），而 30 s/° 真峰的镜像点低 6–12 dB（不成对）。
  脚本：`G1/04_landtime_fk/check_estimator_symmetry.py`（含注入自检，残差应 0.0000 rad）。

### 13b. 近零慢度族 = 与目标相无关的共模能量（用无信号窗判定）

对照窗 = **同一带、同一网格、同一 method，只把窗换到完全没有目标相的时间段**。
XA G1（陆地计时 −60…90 s，比 T-S 理论包 173.6–235.3 s 早 80 s 以上）：

| 特征 | T-S 窗 120–270 s | 无 T 波窗 −60…90 s |
|---|---|---|
| ~30 s/°（源向真 T-S） | 28.4 s/°@132°，prom 5.12 dB | **不存在**（argmax 塌到 ≈0）|
| ~10 s/°（源向） | 10.7 s/°@136.3° | 不存在 |
| 近零族 ~8 s/° | 8.2 s/°@316.7° | **同样存在**：T 1.76@0°、Z 0.79@63°、R 0.79@333°，与镜像点差 −0.01…−0.08 dB，**prom 9.18–9.25 dB** |

⇒ 近零族是**与目标相无关的各台共同低频相干能量**（包络链长周期端公共成分／共模噪声）。
⚠️ **推论：`prom`（峰−中位）不能当显著性判据** —— 无信号窗的 prom 比真信号峰还大（9.2 vs 5.1 dB）。
判"是不是信号"只能三条：① 方位 = 理论大圆 BAZ（勿用 `stations.csv` 的 baz 列，偏西 ~11°）；
② 慢度 = 与 F-K 无关的滞后拟合；③ **随目标相出现而出现、在无信号窗消失**。

⚠️ **跨图比较必须用"值 − 该图中位"**：每个 beam 文件是按**各自峰值**归一的（0 dB = 各图自己的峰），
绝对 dB 不能跨图比；只要各图背景中位近似相同（实例 −9.08 / −9.12 / −9.24 dB，差 <0.2 dB），
就可以用"相对中位的 dB"并列比较（13b 的表就是这个口径）。报数时把中位一起写出来，读者才能核。

### 13c. 排除无关能量不算造假的前提（判据前置 + 全量报告 + 独立证据）

1. **判据前置**："什么算信号"在看结果之前写死（即 13b 的三条），与"希望看到什么"无关；
2. **频带/窗由公式定**：带上下限来自 `1/T` 与 `SMAX ≤ C/f_hi`，窗来自 `[min(理论)−30, max(理论)+50]`，
   不是按图挑；换到最低合法频点这类操作必须有公式依据（`f ≥ 1/T` 的最低档）；
3. **遮罩只作表达**：`MASK=origin/back` 半径取自主瓣半宽 `0.64/(f_hi·D_deg)`，并在图注写明"已遮什么、依据是什么"；
4. **报告里列出被排除项**（把近零族等一并列出 + 对照窗数字），读者可复核。

缺任何一条才构成问题；四条都做 = 常规处理。范例落档：
`G1/04_landtime_fk/07_derivation_fig_ts120_270_T.md`（§7 判定、§8 正当做法）。

### 13d. 用户说"窗口选择你对比一下，选最好的一个出图" —— 落地表 + 两处溢出复核

做法（一次跑完，不要逐窗慢慢试）：候选窗（至少含一条**不含另一相**的窗、一条**无信号对照窗**）× 三分量各跑一遍
（入口 `.m` 里加 `RUN_METHODS={'coarray'}` 之类的环境开关只跑默认方法，一个配置 3 分量 ≈ 50 s），
把每格在**两条慢度支**（T-P 支 ≈ `111.195/6.0`、T-S 支 ≈ `111.195/3.6`）上、**方向落在理论视向 ±20° 内**的
最强局部极大列出来（dB 相对各自峰值），再逐列减掉对照窗同判据的值 —— 差值就是"该窗多出来的东西"。
判据写在表头之上（前置），**不要用 prom、也不要用全局 argmax**（13b/13c）。

G2 实测（陆地计时、SMAX 30 / SPTS 171 / coarray、T-S 支 26–40 s/°；[边] = 峰钉在网格边界）：

| 候选窗 | T | R | Z | 窗内有 T-P 尾 |
|---|---|---|---|---|
| 规则窗 142.5–293.1 | 37.6@141° −3.55 | — | — | 有 |
| G1 口径 120–270 | 39.3@139° −2.88 | 38.4@141° −4.44[边] | 38.2@142° −3.95[边] | 有 |
| **150–280（定稿）** | **38.0@128° −0.79[边]** | **39.1@130° −1.71[边]** | **32.2@148° −4.61** | **无** |
| T-P 窗 73.5–195.8 | 27.9 −8.18 | — | 32.7 −8.30 | 只有 T-P |
| 无信号窗 −60…90（对照） | 29.4 −7.85 | 31.9 −8.23 | 32.4 −8.12 | 无任何相位 |

三条读法：① **T-P 窗在 T-S 支上与对照窗同水平（−8.2 dB）⇒ 不可判读**（换频带也救不回，见 §4 地板）；
② 三个 T-S 窗的源向特征都比对照窗高 **4–7 dB**，取其中最强的；③ 窗里带 T-P 尾的窗会在 **T-P 支**多出
−2.3…−4.6 dB 的强峰（§2a 的量化版）⇒ 定稿窗取**把 T-P 理论包整段排掉**的那个（起点 > T-P 理论包最大值）。

**出图前必查两处"溢出"**（用户会明确要求"有溢出上下限就另外告诉我"）：

1. **网格边界**：判据**不是**比较 `|u_peak|` 与 SMAX（方格角点可达 `√2·SMAX`，`u > SMAX` 本身不违规），
   而是看 `|x_peak|` 或 `|y_peak|` 是否顶到 SMAX（§4b-1 的三件自查）。G2 在 ±30 下 T/R 的 T-S 支峰 x = 30.00
   正好贴边 ⇒ 38–39 s/° 是**被截的**读数；换 ±37.2（3 档最大内切圆）或 ±45（收一档频带）后峰回到格内，
   同一特征在 u ≈ 32–42 s/°、BAZ 124–149° 之间摆动 ⇒ 可以说"特征存在"，报具体慢度**必须带网格半径**。
2. **色标**：**先算落在色标范围内的网格占比**（`np.mean(D >= vmin)`）。G2 定稿窗三格只有 **1.7–2.5%** 的点 ≥ −0.7 dB
   （数据 −24…0 dB、中位 −5…−8 dB），而源向特征比近零共模峰低 **0.8–4.6 dB** ⇒ 按 `−0.7…0 dB` 的固定色标
   **图上只剩中心那一坨、特征被压成最低色而看不见**。⇒ 固定色标出图的同时**另出一张色标放宽到特征电平的诊断版**
   （如 `ERANGE=-5`），并在回复里说明"哪张是定稿口径、哪张才看得见特征"。G1 没这个问题，只是因为它那套窗里
   T-S 峰本身就是全局峰 —— 换子阵/换窗后这条要重算，不能沿用。

落档形态照 §13c：`<子阵>/04_landtime_fk/07_derivation_fig_<tag>.md`（候选表 + 判据 + 两处溢出 + 复算命令 + "待用户定"三项）。

| `tt_p`（TauP P，绝对计时） | **10.77 s/°** | 137.3° | T-P_local **10.0** ✓ |
| `tt_s`（TauP S，绝对） | 19.69 s/° | 137.3° | — |
| **`tt_ts` = `tt_ocean + tt_land_s`（绝对）** | **23.90 s/°** | 136.8° | T-S_local **24.7** ✓ |

## 15. 慢度峰不是地理位置：把 F-K 结果画到地形图上的正确形态

用户会问"能不能把慢度图放到地形图上？中心为子阵、峰值为转换点，对吗？"——照此答，别顺着点说"对"：

- **中心 = 子阵：对**（慢度矢量定义在台阵参考点，峰的方向 = 信号来自的方位 = 引擎报的 BAZ）。
- **峰 = 转换点：不行**。慢度图的两个轴是慢度 s/°（`POLAR=false` 的笛卡尔网格 `(sx, sy)`），**不是距离**：
  峰只给 ① 方向（BAZ）② 视速度 `v_app = 111.195/|u|`（实例 28.4 s/° → 3.9 km/s）。图上同心圆 = 等视速度线，
  **不是等距线** ⇒ 一张慢度图只等价于"从子阵出发的一条方位线"，落不到一个点。
- 要落到点必须有**距离**约束：① 射线理论走时差（T-P/T-S）+ 传播速度（推荐，论文口径，见 §14）；
  ② 包络峰时刻 + T 波海段声速 1.48 km/s；③ 多子阵方位线交会 —— **先用下面的比值判能不能用**：

```
交会可用条件：   基线 / 目标射程 ≳ 0.3            （＝两方位线的夹角要够大）
方位不确定度：   σ_θ ≈ 主瓣半宽 / |u|   [rad]     主瓣半宽 = 0.64·111.195/(f_hi·D)
```

XA G1 反例（该几何下交会无定位能力，别硬算）：G1/G2 中心相距 **353 km**、目标 ~2400 km ⇒ 比值 0.15、
两线夹角仅 6–7°；±1° 方位误差把交点推走 **300–380 km**、±5° 推走 **1000–3600 km**。而方位本身的精度：
主瓣半宽 19.4 s/°（f_hi = 0.0117 Hz）/|u| = 28.4 ⇒ 约 **±35°**；带符号台对滞后拟合（rms ~5 s、基线 ~2°）
约 **±5°** ⇒ **报方位一律用滞后拟合，不要用 F-K argmax**（同 §3、§10 的口径）。

规范出图（本项目已定稿）：地形/水深底图 + 两个子阵中心与台站 + 震源 + 从各中心沿方位延伸的线
（F-K 峰方位实线、滞后拟合虚线）+ 交会点（**只作示意，并画 ±σ 扇形**）+ 图上文字写明"慢度峰只给方向、不给距离"。
真正要拿慢度图当地理证据的形态 = **沿方位线的距离-水深剖面**：方位来自 F-K/滞后拟合、距离来自 T-P/T-S 定时，
再看该距离落在哪种地形上（大陆坡 / 海岭 / 海底山）。
脚本与产物：`G1/04_landtime_fk/map_azimuth_lines.py` → `fig_azimuth_lines_topo.png`（几何诊断 `log_azimuth_to_topo_geometry.txt`）。
