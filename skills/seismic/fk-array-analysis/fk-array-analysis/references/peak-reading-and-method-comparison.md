# 读慢度图的峰 / method 对比表（报数前的最后一道关）

## 1. 铁律：导出脚本只读**全局最大**一个峰

项目里所有 `export_*.m` 的读峰只有一行：

```matlab
[mx, idx] = max(beam(:));  [iy, ix] = ind2sub(size(beam), idx);
```

`fk4d` 本身**不做峰值检测**（返回整张 beam 网格），argmax 是脚本自己加的口径 ⇒
**一张图上若有两个能团，只会报出较大的那个**（论文 Fig.4 那种"两个能团同图"永远读不全）。
见到"图里明明有第二个峰，脚本却没报"时，改工具、不要改数据。

## 2. 多峰读数（要读第二/第三个峰时）

`peaks_table.py`（`4_fk_analysis/G1/03_fk_paper_measured_params/`）：

```bash
python peaks_table.py <理论BAZ> <beam文件或目录> [前N名]
```

做法：`scipy.ndimage.maximum_filter(beam, 5)` 取局部极大 → 连通域去重 → 按相对峰 dB 排序 →
每个峰报 `慢度 / BAZ / |dBAZ| / 相对峰 dB / prom / 是否在搜索半径内`。

- 这个配方对自写壳的 beam txt 与 SEIZMO 导出的 map txt（`x y beam_dB` 同列序）都适用。
- 案例（G1 T-S 整带 0.006–0.0131 Hz，Z）：`#1 43.82 @147°（在 SMAX 外，边角）`、
  `#2 9.77 @125°（−0.62 dB）`——两个能团并存，旧的 argmax 读数只给了 #1。
- **图内同一配方**：出图脚本 `plot_landtime_map.py` 的 ★参数区 `NPEAK / PEAK_DBAZ / THEO`
  把峰直接标在图上（口径与 `peaks_table.py` 一致，图和表不许两套数）。

## 3. 报数的三件套（每个峰都要过）

1. **峰必须在搜索半径内**（`u ≤ SMAX`）：超出半径的"峰"是网格截断产物，不能报。
2. **|dBAZ|**：与理论方位（真实大圆 BAZ）之差，>50° 基本等于没测到。
3. **prom = 峰 − 背景中值（dB）**：log 里同一行有；只报慢度不报 prom 的结论不算数。

- `prom` 只是**脚本字段名**（`mx - median(beam(:))`），不是某种定理、也不等于显著性：宽平顶也能高、
  换 SMAX/SPTS/频点数会改变背景中值 ⇒ **跨配置不可比**（报数时把 SMAX/SPTS/频点数一起写），
  且 0 慢度针尖的 prom 也高（§5）。解释它时照脚本原话叫"峰 − 背景中值"，**别另起"峰背比 / prominence"
  这类新名** —— 用户会直接否掉（"不要自己造词造出一个概念"）。

## 4. method 对比表是每次必出的（用户会直接问"方法有做对比吗？"）

三列 `center / coarray / full`，按 相位 × 分量 给全。实测规律（G1/G2、绝对/陆地四个组合都成立）：

- **峰位与 method 无关**：慢度差 ≤0.5 s/°（如 G2 T-S R：49.11 vs 49.29），**方位逐位相同**
  ⇒ 这个峰不是某种台对组合造出来的。
- **只有 prom 有系统差**：`center ≈ full > coarray`，coarray 低 0.3–2.3 dB（稀疏子阵更"糊"）。
  G2 T-S Z：5.85 / 7.11 / 5.81 dB；T：11.29 / 8.97 / 11.23 dB。
- **副峰比主峰更依赖 method**：G1 一窗一带（0.005–0.013 Hz、窗 60–260 s、陆地计时）里
  `~35 s/°` 团三方法都读得到（R 35.0@150、Z 34.9@122、T 35.4@124），而 `~20 s/°` 团
  只有 coarray 上读得出来（center/full 只剩 `~34 s/°` 一团：Z 33.8@123 −2.56、T 34.2@124 −1.35）
  ⇒ 报第二/第三个峰时 method 表更不可省。
- 出图版式：**每个分量一张，2 行（T-P / T-S）× 3 列（method）**；用户点名"只看 R(T-P) + Z(T-S)"
  时另出精简版（`fig_G*_methods_{Z,R,T}.png` 与 `fig_G*_TP_R_TS_Z_3methods.png` 并存）。
- 报结论时**同时给 method 表**：只报一个 method 的结果会被追问。

## 5. 判“有没有信号”的最后一道读数：理论点 vs **0 慢度**（不是 vs 峰）

包络的 beam 图在 `s≈0` 必有公共模式针尖（各台包络同时涨落、零延迟处完美聚焦）⇒
**`beam(0°)` 几乎总紧贴全局峰**（G1 实测 −0.01…−0.54 dB）。因此“理论慢度点离峰只差零点几 dB”
说明不了任何事；正确读数 = **在理论慢度点上取值，再与 0 慢度比**：

```python
# 理论点坐标 = (s·sin(BAZ), s·cos(BAZ))；0 慢度 = 网格原点最近点
beam[理论点] - beam[峰]     # 相对峰（好看，但会被主瓣宽度骗）
beam[理论点] - beam[0°]     # ← 判据用这个
```

G1 的 T-P 七配置实测（相窗/并集窗 × 单频点/整带，Z 与 R 各跑一遍；数值为 Z）：

| 配置 | f (Hz) | 主瓣半宽 | 峰 | `beam(0°)` | 理论 13.7 | 理论 18.5 |
|---|---|---|---|---|---|---|
| 整带·相窗 | 0.0201 | 11.3° | 0.99@135° | −0.07 dB | −9.85 | −13.81 |
| 单频·并集窗 | 0.0078 | **29.2°** | 34.18@135° | −6.96 dB | −2.07 | −1.19 |
| 单频·并集窗 | 0.0117 | 19.5° | 3.47@135° | −0.21 dB | −2.53 | −4.84 |
| 单频·相窗 | 0.0156 | 14.6° | 1.48@135° | −0.05 dB | −4.03 | −8.88 |
| 单频·相窗 | 0.0234 | 9.7° | 1.98@135° | −0.28 dB | −8.61 | −20.85 |
| 单频·相窗 | 0.0312 | 7.3° | 0.49@135° | −0.01 dB | −16.97 | −11.26 |

读法：

- **理论点从未超过 `beam(0°)`**（R 分量同构，低 0.3–11.6 dB）⇒ 判无信号；别把“低频处理论点只比峰低
  0.8 dB”读成信号——主瓣半宽 `0.64·111.195/(f·D)` 在低频处（29.2°）本来就把理论点罩在 0 慢度主瓣内。
- ⚠️ **并集窗（一个窗装两相）里最先出现的是下一震相**：0.0078 Hz 上 Z 给 34.18@135°，那就是 T-S
  的信号（T-S 窗同频点 35.31@138°）⇒ “并集窗 + 最低频点找 T-P”这条路不通。
- ⚠️ **论文式“一窗一带、两能团同图”的 argmax 可能整个偏离目标相**：并集窗 + 交集带 `[0.008 0.022]`
  （SMAX 28.2、SPTS 163）的 SEIZMO 源码图，全局峰 = `2.51 s/° @236°`（|dBAZ| 99°），
  源方向的 `39.88 s/° @135°`（|dBAZ| 2°）低 **5.11 dB** ⇒ 只画一张图就把错误方位当结果报了，
  必须多峰读数 + 逐相分窗（窗口径见 `phase-window-definition.md`）。

### 判“有没有**源向**峰”的例行读数（`scripts/sector_peak_check.py`）

源向峰的存在性要在**理论 BAZ ±20° 扇区内找局部极大**（8 邻域最大值 `maximum_filter(b,5)` 口径、
`|u| ≥ 5 s/°`），一次报四个数：**扇区最强 `|u|@BAZ`、相对全图峰的 dB、全图中位 dB、全图峰位置**。
只报全图 argmax 会把非源向伪影（原点针尖 / 混叠像 / 别的震相）当成结果——旧盘四套参数上全图峰落在
217.9° / 18.9° / 47.6° / 31.9°，而理论 BAZ 是 137°。

```bash
python scripts/sector_peak_check.py <beam.txt> 137.3 20 5 31.2,24.9,10.8   # BAZ / 扇区±° / |u| 下限 / 理论慢度表
```

⚠️ **慢度数值接近论文读数 ≠ 看对了相位**：必须连 BAZ 一起报。实例：论文口径（0.25 Hz 低通包络）
输入的一张图全局峰 `25.14 s/°`，数值紧贴论文 T-S 的 24.7，但方位 47.6°（差 89°）⇒ 是伪影，不是 T-S。
判据照 §7 固定写法：**慢度在理论量级 且 `|dBAZ| ≤ 15°`** 才算一个相。

## 6. 一窗一带出"两个能团"（论文 Fig.4 式）：先过带宽关，再谈标注

要**在一条带里**同时看到两类能团（本项目 G1 陆地计时实测：`~20 s/°` ≈ T-P 陆段预测 18.53、
`~35 s/°` ≈ 实测 T-S），约束是联立的两条：

```
SMAX ≥ 1.70 × u_max          # 装得下最大慢度（u_max ≈ 35 s/° ⇒ SMAX ≳ 42；保守口径取 60）
SMAX ≤ 0.550231 / f_hi       # 抗混叠，f_hi = 带内最高频点
⇒ f_hi ≤ 0.550231 / 42 ≈ 0.013 Hz      # 一条带能同时装下两团的带宽上限
```

⇒ **把带往上扩到覆盖 T-P（0.02–0.032）必然丢掉大慢度那个团**（SMAX 被压到 17.6，`~20 s/°` 团也顶到网格边）。
实测带宽扫（T 分量、窗 60–260 s、陆地计时、coarray、理论 BAZ 137.3°）：

| 带 (Hz) | 频点 | SMAX | 源方向上的峰 |
|---|---|---|---|
| 0.005–0.0095 | 1（0.0078） | 52.5 | 21.2@124°（−0.00 dB）—— 只一个团 |
| **0.0078–0.013** | 2（+0.0117） | 42.2 | **20.5@134°（−0.95）+ 35.4@124°（−2.61）—— 两团齐全** |
| 0.0078–0.0156 | 3 | 35.2 | 22.0@125°（−3.49）+ 14.4@126°（−3.61）—— 大慢度团消失 |
| 0.0078–0.022 | 4 | 28.1 | 13.7@108°（−2.38）+ 23.4@137°（−3.25）—— 大慢度团消失 |
| 0.0195–0.032 | 4 | 17.6 | 全挤在 ≤13 s/°（T-P 自己的 18.5 也在网格外） |

读法：

- **两条频点各撑一个团**：0.0078 撑大慢度团，加进 0.0117 才把 `~20 s/°` 团带出来。
- 要看 T-P 相位本身**另开 T-P 带**（SMAX 只到 17.6），不要指望一条带兼顾两相。
- 写的带边界不必是频点：`1/T` 以下自动没有频点，200 s 窗写 `0.005–0.013` 与 `0.0078–0.013` 等价
  （带内合法频点都是 0.0078/0.0117）；报参数时把**窗长 + 带内频点**一起写，别只写带边界。

**图内标注**（`plot_landtime_map.py` ★参数区 `NPEAK / PEAK_DBAZ / THEO`）：
`ndimage.maximum_filter(b, 5)` 取局部极大 → 连通域去重 → 按相对峰 dB 排序 →
**保留全局最大 + 前 (N−1) 个 `|dBAZ| ≤ PEAK_DBAZ` 的峰**（只标源方向的团时取 35°），
画空心圈 + 标签 `#rank u@baz (ΔdB 相对峰)`（**诊断版专用**，交付版 `NPEAK=0`）；`THEO=1` 再把理论点
（该理论 BAZ 方向上 18.53 / 30.89 s/°）用**淡绿色十字 + 50% 透明度**标上
（`ax.plot(..., marker="+", color="lightgreen", alpha=0.5, ms=13, mew=2.0)`）。

⚠️ **交付图的文字口径（用户逐条否过，别再回退）**：理论点**只画十字、不写 `T-P 18.5` / `T-S 30.9`**；
**图上不出现任何数值**（峰慢度 / `ΔBAZ` / `peak − median` 只进图注、summary 表与 log）；
**页脚/图例说明整块不写**（原话"下面的文字描述不必要的，例如色标这种能看出来的不必标注"）——
色标读色条、线型与理论点含义写进 **caption**（`crosses: theoretical land-segment slowness
(18.53, 30.89 s/°), plotted where inside the search range`）。十字的两条收尾仍必须做，否则规范自查报相交：

1. **十字裁到面板内**（marker `clip_on=True`；若某版要加标签，注释也要 `annotation_clip=True`）：
   小 SMAX 面板装不下 18.53/30.89（±17 那两格），不裁就画到面板外、压邻格的 y 刻度；
2. **点落在面板右半边时**（若加了标签）翻到左侧（`ha="right"`, `xytext=(-7, 7)`），否则越过面板边界——
   实测与邻格 y 刻度相交 48 px² 就是这么来的。

**色标权衡（必须主动说明）**：这些副峰只比原点针尖低 0.95–5.3 dB ⇒ **标准 −0.7…0 dB 色标下
填色里根本看不到团**。两种出法都给：① "看团"版把能量下限放宽（如 −6/−8 dB）；
② **诊断版**用标准色标 + 空心圈把数值标在图上（交付图不标数值，见上）。标签里的 `ΔdB` 是相对各自全局峰，不是绝对能量。

## 7. F-K 功率图**没有** ±u 镜像（别拿 Hermitian 互谱推）⇒ 方位必须由**带符号台对滞后**定解

🔴 **不要声称"功率对原点中心对称、图上有等高镜像峰"——已被实测证伪**（曾这样对用户断言过，当场用合成注入推翻）：

```
B(s)  = |Σ_i c_i e^{+i2πf s·r_i}|² = Σ_ij c_i c_j* e^{+i 2πf s·(r_i−r_j)}   # Hermitian ⇒ 只是保证 B 为实数
B(−s) = |Σ_i c_i e^{−i2πf s·r_i}|²                                        # 换哑标 i↔j 换不回原式
```

Hermitian 互谱只给"B 是实数"，**给不出 `B(−s) = B(s)`**：那需要台站集合在 `r → −r` 下不变（反转对称孔径），
真实台阵没有这个性质。合成注入实测：**`max|B(s) − B(−s)| = 0.96`（远不是 0）**；
注入 32.5 s/°@319° 时，全局峰的反极点只有 **0.041**（相对峰 −13.9 dB）⇒ **图上没有等高镜像峰，也读不出那个方位**。
（自查脚本 `scripts/check_power_map_symmetry.py`：对任意 beam txt 报 `max|B−B_flip|` 与"反极点的 dB 落差"。）

**用户问"那个反方向的峰是什么"时，只能按这三条答**（三条都实测过、都是真源，不是对称影）：

1. **原点针尖（s≈0）**——包络非负造成的公共模式（§5），它的方位完全由数值噪声定，
   换 method / 窗 / 采样率就跳（实测同一格在 45°/207°/315° 之间乱跳）；
2. **混叠复制像**——位置 = `u ± 111.195/(f·d_min)`，换频点就跟着移动；
3. **真实次级震相 / 泄漏震相**（另一个转换点、上一相的尾波），位置随窗变。

⇒ 别把"反方向的峰"归成"镜像"这个机制（用户已明确否掉自造概念），要给出上面三条里的哪一条，
并附一个能判别的观测（换频点后峰是否移、换窗后是否移、是否落在原点上）。

**方向仍不能用 F-K 的 argmax 读**（`|·|²` 里没有符号信息，且目标相常没有可辨波前时 argmax 就落在针尖上，
方位是噪声决定的）。定解用带符号的台对滞后
`τ_ij = s·(r_i − r_j)`：互相关峰的滞后是**带符号**的，配真实台站几何做最小二乘（2 个未知量、
N(N−1)/2 个方程）方向唯一；镜像候选代进去残差会炸。判据 = **镜像候选 rms ÷ 最好拟合 rms**。

G1 陆地计时实测（`xcorr_direction_check.py`，窗/带与出图配置一致，理论 BAZ 137.3°）：

| 配置 | \|u\| | 拟合 BAZ | 拟合 rms | 镜像候选 rms | 比值 |
|---|---|---|---|---|---|
| T-S, T（120–270 s, 0.005–0.013） | 32.5 s/° | 139.0° | 5.54 s | 73.6 s | **13.3×** |
| T-S, T（60–260 s, 0.005–0.013） | 32.3 | 136.9° | 5.41 s | 73.9 s | 13.6× |
| T-S, T（60–260 s, 单频点 0.0078） | 32.0 | 134.1° | 5.70 s | 74.4 s | 13.0× |
| T-P, R／Z（两个窗） | 3.6–17.9 | 随机（2–282°） | 30–49 s | 30–60 s | ≈1× |
| T-S, R／Z（60–260 s） | 5.6–6.4 | 随机 | 35 s | 37–39 s | ≈1.1× |

三条硬规则：

1. **比值 ≫ 1（本例 13×）⇒ 方向唯一、可用**；**比值 ≈1 且 rms 与"随便一个平面波"同量级 ⇒ 该配置
   根本没有可拟合的波前，不报方向**（T-P 带与 R/Z 都属此类，它们的"峰"就在 0 慢度针尖里）。
2. **判真源的组合判据**：慢度在 18.5 / 30.9 量级 **且** `|dBAZ| ≤ 15°`；拟合出的**反方向支**
   （`|dBAZ| ≈ 180°`）一票否（反方向支的 rms 会是最好拟合的十几倍）。
3. **慢度大小仍可用 F-K**（`|u|` 不受镜像影响）；**方向一律用滞后拟合** —— 这就是两者的分工。

**出图口径（本项目定稿）**：图上那条"实测方向"实线**取自滞后拟合**，不用 F-K argmax 的方位；
拟合不过就在该格**不画**实线（只留理论虚线 + 淡绿十字）。落在 `plot_landtime_map.py` ★参数区 `MEAS_BAZ`
（键 `(tag, comp)`，值 = 拟合 BAZ，`None` = 拟合不过）；数值来源 = 同目录 `xcorr_direction_check.py`
产出的 `xcorr_direction.csv`（列：`comp f1 f2 w1 w2 |u| 传播方位 BAZ rms 镜像rms`）——
**报数与改图都读这份 csv，别手抄**（解析用 `l.split()`，脚本写的是空格分隔、不是逗号）。

**想让镜像从像素层面消失**（三选一，按代价排）：① 方向改由滞后拟合给（零成本，已定稿）；
② 出图只画半平面（如 BAZ 45–225°）——是"藏"不是"消"；③ 时延域 **signed cross-correlation beam**
`B(s) ∝ Σ_ij w_ij ρ_ij(τ = s·Δr_ij)`，用**有符号的 ρ** 而非 `|ρ|`（真支落在相关峰上、反方向支落在反因果侧≈0）；
要上这条路先做合成注入标定再上真实数据（实测：注入 32.5 s/°@319° → 回收 32.64@318.9°；
真实数据该配置 31.88@138.6°、反方向支仅 −0.044 ⇒ 有符号域确实只剩一支）。
⚠️ 遮反方向峰时用**反方向楔形**（`MASK=back`，±60°）而不是整圈近原点遮罩——后者会把源方向也削掉；
用户对"把反方向的峰消掉"的原话就指楔形那一个峰。

## 8. 「这个方法与我之前的方法的区别」= 两套口径逐项对照（照此答，别现编）

用户会问"你这个（复现用的她的 fkmap 路线）与我之前的方法（本项目 fk4d 路线）区别是什么"。
先说共同点：**同一台阵、同一个估计量**（SEIZMO coarray：白化 → 互谱 → 相位斜坡 → 求和后取实部），
差别全在**输入口径 / 窗 / 频带 / 网格 / 判读**五处，然后给这张表：

| 项 | 旧盘 `fkmap` 路线（能复现她的图） | 本项目 `fk4d` 路线（论文文字口径 + 判读） |
|---|---|---|
| 输入 | 2–8 Hz → `abs(hilbert)` → `getspline(0.1)`，**20 sps、不做 0.25 Hz 低通** | 2–8 Hz → 包络 → **0.25 Hz 低通 → 2 sps**（`envelope_0.25LPF/`） |
| 时间窗 | 固定 1000 s（同步后 1200–2200 s），不区分相位 | 按理论到时切 T-P/T-S 相窗（140–215 s）+ 含另一相的污染对照 |
| 频带 | `frng=[1/1000 1/25]` = 0.001–0.04 Hz（Δf=6.1e-4，64 个频点） | `FRNG=[0.02 0.25]`（2 sps 下 Δf≈0.004，7–44 个频点） |
| 网格 | 固定 ±30 s/°、300×300，不查混叠 | ±35 s/°、201×201；SMAX 由"装下理论 24.7×1.4"与 `f·SMAX ≤ 111.195/(2·d_min)` 联立定 |
| 子阵 | `sf([2:9,11])` / `sf([9:16,24])`（9+9 台） | G1 7 台 / G2 8 台（论文 southern/northern 子阵） |
| 引擎层 | `fkmap` 单窗带内平均（一图一帧） | `fk4d` 滑窗壳（`WIDTH=100` 时同样是一帧）+ `center/coarray` 对照 |
| 判读 | 取图上**单一最大值** | prom + `beam(0°)` 共模判据 + 反极点电平 + 显著性 + 合成注入标定（§3–§7） |

三条要讲透的差别（用户必追问"那到底差在哪"）：

1. **包络之后要不要再 0.25 Hz 低通——实测无差别（此条曾写错，已按单因子实验纠正）**：同子阵（9 台）、同窗
   （同步后 1200–2200 s）、同网格（`smax=30` / `spts=300` / `frng=[1/1000 1/25]`）下，`|Hilbert|` 之后接
   **0.25 Hz 低通（20 sps）** 与接她的 **`getspline(0.1)`** 给出**逐位相同**的图（25.13 s/°@133.1°、
   T-P 区 9.89@143.2（−0.19 dB）、prom 6.72 dB）；降到 2 sps → 25.14@132.4（prom 7.44）。⇒ 两者是同一件事的
   两种表述，**不是差异源**。此前记的"低通版 10.2 s/°@136°"来自一个**同时**换了子阵（8 台）与 `spts`（200）的
   配置 —— 多重改动，不能归因给低通。
2. **名次真正的裁判是带内 bin 集合与子阵成员（两相近简并）**：同一份她口径输入只改上界/`spts`/子阵即翻名次
   （9 台 0.04/300 → 25.13@133.1 T-S；9 台 0.03/300 → 29.37@135.0；8 台 0.04/200 → 25.38@133.1；
   8 台 0.03/200 → 11.63@161.1；9 台 **0.0388**/300 → 9.82@145.8 T-P）⇒ 报数同时给前两个局部极大 + prom，
   断言"最强是哪个相"必须写明合并方式 / 子阵 / bin 集合，并做带边界 ±1–2 bin、去掉 1 台的稳健性扰动。
3. **网格是否按无混叠定**——固定 ±30 s/° 在带的上半段（>0.018 Hz）已越界（含混叠能量）；
   本项目网格由 `f·SMAX ≤ C`（`C = 111.195/(2·d_min)`）反推，频带/窗长/频点数互相锁死。
4. **判读门槛**——她只看最大值；本项目每个候选峰都要过"在搜索半径内 / `|dBAZ|` / prom"三件套，
   并附 `beam(0°)` 与镜像对照、合成注入标定，才能说"这个峰可判读"。

相同点一并说掉（否则用户会以为差得比实际多）：平面波前假设、子阵孔径约束（<400 km，Rost & Thomas）、
都用包络、都基于同一套 coarray 数学、**两者都是单帧（无时间分辨）**。
