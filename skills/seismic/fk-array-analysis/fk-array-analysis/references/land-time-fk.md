# 陆地段计时 F-K（扣掉海洋段走时，只留 land_km 上的走时差）

用户口径："要把海洋差异扣掉，要不然怎么算陆地的走时差"。F-K 默认给的是**全路径视慢度**
（海段 1.48 km/s + 陆段 6.0/3.6 混合），要单独测陆地段，必须先逐台扣掉海段走时。
本文件是做法 + 链路标定 + 读数口径；窗的构造见 `phase-window-definition.md`。

> ⚠️ **本文件是"陆地段"口径，不是论文口径**（两者的完整对比在本文后段「"现在送检的是哪个口径"怎么答」一节，不重复）。
> 新增的量化补充（2026-09-28）：逐台平移的等效慢度偏置**随子阵而异**——
> G1（XA 七台，海段跨度 10.1 s）只 **1.12 s/°**（静校正级，怎么做都对得上论文）；
> MAHA5（马达加斯加南部 5 台，海段跨度 **99.3 s**）达 **32.84 s/° @19.4°**
> （沿传播向 +20.4、横向 +25.6）—— 与 T-S 信号同量级。⇒ 报数写明口径，两族不得并列成同一个量；
> 图上标签用 `abs (common axis)` / `land (per-station)`。
> 复算：`scripts/check_static_shift_slowness_bias.py`

## 1. 换算

```
t_land,i = t_origin − L_ocean,i / 1.48        [s]     0 = 该台理论上岸时刻
```

- 速度取 **1.48 km/s**（本项目现行口径，图/表/文档统一用这个数）；`L_ocean = 总距离 − land_km`。
  ⚠️ **论文作者自己的脚本用的是 1.5**（`home_yzhou/bin/Ttime`：`vp 6.0 / vs 3.6 / vt 1.5`，逐台平移、理论到时线、
  τ 判据全都跟着变），详见 `zhou2021-southafrica-fk.md`「作者原始代码」节 —— 要与论文口径逐台对齐前先确认用哪个，
  改就是全链重算（输入平移 / 到时线 / 窗 / 判据）。`L_ocean≈1630 km` 时 1.48 给 1101.4 s、1.5 给 1086.7 s（差 ~15 s）。
- XA G1 七台：海段 **1098.65–1108.78 s**（极差 10.14 s；SA18/SA23 = 1098.65、SA16 = 1108.78）。
  这 10 s 的台间差异摊到 312 km 孔径 ≈ **3.6 s/°**，与论文 T-S 的 24.7 s/° **同量级** ⇒
  不扣掉，测出来的"慢度"里混着一大块与目标震相无关的海段几何。
- 陆地计时到时（V = 6.0 / 3.6）：T-P **104.17–141.17 s**、T-S **173.61–235.28 s**（land_km 625–847 km）。

## 2. 输入生成（逐台平移，落在同一绝对轴上）

- 源：上游 2 Hz 包络 SAC（`envelope_0.25LPF/envelope_lp_all_28{,_R,_T}/`）。
- **逐台按自己的 `L_ocean/1.48` 平移**（不是逐台重切窗）：各台扣掉的量不同，平移量当然不同；
  平移后再重采样到**共用的陆地计时网格**，写出的文件统一 `b = −100 s`、`o = 0`、`npts = 1001`
  （覆盖 −100…+400 s）。共用的 b/o 是 fk4d 能开机的前提（各台起点不一致 ⇒ 插不到值 ⇒ NaN）。
- ⚠️ **obspy 写 SAC 的时间基座**：想让文件带想要的 `b`，必须同时设
  `tr.stats.starttime = REFTIME + b`——**只设 `tr.stats.sac.b` 会被 starttime 覆盖**，读回来是 `b = 0.0`。
  写完必读回核对 `b / o / npts / starttime` 四项，别信"写成功"的返回值。
- ⚠️ **Seizmo record 结构体的波形字段是 `data(i).dep`**（不是 `.data`）。注入合成波形：
  `data(i).dep = cast(wav(:), class(data(i).dep));`；`getheader(data,'b')` 要**逐文件取标量**
  （一次取整数组会报错）。
- Octave 侧切窗即 `cut(data, win)`（陆地计时输入里 o = 0，win 直接就是陆地计时窗口）。

## 5. 判读规则（本次得到的两条硬结论）

1. **单频点/单窗下，慢度对"计时口径 + 分量 + 估计器"都不稳健**：三者互换就换答案（上表 24.78 ↔ 29.00、
   Z ↔ T、fk4d 10.67 ↔ 滞后拟合 29.0）。**报数必须写明（计时口径, 分量, 频点, 估计器）**，
   不能只写"测到 X s/°"。与 §4 的几何地板 41% 是同一件事的两个侧面。
2. **别用"总走时窗"一次跑两相**（用户会问"一个窗把 T-P 和 T-S 都涵盖、频带也涵盖，可行吗"）：
   一次 F-K 只拟合一个平面波，窗里两种慢度 ⇒ argmax 只是挑大的那个。实测并集窗（211 s）+ 并集带：
   prom 掉到 **5.8 / 6.7 dB**（单相窗是 9.9 / 8.7 dB）、峰退化到 1.1–1.3 s/°、两相都对不上。
   要"一次两相"只能**逐频点**各自出图（每频点用 `SMAX_k = 0.550231/f_k`），按相位取频点判读。
   - ⚠️ **但论文本身就是这么画的**：Fig.4b/4d 每个子阵只一张图、图上"clearly shows two distinct
     energy packets"、同图标出 T-P 与 T-S 两个理论慢度；其 F-K 输入写明是"**垂直分量**包络 + 0.25 Hz
     低通"，**没有按相位选带**。⇒ 要对上论文的图就必须用这个口径，并在同一张图上**分别读两个峰**
     （多峰表见 `peak-reading-and-method-comparison.md`），而不是分两次 F-K。
   - 两相的合法带几乎不重叠（本项目：T-S 0.008–0.0224、T-P 0.020–0.0552）⇒ "一个带涵盖两相"
     实际只在 **≤0.022 Hz** 成立；交集带 [0.008, 0.022]（SMAX 28.2 / SPTS 163）是唯一两相都合法的选择。
   - 纯源码复跑该口径（G1，并集窗 + 交集带）：argmax 给 **2.51 s/° @236°（方向不对）**，
     源方向的峰 **39.88 @135°（|dBAZ| 2°）低 5.11 dB** ⇒ 论文式画法下"最大的峰"并不是源方向的峰，
     这正是必须用多峰表读数的原因。
3. **三个典型频带（b1/b2/b3）里没有任何指向震源的相干平面波**：六种"带 × 分量"组合的峰全落在
   0.35–1.27 s/°。真正相干的是 **0.0078 Hz（= 窗长允许的最低频点）与 0.0039 Hz**，
   而它们**低于 b1/b3 的下界 0.02 Hz** ⇒ 用这三个带跑，等于把有信号的频点关在门外。

（G2：绝对 1194–1318 / 1263–1405 s；陆地 73.5–195.8 / 142.5–293.1 s）。

| 计时 | 子阵 | T-P Z / R / T | T-S Z / R / T |
|---|---|---|---|
| 绝对 | G1 | 0 / 0 / 0.35 s/°（原点针尖） | **35.3 / 35.8 / 34.8 s/° @138/133/137°（\|dBAZ\| 0–4°）** |
| 绝对 | G2 | 1.10 / 2.34 / 1.74（近零，T 的 \|dBAZ\| 0°） | **36.2 / 49.1 / 35.0 s/° @152/149/150°（\|dBAZ\| 6–9°）** |

三条结论：

1. **绝对计时下两个子阵的 T-S 都给指向震源的 ~35 s/° 峰**（G2 的 R 偏到 49 s/° = 2.26 km/s，

2. **陆地计时（逐台扣海段）反而更差**：G1 的 Z 跑成反向、G2 只有 T 分量成立 ⇒ 该口径能**诊断**

3. T-P 在两个子阵、两个口径、三个分量上全是近零峰 ⇒ 与 SKILL.md 里"T-P 窗无可用结果"的逐频点

（链见 §0/`three_comp_chain.py`：N/E → `rotate_ne_rt(baz)` → 2–8 Hz 零相位带通 → \|Hilbert\| →
0.25 Hz 低通 → 2 Hz）。补 G2 的 R/T 时必须**与既有 Z 逐点同网格**（读 `SA31_env_lp.sac` 的

## 8. 换计时口径时，哪些 F-K 参数要重算（参数地图）

回答用户会问的"都改用陆地计时，是不是全方位参数都要更新"：**不是**。分三类，按此顺序答（先一句直答再给算式）。

### 8.1 随口径走的只有三样

| 量 | 绝对计时 | 陆地计时 |
|---|---|---|
| 窗边界 | `[min(式(1) 绝对到时)−30, max+50]` | `[min(L_land/v)−30, max(L_land/v)+50]`（v = 6.0 / 3.6 km/s） |
| τ（选窗 + 可行性判据） | `max|τ|/T` | `(τ_max−τ_min)/T`（τ_i = L_land,i/v 全正、只差一个公共偏移） |
| 读数含义 | 全路径视慢度（混海段，论文 T-P 10.0 / T-S 24.7） | 陆段慢度 `111.195/v`（T-P 18.53 / T-S 30.89 s/°） |

⚠️ **方向侧要分清两件事**（本文件旧版写成"BAZ 侧不动"是错的，已按实测更正）：

- **不随口径变的**只有 `BAZREF`（仅用于打印 |ΔBAZ|）与**大圆 BAZ**（台站→震源，纯几何）；
- **图上那条理论方向线、以及引擎报的峰方位**测的是"你喂进去的那套到时场"的**平面波梯度** ——
  换计时口径，梯度方向会转。实测（XA 1997-04-28，两台站集，最小二乘 `t_i ≈ t0 + sx·E_i + sy·N_i`）：

| 到时场 | G1 梯度 → 视向(BAZ) | G2 梯度 → 视向(BAZ) |
|---|---|---|
| `land/6.0`（式(1) 陆段恒速） | 137.7° | **136.5°** |
| `tt_ts − L_ocean/1.48`（陆地计时） | 138.1° | **136.7°** |
| `tt_ts`（绝对计时） | 136.8° | **160.1°** |
| 大圆 BAZ（旁证，不是梯度） | 137.3° | **144.2°** |

- 偏角随「逐台扣掉的秒数差 / 孔径」增大：G1 海段台间差 10 s / 孔径 312 km ≈ 3.6 s/° ⇒ 陆地计时视向与大圆只差 **<1°**
  （所以 G1 的图看不出问题）；G2 差 33 s / 363 km ≈ 10 s/° ⇒ 陆地计时视向比大圆偏西 **≈8°**（136.5° vs 144.2°），
  绝对计时的 `tt_ts` 梯度更到 160.1° —— 三者互不相等，**大圆 BAZ 不是任何一套到时场的梯度**。
- ⇒ 画陆地计时图时**理论虚线用陆地计时视向**（对 `land/V` 或 `tt − L_ocean/1.48` 做平面波最小二乘取方向，附 rms），
  大圆 BAZ 只写进图注作旁证；否则会把"特征偏西 8°"误读成"这个子阵测错了"。报 |ΔBAZ| 时同样点名用的是哪条参考线。
- 同一个秒数区间在两口径下对每台指的是**不同的绝对时刻**（陆地轴已逐台扣掉各自的上岸走时）——报数时说明口径。

### 8.2 不随口径变的（只要窗长落在同一 2ⁿ 档，逐字相同）

一条链讲清理由：F-K 吃台对互谱 `c_i·conj(c_j)`；逐台平移 `Δ_i = L_ocean,i/1.48` 只是给第 i 台的谱乘
`e^{−i2πfΔ_i}` ⇒ 改的是**台间相位差**，每台自己的谱栅格定义没动。于是：

| 量 | 由什么定 |
|---|---|
| `nsp = 2^⌈log₂(T/dt)⌉` | 窗长 + 采样率 |
| `Δf = 1/(nsp·dt)` | 同上 |
| 带内频点集合 | 频带 + Δf，且只取 `f ≥ 1/T` 那几档 |
| `SMAX ≤ 0.550231/f_hi` | 带内实际最高频点 |
| SPTS、`Δs = 2·SMAX/(SPTS−1)` | SMAX + 目标慢度 |
| FRNG / method / POLAR / 分量 | 与时间轴无关 |

G1/G2 实测（数值即脚本参数区里的值，复算见 §8.4）：

| 子阵·相位 | 绝对窗 | 陆地窗 | 两版是否同档 |
|---|---|---|---|
| G1 T-P | [1173,1292] T=119.0 s | [74.2,191.2] T=117.0 s | 都 nsp 256、Δf 0.0078125、3 频点 0.0156/0.0234/0.0312、f_hi 0.03125、合法 SMAX ≤ 17.61（脚本用 17.1/99） |
| G1 T-S | [1243,1386] T=143.0 s | [143.6,285.3] T=141.7 s | 都 nsp 512、Δf 0.00390625、单频点 0.0078、合法 SMAX ≤ 70.43（脚本用 42.2/243） |
| G2 T-P | [1194,1318] T=124.0 s | [73.5,195.8] T=122.3 s | 都 nsp 256（同上） |
| G2 T-S | [1263,1405] T=142.0 s | [142.5,293.1] T=150.6 s | 都 nsp 512（单频点 0.0078） |

G2 的两版在**同一个 .m** 里（`export_G2_landtime_fk.m`：C(1)(2) 陆地 / C(3)(4) 绝对），
`SMAX/SPTS/FRNG` 完全相同、只换 `win` —— 这就是"参数不用全改"的可核对证据。

### 8.3 什么时候 8.2 那批也要跟着改：窗长跨 2ⁿ 阶梯

`nsp` 只取 2 的幂 ⇒ `T/dt` 越过 128 / 256 / 512 s 时 `Δf` 翻倍或减半 → 带内频点变 → `SMAX/SPTS/Δs` 全部重算。
两版窗长之差 = 子阵内"上岸时刻"的跨度（≈ ocean_km 跨度 / 1.48）：

| 台组 | ocean_km 跨度 | 上岸时刻跨度 | 后果 |
|---|---|---|---|
| G1 7 台 | 15 km | 10.1 s | 两版窗长只差 1–2 s，同档 |
| G2 8 台 | 49 km | 33.1 s | 仍同档（150.6 vs 142.0 s 都 512） |
| 全阵 37 台 | 188 km | 188 s | 换口径很可能跳档 |

余量示例：G1 T-P 陆地窗 117.0 s 距 128 s 阶梯只剩 11 s。⇒ 换口径/换台组前先跑 §8.4 脚本确认两版 `nsp` 相同，
再讲"参数不用改"；否则先重算频点与 SMAX。

### 8.4 复算（报参数前先跑，不要手算）

## 9. 「陆地计时对齐」≠「震中距对齐」：逐台平移的等效慢度偏置

用户口径："按陆地计时开始对齐这一点和按震中距对齐送检 F-K，是有区别的吧" —— 区别是**性质**的，不是量的大小。
先把三种做法分清（最容易混）：

| 做法 | 数据动没动 | F-K 读数 |
|---|---|---|
| 只改画图轴 / 只用理论到时定窗 | 没动 | **一字不变**（口径仍是绝对 / 全路径） |
| 逐台平移海段走时 `L_ocean,i/1.48`（§1–§2） | 动了 | 变，但峰位**仍在测慢度**（陆段） |
| 逐台平移距离 / 预测走时 `d_i/v_ref` | 动了 | 峰位测的是**残差** `u − u_ref`，不再是 u |

**公式链（任何逐台平移都适用）**：F-K 只吃台间时延的平面波梯度 ⇒

```
u_读数 = u_真 − u(Δt_i)，   u(Δt_i) = 把 Δt_i 对台站坐标做最小二乘平面拟合得到的斜率矢量
```

拟合出的**线性部分会被波束的平面波拟合整段吸收**（= 直接改慢度读数）；拟合残差是吸收不掉的波前形变
（rms 秒）。全局平移落进常数项 ⇒ 不进斜率 ⇒ 不改读数（与 SKILL.md"全局零点平移不改变慢度"同一条）。

实测（XA 1997-04-28，stations.csv + 真实大圆几何；脚本 `scripts/check_static_shift_slowness_bias.py`）：

| 平移量 | 子阵 | \|u\| (s/°) | 方位 | 沿传播向 | 横向 | 拟合残差 rms |
|---|---|---|---|---|---|---|
| `ocean/1.48`（陆地计时） | G1 | 1.12 | 166.7° | −0.98 | −0.55 | 3.87 s |
| `ocean/1.48`（陆地计时） | G2 | 10.34 | 56.8° | −0.46 | **+10.33** | 2.61 s |
| `dist/1.48` | G1 / G2 | 74.87 / 75.77 | 317.2° / 324.1° | +74.84 / +75.72 | −0.13 / −0.19 | 0.84 / 1.05 s |
| `dist/3.6` | G1 / G2 | 30.78 / 31.15 | 同上 | +30.77 / +31.13 | −0.05 / −0.08 | 0.35 / 0.43 s |
| `dist/6.0` | G1 / G2 | 18.47 / 18.69 | 同上 | +18.46 / +18.68 | −0.03 / −0.05 | 0.21 / 0.26 s |
| `land/3.6` | G1 / G2 | 31.19 / 31.66 | 317.7° / 316.5° | +31.17 / +31.35 | +0.25 / −4.26 | 1.26 / 0.92 s |

读法：

1. **陆地计时**的等效偏置是小量、且方向多不沿传播向（G1 因海段只差 15 km 几乎可忽略；G2 那 49 km
   海段差**不沿传播方向单调变**，几乎是纯横向 10.3 s/°）⇒ 相当于一个小静校正 / 波前倾斜，`u` 基本保留。
2. **震中距（走时）对齐**的斜率 = `111.195/v_ref` 本身，横向 ≈0 ⇒ 扣掉的与 `u` 同量级同方向，是 `u` 的
   复制品：`v_ref` 取真值时残差 0、峰塌到网格原点，能读出来的只有参考速度误差。
3. 于是参数口径不能互抄：方式 2 的 `SMAX` 要覆盖陆段预测慢度 `111.195/v`（T-S 30.89 ⇒ ≥52.7；
   T-P 18.53 ⇒ ≥31.6）；方式 3 的 `SMAX` 只需覆盖容许的速度误差（`v_ref` 偏 ±10% ⇒ ~±3 s/°），
   合法带顶 `f ≤ 0.550231/SMAX` 随之放开、`Δs/SPTS` 变；判据改成"峰不在原点 = 参考速度偏了"。
   拿方式 3 的读数当"台阵测得的视慢度"报出去是**循环论证**。
4. **数字对账**：`03_fk_paper_measured_params/README.md` 把逐台扣海段的效应折成 **3.61 s/°**，
   那是**上界**算法（海段极差 10.14 s ÷ 312 km 孔径的角长 2.81°）；平面拟合给出沿传播向只有
   **0.98 s/°（G1）** —— 真正会被 F-K 吸收的部分更小。两处对不上时按"上界 vs 吸收量"解释，别当成矛盾。

**旁证（同一个 .m、只换窗）**：G2 绝对口径 T-S T `35.00 s/° @150°` → 陆地口径 `33.13 @127°`，
差 1–2 s/°，量级与上表"海段静校正"同档；绝对口径 Z `36.19 s/°`（= 111.195/36.19 = 3.07 km/s）
既不是水速也不是陆段速度 ⇒ 混合口径的产物，别把它当"速度"去解释。

## 10. 切窗错位 100 s（`synchronize` 重定基准）—— 陆地计时"近零峰"的一半是伪影

用户会问"陆地计时的 0.0078 Hz T-S 窗口到底有没有峰值"。按现状脚本跑，答案是"有网格最大值、但不是波前峰"；
而这个"没有"有一半是假的。

**机制（实测打印，不是推测）**：陆地计时输入写成 `b = LAND_T0 = −100`、`o = 0`；`synchronize` **会重定记录基准**：

```
readheader : b=-100 e=400 o=0   npts=1001
synchronize: b=0    e=500 o=100        # 参考时刻被挪到记录起点，o 跟着 +100
cut(data,143.6,285.3) → 实际切到【事件相对 1146.0–1287.7 s】= T-P + T-S 起点前段，而非标称的 1246–1388
```

裸偏移是相对**参考时刻**算的（`cut(d,1000,1005)` → 输出 `b=1000`；`cut(d,'o',1000,'o',1005)` → `b=1600`，
说明偏移与 `b` 同一坐标、加 `o` 才换算到事件轴）。陆地文件原本靠 `b=−100` 让"参考相对"与"陆地相对"重合，
`synchronize` 一归一化，脚本注释里的前提（"o = 0 ⇒ 直接按陆地计时切窗"）即失效 ⇒ 窗整体前移 100 s。
**同一错位在所有 `G1/04_landtime_fk/*.m`**（`export_landtime_fk`、`export_G1_landtime_allcomps`、
`export_newlightwindows`、`sweep_window`、`check_contamination{,2}`、`check_landtime_inject`）；
**G2 不受影响**（写的是 `cut(data, o+win)`，synchronize 后 `o=100` 自动补上）；绝对计时族输入 `b=0`、
`synchronize` 不动 `o` ⇒ 也不受影响。⇒ **注入标定"通过"证明不了窗位对**（注入与切窗在同一错位框架里自洽）。

**受控 A/B（同一引擎、同一 bin 0.0078 Hz、同一网格、窗都覆盖事件相对 1246.0–1387.7 s）**：

| 受试件 | 读数 Z / T |
|---|---|
| 原始绝对输入（基线） | 34.30 / 34.06 s/° @137–139° |
| 同输入、窗整体平移 ±3 / ±6 s | 33.8–34.4 / 32.8–34.4（窗位不敏感） |
| 同输入、数据只做逐台海段差（±5 s 错开、不截断、保留原基准） | 35.14 / 34.61 ⇒ **"扣海段"本身不是原因** |
| 同输入、截断到 500 s（原基准、原参考时刻） | 34.35 / 34.06 ⇒ 截断不是原因 |
| 内存里改 `b/o`、窗选择随之等价 | 34.35 / 34.06 ⇒ `b/o` 本身不是原因 |
| 陆地配方（重定基准 + 截断 + 重采样） | 6–11 / 0.35–5 ⇒ 近零 |

⇒ 单项都不致错，**错在窗位**：把陆地脚本的窗位统一 `+100 s`（`cut(data,143.6+100,285.3+100)`，
或改写成 `cut(data, o+win)`）后，同一档同网格给出
**Z 35.73 s/° @141°、R 35.80 @138°、T 35.68 @141°，prom 9.2–9.7 dB**（三分量一致、\|dBAZ\| ≈4°），
与绝对计时同窗（34.30/34.06）及 Python 侧互相关拟合（29.00 s/° @309.8）同向同量级
⇒ **陆地计时在该档有干净峰**；§4/§5/§7 的"陆地计时没有分量落在陆段预测慢度上"要按修正窗位重跑后再定。

**定位手法（不看图、不猜）**：① 打印 `synchronize` 前后的 `b/e/o`（一行 `num2str(getheader(...))` 就够）；
② 用段和/指纹定位实际切到的段（错位段 `5.83e-07` vs 预期段 `1.51e-06`；在源记录里扫等长窗即可复现）；
③ 修好窗位后读数应回到指向震源的量级，否则回去查输入生成。

**修法（任选）**：① `cut(data, o+win)`，`o` 取 synchronize 之后的值（最稳，跨口径通用）；
② 裸偏移统一 `+|b|`；③ step1 直接写 `b=0, o=|LAND_T0|`，与 synchronize 归一化后的框架一致。

**报告口径**：被问"陆地计时那个窗有没有峰值"时答四段 —— ① 有 argmax 但慢度/方位都不对（给数字 + prom + 峰宽）；
② 这是窗位错位的伪影；③ 修正后的数字；④ 与互相关、绝对计时三方同向 ⇒ 该档的慢度可报，但要点明"修正后"。

## 14. 图面口径定稿（色标刻度 / 理论标注 / 说明块 / 反查手法）

用户口径："能量峰值强制为 0、-0.2、-0.4、-0.6，到 -0.7 下限（标度尺为 0.2 间隔标），理论慢度值用半透明绿色十字标出"
＋"理论慢度直接标注论文的预测值就行，不用自己算了（论文的慢度值怎么算的他后面自己研究）"。

- **色标**：每格各自 `D = b − b.max()` ⇒ 峰值恒 0 dB；`VMIN, VMAX = −0.7, 0`；**刻度固定
  `cticks=[0, -0.2, -0.4, -0.6]`（0.2 间隔）**，不要按数据范围自动取刻度。
- **理论慢度 = 论文预测值**：淡绿半透明十字（`marker="+", ms=13, mew=2.0, C_THEO="lightgreen", alpha=0.5`）标
  Zhou2021 的 T-P **13.7**、T-S **24.7** s/°（= 8.1 / 4.5 km/s 的倒数 × 111.195）。**不要用自己复算的到场梯度值**
  （本子阵投影给 19.0 / 31.7，与论文值差 0.5–5 s/°）。十字旁加**不透明**小字（`#2e7d32`、7 pt、白描边）
  写 "T-P 13.7" / "T-S 24.7"；开关 `THEO` / `THEO_LABEL`（env）。⚠️ 两件事分开：**十字的方向**随本子阵口径走
  （陆地计时图用陆地计时视向，§8.1），**十字的慢度值**取论文预测值。
- **说明块（`CAPTION=1`）行数一变就要跟着调版面**：块顶 `y_top = min(0.30, y_pan − 0.03)`，行高 ≈ 9.8 pt × 1.6；
  从 6 行加到 7 行后块底到 −0.003（掉出画布），把 CAPTION 时的 `subplots_adjust(top=0.83, bottom=0.35)` 才回到 0.031。
  ⇒ 改完说明块文本**必须核对脚本自查打印的三个 True**（`未出框` / `与主图不重叠` / `色标在画布内`）。
- **像素级反查标注（不看图也能验收）**：50% 透明标记压在不同底色上颜色会变 ⇒ 只用"淡绿"颜色掩膜会漏（同一张图
  有的十字检出、有的漏）。改用**不透明**元素做掩膜：小字标注色 `#2e7d32` 与任何底色的混合都可辨，按面板
  三分区统计像素（每区 >50 即该格有标注）；十字本身则按连通块尺寸（≈700–800 px）筛。

## 15. 窗长最长能取多长（三类上限）＋ 长窗实测

用户会问"窗长我最长可以选多长"。三条上限各有各的紧，先给这三条再给数：

| 约束 | 上限 | 机制 |
|---|---|---|
| 数据范围（硬） | 现有陆地计时输入只有 −100…+400 s（`b=−100`、`npts=1001`、`dt=0.5`）⇒ **≤ 500 s** | 窗必须整段落在这区间；要更长得重做 `step1`（源包络到 +3599.5 s、陆地轴可做到 ~2475 s）——**不是模型限制** |
| 相位纯净（推荐口径） | **254 s** | 只装 T-S：左界 ≥ T-P 末（G2 145.8 s）、右界 ≤ 数据末 400 s ⇒ [146, 400]；再长就开始装 T-P / 尾波 |
| 频点台阶 | **256 s** | `nsp = 2^⌈log₂(T/dt)⌉`：≤254 s 时 nsp 512、SMAX 30 下 3 档；跨 256 s ⇒ nsp 1024、**8 档**（新增全在低频端 0.0039–0.0176 Hz）；600 s ⇒ 18 档 |

⇒ 一句话答法：**纯净口径下最长 254 s（差 2 s 上不了 8 档那道台阶）；要吃 8 档就得放宽到含 T-P（50…400 s = 350 s）**；
且 SMAX 决定 `f_hi` 上限不变 ⇒ 加长窗的收益**全在低频端**，目标能量峰在高频端时未必划算。

长窗实测（G2，同带 0.005–0.0176 Hz、同网格 ±30/171，源向判据 136.6°±20°，电平 dB re 各格峰值）：

| 窗（陆地计时） | 窗长 | T-S 支（T/R/Z） | 滞后拟合 rms（T/R/Z） |
|---|---|---|---|
| 100–250 s | 150 s | −5.38 / −7.80 / −5.52 | 31.0 / **8.4** / 30.4 |
| **150–280 s（定稿）** | 130 s | **−0.79 / −1.71 / −4.61** | **15.0** / 34.6 / 24.8 |
| 50–250 s | 200 s | −5.43 / −5.86 / −5.74 | 35.4 / 34.5 / 32.5 |
| −60…90 s（噪声对照） | 150 s | −7.85 / −8.23 / −8.12 | 64.2 / 24.4 / 17.1 |

读法：① **窗越长 T-S 源向特征越弱**（两个长窗只比噪声窗高 1.5–2.5 dB，定稿窗高 4–7 dB）——混相 + 稀释（§2a/§5）；
② 窗里混两相后**单慢度滞后拟合整批失效**（100–250 只剩 R 过、50–250 三分量全不过）⇒ 图上没有实测方向线要交代；
③ 反直觉的一条：50–250 s 的三格 T-S 支峰落在 26–31 s/° @ 144–149°，**贴着论文预测 24.7 与大圆 BAZ 144.2°**，
而定稿窗是 32–39 s/° @ 128–148° ⇒ 两条都报，别只挑好看的那条。
