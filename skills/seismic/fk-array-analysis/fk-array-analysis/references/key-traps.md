## 关键陷阱（详细见 references/python-fk-implementation.md）

### 旋转约定与方位角口径（ZNE→ZRT / `baz` 列 / BAZ 的三种口径）
- ⚠️ **ZNE→ZRT 旋转统一用 obspy `rotate_ne_rt`，禁止手写公式**（2026-09-02 全项目统一）：
  手写 `R=+N·cos(baz)+E·sin(baz)` 与 obspy（`R=-N·cos(baz)-E·sin(baz)`）差 **180° 反相**
  （R 指向震源 vs 背离震源）。能量/SNR/包络/频谱不受影响（\|振幅\|² 不变），但带符号的
  偏振角 %360 会差 180°——本项目偏振判别用 %180 轴向所以历史结果仍有效。
  ⚠️ obspy **没有 `rotate_zne_rt`**（import 必失败 → 静默走手写 fallback 掩盖不一致）。
  详情见 `references/rotation-convention-zne-zrt.md`（含逆变换公式、验证方法、已改文件清单）。
- ⚠️ **stations.csv 按列名解析，勿用固定索引**：15 列格式
  `sta,az,dist,land_km,ocean_km,tt_p,tt_s,tt_tp,tt_ts,snr,snr_r,snr_t,lon,lat,baz`
  中 `p[12]` 是 lon 不是 baz（旧 13 列才是 baz）——曾致 R/T 旋转用错方位角。
- ⚠️ **`baz` 列是错的（震源端方位角 ≠ 台站端），偏西 6–13°**：实测该列 ≡ `lib/arrivals.py: dist_az()`
  返回的 `azi1 + 180`（`azi1` = 大圆在**震源端**的出射方位角），38 台逐台吻合 ±0.05°；
  真实大圆 BAZ（台→震中）= `gps2dist_azimuth(sta_lat, sta_lon, ev_lat, ev_lon)[1]`
  （≡ geographiclib `GEOD.Inverse(ev, st)["azi2"] + 180`）。G1 十台偏 **10.2–12.1°**，
  差值 ≈ 大圆弧沿路径的方位角旋转量（Clairaut `Δλ·sin φ_mid`）。
  ⚠️ **不要把根因写成"平底公式漏 cos 纬度"——那个归因是错的**（该列并不是 `atan2(Δlon,Δlat)`）。
  ⇒ **用该列之前先重算**（R-T 旋转基准、理论 BAZ 线都会偏；偏 ~11° 不是 180° 那种显性错误，图看着正常）。
  修口径 = 把 `dist_az()` 的 `azi1` 改 `azi2`，并**整链重跑**：`stations.csv.baz`（连带 `snr_r/snr_t`）→
  依赖它的 R/T 包络 npz → 单台图 → 剖面/频谱剖面 → F-K 输入 `envelope_lp_all_28_{R,T}/*.sac` → beam 与 F-K 图；
  **Z 分量逐字节不变**（用 `array_equal` 当"没改坏"的对照）。
  **正向变动不变量**：偏振 BAZ / 入射角只用 Z 与 R/T 的矢量关系，两边同步平移 ⇒ 改口径前后逐点差应为 0.00°，
  不需要跟着重跑。逐台 `abs(baz_used − gps2dist_azimuth(...)[1]) < 0.1°` 可作为任何旋转/造数据脚本的一行自检。
  理论 BAZ 的**三个口径要分清**：各台→转换点方向的均值（波束实际可测，本项目 134.8°）｜
  子阵中心→目标方位（远场几何，137.2° = 与真实 BAZ 一致）｜旧 `baz` 列（126.4°，有 bug）。
  正演注入与 F-K 反演都以 134.8° 为基准时残差 ≤0.5°；照旧值 126.4° 当基准会凭空多出 ~8.4° 系统差。
  合成/正演的「理论 BAZ」用哪个口径必须写进 README 与图表（用户会逐图核对方向）。
  ⚠️ **在图上标方位角还有第四个自由度：大圆路径上的方位角本身沿路径在变** —— 本项目 G1：震中端出射
  305.90° → G1 端到达 317.24°（反向即来向 137.24°），**路径中点的局部来向是 132.56°**。把数值标在
  大圆中点却写"台阵来向 137.24°"，与"该点方位角"差 4.7° ⇒ **标注位置与数值口径必须分别参数化**
  （`BAZ_AT='mid'|'g1'` × `BAZ_MODE='centroid'|'mean'|'local'`，三个值都写进参数区注释），交付时
  说明用的是哪一个。取端点到达方位角用 `inv.Position(inv.s13)["azi2"]`——`GeodesicLine` 对象本身只有 `.azi1`，
  **没有 `.azi2` / `.azimuth`**（照属性直觉写必抛 AttributeError，白跑一轮）；沿线任意点同理用 `inv.Position(d)`。用户会主动问"在中间标的是多少度"，先把三套数摆出来让他选，别只给一个数。
  标在白底海面上的做法：文字带白底描边框（`fill='white@20'` 类）+ 居中压在路径中段，比引线标注清楚。
### 三种"包络"的身份与溯源（被问"这个包络怎么算的"先辨哪条链）
- ⚠️ **被问"这个包络是怎么计算的"先辨明是哪一条**（同一项目里至少三种产物）——**且默认问的是"我们自己项目里怎么实现的"**（哪条链、哪些参数），不是"论文有没有写"：后者是另一个问题，除非用户明确说"论文里有没有提 X"（用户会追问"我是说预处理阶段的包络计算""我们现在自己的预处理"来纠正跑偏）。先按我们的脚本答，再按需补论文口径。三条产物：F-K 输入
  `envelope_0.25LPF/envelope_lp_all_28*/{STA}_env_lp.sac` = 去响应速度 → 2-8 Hz 零相位带通 → \|Hilbert\| →
  **0.25 Hz 低通** → 抽到 2 Hz（全台共用起点）；剖面/偏振 `sacprocess/envelope/{STA}_envelope_2-8Hz.npz`
  = butter 带通 → \|hilbert\| → **6 s 滑动平均**、保持 20 Hz；`synth_forward/*/` 是**解析高斯驼峰**（非 Hilbert）。
  三者不可互换（F-K 包络别拿去算 SNR/频谱，npz 别直接喂 fk4d）。**反查 = 从源头 SAC 按候选链路重算、
  与存盘逐点比对**（浮点量级吻合者才是数据源），别凭脚本名或 mtime 断言。
  身份卡、实测残差与频带旁证见 `references/envelope-fk-band-coherence.md` §0。
  ⚠️ **参数溯源**：被问"论文里有没有提 X（几秒平滑？包络怎么算？）"时先提原文文本再 grep 关键词、
  把命中与**零命中**都摆出来，不要凭印象答。Zhou2021 正文+SI 对 `smooth/moving average/second/Hilbert/
  decimate` **全零命中**，包络只有一句"The envelope for the filtered seismograms…"无算法；论文给的只有
  **2–8 Hz 滤波 + 0.25 Hz 低通**，预处理出处 Matsumoto et al. (2016) three-step（>1 Hz 高通→取包络→
  <0.4 Hz 低通；正文 closed，参数取自同组会议摘要），**同样没给平滑窗长**。⚠️ **更硬的落点是论文自己点名的工具**：Data Availability 写明"The code SEIZMO … is used for data preprocessing and F-K analysis"，读它的 `solo/envelope.m` 即可定案——包络 = 频域解析信号取模（`1+sgn(ω)` 乘子后 `abs`）、**函数签名里没有窗宽/平滑参数、代码里也没有平滑步骤**，且 `fk/*.m` 全部引擎不做 smooth/envelope/lowpass（输入全靠使用者准备）⇒ 论文只给一个方法词时**优先读它点名的工具箱源码**，比翻会议摘要更确定（细节见 references §4a）。⇒ 报复现参数一律分
  「论文给的」/「我们自选的」两栏（6 s 滑动平均、Hilbert、零相位实现都是自选），用户逐条核对这个区分。
  核验方法与出处链见 `references/envelope-fk-band-coherence.md` §4a。
### 理论到时（T-P / T-S）：论文给的 vs 我们自选的
- ⚠️ **理论到时（T-P/T-S）同样分"论文给的 / 我们自选的"，而且差 20-25 s**：论文式 (1) 的陆地段是
  **恒速** `L_land/6.0`(P) 或 `3.6`(S)，我们的 `t_phase_analysis.tt_t()` 陆地段走 **TauP(iasp91)**
  （只有 NaN 才回退恒速，`vel/vel_s` 参数平时不生效）⇒ stations.csv 的 `tt_tp/tt_ts` 系统性偏早
  （SA18 land 626 km：−20.6 / −24.3 s）。**校准标尺用 T-S 包络峰**（最高峰 1278 s：论文式 1272.5 落在
  93% 峰高、TauP 式 1248.2 只在 63%）；**T-P 不能当标尺**——它邻域有两个小峰（1182.7 / 1207.6 s），
  两套口径各落一个。作图级切换 `process_image.py --tt-paper`（只覆盖图上到时，不动 stations.csv/npz）；**同一张图同时画两套
  用 `--tt-both`**（虚线=射线理论、点线=论文恒速，图内右上用**英文**注记两套时刻值——图内不放中文，避免缺字）；
  落到数据层要连带重跑偏振窗/F-K 相窗。口径命名跟用户走：**我们的这套叫"投影走时"**（代码里的"投影"=
  `traveltime_profile.py` 用 `pygmt.project` 沿大圆路径投影取点生成地形剖面再分段），别只说成 "TauP"。
  量化表、命名与切换方式见 `references/theory-arrival-convention.md`。

## 关键陷阱（续）：估计器与频谱

### 频谱计算：整窗 FFT（Welch / STFT 都是坑）
- ⚠️ **频域 F-K 必须用整窗 FFT，不能用 Welch PSD 或 STFT 时间平均**（2026-09-02 实测三轮调试）：
  1. **Welch PSD 丢失相位**：`scipy.signal.welch()` 返回实数功率谱 |X|²，相位已丢失。白化后
     所有台站变成 ±1.0，steering vector 失效，峰值必然在慢度原点 (0,0) = 无限大速度假象。
     症状：所有分量/时间窗都返回慢度 0.00 s/deg。
  2. **STFT 时间平均抹掉相位延迟**：改用 `stft()` 获取复数频谱是对的，但若对时间轴做 `.mean(axis=1)`
     会抹掉台站间的相位延迟信息（不同时刻的相位矢量平均→随机游走）。症状：慢度值非零但偏离
     理论 30-600 倍（如实测 0.03-0.57 s/deg vs 理论 18.5-30.9 s/deg），BAZ 方向混乱。
  3. **正确做法**：用整个时间窗的 FFT（`np.fft.rfft`），不做时间平均。120s 窗的频率分辨率
     ~0.008 Hz 已足够，直接 FFT 保留完整相位信息。
  - **单位转换**：台站坐标 km → 慢度必须 s/km → `sx_km = sx_deg / 111.32`（1 deg ≈ 111.32 km）
  - 参考：`references/fft-vs-welch-stft-pitfall.md`（2026-09-02 补充，含三轮调试过程与测试脚本）
- ⚠️ steering 符号：补偿必须 e^{+2πf s·r}（负号→峰值在 -s_true）
- ⚠️ 白化数组 dtype=complex（float 丢虚部，ComplexWarning）
### 慢度网格：SMAX 必须覆盖最慢波型、SPTS 不能太粗
- ⚠️ **慢度网格范围必须覆盖最慢的目标波型**（2026-09-02 马达加斯加调试）：若 SMAX 设置过小，
  真实慢度峰值在网格外，算法只能扫到旁瓣/噪声地板。症状：所有分量慢度都卡在 SMAX 边界（如设
  SMAX=0.8 s/deg 时峰值全是 0.03-0.57 s/deg），BAZ 方向混乱。**正确设置**：
  - T-P 窗（地壳 P 波 6 km/s）：慢度 ~18.5 s/deg → SMAX ≥ 25 s/deg
  - T-S 窗（地壳 S/Love 波 3.6 km/s）：慢度 ~30.9 s/deg → SMAX ≥ 40 s/deg
  - 声道 T 波（SOFAR 1.48 km/s）：慢度 ~75 s/deg → SMAX ≥ 80 s/deg
  建议默认 SMAX=40 s/deg（覆盖地壳波），步长 DS=0.5 s/deg（161×161 网格，计算可接受）。
- ⚠️ **SPTS 网格分辨率不能太粗（SPTS=101/121 太低，2026-09-02 合成验证实测）**：SPTS 决定
  慢度网格密度，太粗会让峰值点偏离真实慢度、显著压低峰值显著性（max/mean）。合成验证实测
  （3 站注入 v=3.6 平面波）：SPTS=101 → 峰值 v 偏到 3.97、max/mean 仅 1.7（理论应 ≈ 站数
  N=3）；SPTS=401 → v 收敛 3.53、max/mean 1.84；SPTS=801 → v=3.59、max/mean 2.62。
  **真实数据 F-K 建议 SPTS≥201**（401 更稳），但网格点按 n² 增长——全岛 20 站+长窗（数百秒）
  时 SPTS=401 会超时，需按「站数 × 窗长」权衡，或只跑 2-8 Hz 单频段（去掉 2-4/4-8 分频段）
  降计算量。之前 fk_analysis/fk6/fk7 一直用 SPTS=101/121，是视速度不准+峰被压低的一个隐性 bug。
### 尾波归一化 ≠ F-K 预处理（别混用）
- ⚠️ **尾波归一化（coda normalization, Aki 1980）≠ F-K 预处理，别混用**：尾波归一化是
  衰减（Q 值）研究工具——用尾波振幅做参考归一化直达波/S 波振幅，目的分离场地效应+震源效应、
  反演路径衰减，跟\"测波来向/视速度\"无关。F-K 波束形成用的是**相位**（到达时间差），且代码
  里的相位白化 `X/|X|` 已把振幅（含场地放大效应）彻底抹平，无需再做尾波归一化。用户若问
  \"是不是该先尾波归一化去场地效应\"，答：不需要——相位白化已等效去掉场地效应的振幅层面；
  场地效应若带来台站间到时偏移，属 station timing residual，靠时延校正，不是尾波归一化能解决。
### 扇区读数与 3 站统计量
- ⚠️ 扇区掩膜 atan2(东, 北) 顺序
- ⚠️ **`peak_in_sector` 的 argmax 在扇区弥散时会返回假峰，数值本身不能作为真假判据**：
  该函数只是在理论 BAZ±容差扇区内取 P 最大值，如果扇区内根本没有真实尖峰、只是一片弥散
  噪声，函数依然会返回某个坐标——看起来是正常输出的 BAZ/v 数字，但其实是噪声地板上的
  随机极值。任何一组反演结果偏理论较大或多个三角"打架"时，必须回头看对应慢度图确认扇区
  内是单一尖峰还是弥散/多峰，不能只凭返回的 BAZ 数字下结论。
- 3 站统计量小：BAZ 波动 ±10-18° 正常，**方向比慢度大小可靠**（视速度偏低是稀疏几何固有）
### 滑动窗的分辨率上限与选窗四判据
- ⚠️ **滑动窗 fk4d（width<100%）的分辨率硬上限 = 帧长/2**（2026-09-11 合成对照证实）：帧长 T
  ⇒ Δf=1/T ⇒ 可无歧义分辨的台间延迟 |τ| ≲ T/2，超过按 T 折叠。width=10%（帧长 12-15 s）只能
  测 ≲2 s/deg；要测 18.5/30.9 s/deg（~300 km 孔径 ⇒ 40-84 s 延迟）需帧长 ≳150 s（width≈100%）。
  合成注入完美相干平面波：整窗精确恢复（31.2 vs 30.9、18.5 vs 18.5），width=10% 却 18 帧里 13 帧
  落回 0-0.8 s/deg、BAZ 乱跳 ⇒ **"滑动窗没出团"不能当"数据没信号"的判据，也不能当复现依据**。
  另：多窗时返回 1×nframes **结构体数组**，须逐帧 `s4d(k).beam`（beam 维度 [SPTS×SPTS×nfreq]）。
  详见 `references/sliding-window-aliasing-limit.md`（含合成对照配方与 BAZ 角定标）。
  **选窗四判据（定窗/换窗前逐条过，2026-09-13 汇总）**：① 窗长 ≥ 2×子阵内最大理论到时差
  （= 帧长/2 判据；未过则该窗的"平/针尖"结果不能用来说明数据没有信号）；② 窗的边界是**双向**的：上边界必须早于下一震相最早理论到时（T-P 窗不得含 T-S 到时，否则出假方位）；
  **下边界（慢/低频相一侧）也要晚于前一相波包结束** —— 一条长窗同时罩住两相时，低频带（≲0.013 Hz）里
  前相包络能量与后相同级，足以把后相峰从 33.5 s/° 直接拉塌到 1.4–1.8 s/°（实测 G1 陆地计时 T-S：
  只罩 T-S 的 150 s 窗 33.48@131° 三 method 逐位相同；换成罩 60–260 s 的并集长窗 1.44–1.78@76–79°）；
  切法与分界见 `references/phase-window-definition.md` §2 / §2b；③ 满足①②后**窗越长越好**：0 慢度公共模式伪峰随窗长
  单调下降（实测 10 s→8.0 dB、74 s→3.9、84 s→3.4、128 s→2.7 dB 显著度）；④ 报"某震相测不出"
  之前，用**到达前的等长空窗**跑同一 F-K 做对照（空窗照样出针尖 ⇒ 伪峰，与窗内有无信号无关）。
### method 不是中性选择（对照必须同窗同带）
- ⚠️ **method 不是中性选择，不能凭单张图定**（2026-09-11 多窗扫描实证）：同一 G1 子阵、同一输入，
  `coarray`（上三角台对、**不含自功率项**）与 `center`/`full`（常规相干波束）给不同方位。
  4 个不同窗扫描 |ΔBAZ|（vs 理论 126°）：**T-P 窗 center/full 平均 33.8°（3/4 窗=9°）、coarray 78.8°**；
  **T-S 窗 coarray 平均 92.8°（4/4 优于 center）、center 142°、full 84.2°**。
  规律：短而相干的波包（T-P）用 center/full 最尖最稳；弥散/相位结构弱的波包（T-S）用 coarray
  （无自功率“基座”）。做法：换窗长/位置或换子阵扫描一遍再选，并以与理论方位的差作判据。
  ⚠️ **固定窗与频带后，`full` 与 `center` 峰位逐位相同**（full 多出来的自配对是零延迟项，只把 prom 抬
  高零点几 dB，不移动峰）——实测 G1 T-S：full/center 都是 43.82 s/°@147°（整带）、35.31 s/°@138°（单频点），
  而 coarray 同窗 prom 低 ~1.5 dB、−3 dB 面积约大一倍（更弥散）。⇒ 三方法对照图里真正要权衡的是
  coarray 与（center≈full）两端，别把 full 当成第三条独立路线去解释差异。
### 分量选择 / 公共起点 / beam txt 的 y 轴降序
- ⚠️ **分量要先选对，别默认用 Z**（2026-09-11 三分量实测，XA G1）：T-S 是切向（Love 型）运动，
  **横向 T 分量 SNR 最高**（T-S：T 24.4/24.9 dB vs Z 20.2/21.8、R 20.0/21.8，峰法/RMS 两判据一致），
  其 F-K 也最可靠：T-S 窗 **T + center** 在 4 个窗均稳定（|ΔBAZ| 5-26°、慢度 23-36 s/°，
  论文 southern T-S_local = 24.7 s/°），而 **Z 分量同窗 4 窗平均 |ΔBAZ| 117°（全废）**。
  T-P 在三分量上都有包络能量（RMS 15.4/16.1/16.6 dB）⇒ 论文“T-P_local 只在 Z/R 可见”未见复现。
  做法：先出**三分量链式对比图**（3 分量 × 3 阶段：2-8Hz zerophase | 包络 | 0.25Hz 低通）
  + 逐分量波包 SNR 表（峰法+RMS 双判据），再定分量。
  R/T 旋转用 obspy `rotate_ne_rt`（R=N·cos(baz)+E·sin(baz)，T=E·cos(baz)−N·sin(baz)）；
  ⚠️ 写 F-K 输入 SAC 时必须给**全台统一公共起点**（同 envelope_0.25LPF/envelope_lp_all_28 做法），
  否则各台起点差几十 ms，fk4d 插值时插不到→NaN→报 `No windows contained 2 or more records!`。
  - ⚠️ **fk4d 存盘 beam txt 的 y 轴要降序还原**（2026-09-11 踩坑，很难自行发现）：
  `fkvolume.m` 里 N-S 轴是 `y=fliplr(sx)'` ⇒ txt 中 **y 列按行递减**。Python 端若用
  `np.unique(d[:,1])`（升序）重建网格，图会在 N-S 方向**镜像**，方位变成 `180°−az`
  —— **慢度模不变，只有方位错**，而且图看起来“正常”。正确：`y = np.unique(d[:,1])[::-1]`，
  或按文件原始顺序 reshape（后者不会错，推荐）。**收尾必做**：同一窗口 Octave 打印的峰方位
  与 Python 从 txt 算的方位要逐位一致（曾出现 36.2@131° vs 36.2@48.9° 才发现）。
  ⚠️ **从 `beams/*.txt` 复算读数做跨子阵对账表时同一条照样管**：升序读法下 slow/prom **一模一样**、
  只有 BAZ 被镜像成 `180°−az`（实测 G1 `ts60_260_T` 文件升序读 33° vs 降序读 147°，而两者与
  `.m` 打印值只差一步）⇒ 对比表的方位整列错却看不出来。做法：复算值先与各自 `.m`/`summary` 的
  打印值逐位对齐，再拿去跨子阵比。
### T-P 窗的近零慢度假峰与"空窗对照"
- ⚠️ **T-P 窗的"极锐零慢度峰"是公共包络假峰，不是平面波**（2026-09-11 三分量×两方法全覆盖实测）：
  三条同时成立即判假——① 峰极锐（prominence 5.6-7.3 dB、−3dB 面积仅 0.1-0.4%）② 峰慢度 ≈0
  （0.0-1.1 s/° = 视速度无穷）③ 与理论方位差 >50°。机制：包络在 0.02-0.25 Hz 带内各台同时涨落，
  零慢度处完美聚焦。T-P 在 Z/R/T × center/coarray 共 12 组里**全部**如此 ⇒ T-P 窗在这套数据上
  无可用结果，别在它上面继续调参；只有 T-S 给出物理量级（23-36 s/°）。
  **决定性对照（判"该震相 F-K 不可用"前必做）**：拿**到达之前**的同长空窗（纯噪声，无目标信号）
  跑同一个 F-K——零慢度针尖照样出现，prominence 甚至**更高**（10 s 空窗 8.3-8.9 dB，而真信号长窗
  只有 2.7-3.4 dB）⇒ 直接证明针尖来自窗内共同起伏 / 白化噪声，与"窗里有没有信号"无关。
  只凭真信号窗出针尖就宣布"只有 T-S 可用"是不充分的，必须补这个空窗对照。
  ⚠️ **判"这条相窗到底有没有平面波"要把频带拆成单频点、每个频点用各自的抗混叠上限各跑一遍**
  （`SMAX = 0.550231/f`；本项目 G1 T-P 的 0.0156/0.0234/0.0312 Hz × Z/R/T 九组峰**全落在 0.5–2.2 s/°**
  ⇒ 视速度 50–220 km/s，对陆壳震相非物理），再用**主瓣半宽** `0.64·111.195/(f·D)` 区分"没信号"与
  "被分辨率糊掉"（0.0234 Hz 处半宽 9.8 s/°，理论 13.7 与 0 差 1.4 个半宽、本该分得开，实测只有 2.2
  ⇒ 判无信号）。G2 同窗同参数复核结论一致 ⇒ **T-P 无峰是数据/几何的性质，不是频带选错**，别再换频带重试。
 ⚠️ **定“某震相到底有没有信号”的最后一道读数 = 在理论慢度点上取值并与 0 慢度比**（不是与峰比）：
 G1 的 T-P 七配置 × Z/R 实测中，**`beam(0°)` 永远紧贴峰**（−0.01…−0.54 dB，公共包络模式），
 而理论点始终比它**低 0.3–11.6 dB** ⇒ 无信号；低频处“理论点只比峰低 0.8 dB”是主瓣半宽
 `0.64·111.195/(f·D)` 的几何必然（0.0078 Hz → 29.2°、0.0312 Hz → 7.3°）。
 配方与逐配置表见 `references/peak-reading-and-method-comparison.md` §5。

### 视速度偏低与 SMAX 表述的方向性错误（易写反）
- ⚠️ **视速度偏低不能用入射角解释**：v_app = v_true / sinθ（θ=入射角），因 sinθ≤1，
  入射角效应只会让视速度**变大**（越垂直入射越大），永远不会让它变小。稀疏台阵测出的
  视速度偏低（如马达加斯加 1.5-2.1 vs 理论 3.6-6 km/s）只能归因于稀疏几何的系统性
  欠估计，不要用"入射角"给偏低找理由（曾在口头解释时犯这个方向性错误，与
  v_app≥v_true 的结论自相矛盾，务必对照公式方向自查）
- ⚠️ **SMAX 与速度是倒数关系，表述"谁比谁快"容易搞反**：SMAX=0.7 s/km 对应网格能覆盖的
  最慢速度下限 v=1/0.7≈1.43 km/s；SOFAR 声道 1.48 km/s **比这个下限快**（1.48>1.43），
  刚好落在网格覆盖范围内，但余量仅 ~3%（声道声速区域波动常在 1.45-1.50 km/s，实际路径
  可能逼近网格边缘、峰值被削平）——别写反成"网格比该速度快"
### 网格范围不覆盖最慢波型 ⇒ 整批弥散假象
- ⚠️ **慢度网格范围必须覆盖最慢的波型，否则整批结果全是弥散假象**（2026-09-01 马达加斯加
  实测的"批量全部 max/mean≈1.1 弥散"根因）：`fk6_summary_map.py`/`fk7_batch12.py` 曾用
  `SMAX_DEG=35.0`（网格边缘 v=111.19/35≈3.18 km/s），但真实 T 波视速度 1.5-1.7 km/s
  对应的慢度 67-73 s/deg **完全在网格外**——算法扫描的区域根本不包含真峰，看到的是旁瓣
  地板，必然整片平坦。而 `fk_analysis.py` 的 `SMAX=0.7 s/km`（≈77.8 s/deg，覆盖
  v≥1.43 km/s）才是对的。**新建/复制 F-K 批量脚本时必须核对 SMAX 单位换算**：s/km ×111.19
  = s/deg；保证 SMAX_DEG ≥ 78（覆盖 SOFAR 1.43 km/s）。改成 77.8 后视速度立刻进入合理
  量级（1.39-1.83 km/s），但 max/mean 仍 1.18-1.21——网格范围是必要条件不是充分条件，
  后续仍要过峰值显著性检查。

### 两相分开做 + 速度先验（环形双掩膜）
- ⚠️ **T-P/T-S 必须分开做，且用已知速度约束慢度半径，不能让视速度自由搜索**
  （2026-09-02 用户纠正的关键方法）：T-P 是陆壳 P 波（v≈6.0 km/s → 慢度 1/6≈0.167 s/km）、
  T-S 是陆壳 S 波（v≈3.6 km/s → 慢度 1/3.6≈0.278 s/km），速度是"清楚的"先验。找峰时用
  「BAZ 方向 ±40° 且 慢度半径 |s|−1/v_theory ≤ 容差（T-P ±0.05、T-S ±0.06）」的**环形双掩膜**，
  而不是只限方向、让 |s| 在整个网格自由取 argmax（否则假峰落在 1.4-30 km/s 的错误速度位置）。
  实测：加速度约束后视速度从乱跳收敛到理论附近（全岛 T-S 窗 v=3.67 vs 理论 3.6），但 BAZ
  仍可能偏、max/mean 仍低（说明峰仍不尖锐，速度约束是必要条件不是充分条件）。
  Zhou et al. (2021) 摘要正是靠"T-P/T-S 的偏振和慢度有明显差异"区分两个转换震相——速度先验
  是识别转换震相的核心，不是可选参数。
### 相位窗 = 全台共用的绝对时间窗（不是逐台开窗）
- ⚠️ **相位窗是全台共用的"绝对时间窗"，不是逐台独立开窗**（用户会追问这个，务必答准）：边界由
  **逐台理论到时**算出（`t_lo=min(理论)−30 s`、`t_hi=max(理论)+50 s`，min/max 取遍子阵所有台），
  但算完即作为**同一个区间**施加到每条记录：Python 端 `t=(starttime−ORIGIN)+sac.b+i/sr` 上套同一掩膜；
  Octave 端 `cut(data, o+win(1), o+win(2))`（输入已统一公共起点 ⇒ 同一绝对窗）。**必须如此**：F-K 测的
  就是台间到时差，同一窗内各台波包本就落在不同位置（XA G1 T-S 窗 [1243,1386]：SA18 在窗内第 29.5 s、
  SA29 第 93.0 s，摊开 63.4 s）；若逐台以自己理论到时为中心开窗，各台都落在窗内同一位置、台间散布
  归零 ⇒ F-K 只能给 0 慢度（这正是**对齐残差 F-K** 的用途：验到时模型自洽，测不了绝对慢度）。

### 时间基准与陆地计时（零点 / 逐台平移 / `b≠0` 的切窗错位）
- ⚠️ **时间基准：送进 F-K 的波形零点 = 发震时刻（= 相位窗的计时原点），且"全局零点平移不改变慢度"**：
  写法 = 统一公共起点时写 `o = ORIGIN − common_start`（`b=0`），Octave 端 `cut(data, o+win(1), o+win(2))`，
  脚本里的 `win` 一律是"**发震后秒数**"（不是 SAC 相对秒）。用户会追问"我用 T 波，零点不该取陆地计时
  开始吗，这样慢度才对得上、消除海面影响"——答法两条：① 零点整体平移**在数学上不影响慢度**
  （台对互谱里共同相位因子 `e^{−i2πfΔt₀}` 自动抵消），它只决定"切到哪段样本"以及"是否已预先对齐"；
  ② 海面/陆地的贡献要用**窗内主控段**算：本案例 G1 各台在窗内 `ocean_km` 只差 ~15 km（陆地段
  600-980 km 主导）⇒ 纯陆地时差场梯度 31.2 s/° vs 含海 30.2 s/°，仅差 **+1.0 s/°（3%、方位 ~1°）**
  ="消除海面影响"**解释不了**慢度不符，别把它当复现失败的归因方向（真正相关的是窗内有没有相干波前：
  `references/phase-window-definition.md`、`envelope-fk-band-coherence.md`）。
  ③ **"逐台按自己上岸时刻平移后再 F-K"已经实测过**（用户会直接要求"把陆地计时为零送检"、"f 图送检"）：
  平移 = 移除台站间 `Δocean/1.48` 的到时差 ⇒ **逐台平移 ≠ 全局平移**（全局平移在台对互谱里抵消，
  逐台差移会直接改台间时延，等于重定义阵列几何）。G1 7 台实测（T 分量包络、0.02–0.25 Hz、同窗长）：
  各台上岸时刻只差 **10.1 s**（ocean 1626–1641 km）⇒ 平移后峰 **36.79 → 35.69 s/°、BAZ 291.2 → 295.6°**
  （≈1 个慢度格点）、峰-中值 2.29 → 2.75 dB，**对 G1 可视为无影响**；要看到效应必须换上岸跨度大的台组
  （全台阵 37 站 ocean 1626–1904 km，跨度 **188 s**）。
  ⚠️ **对照必须同窗长**：陆地计时 0–400 s 的宽窗（801 点 vs 256 点）给 BAZ 148.7°，那是"窗变宽混入
  非相干能量"，不能算作陆地计时的效应——用户会拿不同窗长的结果并列，报结论前先核点数。
  实现 = 每台 `t' = t − ocean/1.48` → 插值到共同 t' 网格 → 照常 F-K；脚本/产物：
  `4_fk_analysis/fk_landtimed_test.py` → `fk_landtimed/{results_landtimed.csv, beam_*.npy, fig_landtimed_fk.png}`。
  ④ **子阵维度复核过（G1 7 站 vs G2 8 站，同窗同参数、同单频点 0.0078 Hz）**：**绝对计时**下两个子阵
  都给指向震源的峰 —— G1 34.8/35.3/35.8 s/°（Z/R/T，\|dBAZ\| 0–4°）、G2 36.2/49.1/35.0 s/°（\|dBAZ\| 6–9°，
  R 分量偏大须在图/表里注明）；**陆地计时**下 G1 的 Z 跑成反向、G2 只有 T 分量成立（33.1 s/°），另两个分量散掉。
  ⇒ **要测陆段走时，用绝对计时 F-K 测出 u 再事后换算，不要用"逐台平移后的 F-K"**：逐台平移改的是
  台间时延（= 重定义阵列几何），不是公共零点；G2 的结论与 G1 一致，可作为该口径选择的实测依据。
  ⑤ **被问"这组波束/这张图用的是陆地计时还是总计时"时从产物反查，别看文件名猜**：输入目录 `input_landtime/`
  或窗写成 143.6–285.3 s ⇒ **陆地计时**（等价绝对 1243–1386 s）；绝对计时那族窗写 1243–1386 s 且输入是

### 逐台平移 vs 走时对齐（性质不同，别当一件事）
  ⚠️ **"陆地计时对齐"与"震中距/走时对齐"性质不同，别当同一件事**（用户会连问"这俩是有区别的吧"）：
  任何逐台平移 `Δt_i` 都把读数改成 `u_读数 = u_真 − u(Δt_i)`，`u(Δt_i)` = 把 `Δt_i` 对台站局部坐标
  做最小二乘平面拟合的斜率（全局平移只进常数项、不进斜率，所以不动读数）。海段平移 `L_ocean,i/1.48`
  的斜率是小量且多横向（G1 \|u\| 1.12 s/°、G2 10.34 s/°、G2 沿传播向只 −0.46 s/°）；
  `d_i/v_ref` 的斜率恰好是 `111.195/v_ref` 且严格沿传播向（v = 1.48/3.6/6.0 → 75/31/18.5 s/°、横向 ≈0）
  ⇒ 后者扣掉的正是要测的 u：v_ref 取真值时峰塌到网格原点、只能读出参考速度误差，按它报数即循环；
  它的 SMAX 只需覆盖"容许的速度误差"，而陆地计时的 SMAX 要覆盖陆段预测慢度 `111.195/v`。
  只改画图轴（不动数据）则读数一字不变。数值、对账与实际现象见 `references/land-time-fk.md` §9；
  复算跑 `scripts/check_static_shift_slowness_bias.py`，别手算。

  ① **随口径走的只有三样**——窗的秒数（陆地窗 `[min(L_land/v)−30, max(L_land/v)+50]`）、

### 相位窗不得跨到下一震相（空隙中点分界）
