# 包络 F-K 的 DC 针尖，与"这个峰能不能当证据"的判据

## 1. 现象：包络非负 ⇒ 波束在 s ≈ 0 处必然有针尖（needle）

包络（Hilbert 取模）无负值 ⇒ 各台同相叠加的最大值总出现在"不引入相位差"的 s = 0 附近。
后果：**全局 argmax 永远报 0–1.4 s/°**，与窗长、方法（center/coarray）、频带几乎无关。
实测（XA G1，T-P × R，12 个 beam 文件）：全部报 0.0–1.4 s/°、BAZ 从 0 到 270 乱跳。
⇒ **看到 s≈0 的峰不要解读为物理**，先判是不是这条针尖。

## 2. 去 DC / de-trend 怎么做（SEIZMO 陷阱）

⚠️ SEIZMO `readdata` 不挂 `.data` 字段（`isfield(data,'data')` = 0，readheader/synchronize/cut 同样）
⇒ **无法在内存里去 DC**，必须写临时 SAC（窗内 demean / demean+线性去趋势）再喂 fk4d。

结果（coarray，18 次 fk4d）：针尖消失，但

| 指标 | 原始 | 去 DC 后 |
|---|---|---|
| prom（峰/次峰，dB） | 4.6–6.4 | 2.5–3.9 |
| −3 dB 面积 | 0.2–2 % | 20–70 % |
| 报出的慢度 | 0–1.4 s/° | 9–41 s/°（乱跳） |

⇒ **去 DC 只削掉针尖，不会凭空造出可判读的峰**；平掉之后图面近乎全平，说明主导限制是
窗长/频带的无混叠约束（见 `fk-parameter-selection.md` §2b、§4b），不是 DC。

## 3. 判据：不只看 argmax，要"在理论点上取值"

对每张 beam 网格算三件事：

```
① 理论点值   B(s_theory, BAZ_theory)  → 报 距全局 max 多少 dB、距整图【中位数】多少 dB
② 方向约束   理论方向 ±30° 内的局部最大（slow, BAZ, 距 max 多少 dB）
③ 峰宽       −3 dB 面积占比（越小越像真峰）
```

**三条同时满足才算找到波前**：① 理论点 − 中位数 ≥ +2~3 dB；② argmax 的 slow **与** BAZ 同时接近理论；
③ −3 dB 面积小。只满足"慢度像"不算——那是平坦波束场里挑最大值的偶然。

XA G1 T-P × R 实例（去 DC 后）：

| 窗 | 全局 max | 理论点距 max / **距中位** | ±30° 内局部 max | 判 |
|---|---|---|---|---|
| R (91 s) | 16.41 s/°@236°（慢度像 17.7，方向差 99°） | −3.78 dB / **−0.98 dB** | 30.4@154° | ✗ |
| C (97 s) | 10.34@246° | −3.30 / −0.36 | 15.7@163° | ✗ |
| G (59 s) | 29.78@114° | −2.36 / **+1.53** | 29.8@114° | ✗（G 窗仅 0.75 个无混叠频点） |

⇒ 用户会问"R 窗慢度好像最接近理论值？"——**慢度数量级对上但方向差 99°、理论点还在中位数以下，就不能算**。
答话要把"慢度 + 方向 + 显著性 + 峰宽"四项一起摆出来。

## 4. 其他会误导的"像峰"的来源（都已实测踩过）

- ⚠️ 自制 Bartlett 波束器验不了这件事：包络恒非负 ⇒ 其最大值永远在 DC，退化成针尖；
  要 A/B 就用**同一个 fk4d 引擎**跑新/旧输入包络比。
- `SMAX` 报在网格边缘（|s| ≈ SMAX）= 波束朝外单调上升被裁断，不是峰。
- 折叠像平移不变（`B(s) = ARF(s − s_true)`），任一"像"都能被摆到像真的位置。
