## 0. 采样率出处（被问"这个采样率哪来的"先答这条）

F-K 输入 = 去响应速度 → 2–8 Hz 零相位带通 → `|Hilbert|` 包络 → **0.25 Hz 低通** → **抽到 2 Hz**。
- **0.25 Hz 是低通截止（数据带宽上限）**，**2 Hz 是采样率**（`dt = 0.5 s`）——两个数别混着说。
- 2 Hz 是**脚本参数**：链子顶部 `BP = (2.0, 8.0); LP = 0.25; NEW_SR = 2.0`（`fk_python/three_comp_chain.py`
  Z 分量同口径在 `gen_env_all_28.py`），落地是 `decim = int(round(sr / NEW_SR))` 的**整数抽取**；
  上游去响应数据 20 Hz ⇒ `round(20/2) = 10` 倍（obspy `decimate` 要整数倍因子，20→2 正好整除）。
- 它满足奈奎斯特（内容 <0.25 Hz，奈奎斯特 0.5 Hz，留 4 倍余量）且保住包络的时域分辨率；
  **但更换它并不改变分析频率阶梯**，见 §1b。

## 1. 降采样对照：假设证伪（别再重复试）

**动机**：论文链只有 "2-8Hz bandpass → Hilbert 包络 → 0.25Hz 低通 → F-K"，我们自己多加了
`decimate(factor=10, no_filter=True)` → 2 Hz，怀疑 0.25 Hz 低通非砖墙、残余折叠回基带污染 F-K 频段。

**做法**：
- `fk_python/gen_env_nodownsample.py`：同口径但**不降采样**（保持 20 Hz）→ `envelope_lp_20hz/`
- `fk_code_octave/compare_2hz_20hz.m`：两组输入、**同一 fk4d 参数（SMAX=35, SPTS=201, FRNG=[0.02 0.25],
  width=100%, overlap=0）+ 同一判据**，24 次反演（2 输入 × 2 子阵 × 2 窗 × 3 方法）
- 日志 `fk_code_octave/compare_2hz_20hz_log.txt`，表格 `fk_code_octave/parse_compare_table.py`

**结果**：center/full 峰位置**逐格相同**（G1 TS center (−3.1,11.6)；G2 TS center (30.8,−22.0)），
最大差异 0.9 格 = 0.30 s/deg（网格步长 0.35 s/deg）；coarray 差异大（G2 TS 差 30 格）但那是该方法
本身在 6-8 站稀疏台阵上的不稳定（两侧同为不可信结果）。峰-中值 (dB) 差异 <0.8 dB。

**结论**：包络 + 0.25 Hz 低通之后降采样到 2 Hz 对 F-K **无实质影响**（0.25 Hz « Nyquist 1 Hz，
残余混叠量级不足以改变波束图）。此假设已排除，不要再当作"论文能出峰而我们不行"的解释。

## 1b. 反向对照：2 Hz vs 4 Hz —— 采样率翻倍不产生新频点

**做法**：按 §0 的原链从 20 Hz 去响应数据重建 T 分量包络两套（`NEW_SR = 2.0` 与 `4.0`，抽取比 ÷10 与 ÷5），
同一窗/频带/分量/method 各跑一遍 fk4d，逐项对照。

**前置校验（不做这步整组对照无效）**：重建的 2 Hz 与工程现用
`envelope_0.25LPF/envelope_lp_all_28_T/*.sac` 必须**逐点 `max|Δ| = 0`** 才开始比。
⚠️ 首次重建漏掉了链子里的 `bandpass(2,8) → |Hilbert| → lowpass(0.25)`（直接把旋转后的原始记录当"包络"），
结果与现用文件差 **4 个量级、相关系数 0.05** —— 形状完全不同，却差一点被当成"采样率效应"报出去。
定位方法 = **分量对照**：Z 不经旋转且已有现用文件，先把 Z 链重建一遍；Z 逐点一致 ⇒ 链子没写错、
差异来自旋转那条支路（本例真相是脚本里缓存了旋转后的 T 却没调用链子）。

**结果**（T 分量、coarray、SMAX 42.2 / SPTS 243、同一绝对窗 1243–1386 s）：

| 配置 | 2 Hz（dt 0.5，287 点 / nfft 512） | 4 Hz（dt 0.25，573 点 / nfft 1024） | Δf（两者） |
|---|---|---|---|
| T-S 带 0.005–0.014 Hz | 11.59 s/° @136°（prom 5.77 dB） | 11.59 @136°（5.79 dB） | 0.00390625 Hz |
| T-S 单频点 0.0078 Hz | 34.79 @137°（8.91 dB） | 34.54 @137°（8.91 dB） | 0.00390625 Hz |
| T-P 带 0.020–0.035 Hz（无信号） | 0.35 @270°（8.35 dB） | 0.49 @**225°**（8.35 dB） | 0.0078125 Hz |

**结论**：`Δf = 1/(nfft·dt)`、`nfft = 2^⌈log₂(T/dt)⌉` —— **dt 减半时 nfft 同步翻倍，`nfft·dt` 不变**
⇒ 采样率翻倍**不产生新频点、也不移动已有频点**；有信号的配置读数一致到小数点后两位
（0.7% 的差来自 ÷10 与 ÷5 两次抽取的滤波细节）；**无信号配置的"峰位"换地方**，可作为"那个峰是噪声落点"
的又一独立证据。代价 = 文件与 FFT 各 ×2、零增益 ⇒ 沿用 2 Hz（换成 1 Hz 也等效，`nfft` 减半而已）。
**要改分析频率阶梯只能改窗长**（`Δf ∈ (1/2T, 1/T]`，由窗长主导）。

## 3. fk4d 数据结构的两个确认

- `s4d.beam` 维度 = **[SPTS × SPTS × nfreq]**（`fkvolume.m` 里
  `svol(a).beam=zeros(spts,bazpts,nfreq,'single')`）→ `mean(s4d.beam,3)` 是**频率平均**，正确。
  时间维只在 width<100% 时才出现（多帧），此时 beam 多一维。`width=100, overlap=0` = 单帧，
  等价于整窗 `fkvolume`。
- `s4d.beam` 已按峰值归一化为 dB（`.normdb` 记录 0 dB 参考）。

## 4. 显著性判据必须统一（否则跨输入/跨脚本比较无意义）

- 用 **峰-中值 (dB)** + **峰值−3 dB 内网格占比 (%)** 这一对判据。
- ❌ `max(beam)/mean(beam)` 在 dB 归一化的 beam 上会得到 <1 的数值（全是负 dB），
  与"dB 差"完全不可比——曾用两种脚本各算一个判据，导致表格看起来结论矛盾。
- 判读：占比 >10% 或峰-中值 <1.5 dB ⇒ 弥散/无真峰；占比 ≪10% 且峰-中值 >4 dB ⇒ 真尖峰
  （但要再看**峰的位置**是否有物理意义）。
