# 理论 T-P/T-S 窗口比较与绘图规范

适用：单台理论窗口 PCA 的敏感性比较，不替代主结果的物理判读。

## 两种必须区分的图

- **严格理论窗**：T-P = `ttp±3 s`，T-S = `tts±3 s`。
- **平移窗对比**：仅在用户指定或敏感性测试时使用，例如两窗均 `+12 s±3 s`；文件名必须包含平移量，如 `both_plus12s_pm3s`，不得覆盖严格理论图。

## 图内展示（左下角）

1. 横轴使用相对发震时间；若分析窗在陆地走时坐标定义，先加回 `tt_ocean` 才可画色块。
2. 显示 Z/R/T 三分量 2–8 Hz：
   - 三分量共用展示时段的 global P98，保留相对振幅；
   - 波形统一淡灰；
   - 包络按分量着色（Z 黑、R 蓝、T 红）；单台短窗口诊断使用 4 s Hilbert 包络平滑；
   - 用半透明蓝/紫长方形标记实际参与 PCA 的 T-P/T-S 窗口，并保留理论中心虚线。
3. 图总标题只保留 `STA | SNR | T-P | T-S`；子窗长度、重叠率、平滑和窗口策略写入代码注释，不堆入表头。

## 判读边界

- 1 s PCA 子窗、0.25 s 步长（75% 重叠）是估计单元；外层理论窗为 ±3 s。
- 平移量不是通用走时校正。严格理论与平移窗的比较应逐台站报告；若不同台站的 T-P/T-S 结果不一致，不可将某一台站的平移量机械施加到其他台站。
- 理论 T-S 原窗受 T-P 尾波污染、而平移后更横向，只能表明该台站的横向主能量晚到；不能单独宣布整个 T 波模型统一提前。
