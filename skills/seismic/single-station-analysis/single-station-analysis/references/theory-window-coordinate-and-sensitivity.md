# 理论偏振窗口：坐标与敏感性检查

## 适用
用于 T-P/T-S 理论窗口 PCA 图，尤其是 SAC 数据以 `o` 字段定义发震相对时间、而窗口计算使用陆地走时的事件。

## 坐标铁律
- 窗口可在陆地走时定义：`TTP_LAND = tt_tp - tt_ocean`、`TTS_LAND = tt_ts - tt_ocean`。
- 若波形面板横轴为发震相对绝对时间，绘制色块前必须转换回绝对时间：
  `w_abs = w_land + tt_ocean`。
- 不得直接把陆地走时窗口 `w_land` 画到绝对时间轴，否则色块会错误偏移约一个海洋走时。
- 波形面板应显示半透明色块和中心虚线：T-P 蓝色、T-S 紫色。

## 标准与敏感性
- 主结果：T-P 为理论到时 ±3 s；T-S 为理论到时后移 12 s 的 ±3 s（`TTS_LAND+9` 至 `+15`），用以避开 T-P 尾波。
- 任何改变（如 T-P/T-S 都后移 10 或 12 s、原始 T-S ±3 s）只能作为**独立命名的敏感性对比图**，不得覆盖主结果。
- 对比图须报告每个窗口的 R-T 中位角、线性度和实际绝对时间范围。

## AMPY 2013-08-17 复核例
- 理论 T-P ±3 s：R-T −21.5°，线性度 0.997。
- T-S +12 s ±3 s：R-T 84.2°，线性度 0.999。
- 原始 T-S ±3 s：R-T 51.6°，说明 T-S 明显受窗口位置影响。
- T-P/T-S 均 +10 s：T-P R-T −114.1°、T-S 81.6°；此为敏感性结果，不能替代主窗口。
