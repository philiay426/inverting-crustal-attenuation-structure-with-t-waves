# 全时段偏振扫描（整段 T 波一视同仁）+ 拾取边界验证

1D/2D 参数敏感性扫描（窗宽×搜索半宽、窗宽×海洋声速；VOI 实测 ±3~4s 稳定平台、v_ocean=1.48 双向稳健）
见 `references/window-velocity-grid-scan.md`。本文件记录**把偏振引导搜索推广为整段 T 波波列扫描**的方法、图规范与判读。

## 用途

1. 验证理论窗处是否真有对应偏振簇（径向/横向）——搜索方案找不到合格窗时回答"是没信号还是理论错了"；
2. 验证贴 ±15s 搜索边界的拾取是否真实（skill 规则：candidate at ±15s boundary is a review flag → 用全时段扫描独立复核）；
3. 展示整段 T 波列偏振结构（径向/横向交替多簇属正常，T 波多次路径/转换波包）。

## 方法（脚本 `templates/full_scan_polarization.py`）

- **多台站批量版**（不是每站复制一份）：`python full_scan_polarization.py [STA ...]`，默认 10 个高SNR站；
  每站参数从 `stations.csv` 读，输出到自己的 `process_flow/2_single_station_analysis/{STA}/`。
  改顶部 `EV_ORIGIN / BASE` 适配其他事件。
- 并行：`multiprocessing.Pool(min(len(stations), 8))` + `if __name__ == '__main__'` 保护；
  16 核上 10 站（每站 ~2500 窗口）约 3 分钟。
- **CSV 缓存复用**：`{STA}_polarization_fullscan.csv` 已存在且行数与首个中心一致 → 直接读回，
  **改图不重扫、秒出**；改扫描范围/步长时行数不匹配会自动重扫。
- 扫描区间 `[理论T-P−100s, 理论T-S+500s]`、步长 0.25s；每候选中心 ±3s 窗口 PCA
  （1s 子窗 / 75% 重叠 / analytic / ZNE→ZRT(baz)），与 `run_polarization_guided_picks.py` 同口径
  → 结果可直接与搜索 CSV 对比。
- CSV 列：`center_s, rt_angle_med_deg, linearity_med, radial_res_deg, transv_res_deg, snr_db, n_subwin`。

## 图规范（用户定稿）

- 三行共享时间轴：
  1. **Z/R/T 三分量 2–8 Hz 包络**（`rotate_ne_rt(BHN, BHE, baz)`，三分量共用 global P98，
     ylabel `Norm. Amp.`，4s 平滑，黑色 Z / 蓝 R / 红 T）；
  2. **dist-to-radial 折线**（0°=径向绿虚线、±90°=横向红虚线，`radial_res` 无跳变，直接画折线）；
  3. **线性度折线**。
- 竖线**只画理论到时**（蓝/红虚线 + `T-P = xxx s` / `T-S = xxx s` 数值标注）。
- ⚠️ **不要画未标注的辅助线**：在某版图上画了引导拾取实线但没进图例/标注，用户立刻问
  "有个实线是什么"，随后要求"只留理论线"。要画就必须标注，否则不画。
- 标题精简：`{STA} T-wave polarization scan (2-8 Hz, ±3s win)`，参数写代码注释而不是标题；
  只有一条曲线的面板不加图例（与 y 轴标签重复）。
- 理论标注放**顶部留白**：`set_ylim(0, ymax*1.32)` + 文字放 `1.20*ymax`，T-P 靠左、T-S 靠右错开
  （旧散点版用 `transform=get_xaxis_transform(), y=0.98`，易被裁或压住包络）。

## 判读规则

### 用连续簇，不用全局最小窗口

- 先筛合格窗口（`residual<10° & linearity>0.99`），再**分簇**（相邻合格窗中心间隔 ≤0.5 s 归同簇），
  保留簇长 ≥1 s（≈4 个连续 0.25 s 窗口）的簇；在**理论 ±60 s** 内取**最早**的合格簇。
- **为什么不能用"全局残差最小的窗口"**：长时段内总会撞到几个偶然纯径向/横向的孤立窗口
  （VOI 实测"全局最优横向"落在理论 −43.7 s，是伪簇），会给出与真实波包无关的结论。
- 理论 T-P 处无径向簇、但拾取位置（常贴搜索边界）有稳定簇 → **边界拾取是真实信号**，
  不是搜索假象，可放心使用并注明由全时段扫描复核。
- 理论无支持且搜索也失败 → 该震相在此台站不可用，不强行给窗口。

### 跨站结论（10 高SNR站，2013-08-17 Madagascar）

- 10 站**全部**在理论 ±60s 内找到径向簇与横向簇（残差 0.5–9.6°、线性度 >0.99）→ 方法普适，非单站个例。
- 但相对理论的偏移 **−31.5 s ~ +45.5 s 各站不一致**（KIRI +45.5s、SOLA −31.5s、VOI/BKTA 偏负、BATG/AMPY 偏正）
  → **不能用统一固定时移修正**，必须逐站扫描；偏差来源不是单一走时模型误差（v_ocean=1.48 已由网格扫描证明稳健）。

## 实例（BATG，2013-08-17 Madagascar）

- 理论 T-P=1046.2s / T-S=1099.1s；引导拾取 T-P=1060.95s（=理论+14.75s，贴 ±15s 边界）、T-S=1100.6s，均 accepted。
- 全时段扫描核对：理论 T-P 处无径向支持（最小径向残差 14.5°@1047.95s）；真实稳定径向簇 **1058.2–1061.95s**（1.4°@1060.7s，比理论晚 ~14.6s）→ 引导 T-P 拾取虽贴边界但真实。理论 T-S 处横向支持良好（2.1°@1098.95s），拾取 T-S 落在同一横向簇。
- 整段波列径向簇还出现在 1005–1023s、1077–1084s、1126–1132s、1164–1166s 等；横向簇在 981–984s、1206–1210s、1250–1254s 等；线性度全程 >0.95、SNR 自 ~1050s 稳定 >20dB → 多簇非噪声伪簇。
- 结论：单台"T-P 只有一个径向窗口"的简单图景不成立；T 波列是多次路径/转换波包的偏振分集。

## 陷阱

- **线性度全程 0.996–1.000**：若纵轴取 0.6–1.02，"显示线性度变化"就是一条贴顶直线，看不出任何信息。
  必须放大纵轴 `set_ylim(lmin − 0.003, 1.001)` 并把 `min = x.xxx` 标在轴上。
- **`/mnt/e` 上 PNG 被 Windows 图片查看器占用**时 `savefig` 报 `OSError Errno 22 Invalid argument`：
  `mv` 旧图到 `/tmp` 再重生成；批量脚本里给 savefig 套 `try/except → unlink → 重试`。
