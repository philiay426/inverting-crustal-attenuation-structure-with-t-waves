# pyGMT 图标注布局（文字/图例重叠陷阱 + 白色描边）

## 案例：top10_obs_vs_theory_conversion.png（Madagascar 2013-08-17，2026-08-24）

用户报告"地震信息和图例重叠了"。根因：

```python
# ❌ 重叠：两者都落左下角
fig.text(x=R[0]+0.5, y=R[2]+0.7, ...)      # 地图坐标左下角 (42.5, -35.3)
fig.legend(spec=..., position='jBL+o0.35c/0.55c')  # 图例也是左下角
```
→ "2013-08-17 Mw 6.2" 文字被塞进图例框内部，与图例项挤压。

## 修复方案

### 1. 文字移到图例上方空白海域
```python
fig.text(x=R[0]+0.5, y=R[2]+5.0, ...)   # 上移 5°，避开图例框（约 34-36°S）
```

### 2. 或放震源机制球旁边（用户最终选定）
```python
fig.text(x=EVLO, y=EVLA+0.9, text='2013-08-17 Mw 6.2',
         font='9p,Helvetica-Bold,black', justify='CB',
         pen='0.4p,white')   # pen = 文字白色描边；不设 fill = 无背景框
```
- `pen` 在 pstext 中是文字轮廓（outline），`pen='0.4p,white'` 实现白描边
- 不要 `fill='white@70'` 背景框（会遮挡数据）
- 黑字白描边在深蓝海域上清晰可读，透明背景不挡台站/射线/转换点

## 画图后必做自查（用户明确要求"以后这种东西你要自己检查一边"）

用 `vision_analyze` 检查输出图，确认：
- 标题/表头文字完整，没被截断或超出图边界
- 图例与任何文字/标注不重叠；文字不在图例框内部
- 文字落在空白区域，不遮挡数据主体（台站名/射线/转换点/震源球/色标）
- 图例位置符合用户要求（左下角/右上角等），背景浅白半透明

## 信息量原则（用户偏好，2026-08-23 定稿）

- 表头只标关键对比（如 `T-P th 964.4s → pick 956.7s`），不堆叠子窗/重叠率/算法名
- 图例只标拾取中心时间（`T-P pick 956.7s`），不标窗口范围（`[x, y]s`）
- 理论到时虚线也进图例（`T-P th ...`）
