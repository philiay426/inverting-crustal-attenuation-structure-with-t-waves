# 理论 T-P/T-S 窗口对比工作流

## 适用
当需要检验理论到时窗口、后移窗口及 T-P/T-S 极化分离时使用。先做少数高 SNR 台站的对比，不要把单一后移量直接批量套用。

## 只用最新布局脚本
比较图必须从当前已验证的 `pca_theory_polarization.py` 复制生成，不能复用旧台站副本。新版图必须具备：
- 标题仅含台站名、SNR、理论 T-P/T-S；参数写在代码注释；
- 左下角 Z/R/T，2–8 Hz，灰色波形；
- Z/R/T 共用展示时段的 global P98，保留相对振幅；
- 彩色 Hilbert 包络（单台短窗诊断使用 4 s 平滑）；
- 蓝/紫半透明时窗块，且把陆地走时窗口换算到相对发震时刻后再画；
- 每个变体独立命名，不能覆盖主图。

## 窗口
默认对比两张：
1. 严格理论：T-P ±3 s，T-S ±3 s；
2. 共同后移：T-P/T-S 均后移指定秒数，均 ±3 s。

T-S 若需要找横向波包，在理论 T-S 后逐步扫描中心（建议 0.25–1 s），每个候选固定 ±3 s；以所有子窗的玫瑰图和横向轴残差共同判断。不能只凭 R–T 中位角决定“纯横向”。

## 判读
- T-P：R–T 接近 0°/±180°且连续稳定，才支持径向 P/SV；
- T-S：R–T 接近 ±90°且玫瑰图集中，才支持横向 SH/Love；
- 高线性度不等于目标波型：方向随相邻窗大幅跳变时，不能把该窗作为可靠到时或反方位角证据；
- 不同台站的最佳后移量可以不同，先报告台站特异性，再讨论统一模型残差。
