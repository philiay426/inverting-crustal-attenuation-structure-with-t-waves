# 理论到时偏振窗口敏感性比较

## 适用情形
当严格理论 T-P/T-S 窗口的玫瑰图不集中，先做单台、单窗口敏感性比较；不要把任意后移量直接写成全事件通用校正。

## 目录与保留规则
- 比较图、源脚本、扫描 CSV 放在 `process_flow/2_single_station_analysis/theory_window_comparison/{STA}/`。
- 每次比较从**当前 `pca_theory_polarization.py` 新模板**生成，不能从旧台站副本复制；旧副本可能缺少统一归一化、正确绝对时间色块和当前玫瑰图格式。
- 最终只保留用户指定的严格理论图与一个选定的偏移图；扫描 CSV 可保留作为窗口选择依据。

## 固定图件样式
- 图总标题仅：`STA | SNR | T-P | T-S`。
- 左下：2–8 Hz Z/R/T；三分量共用展示时段 global P98；灰色波形；Z 黑、R 蓝、T 红的 4 s 平滑 Hilbert 包络和浅色填充。
- 窗口色块坐标必须从陆地走时转换到相对发震时间：`w_abs = w_land + TT_OCEAN`。
- R/T 玫瑰图保留径向计数刻度、绿色 R=0°与红色 T=90°参考虚线；R/T 字母加粗、放图内近外缘，避开方位刻度。

## 比较方法
- 标准理论图：T-P `±3 s`；T-S 作为严格理论对照 `±3 s`。
- 偏移试验：窗口中心后移量逐站测试，通常窗口 `±3 s`；窄窗（如 `±1 s`）仅用于局部诊断，必须报告 PCA 子窗数，不能作为稳健统计的默认结果。
- 用滑动窗口扫描辅助定位：中心覆盖理论到时附近，分别看 R–T 角、线性度和玫瑰图集中程度。
- 判定不能只看线性度：高线性度只说明单一方向运动；T-P 还需连续子窗接近径向，T-S 需连续子窗接近横向。

## 当前事件例子（仅示范，不外推）
2013-08-17 Mw6.2 马达加斯加的 AMPY/BKTA/CPSM 表明最佳偏移量可以随台站和波包不同，不能机械使用统一 `+12 s`。
