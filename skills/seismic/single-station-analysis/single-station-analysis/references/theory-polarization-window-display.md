# 理论偏振图：窗口与三分量展示

## 窗口定义与绘图坐标
理论窗口可在陆地走时坐标定义，但波形面板若以发震时刻为零，必须转换为绝对相对发震时间：

```python
w_tp_abs = (w_tp[0] + TT_OCEAN, w_tp[1] + TT_OCEAN)
w_ts_abs = (w_ts[0] + TT_OCEAN, w_ts[1] + TT_OCEAN)
```

否则理论窗口会错误画在陆地走时的几十秒位置，而非 T-P/T-S 实际位置。

## 图形要求
理论 PCA 图左下角必须：

- 显示 2–8 Hz Z/R/T 三分量；灰色细波形 + 分量着色包络；
- 显示 T-P 与 T-S 实际 PCA 窗口为半透明色块（T-P 蓝、T-S 紫），并保留理论中心虚线；
- 三分量共用同一展示时段的 global P98，保留相对振幅；
- 诊断短窗可用 2 s Hilbert 包络平滑；长时窗单台图仍用 8 s，步1剖面缓存用 6 s。

## 窗口敏感性
理论 T-S 默认采用后移 12 s、±3 s；单站试验时必须输出独立命名图，不能覆盖主结果。AMPY 测试中，T-P/T-S 同时后移 12 s ±3 s 得到 R-T 中位角约 −16.9° / 84.2°，显示 T-S 横向偏振稳定、T-P 对秒级窗口位置敏感。
