# 弱信号短时窗的偏振引导拾取

适用于 T 波单波包 SNR 不高、连续偏振簇过严会漏检的情形。

## 基本规则

- 理论 T-P / T-S 仅作先验；各自在理论中心 **±15 s** 内扫描；
- 2–8 Hz；候选 PCA 窗口默认 ±3 s，滑动中心步长 0.25 s；PCA 子窗 1 s、75% 重叠；
- 不强制连续多个候选窗：短时窗中可选择单个质量最优的径向/横向窗口；
- 但必须同时满足：单波包 SNR ≥10 dB、线性度 ≥0.8、T-P 径向残差或 T-S 横向残差 ≤20°；
- **物理顺序铁律**：T-S 拾取中心必须晚于 T-P 至少 3 s。对候选对联合筛选，不能各自独立最优化后得到反序结果。

## 输出应区分的量

不要将“偏振最优窗口”等同于严格初至。CSV 至少记录：

- `tp_pick_center`, `ts_pick_center`：短时窗偏振候选；
- `tp_theory`, `ts_theory`：模型先验；
- `tp/ts_rt_angle`, 残差、线性度、单波包 SNR；
- `accepted` 与 `reject_reason`。

如需严格初至，应在偏振候选附近再用噪声统计阈值/包络起跳复核；不要仅凭最纯偏振窗口声称初至。

## 展示规范

理论/偏振图左下角用 Z/R/T：共同 P98、淡灰波形、彩色 4 s 平滑包络；将实际分析时窗以蓝色（T-P）和紫色（T-S）半透明矩形显示。图表头仅显示台站、SNR、理论 T-P/T-S；窗口、子窗与平滑参数写入代码注释。
