# 偏振分析窗口宽度：判读与论文/汇报表述依据

日期：2026-09-02（AMPY ±1/2/3/4/5s 对比表 + 用户要求"根据经验一两句话解释"）

## 窗口对比表的正确判读
指标必须是"偏离径向/横向角度"（dev_tp/dev_ts，越小越接近理论偏振），
不是 R-T 角绝对值。AMPY 实测：

| 半宽 | dev_tp (偏径向) | dev_ts (偏横向) | 判读 |
|---|---|---|---|
| ±1s | 65.8° | 3.4° | 子窗点数太少 → 主轴抖动，T-P 完全不可用 |
| ±2s | 21.5° | 33.7° | **进入稳定平台的最短窗**（读表"±2s 最合适"的来源） |
| ±3s | 21.5° | 38.4° | 当前流水线定稿值（HALF_WIN=3） |
| ±4s | 21.5° | 45.5° | 无改善 |
| ±5s | 19.6° | 39.7° | 无改善 |

结论表述：**在保证 PCA 协方差主轴估计稳定的前提下取最短窗**。
±1s 点数不足 → 角估计抖动；≥±2s T-P 进入平台；T-S 偏横向反而随窗变长略劣化
（窗越长越可能混入相邻波包/散射尾波），故 ±2s 优于 ±3s 但差异小。
⚠️ 模板/流水线仍定稿 ±3s；若结论采纳 ±2s 需先经用户确认再统一改 HALF_WIN。

## 引用依据边界（防编造）
1. **Shearer (2019) Introduction to Seismology, 3rd ed., Ch. 13.5.1（协方差偏振法）**：
   只给了操作流程（去均值 → 开窗取目标信号 → 协方差 → 特征值/特征向量）和模型假设
   （窗内 = 单一方向信号 + 非相干噪声）。**书中没有给出具体窗长秒数**，
   引用时只能落在原理层面："窗须短到只含目标波列（保证协方差模型成立），
   长到样本足够（主轴估计稳定）"。不得声称书里推荐 ±2s/±3s。
   用户本地 PDF：`/mnt/e/sharedate/docx/Shearer - 2019 - Introduction to Seismology.pdf`
   （`pdftotext` 后可检索；2–8Hz 频段 ±2s 的 4s 窗 ≈ 含 8–32 个主周期、十数个 1s 子窗，
   这些数值是自己可算的补充论据，不是 Shearer 原话）。
2. **美东（PR2014，USArray TA）经验**：`seismic-twave-analysis/references/merged-polarization.md`
   记录 P 波偏振窗宽教训——窗口太窄 → 测量点数不足 → 方位角抖动：
   W57A：±2s（3s 滑窗）只 5–6 个测量点，方位偏 7°；加宽 ±5s 有 13–14 点，偏 1°。
   核心教训与 ±1s 不稳同源（点数/统计稳健性），可用于跨数据集佐证。

## 可用的示例表述（中文，约两句）
> 偏振分析窗的选择需在"协方差主轴估计稳定"与"窗内波型纯净"间取平衡：窗过短则
> 独立样本不足、主轴方向抖动（±1s 时 T-P 偏径角跳至 66°），而窗内只需包含目标
> 波列数个主周期即可稳定估计——2–8 Hz 频段 ±2s（4s 窗约含 8–32 个周期、十数个
> 1s 子窗）已充分满足 Shearer (2019, Ch. 13.5) 协方差偏振法中"窗内近似单一方向
> 信号叠加非相干噪声"的前提，再拉长则混入相邻波包、偏振被平均成中间方向；这一
> 口径也与此前美国东海岸台网（PR2014，USArray）偏振测向中"点数不足导致方位角
> 抖动、需取最短稳定窗"的经验一致。

## 相关参数速查
- 1s 子窗 + 75% 重叠（步长 0.25s）：Flinn (1965) 滑动协方差惯例；
  ±2s 分析窗内 ~13 个 1s 子窗中心（比 ±1s 的 ~7 个稳健得多）。
- 分析窗与搜索半宽是两回事：搜索半宽 ±15s（覆盖理论到时误差），最终窗 ±2/±3s。
