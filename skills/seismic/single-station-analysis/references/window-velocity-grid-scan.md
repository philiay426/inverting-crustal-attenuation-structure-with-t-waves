# 窗口宽度 x 海洋声速二维网格敏感性扫描（loss-landscape 热力图）

## 适用情形
用户要求"做不同尺度的对比来验证可靠性"，且涉及两个及以上参数（如分析窗口半宽 HALF、
搜索半宽 SEARCH_HALF_S、海洋声速 v_ocean）时，不要只做一维表格逐个扫描，改用二维网格
扫描 + 热力图，类似超参数网格搜索的 loss landscape：x/y 轴为两个参数，颜色=残差/得分，
一眼看出当前方案是否落在"谷底"（稳健）还是边缘/局部尖峰（脆弱）。

## 方法

1. **先做一维扫描定性**（每次只改一个参数，其余固定），确认单参数的稳定区间和明显失效点
   （例：VOI 窗口半宽 1s 太窄跳变、5s 太宽跨界；搜索半宽 15s 是拾取贴边情形）。
2. **再做二维网格锁定交互效应**：例如"窗口半宽 x 海洋声速"或"窗口半宽 x 搜索半宽"，
   网格里每个格点独立跑一次单窗 PCA（不做候选搜索，隔离两个维度的独立影响），记录
   T-P 径向残差、T-S 横向残差、联合得分 `score = res_tp + res_ts`。
3. **画三联热力图**：T-P 残差 / T-S 残差 / 联合得分，各自 `pcolormesh`，颜色越深=残差越小
   （越"谷底"）；当前方案参数点用红星 + 白色虚线十字标出，一眼判断是否落在深色区域。
4. **报告两个数字**：当前方案在网格中的得分，和全网格最优点位置+得分。如果最优点与当前
   方案的某个维度重合（如声速仍是 1.48），说明该参数本身合理，不需要调整；如果最优点明显
   偏离，需要进一步讨论是否改用最优值。

## 注意

- 网格扫描（单窗直接开窗）算出的残差数值会比实际搜索方案（±15s 内找最优中心）大得多
  （VOI 实测：网格单窗 42.9°，搜索方案 0.9-1.0°）——这是正常的，网格扫描回答的是"给定
  参数直接开窗能有多好"，不是"搜索方案最终能拾到多准"；汇报时必须说明这个区别，不能
  让用户误以为搜索方案效果变差了。
- 海洋声速 v_ocean 默认 1.48 km/s（SOFAR 声道），做声速敏感性网格时要覆盖两个方向
  （如 1.40~1.56），不要只往一侧（比如只测 ≤1.48）扫描——单侧扫描无法判断当前值是否
  已经是双向最优。
- 用 `pcolormesh(x, y, mat, shading='nearest')` + `vmin=0, vmax=np.nanpercentile(mat,95)`
  避免个别离群格点把色标拉爆导致大部分区域看不出层次。
- 配色遵循 plotting-standards（viridis，不用 jet/rainbow）。
