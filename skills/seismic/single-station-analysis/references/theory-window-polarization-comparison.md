# 理论窗偏振对比：可复现与图件规范

## 适用
当用户要求比较严格理论到时窗与后移窗、或逐秒扫描 T-P/T-S 偏振时使用。比较图必须由当前新模板生成；不要拷贝旧台站脚本，因为旧版可能缺正确的时轴转换、统一归一化或时窗色块。

## 时间坐标
- 理论窗通常在陆地走时定义：`w_land`。
- 波形图横轴通常是相对发震时间；画色块前必须转换：`w_abs = w_land + tt_ocean`。
- SAC 有效 `o` 时：`t_off = b - o`。不得用 `starttime == origin` 推断记录从发震开始。

## 比较图固定布局
- 标题仅保留：`STA | SNR | T-P | T-S`；子窗、平滑、窗口策略写代码注释，不堆进图头。
- 左下角：Z/R/T 三分量 2–8 Hz，**共用 global P98**；灰色波形（薄线）+ 分量着色的 Hilbert 包络及淡色填充。
- 偏振诊断图包络使用 **4 s 平滑**；步1剖面图的 6 s 与单台长时窗图的 8 s 不要混用。
- 用蓝色/紫色半透明方框准确标注实际 PCA 分析窗；虚线表示原理论中心。
- 玫瑰图：两个面板必须共享径向最大值和刻度；显示径向计数刻度。R/T 标签放图内、加粗、避开角度刻度。

## 窗口与判读
- PCA 基本子窗：1 s，步长 0.25 s；理论比较的总窗默认 ±3 s。
- 后移窗口只能作为台站级敏感性测试，输出独立文件，不能覆盖严格理论版本。
- 线性度高不等于目标波型正确；同时要求 R–T 角在相邻窗口稳定。
- 滑动扫描时，应输出每一中心位置的 R–T 中位角和线性度；选择窗口需报告扫描依据，不能仅挑一个最好看的窗口。
- R–T 轴向判据：约 0°/±180° 为径向（T-P/P-SV），约 ±90° 为横向（T-S/SH/Love）。
