# 从三分量偏振反推入射角（i）：公式链、读式陷阱、复算配方

适用：用户问"某台的入射角怎么算的 / 这个公式对吗 / 这个是 arctan 吗"，或要把入射角写进论文/汇报。
存档约定见本 skill 的"入射角（要 Z 分量参与）"节（`process_flow/2_single_station_analysis/{STA}/incidence_angle/`：
README + 可重跑脚本 + 逐窗/分频带/SNR/闭环 CSV + `i(t)` 与直线度双面板图，**图内文字英文、中文只进 README/日志**）。

## 1. 公式链（按顺序给，别只给一个式子）

```
① 水平分量旋转（R 指向震源的大圆方向）
     R, T = rotate_ne_rt(N, E, baz)      baz = gps2dist_azimuth(台站, 震中)[1]   ← 台站端真实大圆 BAZ
     ❌ 不用 stations.csv 的 baz 列（震源端口径/平底公式，偏西约 11°）

② 入射角 = 窗内 (Z, R, T) 三分量的 3D PCA 主轴与垂直轴的夹角
     C = cov([Z, R, T])  →  特征分解  →  最大特征值对应主轴 p = (p_Z, p_R, p_T)
     i = arccos( |p_Z| / |p| )                    单位：度，自垂直方向量

③ 独立对照估计器（不做特征分解，只比"水平/垂直"的能量分配）
     i_amp = tan⁻¹( √(RMS_R² + RMS_T²) / RMS_Z )   = atan(v_H / v_Z)

④ 与慢度/视速度换算（和 F-K 闭环对照用）—— 慢度**统一记 u**，只换单位
     u = sin i / v                 [s/km]     水平慢度（= 1/v_app；矢量 u 指向传播方向，标量取其模）
     u = 111.195 · sin i / v       [s/°]      同一量换成"每度多少秒"（1° 大圆 = 111.195 km）
     v_app = v / sin i
     ⇒ 反推介质速度  v = sin i / u            （u 取 s/km；u 取 s/° 时先除 111.195）
```

**符号约定（2026-09-17 用户定）**：慢度一律写 **u**；`s/°` 里的 s 是"秒"这个**单位**，不是符号，小写 s
不再当慢度用。Seizmo 代码的 `smax` / `svol` / beam 列名 `x(s/deg)` 是它的参数命名（= 这里的 u），
**代码符号不要搬进公式**；本文件里的小写 `p` 专指 3D PCA 的主轴向量（偏振方向 `p_Z, p_R, p_T`），两者别混。

**为什么 i 与 baz 无关（用户必问"这不循环吗"）**：i 只取决于垂直/水平的能量分配；水平面内怎么转
（换任何 baz）主轴的水平模长 `√(p_R²+p_T²)` 都不变 ⇒ **i 是水平旋转的不变量**。数值自证：用真实 BAZ 与
旧 bug 值（SA18：137.63° vs 126.8°）各算一遍，i 逐位相同（差 0.00°）。真正要交代的两处见 §5。

## 2. 三角函数与读式陷阱（用户逐个追问过的点）

- `tan⁻¹` = `atan`，同一件事；`atan2(H, Z)` 与 `atan(H/Z)` 在 H,Z ≥ 0 时等价，区别只是不除零。
- **恒等式**：`atan(h/z) ≡ acos(z/√(z²+h²))`。所以 PCA 的 `arccos` 与振幅比的 `atan` **不是两种方法在打架**，
  差别只来自"喂进去的是什么常数"：PCA 喂单位特征向量 p，振幅比喂窗内三分量 RMS。直线偏振时两者同向 ⇒ 结果一致。
- 🔴 **根号位置**：正确 = `√(RMS_R² + RMS_T²) / RMS_Z`（逐分量平方 → 相加 → 开根）。
  错读成 `RMS(√(R²+T²)) / RMS_Z`（先开根再取标准差）会偏小：SA18 ±5 s 窗 **38.24° vs 57.46°**。
  机制：`√(RMS_R²+RMS_T²)`² = `mean(R²)+mean(T²)` = `mean(R²+T²)` 是水平矢量模的均方根；
  `std(√(R²+T²))` 是"模自身的起伏"，把水平方向的直流分量扣掉了，恒 ≤ 前者。
- `RMS`（不去均值）vs `np.std`（去均值）：窗内均值为 0 时逐位相同（SA18 带通窗实测 57.459° 两者一致，
  分量均值打印 −0.）；未去趋势/有偏置的窗不等价。代码用 `np.std` 没问题，但论文里只写一个口径。
- `|p_Z|` 的绝对值 ⇒ 丢掉 Z 的正负号，只答"离垂直多远"，**不能用来判初动/上行下行**。
- 排版级错误也要点出来：多余的未配对括号、没闭合的绝对值竖线、把分数整条塞进根号（视觉上被拉长而误读）。

## 3. 两个估计器的适用边界（合成实测）

| 粒子运动 | i_amp（RMS 比 / atan） | i_PCA（arccos 主轴） | 直线度 |
|---|---|---|---|
| 直线偏振 i_true = 30/55.4/75° | 30.03 / 55.40 / 74.98° | 30.01 / 55.40 / 75.01° | 1.000 |
| 直线偏振 i_true = 5° | 5.12° | 4.99° | 1.000 |
| 椭圆偏振 i = 55.4°（Z–R 相差 90°） | **55.40°** | **90.00°** ❌ | 0.524 |

⇒ 椭圆（相位差 90°）时协方差非对角项被抹掉，特征向量退化成 Z 轴/R 轴本身，主轴取方差大的那个。
**直线度低（<0.7）时只信 `i_amp`**；两个估计器差 ≤3° 才把结果当稳。

## 4. 复算配方（回答"这个对吗"时现跑一遍，别只讲道理）

① **合成真值注入**：造已知 i、已知方位 az 的直线偏振波包（窄高斯包络 × 正弦），
`X = outer(包络, [cos i, sin i·cos az, sin i·sin az])` + 1e-9 量级噪声；
对 X3 列做 `eigh(cov)` 与两个估计器，真值应原样复原（±0.05°）。
⚠️ 必须**先标定再引用**：把诊断脚本的数字写进笔记前，用这组已知真值跑通。
② **真实数据核对**：对目标窗跑同样代码，数字必须能对上已存档的结果表
（SA18 2–8 Hz、±5 s、baz 137.63°：`i_PCA = i_amp = 57.459°` ↔ README 表里的 57.5°）。
对不上就是读式/代码口径出了问题，不要改 README。

▶ **现成脚本**：`scripts/check_incidence_formula.py` = 上面 A/B/C 三项一次跑完
（`--base <事件目录> --sta SA18 --pick 1195.15` 才跑真实窗核对，默认 `--expect 57.459`）——别每次手抄这段代码。

## 5. 报告时必须一起交代的三件事

1. **窗、频带、直线度**：i 随窗长/频带变（SA18 ±2…±25 s 稳定在 51–57°、±40 s 直线度塌到 0.39 已混相；
   ≥5 Hz 直线度 <0.5、能量只剩 1/10 ⇒ 噪声主导，不参与判读；2–5 Hz 内部还有 ±7° 频散）。
2. **自由表面效应**：地表质点运动的视入射角 > 真实射线入射角（偏陡）⇒ 由 i 反推的 v 偏小，
   报 v 要说明它是下界/量级。
3. **单台 ≠ 整阵**：i 只说明该台窗内的质点运动方向；阵列慢度是整阵量，两者靠 `v = sin i / u` 闭环对照，
   闭环里的 `u` 来自 R/T 分量包络 ⇒ 依赖 baz（要彻底避开就做原始 N/E 矢量波束形成、或只用 Z 做 F-K）；
   闭环**只作筛伪峰**用（排掉慢度≈0 的极点伪峰与"对应速度远小于地壳速度"的格点），不当通过/失败判据。
4. **论文的"预测慢度"是主量，括号里的 km/s 是它的换算（方向别搞反）**：论文原文
   `predicted value of 13.7 s/° (8.1 km/s)` —— 13.7 s/° 是**预测慢度**，8.1 km/s = `111.195/13.7` 是它的
   **等效视速度**（式(1) 预设的只有 1.48 / 6.0 / 3.6 km/s）。⇒ ❌ 写成 `u_pred = 111.195/v, v 取 8.1` 是把论文的
   输出当输入（循环，不算复现）；❌ 给 13.7 乘 sin i 同样是造一个它没有的因子。
   由偏振 i 算的 `u = 111.195·sin i/v` 与论文的 13.7 是**同一类量**（都是慢度），可直接比，但要说清等效视速度
   （G1 七站 15.3 s/° ↔ v_app ≈ 7.3 km/s vs 论文 8.1 km/s）；报数时写明用的哪一套。
5. **慢度符号一律写 u**（`s/°` 里的 s 是单位秒；代码 `smax`/`svol` 是参数命名，不进公式）——改口径时
   案例 README / 脚本打印 / 本 skill / F-K 推导文档一次改全，并重跑脚本核对数值逐位不变。

## 6. 全子阵扩展：一次算 N 个台的 i 与"计入 sin i"的预测慢度

用户说"按单台的做法把某子阵所有台都算一遍、给平均值"时的配方（案例存档：
`process_flow/2_single_station_analysis/G1_incidence_angle/` = `step1_*.py` + 逐站 CSV + 敏感性 CSV + log + README）：

1. **窗要逐站取，不能统一**：用偏振引导拾取的 T-P 中心
   （`polarization_guided_picks/polarization_guided_tp_ts_picks.csv` 的 `tp_pick_center`）±5 s、2–8 Hz；
   各站实际偏移差 −31…+45 s，用理论到时统一开窗会罩不住真波包。
2. **逐站算两个估计器**（`i_PCA` + `i_amp`）+ 直线度 + R-T 角，再 `u = 111.195·sin i / v`（v = 6.0 km/s ↔ T-P）。
3. **点名"真实大圆路径 vs 理论 AZ−180"时，两种 BAZ 基准各算一遍**：真实大圆 =
   `gps2dist_azimuth(台站, 震中)[1]`；理论 AZ−180 = `stations.csv` 的 `az` 列 − 180（旧口径，偏西 10.2–12.2°）。
   **结果必然逐位相同**（i 是旋转不变量）——G1 七台 `i_PCA`/`i_amp` 的 max|Δ| = 0.000°，唯一变化是 R-T 平面角
   整体平移 −10.2…−12.2°。表里就并列两套值 + 一行"逐站 Δ"当数值证明，并明说 u 与平均值也随之相同
   （用户问这个就是在验证不循环，不是真想要两套数）。
4. **平均用振幅比估计器，并附直线度门控子集**：PCA 的大标准差常由**个别低直线度台**贡献
   （G1：SA29 i_PCA = 87.8° / 直线度 0.633 是椭圆偏振下主轴退化的真实实例；SA17 直线度仅 0.254）。
   三档一起报：全站 `u_amp`、门控（≥0.7）`u_amp`/`u_PCA` 均值与中位数。
5. **必带窗长敏感性**：±2/±5/±10/±15/±25 s 的 N 站均值应稳定（G1：`u_amp` 15.19–15.32、`u_PCA` 15.27–15.45 s/°）。
6. **与论文对照列成表、逐行写口径**（用户会逐行追问）：G1 实测 —— 偏振链 **15.3 s/°**（v_app ≈ 7.3 km/s）、
   我们自己 F-K R 窗峰 16.41（−7%，偏振链与阵列链自洽）、论文预测 13.7、论文 southern 实测 10.0。
   ❌ 不给论文的 13.7 乘 sin i；❌ 不用 `111.195/8.1` 去"复现"它（见 §5.4）；⚠️ 重申自由表面效应 ⇒ 偏振链的 u 偏大，
   读作量级/上界。

15.76 / 15.84 / 15.62 / 13.77 / 14.76 / 15.02 / 16.46（SA16/17/18/22/23/25/29）⇒ 均值 **15.32 ± 0.88 s/°**；
