# 独立偏振玫瑰图：振幅法 / 地理方位 / 论文 ±25s 口径（SA18 2026-09-08 验证）

用户要求"画两个玫瑰图 / 单独玫瑰 / ±25s / 用振幅法 / 原始采样点计数 / 恢复旋转前方向"时，
指的是**独立玫瑰图**（论文 Fig2e/f 风格），不是 pca 2×2 诊断布局里的玫瑰格。按本节做。

## 1. 窗中心必须用论文口径走时，不要用 stations.csv 的 TauP 到时

Zhou 类事件复现：`tt_tp = ocean/1.48 + land/6.0`、`tt_ts = ocean/1.48 + land/3.6`（Equation 1），
**不是** stations.csv 的 TauP `tt_tp/tt_ts`（偏早 ~20-25s：SA18 TauP T-S=1248s vs 论文 1273s，
实际 T-S 能量峰 ~1280s）。窗中心用错 → ±25s 窗罩不住真波包 → 玫瑰/PCA 方向全乱
（曾出现 T-S 主轴 1.3°"近径向"假象，根因就是窗没框住横向 T-S 能量）。

## 2. 宽窗（±25s）协方差 PCA 主轴不可靠 → 用扇区占比判别

±25s 窗内混多个波包（T-P 尾/T-S/窗内其它能量），PCA 整窗协方差主轴/中值角被混合能量拉偏。
判别改用**方向扇区能量（或计数）占比**：径向 = 与 BAZ(或 R 轴) 差 ≤22.5°，
横向 = 与 BAZ±90 差 ≤22.5°。读占比不读 PCA 中值。
SA18 实测：T-P 径向 38%/横向 14%（径向主导）、T-S 横向 43%/径向 8%（横向主导）→ 干净判别。

## 3. 振幅法算法与"原始计数"

- 2-8Hz 滤波后逐样本角 `a = atan2(T, R)`（ZRT 已旋转）或 `atan2(E, N)`（地理，见下节）；
  直方 10° bin。
- 权重默认 `R²+T²`（或 N²+E²）；用户说"原始采样点计数"时去掉权重、每样本等权 1 票。
- ⚠️ 扇区占比必须除以总权重/总数；曾把加权和当百分比打印 → 全部 0.0% 的假 bug。

## 4. "恢复到旋转前的方向" = 不旋转，画 N/E 地理玫瑰

- 直接读去响应 BHN/BHE → 2-8Hz bandpass → `a = atan2(E, N)`（0°=北、90°=东）；
  不用 npz 的 waveform_r/t（那是 ZRT 旋转后的）。
- 理论线按地理角：径向 = BAZ（台站→震中），横向 = BAZ+90。
- 判读注意：N/E 版 T-P 径向占比会低于 R/T 版（SA18: 38%→18.5%）——波若来自转换区而非
  正对震中，偏振会偏离理论 BAZ，这是物理信息不是 bug，不要"修"。

## 5. 版式偏好（用户多轮定稿，务必一次到位）

- 每面板**只画与本相位相关的理论线**：T-P 面板只画径向（BAZ 方向）、T-S 面板只画横向
  （BAZ+90）；不把径向+横向都画上。
- 理论线**黑色实线、过圆心的完整直径**：极坐标里连接 (θ, mx) 与 (θ+180, mx) 两端点；
  ❌ 勿画从圆心出发的 [0, mx] 半轴（用户两次纠正"不要只画一半"）。
- 刻度极简：只标 N/E/S/W（或 0/90/180/270），不标 45/135…
- 标题极简：如 `T-P radial 19%`（只报该相位相关量），suptitle 一行短句。
- 两张玫瑰并排一张图（1×2 polar），不要拆两个文件（除非用户要）。
