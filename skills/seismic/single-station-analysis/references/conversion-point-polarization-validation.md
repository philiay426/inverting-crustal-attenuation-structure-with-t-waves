# 接收端转换点与单台偏振验证：2013-08-17 Mw6.2 诊断

## 已验证事实

### AMPY 数据基础
- SAC 正确时间轴必须用 `t_off = b - o`：AMPY `b≈0`、`o=600 s`，记录相对发震时间为 `-600 ~ 3600 s`。
- 分量方向正确：BHZ `cmpaz=0/cmpinc=0`，BHN `0/90`，BHE `90/90`。
- −1000 m 等深线转换点：26.0889°S, 45.8842°E；海洋段 1255.0 km，陆地段 191.7 km。
- 转换点→AMPY 方位为 323.0°；震源→AMPY 大圆方位 318.8°，相差约 4.2°，几何上自洽。

## 重要结论

自动包络峰并不能直接验证转换点：AMPY 理论 T-P=879.0 s，但最大局部包络峰在 925.55 s（+46.55 s），另有约 908.33 s 的明显前导能量。最大峰可能是 T-P 后续能量或与 T-S 混合，不能直接以其水平主轴否定转换点。

## 正确验证顺序

1. 先检查 SAC `o`、`b` 以及 Z/N/E `cmpaz/cmpinc`。
2. 算 −1000 m 转换点及转换点→台站理论方位。
3. 在理论 T-P 邻域用**噪声统计初至阈值**选首次持续起跳；不要用最大包络峰代表 T-P 初动。
4. 在起跳后的短窗口做 ZNE 水平偏振；处理 180° 轴向歧义后与理论方位比较。
5. 只有波包独立 SNR、线性度和方向稳定性均合格时才作结论。

## 禁止的推论

- 现有 ZRT 单台图把理论 `baz` 用于旋转，仅能检验该既定坐标下 R/T 偏振，不能独立反演反方位角。
- 自动 N-E 主轴与转换点方位残差大，不能在未确认 T-P 初动的前提下直接判定“转换点错误”。
