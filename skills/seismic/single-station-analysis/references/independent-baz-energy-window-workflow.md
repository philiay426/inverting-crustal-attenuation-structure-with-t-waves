# 独立 BAZ 轴与转换点联合约束：能量挑窗流程

适用于需要避免用理论 BAZ 参与 T-P 窗口选择、并将观测偏振方向延伸至海陆转换边界的 T 波分析。

## 不依赖理论 BAZ 的主流程

1. **挑窗**：在理论 T-P 到时附近限定搜索范围（例如 ±15 s），使用未旋转的 `N/E`，或 `Z/N/E` 矢量解析包络；以发震前噪声的稳健统计阈值（如 median + `k × 1.4826 MAD`）找到最早持续显著突增。理论到时只限定时间搜索域，不能用于 R/T 径向性筛选。
2. **独立偏振轴**：在初动后的短窗（建议测试 1–3 s 敏感性）对原始 `N/E` 协方差矩阵做 PCA。最大特征向量的 N/E 方位给出无向水平偏振轴。三分量 PCA 可用于线性度、倾角和 P/SV 诊断；BAZ 取三维主轴的 N/E 投影。
3. **180° 简并**：必须保存 `axis` 与 `axis+180°` 两条射线；PCA 特征向量符号不能独立决定传播方向。
4. **双分支转换点与走时**：每个分支分别与海岸线或指定等深线求交，分别计算海洋段和陆地段，使用 `t_pred=ocean_km/v_ocean + land_km/v_land` 对照观测 T-P 初动。仅当一个分支的绝对残差有明确优势时才能选为 `selected_ray`；差异很小时保留双解（`selected_ray=0`），不得用数值微小差异强行定向。
5. **事后一致性检查**：把已经选定的窗口旋转到理论 BAZ 对应 R/T，检查 R/T 能量比、T-P 径向性或 T-S 横向性。该结果只作讨论中的佐证，绝不可反过来用于新流程的挑窗、偏振轴或分支判定。
6. **稳健性对比**：并行保留旧 R/T 径向性挑窗结果与新能量挑窗结果，按轴向角差（模 180°）比较 BAZ 和转换点。若差异显著，报告旧流程可能受理论 BAZ 引导的影响，优先新流程。

## 输出最低字段

- `tp_onset_s`, `onset_threshold`, 噪声统计量与初动窗长度；
- `pol_axis_deg`, `ne_linearity`（及可选 3D 倾角/线性度）；
- 两支的方位、交点、海洋/陆地距离、预测到时和残差；
- `selected_ray`、最终坐标（仅唯一受约束时填入）；
- `theory_baz_deg`、R/T 能量比（明确标为 diagnostic）；
- 旧/新轴向差以及旧/新转换点距离。

## 解释与措辞

- N 是未旋转的地理北向分量（BHN/HHN），不是 R/T 旋转后的量。
- 偏振 PCA 独立得到的是**轴**，不是天然有向 BAZ。
- 走时模型残差较大时，产物应称为“走时约束优选的候选转换点”，不能称为最终转换点。
- 向用户说明原理时使用连贯、简短叙述，不贴代码、不过度切分段落，除非用户明确要求实现细节。
