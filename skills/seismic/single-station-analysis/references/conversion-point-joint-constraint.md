# 转换点：BAZ、初动与到时联合约束

## 核心原则

BAZ 与海岸线/海陆边界的几何交点只是候选点，不能直接称为转换点。最终转换点必须同时满足：

- T-P 初动时间约束；
- 观测水平偏振/径向方向约束；
- 海洋段与陆地段速度模型的联合走时约束。

## 推荐流程

1. 在理论 T-P 邻域用噪声统计阈值寻找最早持续初动，不用最大包络峰代替初动。
2. 在初动窗口对 N/E 分量扫描 BAZ 轴。理论 BAZ 只能用于结果对比，不能作为观测反演输入。
3. 由于水平偏振轴有 180° 歧义，保留 `BAZ` 与 `BAZ+180°` 两条射线。
4. 将每条射线与海岸线或指定海陆转换边界求交。
5. 对每个交点计算：

   `t_pred = ocean_km / v_ocean + land_km / v_land`

   并计算 `residual = t_pred - tp_onset_c`。
6. 只有方向、初动极性和 `abs(residual) <= tolerance` 均满足时，才写入最终坐标。没有唯一通过项时保持 `selected_ray=0`，最终坐标为 NaN。

## CSV 最低字段

每条候选射线至少保存：

- 方向角、交点经纬度；
- `ocean_km`、`land_km`；
- `tp_obs_s`、`tp_pred_s`、`residual_s`；
- `pass_time`；
- `selected_ray`；
- `final_conv_lon`、`final_conv_lat`。

## 角度约定

必须在表头或脚本注释中明确角度是：

- 北起顺时针传播方位角；还是
- 台站指向震源/转换点的反方位角；还是
- 仅表示无向偏振轴。

传播方向与偏振轴不能混用。若没有极性或其他物理先验，两个 180° 候选都应保留，不能用 `h1 or h2` 自动选择第一项。
