# 理论到时偏振窗敏感性与展示标准

## 适用情形
当固定理论 T-P/T-S 到时窗无法给出清晰的“径向 T-P + 横向 T-S”组合时，理论到时只能作为先验，不可逐站机械套用固定后移量。

## 工作顺序
1. 先保留一张**严格理论窗**对照图：T-P ±3 s，T-S ±3 s。
2. 对 T-P、T-S 分别在合理物理搜索范围内做滑动敏感性扫描；扫描结果只用于选择候选窗，不应以“最优角度”替代走时物理约束。
3. 候选 T-P 要同时满足：接近径向（R-T 轴向残差小）、连续多个子窗稳定、高线性度、且位于 T-S 前；候选 T-S 要接近横向并在 T-P 后。
4. 对比图保留严格理论窗与经解释的候选窗；图注/代码注释必须说明窗口来源与后移量。

## 防止过拟合的约束
- 不因单个窗口玫瑰图“好看”而接受任意大的走时残差。
- 若候选 T-P 已跨越理论 T-S 或明显进入其后续波包，则不得认作 T-P。
- 窄窗（如 ±1 s 或 2 s 总窗）PCA 子窗数量少，只能作为局部候选，不单独用于最终结论。
- 线性度接近 1 不等于 P 波：仍必须检验 R-T 方向集中度与 R/T 相对能量。

## 诊断图展示
理论偏振图左下角统一展示：
- 2–8 Hz Z/R/T；共用 global P98，保留真实分量相对振幅；
- 灰色波形（lw≈0.35）+ Z黑/R蓝/T红的 4 s Hilbert 包络及轻填充；
- 真实参与 PCA 的 T-P/T-S 窗口用蓝/紫半透明矩形，且窗口从陆地走时转换到相对发震时间后再绘制；
- 标题只保留台站、SNR、理论 T-P、理论 T-S；参数写代码注释。

玫瑰图：保留原生径向计数刻度，R/T 参考虚线完整显示；R/T 标签在图内近外缘、加粗，避免压住方位角刻度。若径向刻度过密，刻度步长不小于 0.5。
