# 非洲南部 T 波分析约束（2026-08）

## 台网限制

- 现有台站 ~30-100 站，间距 54-100 km
- 4 个台网混杂（ZT/BX/AF/GT），仪器增益不一致
- XA 台阵（82 站，Zhou 2021 用）已撤，之后再无密集台阵

## F-K 分析

尝试方法：
1. 传统 PMCC (2-8 Hz 原始波形) → **全失败**，0 有效窗口
2. 包络法 (Zhou 2021 方法: 包络 <0.25 Hz) → **全失败**
3. 三站延迟拟合 → **全失败**（包络跨相关 CC>0.96 但 dt=0）
4. 波束扫描 → 组间不一致，相干面平坦

**结论：非洲南部任何现有台网密度都无法做 F-K。54 km 间距对 2-8 Hz T 波信号空间混叠不可逆。Zhou 2021 成功靠 82 站统计堆叠 + 400 km 孔径。**

唯一可靠方向验证：**偏振分析（R-T 玫瑰图）**。

## 衰减分析 (Q 反演)

尝试方法：
1. 尾波归一化 (Zhou 2021) → R²≈0，振幅比不衰减
2. 直接振幅 vs land_km → slope 不稳定，单事件无信号
3. 多事件堆叠 (65 对) → R²=0

**结论：混合台网仪器不一致，振幅离散覆盖衰减信号。单事件不可行，需统一仪器的密集台阵。**

## 数据质量

- XK 台网（2013 事件）存在规律脉冲毛刺，已在 step1 默认排除
- FOMA 等极近台（<100 km）SNR 计算噪声窗口不足，降级为 0
- `sac.o` 未设置导致时间轴偏移。正确修复：`t_off = sac.b - o_val`（有 o 时）；缺 o 时 `t_off = starttime - EV_ORIGIN`。⚠️ 勿用 `getattr(sac,'o',0)`——返回 0 会让时间轴从记录开始起算，整体偏移（南非2019偏移1903s）
