# 尾波归一化 Q 反演的公式链与每一项的出处

> 出处标注四级：**文献**（作者年 + 式号/页）| **源码**（文件 + 行号）| **推导** | **本项目自创**
> 源码行号指导师 2021 年 T 波衰减论文的 MATLAB 链（`simulated_T_waves/*.m`，工作盘 `/mnt/e/sharedate/T_waves`），
> 逐条查证的记录在 `case/zhou_2021_test/5_attenuation_merged/Zhou2021-Q反演-导师口径分析.md`。

## 1. 公式链（待求量放左边）

```
Q(f) = - pi * f / (V * k(f))                                          ... (1)

k(f) = d/dr [ ln( A_dir(f, r) * sqrt(r * h_m) / A_c(f, t_c) ) ]       ... (2)
       （同一事件、同一频带、逐台站对 r 做最小二乘的斜率）

A_dir = 信号窗 [T_ref, T_ref + 20 s] 内的 rms 振幅
        T_ref = 该台理论 T-P（Qp, 垂向 Z）或 T-S（Qs, 切向 T）
A_c   = 尾波窗 [t_c, t_c + 20 s] 内的 rms 振幅
        t_c = 2 * (该台 S 波走时)，lapse time **从发震算起**
V     = 6.0 km/s（P, Qp）或 3.6 km/s（S, Qs）
h_m   = 2 x 35 km = 70 km（几何扩散 1/sqrt(r*h_m)）
r     = 台站-事件**陆段**距离（不是震中距）

ln Q(f) = alpha * ln f + ln Q0        ->  Q0, alpha                     ... (3)
```

## 2. 每一项由什么决定（逐条查证表）

| 项 | 取值 | 出处 | 影响 Q 吗 |
|---|---|---|---|
| 式 (1)(2) | `Q = -pi*f/(c*k)`、`k = regress(ln(A*sqrt(r*hm)), dist)` | 源码 `amp2Q_ecnm.m` L28-29、`k2Q.m`（一行） | 定义式 |
| 式 (3) 不加权 log-log | 对 9 个频点的 Q 做一次回归 | 源码 `plot_alpha.m`；文献 SI Text S2 | 定义式 |
| 振幅量 | **rms**（`sqrt(sum(sdt.^2))/sqrt(sum(sdc.^2))`） | 源码 `measure_amplitude_ecnm.m` L111-113（调用传 `'rms'`） | 影响小：单因子对换（峰值↔rms）实测 alpha 只动 0.01-0.08 |
| 窄带 | 中心频率 2.00-4.00 Hz，步长 0.25，共 9 点，半带宽 ±0.1 Hz | 文献 SI Text S2；数据文件名 `.transed_<f>` | 决定频点 |
| 信号窗 | `[T_ref, T_ref+20]`，从理论到时**之后**起算（非对称） | 文献 SI "20 s waveforms after the theoretical arrival times"；源码调用传 `[0,20]` | 窗位偏一点改变振幅，进而改变 k |
| 尾波窗 | `[2*S走时, +20 s]`，lapse **从发震算** | 文献 SI Text S2 + Aki & Chouet 1975；源码 `case '2S': ts2 = O + 2*(T2-O)` | **强**：换口径 Q0 能差数倍 |

| 陆段速度 | V_P = 6.0、V_S = 3.6 km/s | 文献式 (1) 的恒速口径；源码调用参数 | **线性进入 Q**：V 改 x 倍，Q 就改 1/x 倍 |

| 误差 | 回归系数 95% 置信区间 / 1.96（= 1 sigma） | 源码 `plot_alpha.m`；本项目沿用 | 报数口径 |

## 3. 为什么是"斜率"而不是绝对振幅

式 (2) 只用斜率，所以任何与距离无关的常数（震源强度、台站响应标定、几何扩散里的 h_m、coda 选的绝对振幅水平）都被差分掉。这就是尾波归一化的全部意义：**用尾波当"共享的震源项"**，把逐台的震源-路径耦合消掉，剩下的斜率才是衰减。

代价是：① 必须有足够长的距离跨度（实测要求陆距至少跨 300-400 km，否则 σ_k 压不住）；
② 尾波振幅本身必须与震中距无关（Aki 1980 的 CNM 前提），所以尾波窗要选在"散射场已发育"的位置——2 倍 S 走时是文献里的经典判据。

## 4. ★ lapse time 的分叉点（最容易搞错的一处）

| 口径 | 尾波窗起点 | 结果 |
|---|---|---|
| `2S`（论文口径） | `2 x (S 走时)`，从**发震**算 | 复现论文用这条；窗会落在该台 T 波到达**之前**（因为 2 倍 S 走时通常小于海段 T 波传播时间），这是正常的 |
| `2TS`（陆地计时取 2 倍） | T 波到达后 2 个"陆段 S 走时" | 窗落在 T 波尾里，`A_dir/A_c < 1` → 台站全被筛掉，Q 全 nan；这条是反例 |
| `T-S+dt` | `T-S + dt`（dt = 300/400/600 s） | 替代口径，dt 要按 coda 发育情况逐个试，换了 dt 结论必须重跑敏感性检验 |

一句话：**论文的 lapse time 从发震算起，与 T 波转换点/上岸位置无关**。把"陆地计时"当尾波基准是错的。

## 5. 与频谱比法（t*）的关系

- 频谱比法：`ln(A1/A2) = -pi*f*t* + const`，`t* = ∫ dt / Q`（沿路径积分），逐台对成对事件。
- 本项目：多台站、单事件、振幅随**陆段距离**衰减 → 有效 Q(f)。
- 两者不可混：本项目测的是**陆段路径平均 Q**，掺了 T 波在陆壳内的转换与散射；不能直接与体波 t* 反演的 Q 比较，只能与同样用 T 波做的研究比（如 Zhou et al. 2021）。
