# 质控判据：什么时候可以说"这个 Q 值能用"

> 判据的边界在**台阵质量差、台间噪声差两个量级**的数据上压测过（这类台阵最能暴露阈值问题）。
> 具体事件的台站名单、剔除记录与结果数字写在事件自己的目录里，不进 skill。

三层判据，缺一层结论就站不住。所有阈值必须在跑拟合**之前**写定。

## 1. 台站层（能不能拿这台做样本）

| 判据 | 取值 | 说明 |
|---|---|---|
| 振幅比 | `A_dir / A_c >= 1` | 文献 SI Text S2 的 "SNR > 1"，比的是**信号窗振幅 / 尾波振幅**（比值，不是 dB）。阈值故意低：CNM 要的是"尾波可用、不被自身相位污染"，抬阈值会系统性踢掉远台 → 距离覆盖变窄 → 斜率塌 |
| 偏振 | 见下（**待定稿**） | 旧口径 `frac_T = Et/(Er+Et) > 0.5` 是早期自写脚本的判据，那个脚本已停用（它用步 0 包络 npz 的 R/T，与从 `remove_response` 三分量现算不一致）。现行做法：用 skill `single-station-analysis` 的 `run_single_station.py` 出全时段扫描，判读靠连续簇（>=1 s、residual<10°、lin>0.99）与径向/横向扇区占比对比；要不要再设一个台站级 gate、阈值多少，**等实测若干事件后再写死** |
| 波形目视 | 无毛刺、非空道 | 用户口径：**SNR 达标但波形异常仍要剔**（2026-09-28 定） |
| 剔除留痕 | 写进 `station_qc_notes.md` | 原因要能指到具体频点/具体毛刺，不能只写"质量差" |

## 2. 频点层（这个频点带不带衰减信息）

| 判据 | 取值 | 说明 |
|---|---|---|
| 斜率符号 | `k < 0`（`Q_SIGN=neg`）或取 `\|k\|`（`Q_SIGN=abs`，定案口径） | `abs` 是论文链 `Q = -pi*f/(c*k)` 在图上取绝对值的做法；严格口径要求振幅随距离真的变小。**两种口径出的 Q0/alpha 不同，必须写清用的哪种** |
| 可分辨性 | `\|k\| / sigma_k >= 1` | 本项目自创（2026-10-20 定案）。该频点的距离衰减率与 0 分不开 → 不携带衰减信息 → 不参与幂律拟合。**被剔频点照实报告**（列表 + sigma 比） |
| 样本数 | 该频点 `n >= 8` 台 | 少于 8 台时 σ_k 一般就 > 1e-3，等于自动出局 |

## 3. 整体层（这个 alpha 是不是真的频率依赖）

| 判据 | 取值 | 说明 |
|---|---|---|
| alpha 显著性 | `\|alpha\| / sigma_alpha >= 2` | 1-2σ 之间只叫"弱显著"，报告时必须写"频率依赖不到 2σ"，不能当结论 |
| 拟合点数 | `>= 6` 个频点 | 少于此 alpha 由两三个点撑着，换口径必翻号 |
| 收敛性 | 换 2-3 种尾波口径后 alpha 同号、Q(3 Hz) 在同一量级 | 见第 5 节 |

## 4. 台站剔除红线（用户 2026-10-19 明确）

- 只有**振幅异常**或**明显离散点**的台才有理由剔除。
- **禁止**按拟合指标（alpha、误差、r²）挑台。
- 判据：做"逐台剔除"的全枚举，看 alpha 与 `|k|/sigma_k` 怎么变。多数单台剔除会让 alpha 变差或翻号；
  个别台剔掉后拟合会"变好看"，但同时各频点 `|k|/sigma_k` 掉到 1 以下 —— 那是远端台的杠杆效应，不是质量提升。
  **"从一堆里挑出唯一变好的"本身就是按结果挑台**，不能用。
- 频点层面同理：剔某几个频点的依据只能是 `|k|/sigma_k < 1`（判据在拟合前写死），
  不是因为"剔了就好看"；r² 变好只是判据生效的副产物。

## 6. 禁止的三种"验证"

1. **拿论文值当靶子调参**：论文的 Q0/alpha 只作事后对照（"我们高 15%"），不参与选窗/选台/选频点。
2. **回头改判据**：拟合完发现 alpha 不好看再去剔台/剔频点，就是循环论证；判据要么跑前写定，要么明确标成"探索性试验"。
3. **只看 r²**：r² 只说明 log-log 直线的贴合度，不说明斜率可分辨（`|k|/sigma_k` 才是）。低 r² 时用不用一个频点，Q 能差几倍；r² 变好也可能只是剔掉一个不显著点 —— r² 和 Q 的可信度是两件事。
